第 八 课 : 08. 连读变调 Liándú biàndiào (연독·성조변화 심화)

## 本文 (본문)

普通话说快了，音和音会连在一起。  
Pǔtōnghuà shuō kuài le, yīn hé yīn huì lián zài yìqǐ.  
표준어를 빨리 말하면 소리와 소리가 서로 이어집니다.

两个三声连读，前一个变成二声。  
Liǎng ge sānshēng liándú, qián yí ge biàn chéng èrshēng.  
두 개의 3성이 연달아 오면 앞의 것은 2성으로 변합니다.

比如"你好"读成"ní hǎo"。  
Bǐrú "nǐ hǎo" dú chéng "ní hǎo".  
예를 들어 "你好"는 "ní hǎo"로 읽습니다.

"可以"读成"ké yǐ"。  
"Kěyǐ" dú chéng "ké yǐ".  
"可以"는 "ké yǐ"로 읽습니다.

"一"在四声前读二声。  
"Yī" zài sìshēng qián dú èrshēng.  
"一"은 4성 앞에서 2성으로 읽습니다.

比如"一定"读"yídìng"。  
Bǐrú "yídìng" dú "yídìng".  
예를 들어 "一定"은 "yídìng"으로 읽습니다.

"不"在四声前也读二声。  
"Bù" zài sìshēng qián yě dú èrshēng.  
"不"도 4성 앞에서 2성으로 읽습니다.

比如"不是"读"bú shì"。  
Bǐrú "bú shì" dú "bú shì".  
예를 들어 "不是"는 "bú shì"로 읽습니다.

连读时，前后音会自然过渡。  
Liándú shí, qián hòu yīn huì zìrán guòdù.  
연독할 때 앞뒤 소리는 자연스럽게 이어집니다.

元音结尾的词和后面开头的音会连起来。  
Yuányīn jiéwěi de cí hé hòumiàn kāitóu de yīn huì lián qǐlái.  
모음으로 끝나는 단어는 뒤에 오는 소리와 이어집니다.

掌握连读变调，说话会更快更顺。  
Zhǎngwò liándú biàndiào, shuōhuà huì gèng kuài gèng shùn.  
연독과 성조변화를 익히면 말이 더 빠르고 매끄러워집니다.

但要注意，不是所有地方都要连读。  
Dàn yào zhùyì, bú shì suǒyǒu dìfang dōu yào liándú.  
하지만 주의하세요, 모든 곳을 연독하는 것은 아닙니다.

## 主要词汇 (주요 단어)

### 1. 连读  /  liándú  /  [동사 (v.)]  /  연독하다, 이어 읽다
- 한자 풀이: 连(이을 련) + 读(읽을 독) → 소리를 이어 읽다
- 例句: 说快的时候自然会连读。
- Pinyin: Shuō kuài de shíhou zìrán huì liándú.
- 번역: 빨리 말하면 자연히 연독하게 됩니다.

### 2. 变调  /  biàndiào  /  [명사 (n.)]  /  성조 변화
- 한자 풀이: 变(변할 변) + 调(가락 조) → 성조가 달라짐
- 例句: "你好"的"你"发生了变调。
- Pinyin: "Nǐ hǎo" de "nǐ" fāshēng le biàndiào.
- 번역: "你好"의 "你"는 성조 변화를 겪었습니다.

### 3. 三声  /  sānshēng  /  [명사 (n.)]  /  3성
- 한자 풀이: 三(석 삼) + 声(소리 성) → 셋째 성조
- 例句: 三声是降升调。
- Pinyin: Sānshēng shì jiàngshēng diào.
- 번역: 3성은 내려갔다 올라가는 성조입니다.

### 4. 掌握  /  zhǎngwò  /  [동사 (v.)]  /  익히다, 장악하다
- 한자 풀이: 掌(손바닥 장) + 握(쥘 악) → 손에 쥐다, 익히다
- 例句: 掌握规律就能说得地道。
- Pinyin: Zhǎngwò guīlǜ jiù néng shuō de dìdao.
- 번역: 규칙을 익히면 원어민답게 말할 수 있습니다.

### 5. 顺畅  /  shùnchàng  /  [형용사 (adj.)]  /  매끄럽다, 원활하다
- 한자 풀이: 顺(순할 순) + 畅(통할 창) → 막힘없이 흐르다
- 例句: 掌握连读后，说话更顺畅。
- Pinyin: Zhǎngwò liándú hòu, shuōhuà gèng shùnchàng.
- 번역: 연독을 익힌 뒤 말이 더 매끄러워집니다.

### 6. 过渡  /  guòdù  /  [동사 (v.)]  /  전환하다, 이어지다
- 한자 풀이: 过(지날 과) + 渡(건널 도) → 다른 상태로 옮겨가다
- 例句: 音与音之间要自然过渡。
- Pinyin: Yīn yǔ yīn zhī jiān yào zìrán guòdù.
- 번역: 소리와 소리 사이는 자연스럽게 이어져야 합니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 你好 | nǐ hǎo | 3성+3성 그대로 "니하오" | 앞 3성 2성으로 → "ní hǎo" |
| 一定 | yídìng | 一을 항상 1성(yī)으로 읽음 | 4성 앞 → 2성 "yí" |
| 不是 | bú shì | 不를 항상 4성(bù)으로 읽음 | 4성 앞 → 2성 "bú" |
| 可以 | ké yǐ | 可를 3성(kě) 그대로 읽음 | 3성+3성 → 앞 2성 "ké" |

## 语法点 (어법 포인트)

### 1. 3성 + 3성 → 앞 2성
- 你好 nǐ hǎo → ní hǎo. 可以 kěyǐ → ké yǐ.

### 2. "一"의 변조 — 4성 앞 2성, 그 외 4성
- 一定 yídìng, 一起 yìqǐ, 一天 yì tiān

### 3. "不"의 변조 — 4성 앞 2성
- 不是 bú shì, 不错 búcuò

### 4. 半三声 — 3성이 1·2·4성 앞에서 반3성
- 北京 Běijīng, 老师 lǎoshī

## 应用会话 (응용 회화 - 연독·성조변화)

A: 我发现"你好"读起来不一样。  
   Wǒ fāxiàn "nǐ hǎo" dú qǐlái bù yíyàng.  
   "你好"가 읽히는 게 다르다는 걸 알았어요.

B: 对，两个三声连读，前一个变二声。  
   Duì, liǎng ge sānshēng liándú, qián yí ge biàn èrshēng.  
   맞아요, 3성이 두 개 연달아 오면 앞의 것이 2성으로 변해요.

A: 那"一定"里的"一"为什么读二声？  
   Nà "yídìng" li de "yī" wèishénme dú èrshēng?  
   그럼 "一定"의 "一"은 왜 2성으로 읽어요?

B: 因为"定"是四声，"一"要变二声。  
   Yīnwèi "dìng" shì sìshēng, "yī" yào biàn èrshēng.  
   "定"이 4성이라 "一"이 2성으로 변하는 거예요.

A: "不"也是一样吗？  
   "Bù" yě shì yíyàng ma?  
   "不"도 같은가요?

B: 对，"不是"读"bú shì"。  
   Duì, "bú shì" dú "bú shì".  
   네, "不是"는 "bú shì"로 읽어요.

A: 连读又要注意什么？  
   Liándú yòu yào zhùyì shénme?  
   연독할 때는 또 뭘 주의해야 해요?

B: 音和音自然过渡，不要一个一个蹦。  
   Yīn hé yīn zìrán guòdù, bú yào yí ge yí ge bèng.  
   소리가 자연스럽게 이어지게, 하나씩 끊어 말하지 마세요.
