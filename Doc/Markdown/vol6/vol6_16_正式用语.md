第 十六 课 : 16. 正式用语 Zhèngshì yòngyǔ (격식체)

## 本文 (본문)

尊敬的各位来宾，大家好！  
Zūnjìng de gèwèi láibīn, dàjiā hǎo!  
존경하는 내빈 여러분, 안녕하십니까!

请允许我代表公司向您表示热烈的欢迎。  
Qǐng yǔnxǔ wǒ dàibiǎo gōngsī xiàng nín biǎoshì rèliè de huānyíng.  
제가 회사를 대표하여 진심으로 환영의 말씀을 드리도록 허락해 주십시오.

首先，我谨代表全体同事，感谢您的到来。  
Shǒuxiān, wǒ jǐn dàibiǎo quántǐ tóngshì, gǎnxiè nín de dàolái.  
먼저 저는 전 직원을 대표하여 귀하의 방문에 감사드립니다.

现将有关事宜通知如下。  
Xiàn jiāng yǒuguān shìyí tōngzhī rúxià.  
이제 관련 사항을 다음과 같이 통지합니다.

特此通知，请遵照执行。  
Tècǐ tōngzhī, qǐng zūnzhào zhíxíng.  
이에 통지하오니 준수하여 시행해 주시기 바랍니다.

如需进一步了解，请随时与我联系。  
Rú xū jìnyíbù liǎojiě, qǐng suíshí yǔ wǒ liánxì.  
추가로 확인하실 사항이 있으시면 언제든 저에게 연락해 주십시오.

敬请光临指导。  
Jìng qǐng guānglín zhǐdǎo.  
방문하시어 지도해 주시기 바랍니다.

本会议兹定于下午三点举行。  
Běn huìyì zī dìng yú xiàwǔ sān diǎn jǔxíng.  
본 회의는 오후 3시에 개최하기로 정해졌습니다.

请您届时准时出席。  
Qǐng nín jièshí zhǔnshí chūxí.  
그때 정시에 참석해 주시기 바랍니다.

上述安排如有变动，将另行通知。  
Shàngshù ānpái rú yǒu biàndòng, jiāng lìngxíng tōngzhī.  
상기 일정에 변동이 있으면 별도로 통지하겠습니다.

## 主要词汇 (주요 단어)

### 1. 尊敬  /  zūnjìng  /  [동사·형용사 (v./adj.)]  /  존경하다, 존경하는
- 한자 풀이: 尊(높을 존) + 敬(공경할 경) → 상대를 높이어 공경하다
- 例句: 尊敬的王先生，您好！
- Pinyin: Zūnjìng de Wáng xiānsheng, nín hǎo!
- 번역: 존경하는 왕 선생님, 안녕하십니까!

### 2. 代表  /  dàibiǎo  /  [동사 (v.)]  /  대표하다
- 한자 풀이: 代(대신할 대) + 表(겉 표) → 남을 대신해 의사를 표하다
- 例句: 他代表全班发言。
- Pinyin: Tā dàibiǎo quán bān fāyán.
- 번역: 그는 반 전체를 대표해 발언했습니다.

### 3. 通知  /  tōngzhī  /  [동사·명사 (v./n.)]  /  통지하다, 통지
- 한자 풀이: 通(통할 통) + 知(알 지) → 소식을 알리다
- 例句: 请把通知贴在公告栏。
- Pinyin: Qǐng bǎ tōngzhī tiē zài gōnggàolán.
- 번역: 통지문을 게시판에 붙여 주세요.

### 4. 联系  /  liánxì  /  [동사 (v.)]  /  연락하다
- 한자 풀이: 联(잇닿을 연) + 系(이을 계) → 서로 이어져 관계를 맺다
- 例句: 有事请联系我。
- Pinyin: Yǒu shì qǐng liánxì wǒ.
- 번역: 일이 있으면 저에게 연락하세요.

### 5. 出席  /  chūxí  /  [동사 (v.)]  /  출석하다, 참석하다
- 한자 풀이: 出(나갈 출) + 席(자리 석) → 자리에 나가 참여하다
- 例句: 全体成员都要出席会议。
- Pinyin: Quántǐ chéngyuán dōu yào chūxí huìyì.
- 번역: 전체 구성원은 모두 회의에 참석해야 합니다.

### 6. 事宜  /  shìyí  /  [명사 (n.)]  /  사항, 업무
- 한자 풀이: 事(일 사) + 宜(마땅할 의) → 일의 알맞은 내용, 사항
- 例句: 有关报名事宜请咨询前台。
- Pinyin: Yǒuguān bàomíng shìyí qǐng zīxún qiántái.
- 번역: 신청 관련 사항은 프런트에 문의해 주세요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 尊敬 | zūnjìng | z를 zh로 혼동해 "쭝" | 혀를 펴고 "쯔(zūn)" 평설음 |
| 出席 | chūxí | ch를 'ㅊ', x를 'ㅅ'으로 읽음 | 권설음 "츠(chū)", x는 혀를 평평하게 "시(xí)" |
| 通知 | tōngzhī | zh를 'ㅈ'으로 읽어 "지" | 혀를 말아 올려 "즈(zhī)" 권설음 |
| 光临 | guānglín | l을 n으로 혼동해 "닌" | 혀끝을 윗잇몸에 대고 "린(lín)" 2성 |
| 遵照 | zūnzhào | z와 zh를 모두 'ㅈ'으로 읽음 | z는 평설음 "쯔(zūn)", zh는 권설음 "즈아오(zhào)" |

## 语法点 (어법 포인트)

### 1. "请允许我…" — 정중한 허가·진행 요청
- 请允许我代表公司表示感谢。 Qǐng yǔnxǔ wǒ dàibiǎo gōngsī biǎoshì gǎnxiè. 제가 회사를 대표하여 감사를 표하도록 허락해 주십시오.

### 2. "特此…" — 공문 고정구 (~임을 특별히 알리다)
- 特此通知。 Tècǐ tōngzhī. 이에 통지합니다.
- 特此说明。 Tècǐ shuōmíng. 이에 설명합니다.

### 3. "兹" — 공문 서두의 고어식 표현 (이에, 여기에)
- 兹定于下午三点举行。 Zī dìng yú xiàwǔ sān diǎn jǔxíng. 오후 3시에 개최하기로 정합니다.

### 4. "如…请…" — 조건 + 정중한 요청
- 如有疑问，请及时联系。 Rú yǒu yíwèn, qǐng jíshí liánxì. 궁금한 점이 있으면 즉시 연락해 주십시오.

## 应用会话 (응용 회화 - 격식 행사)

A: 各位来宾，大家好！  
   Gèwèi láibīn, dàjiā hǎo!  
   내빈 여러분, 안녕하십니까!

B: 您好，谢谢您的邀请。  
   Nín hǎo, xièxie nín de yāoqǐng.  
   안녕하세요, 초대해 주셔서 감사합니다.

A: 请允许我代表公司欢迎您。  
   Qǐng yǔnxǔ wǒ dàibiǎo gōngsī huānyíng nín.  
   제가 회사를 대표하여 환영의 말씀을 드리도록 허락해 주십시오.

B: 很荣幸参加这次会议。  
   Hěn róngxìng cānjiā zhè cì huìyì.  
   이번 회의에 참석하게 되어 영광입니다.

A: 现将议程通知如下。  
   Xiàn jiāng yìchéng tōngzhī rúxià.  
   이제 의사일정을 다음과 같이 알려 드립니다.

B: 好的，我记一下。  
   Hǎo de, wǒ jì yíxià.  
   네, 메모하겠습니다.

A: 如有变动，我们会另行通知。  
   Rú yǒu biàndòng, wǒmen huì lìngxíng tōngzhī.  
   변동이 있으면 별도로 알려 드리겠습니다.

B: 明白，谢谢您的安排。  
   Míngbai, xièxie nín de ānpái.  
   알겠습니다, 준비해 주셔서 감사합니다.
