第 一 课 : 01. 成语 Chéngyǔ (사자성어)

## 本文 (본문)

最近我在学习成语。  
Zuìjìn wǒ zài xuéxí chéngyǔ.  
최근에 저는 사자성어를 공부하고 있어요.

成语是汉语中固定下来的四字词组。  
Chéngyǔ shì Hànyǔ zhōng gùdìng xiàlái de sì zì cízǔ.  
사자성어는 중국어에서 굳어진 네 글자 단어 묶음입니다.

学习成语能让我们说话更加生动。  
Xuéxí chéngyǔ néng ràng wǒmen shuōhuà gèngjiā shēngdòng.  
사자성어를 배우면 우리 말이 더 생생해져요.

比如说"画蛇添足"就是多此一举的意思。  
Bǐrú shuō "huà shé tiān zú" jiù shì duō cǐ yì jǔ de yìsi.  
예를 들어 "화사첨족"은 쓸데없는 짓이라는 뜻이에요.

而"亡羊补牢"告诉我们犯了错要及时改正。  
Ér "wáng yáng bǔ láo" gàosu wǒmen fàn le cuò yào jíshí gǎizhèng.  
"망양보뢰"는 잘못을 저질렀을 때 제때 고쳐야 한다고 알려줘요.

他做事总是马马虎虎，一点儿也不认真。  
Tā zuòshì zǒngshì mǎmǎhūhū, yìdiǎnr yě bù rènzhēn.  
그는 일을 항상 대충대충 해서 전혀 성실하지 않아요.

听他说完后，我恍然大悟。  
Tīng tā shuōwán hòu, wǒ huǎngrán dàwù.  
그의 말을 듣고 나서 저는 갑자기 깨달았어요.

他讲故事讲得津津有味。  
Tā jiǎng gùshi jiǎng de jīnjīn yǒu wèi.  
그는 이야기를 아주 재미있게 해요.

这件事真是不可思议。  
Zhè jiàn shì zhēn shì bùkě sīyì.  
이 일은 정말 믿기 어려워요.

他做这件事已经胸有成竹了。  
Tā zuò zhè jiàn shì yǐjīng xiōng yǒu chéng zhú le.  
그는 이미 이 일에 대해 자신 있게 준비되어 있어요.

学成语不能半途而废。  
Xué chéngyǔ bù néng bàntú'ér fèi.  
사자성어를 배우는 일은 중도에 포기하면 안 돼요.

只要坚持，就一定能学好。  
Zhǐyào jiānchí, jiù yídìng néng xué hǎo.  
꾸준히만 하면 반드시 잘 배울 수 있어요.

## 主要词汇 (주요 단어)

### 1. 成语  /  chéngyǔ  /  [명사 (n.)]  /  사자성어, 관용어
- 한자 풀이: 成(이룰 성) + 语(말씀 어) → 오랫동안 굳어진 말
- 例句: 这个成语很有意思。
- Pinyin: Zhège chéngyǔ hěn yǒu yìsi.
- 번역: 이 사자성어는 아주 재미있다.

### 2. 画蛇添足  /  huà shé tiān zú  /  [성어 (idiom)]  /  뱀을 그리다 발을 그려 넣다, 쓸데없는 짓을 하다
- 한자 풀이: 画(그릴 화) + 蛇(뱀 사) + 添(더할 첨) + 足(발 족) → 군더더기를 더하다
- 例句: 这样做真是画蛇添足。
- Pinyin: Zhèyàng zuò zhēn shì huà shé tiān zú.
- 번역: 이렇게 하는 건 정말 쓸데없는 짓이다.

### 3. 亡羊补牢  /  wáng yáng bǔ láo  /  [성어 (idiom)]  /  양을 잃고 우리를 고치다, 늦었지만 잘못을 고치다
- 한자 풀이: 亡(잃을 망) + 羊(양 양) + 补(기울 보) + 牢(우리 뢰) → 뒤늦게나마 바로잡다
- 例句: 现在改还来得及，亡羊补牢嘛。
- Pinyin: Xiànzài gǎi hái láidejí, wáng yáng bǔ láo ma.
- 번역: 지금 고쳐도 늦지 않아, 늦게나마 고치는 거야.

### 4. 马马虎虎  /  mǎmǎhūhū  /  [형용사 (adj.)]  /  대충대충 하는, 아무렇게나
- 한자 풀이: 马(말 마) 중첩 + 虎(범 호) 중첩 → 꼼꼼하지 않은 모양
- 例句: 他做事总是马马虎虎。
- Pinyin: Tā zuòshì zǒngshì mǎmǎhūhū.
- 번역: 그는 일을 항상 대충대충 한다.

### 5. 恍然大悟  /  huǎngrán dàwù  /  [성어 (idiom)]  /  갑자기 크게 깨닫다
- 한자 풀이: 恍(갑자기 황) + 然(그럴 연) + 大(클 대) + 悟(깨달을 오) → 문득 깨닫다
- 例句: 听完解释，我恍然大悟。
- Pinyin: Tīngwán jiěshì, wǒ huǎngrán dàwù.
- 번역: 설명을 듣고 나서 저는 갑자기 깨달았다.

### 6. 半途而废  /  bàntú'ér fèi  /  [성어 (idiom)]  /  중도에 그만두다
- 한자 풀이: 半(반 반) + 途(길 도) + 而(말 이을 이) + 废(폐할 폐) → 중간에 포기하다
- 例句: 学习不能半途而废。
- Pinyin: Xuéxí bù néng bàntú'ér fèi.
- 번역: 공부는 중도에 그만둬서는 안 된다.

## 语法点 (어법 포인트)

### 1. 四字成语的结构
- 成语大多是四个字，意思固定。Chéngyǔ dàduō shì sì gè zì, yìsi gùdìng. 사자성어는 대부분 네 글자이며 뜻이 고정돼 있다.
- 画蛇添足。Huà shé tiān zú. 쓸데없는 짓을 하다.

### 2. 成语作谓语
- 他恍然大悟。Tā huǎngrán dàwù. 그는 갑자기 깨달았다.
- 这件事不可思议。Zhè jiàn shì bùkě sīyì. 이 일은 믿기 어렵다.

### 3. "多此一举" — 쓸데없는 짓
- 别担心，这样做不是多此一举。Bié dānxīn, zhèyàng zuò bú shì duō cǐ yì jǔ. 걱정 마세요, 이렇게 하는 건 쓸데없는 짓이 아니에요.

### 4. "只要...就..." — 조건 표현
- 只要坚持，就一定能学好。Zhǐyào jiānchí, jiù yídìng néng xué hǎo. 꾸준히만 하면 반드시 잘 배울 수 있다.

## 应用会话 (응용 회화 - 사자성어 공부)

A: 你最近在学什么？  
   Nǐ zuìjìn zài xué shénme?  
   너 요즘 뭐 공부해?

B: 我在学成语，很有意思。  
   Wǒ zài xué chéngyǔ, hěn yǒu yìsi.  
   나 사자성어 공부하고 있어, 재미있어.

A: 能给我举个例子吗？  
   Néng gěi wǒ jǔ ge lìzi ma?  
   예를 하나 들어줄래?

B: 比如说"画蛇添足"，就是多此一举的意思。  
   Bǐrú shuō "huà shé tiān zú", jiù shì duō cǐ yì jǔ de yìsi.  
   예를 들어 "화사첨족"은 쓸데없는 짓이라는 뜻이야.

A: 原来如此，那"亡羊补牢"呢？  
   Yuánlái rúcǐ, nà "wáng yáng bǔ láo" ne?  
   아 그렇구나, 그럼 "망양보뢰"는?

B: 它是说犯了错要马上改正。  
   Tā shì shuō fàn le cuò yào mǎshàng gǎizhèng.  
   그건 잘못을 저지르면 바로 고쳐야 한다는 뜻이야.

A: 学成语难吗？  
   Xué chéngyǔ nán ma?  
   사자성어 배우기 어려워?

B: 一开始难，但不能半途而废。  
   Yì kāishǐ nán, dàn bù néng bàntú'ér fèi.  
   처음엔 어렵지만 중도에 포기하면 안 돼.

A: 我也开始学吧，不能马马虎虎。  
   Wǒ yě kāishǐ xué ba, bù néng mǎmǎhūhū.  
   나도 시작해 볼게, 대충하면 안 되지.

B: 好，只要坚持，就一定能学好。  
   Hǎo, zhǐyào jiānchí, jiù yídìng néng xué hǎo.  
   좋아, 꾸준히만 하면 반드시 잘 배울 수 있어.
