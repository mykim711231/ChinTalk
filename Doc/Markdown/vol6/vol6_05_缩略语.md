第 五 课 : 05. 缩略语 Suōlüèyǔ (줄임말)

## 本文 (본문)

缩略语就是把长词压缩成短词的说法。  
Suōlüèyǔ jiù shì bǎ chángcí yāsuō chéng duǎncí de shuōfa.  
줄임말은 긴 단어를 짧은 단어로 줄여 부르는 말입니다.

日常生活里到处都能听到缩略语。  
Rìcháng shēnghuó lǐ dàochù dōu néng tīngdào suōlüèyǔ.  
일상생활 곳곳에서 줄임말을 들을 수 있어요.

"高铁"就是"高速铁路"的简称。  
"Gāotiě" jiù shì "gāosù tiělù" de jiǎnchēng.  
"고속철"은 "고속철도"의 줄임말이에요.

我每天坐地铁上班。  
Wǒ měitiān zuò dìtiě shàngbān.  
저는 매일 지하철을 타고 출근해요.

奥运会是"奥林匹克运动会"的缩写。  
Àoyùnhuì shì "Àolínpǐkè yùndònghuì" de suōxiě.  
올림픽은 "올림픽 운동회"의 줄임말이에요.

他考上了北大，真厉害。  
Tā kǎoshàng le Běidà, zhēn lìhai.  
그는 베이징대학에 합격했어, 정말 대단해.

现在网上购物很方便。  
Xiànzài wǎngshàng gòuwù hěn fāngbiàn.  
요즘 인터넷 쇼핑은 아주 편리해요.

外卖和快递都已经送到家了。  
Wàimài hé kuàidì dōu yǐjīng sòngdào jiā le.  
배달 음식과 택배는 이미 집까지 배달되었어요.

世界杯每四年举行一次。  
Shìjièbēi měi sì nián jǔxíng yí cì.  
월드컵은 4년마다 한 번 열려요.

我的手机没电了。  
Wǒ de shǒujī méi diàn le.  
제 휴대폰 배터리가 다 됐어요.

他正忙着准备考研。  
Tā zhèng mángzhe zhǔnbèi kǎoyán.  
그는 대학원 입시 준비로 바빠요.

学会缩略语，看新闻就方便多了。  
Xuéhuì suōlüèyǔ, kàn xīnwén jiù fāngbiàn duō le.  
줄임말을 배우면 뉴스를 보기 훨씬 편해져요.

## 主要词汇 (주요 단어)

### 1. 缩略语  /  suōlüèyǔ  /  [명사 (n.)]  /  줄임말, 약어
- 한자 풀이: 缩(줄일 축) + 略(간략할 략) + 语(말씀 어) → 줄인 말
- 例句: 这些缩略语在新闻里很常见。
- Pinyin: Zhèxiē suōlüèyǔ zài xīnwén lǐ hěn chángjiàn.
- 번역: 이런 줄임말은 뉴스에서 아주 흔하다.

### 2. 高铁  /  gāotiě  /  [명사 (n.)]  /  고속철도
- 한자 풀이: 高(높을 고) + 铁(쇠 철) → 高速铁路의 줄임말
- 例句: 坐高铁去北京只要四个小时。
- Pinyin: Zuò gāotiě qù Běijīng zhǐ yào sì gè xiǎoshí.
- 번역: 고속철로 베이징에 가면 네 시간밖에 안 걸린다.

### 3. 奥运会  /  àoyùnhuì  /  [명사 (n.)]  /  올림픽
- 한자 풀이: 奥(깊을 오) + 运(운전할 운) + 会(모일 회) → 奥林匹克运动会의 줄임말
- 例句: 奥运会每四年举办一次。
- Pinyin: Àoyùnhuì měi sì nián jǔbàn yí cì.
- 번역: 올림픽은 4년마다 한 번 열린다.

### 4. 北大  /  Běidà  /  [명사 (n.)]  /  베이징대학
- 한자 풀이: 北(북녘 북) + 大(클 대) → 北京大学的简称
- 例句: 北大是中国最著名的大学之一。
- Pinyin: Běidà shì Zhōngguó zuì zhùmíng de dàxué zhī yī.
- 번역: 베이징대학은 중국에서 가장 유명한 대학 중 하나다.

### 5. 世界杯  /  shìjièbēi  /  [명사 (n.)]  /  월드컵
- 한자 풀이: 世界(세계) + 杯(잔 배) → 세계 축구 대회의 줄임말
- 例句: 今年世界杯在哪儿举行？
- Pinyin: Jīnnián shìjièbēi zài nǎr jǔxíng?
- 번역: 올해 월드컵은 어디서 열려요?

### 6. 考研  /  kǎoyán  /  [동사 (v.)]  /  대학원 입시를 준비하다
- 한자 풀이: 考(시험 볼 고) + 研(연구할 연) → 研究生考试의 줄임말
- 例句: 他毕业以后打算考研。
- Pinyin: Tā bìyè yǐhòu dǎsuàn kǎoyán.
- 번역: 그는 졸업 후 대학원 입시를 준비할 계획이다.

## 语法点 (어법 포인트)

### 1. 缩略语的构成方式
- 缩略语常取每个词的首字。Suōlüèyǔ cháng qǔ měi gè cí de shǒu zì. 줄임말은 흔히 각 단어의 첫 글자를 딴다.
- 高速铁路 → 高铁。Gāosù tiělù → gāotiě. 고속철도 → 고속철.

### 2. "简称"과 "缩写"
- 高铁是高速铁路的简称。Gāotiě shì gāosù tiělù de jiǎnchēng. 고속철은 고속철도의 줄임말이다.
- 奥运会是奥林匹克运动会的缩写。Àoyùnhuì shì Àolínpǐkè yùndònghuì de suōxiě. 올림픽은 올림픽 운동회의 줄임말이다.

### 3. "就是...的" — 강조 표현
- 北大就是北京大学的简称。Běidà jiù shì Běijīng dàxué de jiǎnchēng. 北大(베이징대)는 北京大学(베이징대학)의 줄임말이다.

### 4. "每+수량" — 빈도 표현
- 世界杯每四年举行一次。Shìjièbēi měi sì nián jǔxíng yí cì. 월드컵은 4년마다 한 번 열린다.
- 我每星期坐一次地铁。Wǒ měi xīngqī zuò yí cì dìtiě. 나는 매주 한 번 지하철을 탄다.

## 应用会话 (응용 회화 - 줄임말)

A: 你假期去哪儿玩？  
   Nǐ jiàqī qù nǎr wán?  
   너 휴가 때 어디 가서 놀 거야?

B: 我坐高铁回老家。  
   Wǒ zuò gāotiě huí lǎojiā.  
   나 고속철 타고 고향에 갈 거야.

A: 高铁就是"高速铁路"吧？  
   Gāotiě jiù shì "gāosù tiělù" ba?  
   고속철이 "고속철도"라는 뜻이지?

B: 对，就是它的简称。  
   Duì, jiù shì tā de jiǎnchēng.  
   맞아, 그거 줄임말이야.

A: 你今年考研吗？  
   Nǐ jīnnián kǎoyán ma?  
   너 올해 대학원 입시 준비해?

B: 不，我准备找工作。  
   Bù, wǒ zhǔnbèi zhǎo gōngzuò.  
   아니, 나 취업 준비할 거야.

A: 你朋友考上北大了吗？  
   Nǐ péngyou kǎoshàng Běidà le ma?  
   네 친구 베이징대학에 합격했어?

B: 考上了，真厉害。  
   Kǎoshàng le, zhēn lìhai.  
   합격했어, 정말 대단해.

A: 世界杯你看了吗？  
   Shìjièbēi nǐ kàn le ma?  
   월드컵 봤어?

B: 看了，我熬夜看的直播。  
   Kàn le, wǒ áoyè kàn de zhíbō.  
   봤어, 밤새 생방송으로 봤어.

A: 我外卖都凉了。  
   Wǒ wàimài dōu liáng le.  
   나 배달 음식 다 식었어.

B: 谁让你不早点儿吃呢。  
   Shéi ràng nǐ bù zǎodiǎnr chī ne.  
   누가 너더러 일찍 안 먹으래.
