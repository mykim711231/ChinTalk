第 十 课 : 10. 委婉表达 Wěiwǎn biǎodá (완곡 표현)

## 本文 (본문)

中国人说话有时很委婉。  
Zhōngguórén shuōhuà yǒushí hěn wěiwǎn.  
중국인은 말할 때 때로 아주 완곡합니다.

直接拒绝会伤感情。  
Zhíjiē jùjué huì shāng gǎnqíng.  
직접 거절하면 감정을 상하게 할 수 있습니다.

所以我们常用一些委婉的说法。  
Suǒyǐ wǒmen cháng yòng yìxiē wěiwǎn de shuōfǎ.  
그래서 우리는 완곡한 표현을 자주 씁니다.

比如不想去时，会说"我再考虑考虑"。  
Bǐrú bù xiǎng qù shí, huì shuō "Wǒ zài kǎolǜ kǎolǜ".  
예를 들어 가고 싶지 않을 때 "다시 생각해 볼게요"라고 말합니다.

"再说吧"就是委婉地拒绝或推迟。  
"Zàishuō ba" jiù shì wěiwǎn de jùjué huò tuīchí.  
"再说吧"는 완곡한 거절 또는 연기입니다.

提意见时先说"我觉得"，不说"你错了"。  
Tí yìjiàn shí xiān shuō "Wǒ juéde", bù shuō "Nǐ cuò le".  
의견을 낼 때 "당신이 틀렸다"가 아니라 "제 생각에는"이라고 먼저 말합니다.

"还行""还可以"有时表示"一般"。  
"Hái xíng" "hái kěyǐ" yǒushí biǎoshì "yìbān".  
"还行""还可以"은 때로 "그저 그렇다"를 뜻합니다.

请求别人时加"不好意思""麻烦您"。  
Qǐngqiú biérén shí jiā "bù hǎoyìsi" "máfan nín".  
남에게 부탁할 때 "죄송하지만""번거롭게 해서"를 덧붙입니다.

夸奖别人时，对方会谦虚地说"哪里哪里"。  
Kuājiǎng biérén shí, duìfāng huì qiānxū de shuō "nǎlǐ nǎlǐ".  
칭찬을 받으면 상대는 겸손하게 "哪里哪里"라고 말합니다.

委婉不是虚伪，而是尊重。  
Wěiwǎn bú shì xūwěi, ér shì zūnzhòng.  
완곡함은 위선이 아니라 존중입니다.

学会委婉表达，交流会更顺畅。  
Xuéhuì wěiwǎn biǎodá, jiāoliú huì gèng shùnchàng.  
완곡 표현을 익히면 소통이 더 원활해집니다.

但要分场合，该直接时也要直接。  
Dàn yào fēn chǎnghé, gāi zhíjiē shí yě yào zhíjiē.  
하지만 경우에 따라, 직접 말해야 할 때는 직접 말해야 합니다.

## 主要词汇 (주요 단어)

### 1. 委婉  /  wěiwǎn  /  [형용사 (adj.)]  /  완곡하다
- 한자 풀이: 委(맡길 위) + 婉(순할 완) → 직설적이지 않고 부드럽다
- 例句: 他用委婉的方式拒绝了。
- Pinyin: Tā yòng wěiwǎn de fāngshì jùjué le.
- 번역: 그는 완곡한 방식으로 거절했습니다.

### 2. 拒绝  /  jùjué  /  [동사 (v.)]  /  거절하다
- 한자 풀이: 拒(막을 거) + 绝(끊을 절) → 물리치고 끊다
- 例句: 委婉地拒绝别人是一种礼貌。
- Pinyin: Wěiwǎn de jùjué biérén shì yì zhǒng lǐmào.
- 번역: 완곡하게 거절하는 것은 일종의 예의입니다.

### 3. 推迟  /  tuīchí  /  [동사 (v.)]  /  미루다, 연기하다
- 한자 풀이: 推(밀 추) + 迟(늦을 지) → 뒤로 미루다
- 例句: 会议推迟到明天。
- Pinyin: Huìyì tuīchí dào míngtiān.
- 번역: 회의는 내일로 연기되었습니다.

### 4. 谦虚  /  qiānxū  /  [형용사 (adj.)]  /  겸손하다
- 한자 풀이: 谦(겸손할 겸) + 虚(빌 허) → 스스로 낮추다
- 例句: 中国人被夸时常很谦虚。
- Pinyin: Zhōngguórén bèi kuā shí cháng hěn qiānxū.
- 번역: 중국인은 칭찬받을 때 자주 아주 겸손합니다.

### 5. 尊重  /  zūnzhòng  /  [동사 (v.)]  /  존중하다
- 한자 풀이: 尊(높을 존) + 重(무거울 중) → 높이 받들다
- 例句: 委婉表达是对别人的尊重。
- Pinyin: Wěiwǎn biǎodá shì duì biérén de zūnzhòng.
- 번역: 완곡 표현은 상대에 대한 존중입니다.

### 6. 场合  /  chǎnghé  /  [명사 (n.)]  /  경우, 자리, 상황
- 한자 풀이: 场(마당 장) + 合(합할 합) → 특정한 상황과 자리
- 例句: 说话要看场合。
- Pinyin: Shuōhuà yào kàn chǎnghé.
- 번역: 말은 상황을 봐서 해야 합니다.

## 语法点 (어법 포인트)

### 1. "再说吧" — 완곡한 거절·연기
- 最近忙，再说吧。 Zuìjìn máng, zàishuō ba. 요즘 바빠서 다음에 얘기하자.

### 2. "我觉得" — 완곡한 의견 제시
- 我觉得这个方案更好。 Wǒ juéde zhè ge fāng'àn gèng hǎo. 제 생각엔 이 안이 더 좋습니다.

### 3. "还行/还可以" — 완곡한 평가 (그저 그렇다)
- 这部电影还行。 Zhè bù diànyǐng hái xíng. 이 영화는 그럭저럭 볼 만하다.

### 4. "不好意思/麻烦您" — 완곡한 부탁
- 不好意思，麻烦您帮我一下。 Bù hǎoyìsi, máfan nín bāng wǒ yíxià. 실례합니다, 저를 좀 도와주시겠어요.

## 应用会话 (응용 회화 - 완곡 표현)

A: 周末一起去看电影吧？  
   Zhōumò yìqǐ qù kàn diànyǐng ba?  
   주말에 같이 영화 보러 갈래요?

B: 嗯……我再考虑考虑吧。  
   En…… Wǒ zài kǎolǜ kǎolǜ ba.  
   음…… 좀 생각해 볼게요.

A: 你是不想去吗？  
   Nǐ shì bù xiǎng qù ma?  
   가고 싶지 않은 거예요?

B: 没有，最近挺忙的，再说吧。  
   Méiyǒu, zuìjìn tǐng máng de, zàishuō ba.  
   아니에요, 요즘 좀 바빠서, 다음에 얘기해요.

A: 那下个星期呢？  
   Nà xià ge xīngqī ne?  
   그럼 다음 주는요?

B: 看情况吧，现在说不好。  
   Kàn qíngkuàng ba, xiànzài shuō bu hǎo.  
   상황 봐서요, 지금은 잘 모르겠어요.

A: 我觉得这个电影特别好看。  
   Wǒ juéde zhè ge diànyǐng tèbié hǎokàn.  
   제 생각엔 이 영화가 정말 재미있을 것 같아요.

B: 这样吧，要是有时间，我就跟你去。  
   Zhèyàng ba, yàoshi yǒu shíjiān, wǒ jiù gēn nǐ qù.  
   이렇게 하죠, 시간 되면 같이 가요.

A: 好的，一言为定。  
   Hǎo de, yì yán wéi dìng.  
   좋아요, 약속할게요.
