第 二 课 : 02. 惯用语 Guànyòngyǔ (관용어)

## 本文 (본문)

惯用语大多是三个字的固定说法。  
Guànyòngyǔ dàduō shì sān gè zì de gùdìng shuōfa.  
관용어는 대부분 세 글자의 고정 표현입니다.

它们的意思往往不能从字面来猜。  
Tāmen de yìsi wǎngwǎng bù néng cóng zìmiàn lái cāi.  
그것들의 뜻은 종종 글자 그대로 짐작할 수 없습니다.

我和他打交道很多年了。  
Wǒ hé tā dǎ jiāodào hěn duō nián le.  
저는 그와 오랫동안 거래하며 지내왔어요.

明天要考试，今晚我得开夜车了。  
Míngtiān yào kǎoshì, jīnwǎn wǒ děi kāi yèchē le.  
내일 시험이라 오늘 밤 저는 밤샘 공부를 해야 해요.

别给他泼冷水，他在努力呢。  
Bié gěi tā pō lěngshuǐ, tā zài nǔlì ne.  
그에게 찬물을 끼얹지 마세요, 그는 노력하고 있어요.

他第一次上台就出了洋相。  
Tā dì-yī cì shàngtái jiù chū le yángxiàng.  
그는 처음 무대에 올라가서 바로 망신을 당했어요.

他做生意总爱耍花招。  
Tā zuò shēngyi zǒng ài shuǎ huāzhāo.  
그는 장사할 때 항상 잔꾀를 부리려 해요.

这次碰了钉子，他才明白不容易。  
Zhè cì pèng le dīngzi, tā cái míngbai bù róngyì.  
이번에 거절당하고 나서야 그는 쉽지 않다는 걸 알았어요.

这件事可不能走后门。  
Zhè jiàn shì kě bù néng zǒu hòumén.  
이 일은 절대 뒷구멍으로 해서는 안 돼요.

你别钻牛角尖了，想开点儿。  
Nǐ bié zuān niújiǎojiān le, xiǎngkāi diǎnr.  
너 괜히 한쪽으로만 파고들지 말고, 마음을 좀 열어.

他一说话就露了马脚。  
Tā yì shuōhuà jiù lòu le mǎjiǎo.  
그는 말을 꺼내자마자 본색을 드러냈어요.

这些话听起来真像是敲竹杠。  
Zhèxiē huà tīng qǐlái zhēn xiàng shì qiāo zhúgàng.  
이런 말은 정말 바가지 씌우는 것 같아요.

## 主要词汇 (주요 단어)

### 1. 惯用语  /  guànyòngyǔ  /  [명사 (n.)]  /  관용어
- 한자 풀이: 惯(습관 관) + 用(쓸 용) + 语(말씀 어) → 습관처럼 쓰는 말
- 例句: 汉语里的惯用语非常生动。
- Pinyin: Hànyǔ lǐ de guànyòngyǔ fēicháng shēngdòng.
- 번역: 중국어의 관용어는 아주 생생하다.

### 2. 打交道  /  dǎ jiāodào  /  [동사 (v.)]  /  교제하다, 상대하다, 거래하다
- 한자 풀이: 打(치다) + 交道(교제) → 사람과 어울리다
- 例句: 他常和各种各样的人打交道。
- Pinyin: Tā cháng hé gèzhǒng gèyàng de rén dǎ jiāodào.
- 번역: 그는 항상 다양한 사람들과 교제한다.

### 3. 开夜车  /  kāi yèchē  /  [동사 (v.)]  /  밤샘 공부하다, 야근하다
- 한자 풀이: 开(열 개) + 夜(밤 야) + 车(차) → 밤에 차를 몰듯 밤을 새우다
- 例句: 为了考试，他经常开夜车。
- Pinyin: Wèile kǎoshì, tā jīngcháng kāi yèchē.
- 번역: 시험 때문에 그는 자주 밤을 새운다.

### 4. 泼冷水  /  pō lěngshuǐ  /  [동사 (v.)]  /  찬물을 끼얹다, 흥을 깨다
- 한자 풀이: 泼(뿌릴 발) + 冷(찰 냉) + 水(물 수) → 의욕을 꺾다
- 例句: 别给孩子的热情泼冷水。
- Pinyin: Bié gěi háizi de rèqíng pō lěngshuǐ.
- 번역: 아이의 열정에 찬물을 끼얹지 마세요.

### 5. 出洋相  /  chū yángxiàng  /  [동사 (v.)]  /  망신을 당하다, 실수하다
- 한자 풀이: 出(날 출) + 洋(서양 양) + 相(모양 상) → 웃음거리가 되다
- 例句: 他上台就紧张，结果出了洋相。
- Pinyin: Tā shàngtái jiù jǐnzhāng, jiéguǒ chū le yángxiàng.
- 번역: 그는 무대에 오르면 긴장해서 결국 망신을 당했다.

### 6. 碰钉子  /  pèng dīngzi  /  [동사 (v.)]  /  거절당하다, 실패하다
- 한자 풀이: 碰(부딪칠 봉) + 钉子(못) → 못에 부딪치다 → 거절당하다
- 例句: 找工作的时候，他碰了不少钉子。
- Pinyin: Zhǎo gōngzuò de shíhou, tā pèng le bù shǎo dīngzi.
- 번역: 취업할 때 그는 적지 않게 거절당했다.

## 语法点 (어법 포인트)

### 1. 惯用语的特点
- 惯用语多是三个字，不能只按字面理解。Guànyòngyǔ duō shì sān gè zì, bù néng zhǐ àn zìmiàn lǐjiě. 관용어는 대부분 세 글자로, 글자 그대로만 이해할 수 없다.
- 碰钉子不是真碰到钉子。Pèng dīngzi bú shì zhēn pèngdào dīngzi. "펑딩쯔"는 정말 못에 부딪치는 게 아니다.

### 2. "打交道" — 사람을 상대하다
- 我常和外国人打交道。Wǒ cháng hé wàiguórén dǎ jiāodào. 나는 자주 외국인과 교류한다.

### 3. "得" (děi) — 반드시 ~해야 한다
- 明天考试，我得开夜车。Míngtiān kǎoshì, wǒ děi kāi yèchē. 내일 시험이라 밤을 새야 한다.

### 4. "别...了" — 하지 말라는 권유
- 别钻牛角尖了。Bié zuān niújiǎojiān le. 한쪽으로만 파고들지 마라.
- 别给他泼冷水。Bié gěi tā pō lěngshuǐ. 그에게 찬물을 끼얹지 마라.

## 应用会话 (응용 회화 - 관용어)

A: 你中文说得真地道。  
   Nǐ Zhōngwén shuō de zhēn dìdao.  
   너 중국어 정말 원어민처럼 하네.

B: 谢谢，我还得天天学习。  
   Xièxie, wǒ hái děi tiāntiān xuéxí.  
   고마워, 난 아직 매일 공부해야 해.

A: 你听说过惯用语吗？  
   Nǐ tīngshuō guo guànyòngyǔ ma?  
   너 관용어 들어봤어?

B: 当然，像"打交道""开夜车"都是。  
   Dāngrán, xiàng "dǎ jiāodào" "kāi yèchē" dōu shì.  
   물론이지, "교제하다" "밤샘 공부" 같은 것들 말이야.

A: 我明天考试，今晚得开夜车。  
   Wǒ míngtiān kǎoshì, jīnwǎn děi kāi yèchē.  
   나 내일 시험이라 오늘 밤 밤샘해야 해.

B: 加油！不过别熬太晚。  
   Jiāyóu! Búguò bié áo tài wǎn.  
   힘내! 그래도 너무 늦게까지는 하지 마.

A: 上次面试我碰了钉子，很伤心。  
   Shàng cì miànshì wǒ pèng le dīngzi, hěn shāngxīn.  
   지난번 면접에서 거절당해서 마음이 아팠어.

B: 别灰心，继续努力就好。  
   Bié huīxīn, jìxù nǔlì jiù hǎo.  
   낙담하지 말고, 계속 노력하면 돼.
