第 九 课 : 09. 语气词 Yǔqìcí (어기사)

## 本文 (본문)

语气词是汉语里很有味道的部分。  
Yǔqìcí shì Hànyǔ li hěn yǒu wèidào de bùfen.  
어기사는 중국어에서 아주 매력적인 부분입니다.

它们放在句末，表达各种语气。  
Tāmen fàng zài jù mò, biǎodá gè zhǒng yǔqì.  
그것들은 문장 끝에 놓여 여러 어기를 표현합니다.

"吗"表示疑问。  
"Ma" biǎoshì yíwèn.  
"吗"는 의문을 나타냅니다.

比如"你去吗？"。  
Bǐrú "Nǐ qù ma?".  
예를 들어 "你去吗?(갈 거야?)" 같은 경우입니다.

"呢"可以反问，也可以表示正在进行。  
"Ne" kěyǐ fǎnwèn, yě kěyǐ biǎoshì zhèngzài jìnxíng.  
"呢"은 되묻거나 진행 중임을 나타낼 수 있습니다.

"吧"表示建议、推测或同意。  
"Ba" biǎoshì jiànyì, tuīcè huò tóngyì.  
"吧"는 제안, 추측, 동의를 나타냅니다.

比如"我们走吧""大概是的吧"。  
Bǐrú "Wǒmen zǒu ba" "Dàgài shì de ba".  
예를 들어 "我们走吧(가자)" "大概是的吧(아마 그럴 거야)" 같은 경우입니다.

"啊"可以表示感叹或提醒。  
"a" kěyǐ biǎoshì gǎntàn huò tíxǐng.  
"啊"는 감탄이나 주의 환기를 나타냅니다.

"啊"会根据前一个音变成"呀""哇""哪"。  
"a" huì gēnjù qián yí ge yīn biàn chéng "ya" "wa" "na".  
"啊"는 앞 음에 따라 "呀""哇""哪"로 변합니다.

"啦"是"了"和"啊"的合音。  
"La" shì "le" hé "a" de héyīn.  
"啦"는 "了"와 "啊"가 합쳐진 소리입니다.

语气词读轻声，要说得轻巧。  
Yǔqìcí dú qīngshēng, yào shuō de qīngqiǎo.  
어기사는 경성으로 읽어 가볍게 말해야 합니다.

用对语气词，说话才不生硬。  
Yòng duì yǔqìcí, shuōhuà cái bù shēngyìng.  
어기사를 잘 쓰면 말이 딱딱하지 않습니다.

## 主要词汇 (주요 단어)

### 1. 语气词  /  yǔqìcí  /  [명사 (n.)]  /  어기사
- 한자 풀이: 语(말씀 어) + 气(기운 기) + 词(말 사) → 어기를 나타내는 말
- 例句: 语气词常放在句末。
- Pinyin: Yǔqìcí cháng fàng zài jù mò.
- 번역: 어기사는 보통 문장 끝에 놓입니다.

### 2. 语气  /  yǔqì  /  [명사 (n.)]  /  어기, 말투
- 한자 풀이: 语 + 气 → 말에 담긴 기운과 태도
- 例句: 不同的语气词表示不同的语气。
- Pinyin: Bùtóng de yǔqìcí biǎoshì bùtóng de yǔqì.
- 번역: 다른 어기사는 다른 어기를 나타냅니다.

### 3. 疑问  /  yíwèn  /  [명사 (n.)]  /  의문
- 한자 풀이: 疑(의심할 의) + 问(물을 문) → 의심하여 물음
- 例句: "吗"表示疑问。
- Pinyin: "Ma" biǎoshì yíwèn.
- 번역: "吗"는 의문을 나타냅니다.

### 4. 推测  /  tuīcè  /  [동사 (v.)]  /  추측하다
- 한자 풀이: 推(밀 추) + 测(헤아릴 측) → 미루어 헤아리다
- 例句: "吧"可以表示推测。
- Pinyin: "Ba" kěyǐ biǎoshì tuīcè.
- 번역: "吧"는 추측을 나타낼 수 있습니다.

### 5. 感叹  /  gǎntàn  /  [동사 (v.)]  /  감탄하다
- 한자 풀이: 感(느낄 감) + 叹(탄식할 탄) → 느낌을 드러내다
- 例句: "啊"常表示感叹。
- Pinyin: "a" cháng biǎoshì gǎntàn.
- 번역: "啊"는 감탄을 자주 나타냅니다.

### 6. 生硬  /  shēngyìng  /  [형용사 (adj.)]  /  딱딱하다, 어색하다
- 한자 풀이: 生(날 생) + 硬(굳을 경) → 자연스럽지 않고 뻣뻣하다
- 例句: 不用语气词，说话就生硬。
- Pinyin: Bú yòng yǔqìcí, shuōhuà jiù shēngyìng.
- 번역: 어기사를 쓰지 않으면 말이 딱딱해집니다.

## 语法点 (어법 포인트)

### 1. "吗" — 의문문 만들기
- 你去吗？ Nǐ qù ma? 갈 거야?

### 2. "呢" — 되묻기·진행
- 你呢？ Nǐ ne? 너는? / 我吃饭呢。 Wǒ chīfàn ne. 나 밥 먹는 중이야.

### 3. "吧" — 제안·추측·동의
- 我们走吧。 Wǒmen zǒu ba. 우리 가자. / 大概是的吧。 Dàgài shì de ba. 아마 그럴 거야.

### 4. "啊"의 음변화 — 呀·哇·哪
- 好啊 hǎo a → hǎo wa / 来呀 lái ya / 看哪 kàn na

## 应用会话 (응용 회화 - 어기사)

A: 你下班了吗？  
   Nǐ xiàbān le ma?  
   퇴근했어요?

B: 还没呢，你呢？  
   Hái méi ne, nǐ ne?  
   아직이에요, 당신은요?

A: 我也没呢，一起吃饭吧。  
   Wǒ yě méi ne, yìqǐ chīfàn ba.  
   저도 아직이에요, 같이 밥 먹어요.

B: 好啊，去哪儿吃啊？  
   Hǎo a, qù nǎr chī a?  
   좋아요, 어디서 먹을까요?

A: 就楼下那家吧，味道不错。  
   Jiù lóu xià nà jiā ba, wèidào búcuò.  
   그냥 아래층 그 집 어때요, 맛이 괜찮아요.

B: 行，我们这就走啦。  
   Xíng, wǒmen zhè jiù zǒu la.  
   좋아요, 바로 가요.

A: 你真快呀！  
   Nǐ zhēn kuài ya!  
   정말 빠르네요!

B: 那当然啦。  
   Nà dāngrán la.  
   물론이죠.
