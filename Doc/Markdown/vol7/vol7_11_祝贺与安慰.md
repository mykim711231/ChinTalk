第 十 一 课 : 11. 祝贺与安慰 Zhùhè yǔ ānwèi (축하·위로)

## 本文 (본문)

恭喜你！  
Gōngxǐ nǐ!  
축하해요!

恭喜你通过了考试！  
Gōngxǐ nǐ tōngguò le kǎoshì!  
시험에 합격한 것을 축하해요!

祝你生日快乐！  
Zhù nǐ shēngrì kuàilè!  
생일 축하해요!

祝你新年快乐！  
Zhù nǐ xīnnián kuàilè!  
새해 복 많이 받으세요!

你太厉害了！  
Nǐ tài lìhai le!  
정말 대단해요!

别难过。  
Bié nánguò.  
너무 슬퍼하지 마세요.

别担心，一切都会好起来的。  
Bié dānxīn, yíqiè dōu huì hǎo qǐlái de.  
걱정 마세요, 모든 게 좋아질 거예요.

没关系，下次还有机会。  
Méi guānxi, xiàcì hái yǒu jīhuì.  
괜찮아요, 다음에 또 기회가 있어요.

我理解你的心情。  
Wǒ lǐjiě nǐ de xīnqíng.  
당신의 심정을 이해해요.

有什么我可以帮忙的吗？  
Yǒu shénme wǒ kěyǐ bāngmáng de ma?  
제가 도와드릴 일이 있나요?

---

## 主要词汇 (주요 단어)

### 1. 恭喜  /  gōngxǐ  /  [동사 (v.)]  /  축하하다
- 한자 풀이: 恭(공손할 공) + 喜(기쁠 희) → 공손하게 기쁨을 전하다
- 例句: 恭喜你考上了大学。
- Pinyin: Gōngxǐ nǐ kǎoshàng le dàxué.
- 번역: 대학에 합격한 것을 축하해요.

### 2. 祝贺  /  zhùhè  /  [동사 (v.)]  /  축하하다 (격식)
- 한자 풀이: 祝(빌 축) + 贺(하례할 하) → 공식적으로 축복을 전하다
- 例句: 我代表大家向你表示祝贺。
- Pinyin: Wǒ dàibiǎo dàjiā xiàng nǐ biǎoshì zhùhè.
- 번역: 모두를 대표해 당신에게 축하를 표합니다.

### 3. 安慰  /  ānwèi  /  [동사·명사 (v./n.)]  /  위로하다, 위로
- 한자 풀이: 安(편안할 안) + 慰(위로할 위) → 마음을 편안하게 위로하다
- 例句: 她难过的时候，朋友安慰她。
- Pinyin: Tā nánguò de shíhou, péngyou ānwèi tā.
- 번역: 그녀가 슬플 때 친구가 그녀를 위로한다.

### 4. 通过  /  tōngguò  /  [동사 (v.)]  /  통과하다, 합격하다
- 한자 풀이: 通(통할 통) + 过(지날 과) → 관문을 지나 통과하다
- 例句: 他通过了面试。
- Pinyin: Tā tōngguò le miànshì.
- 번역: 그는 면접을 통과했다.

### 5. 担心  /  dānxīn  /  [동사 (v.)]  /  걱정하다
- 한자 풀이: 担(맡을 담) + 心(마음 심) → 마음에 짐을 지다
- 例句: 别担心，我没事。
- Pinyin: Bié dānxīn, wǒ méi shì.
- 번역: 걱정 마, 나는 괜찮아.

### 6. 心情  /  xīnqíng  /  [명사 (n.)]  /  심정, 기분
- 한자 풀이: 心(마음 심) + 情(뜻 정) → 마음속의 감정 상태
- 例句: 我理解你现在的心情。
- Pinyin: Wǒ lǐjiě nǐ xiànzài de xīnqíng.
- 번역: 나는 지금 네 심정을 이해해.

## 语法点 (어법 포인트)

### 1. "恭喜 + 사람/사건" — 축하 표현
- 恭喜你！ Gōngxǐ nǐ! 축하해요!
- 恭喜你通过了考试。 Gōngxǐ nǐ tōngguò le kǎoshì. 시험 합격을 축하해요.

### 2. "祝 + 사람 + ..." — 기원 (~하시길 바랍니다)
- 祝你生日快乐。 Zhù nǐ shēngrì kuàilè. 생일 축하해요.
- 祝你新年快乐。 Zhù nǐ xīnnián kuàilè. 새해 복 많이 받으세요.

### 3. "别 + 동사/형용사" — 금지·위로 (하지 마세요)
- 别难过。 Bié nánguò. 슬퍼하지 마세요.
- 别担心。 Bié dānxīn. 걱정 마세요.

### 4. "会 + 동사 + 的" — 확신의 어조 (~할 거예요)
- 一切都会好起来的。 Yíqiè dōu huì hǎo qǐlái de. 모든 게 좋아질 거예요.

## 应用会话 (응용 회화 - 축하·위로)

A: 听说你考上了大学，恭喜你！  
   Tīngshuō nǐ kǎoshàng le dàxué, gōngxǐ nǐ!  
   대학에 합격했다며, 축하해!

B: 谢谢！我自己也没想到。  
   Xièxie! Wǒ zìjǐ yě méi xiǎngdào.  
   고마워! 나도 생각 못 했어.

A: 你真厉害，为你高兴。  
   Nǐ zhēn lìhai, wèi nǐ gāoxìng.  
   정말 대단해, 네 일이 기뻐.

B: 多亏了你的帮助。  
   Duōkuī le nǐ de bāngzhù.  
   네 도움이 컸어.

A: 别客气，这是你自己的努力。  
   Bié kèqi, zhè shì nǐ zìjǐ de nǔlì.  
   사양 마, 네 노력 덕분이야.

B: 对了，你上次没考好，别难过。  
   Duì le, nǐ shàngcì méi kǎohǎo, bié nánguò.  
   참, 너 지난번에 못 봤잖아, 슬퍼하지 마.

A: 没关系，我会继续努力的。  
   Méi guānxi, wǒ huì jìxù nǔlì de.  
   괜찮아, 계속 노력할 거야.

B: 好，下次一定行！  
   Hǎo, xiàcì yídìng xíng!  
   좋아, 다음엔 꼭 잘될 거야!
