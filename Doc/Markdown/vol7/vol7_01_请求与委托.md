第 一 课 : 01. 请求与委托 Qǐngqiú yǔ wěituō (요청·위임)

## 本文 (본문)

麻烦您一下，我想请您帮个忙。  
Máfan nín yíxià, wǒ xiǎng qǐng nín bāng ge máng.  
실례합니다, 잠깐 부탁 하나 드리고 싶어요.

能不能帮我一个忙？  
Néng bu néng bāng wǒ yí ge máng?  
저를 좀 도와주실 수 있나요?

可不可以替我把这份文件交给王经理？  
Kě bu kěyǐ tì wǒ bǎ zhè fèn wénjiàn jiāo gěi Wáng jīnglǐ?  
제 대신 이 서류를 왕 부장님께 전해 주시겠어요?

麻烦您替我转告一声。  
Máfan nín tì wǒ zhuǎngào yìshēng.  
제 대신 한마디 전해 주세요.

如果方便的话，请帮我订一张机票。  
Rúguǒ fāngbiàn de huà, qǐng bāng wǒ dìng yì zhāng jīpiào.  
가능하시다면 비행기표 한 장 예약해 주세요.

不知您是否方便帮我看看？  
Bù zhī nín shìfǒu fāngbiàn bāng wǒ kànkan?  
괜찮으시면 제 것을 좀 봐주시겠어요?

这件事就拜托您了。  
Zhè jiàn shì jiù bàituō nín le.  
이 일은 부탁드립니다.

请您放心，我一定尽力而为。  
Qǐng nín fàngxīn, wǒ yídìng jìnlì ér wéi.  
안심하세요, 제가 반드시 최선을 다하겠습니다.

交给我吧，包在我身上。  
Jiāo gěi wǒ ba, bāo zài wǒ shēnshang.  
제게 맡기세요, 제가 책임지겠습니다.

这事我帮您想办法。  
Zhè shì wǒ bāng nín xiǎng bànfǎ.  
이 일은 제가 방법을 찾아보겠습니다.

太感谢您了！  
Tài gǎnxiè nín le!  
정말 감사합니다!

多亏了您，真是帮了我大忙。  
Duōkuī le nín, zhēnshi bāng le wǒ dà máng.  
덕분입니다, 정말 큰 도움이 됐어요.

---

## 主要词汇 (주요 단어)

### 1. 拜托  /  bàituō  /  [동사 (v.)]  /  부탁하다, 부탁드리다
- 한자 풀이: 拜(절 배) + 托(부탁할 탁) → 정중하게 부탁하다
- 例句: 这件事就拜托您了。
- Pinyin: Zhè jiàn shì jiù bàituō nín le.
- 번역: 이 일은 부탁드립니다.

### 2. 麻烦  /  máfan  /  [동사·형용사 (v./adj.)]  /  폐를 끼치다, 번거롭다
- 한자 풀이: 麻(삼 마) + 烦(번거로울 번) → 번거롭게 하다
- 例句: 麻烦您帮我个忙。
- Pinyin: Máfan nín bāng wǒ ge máng.
- 번역: 부탁 하나 드리겠습니다.

### 3. 帮忙  /  bāngmáng  /  [동사 (v.)]  /  돕다, 도와주다
- 한자 풀이: 帮(도울 방) + 忙(바쁠 망) → 일을 돕다
- 例句: 能不能帮我一个忙？
- Pinyin: Néng bu néng bāng wǒ yí ge máng?
- 번역: 저를 좀 도와주실 수 있나요?

### 4. 方便  /  fāngbiàn  /  [형용사 (adj.)]  /  편리하다, 편하다
- 한자 풀이: 方(방법 방) + 便(편할 편) → 형편이 좋다
- 例句: 如果方便的话，请告诉我。
- Pinyin: Rúguǒ fāngbiàn de huà, qǐng gàosu wǒ.
- 번역: 가능하시다면 알려주세요.

### 5. 委托  /  wěituō  /  [동사 (v.)]  /  위임하다, 맡기다
- 한자 풀이: 委(맡길 위) + 托(부탁할 탁) → 일을 맡기다
- 例句: 他把这件事委托给我。
- Pinyin: Tā bǎ zhè jiàn shì wěituō gěi wǒ.
- 번역: 그는 이 일을 나에게 위임했다.

### 6. 尽力  /  jìnlì  /  [동사 (v.)]  /  힘을 다하다, 최선을 다하다
- 한자 풀이: 尽(다할 진) + 力(힘 력) → 힘을 다하다
- 例句: 我一定尽力而为。
- Pinyin: Wǒ yídìng jìnlì ér wéi.
- 번역: 반드시 최선을 다하겠습니다.

## 语法点 (어법 포인트)

### 1. "能/可以 + 동사" — 가능·허가 요청
- 能不能帮我一个忙？ Néng bu néng bāng wǒ yí ge máng? 저 좀 도와주시겠어요?
- 可不可以替我去一趟？ Kě bu kěyǐ tì wǒ qù yí tàng? 대신 좀 다녀와 주시겠어요?

### 2. "请 + 동사" — 정중한 요청
- 请您放心。 Qǐng nín fàngxīn. 안심하세요.
- 请帮我订一张票。 Qǐng bāng wǒ dìng yì zhāng piào. 표 한 장 예약해 주세요.

### 3. "把 + 목적어 + 동사" — 위임·처리의 표현
- 请把文件交给王经理。 Qǐng bǎ wénjiàn jiāo gěi Wáng jīnglǐ. 서류를 왕 부장님께 전해 주세요.

### 4. "如果……的话" — 정중한 가정 조건
- 如果方便的话，请帮我看看。 Rúguǒ fāngbiàn de huà, qǐng bāng wǒ kànkan. 가능하시다면 좀 봐주세요.

   Xiǎo Zhāng, máfan nǐ yíxià, xiànzài yǒu kòng ma?

B: 有空，您说。  
   Yǒu kòng, nín shuō.  
   있어요, 말씀하세요.

A: 能不能帮我一个忙？  
   Néng bu néng bāng wǒ yí ge máng?  
   저 좀 도와주실 수 있나요?

B: 当然可以，什么事？  
   Dāngrán kěyǐ, shénme shì?  
   물론이죠, 무슨 일인가요?

A: 麻烦您把这份文件交给王经理。  
   Máfan nín bǎ zhè fèn wénjiàn jiāo gěi Wáng jīnglǐ.  
   이 서류를 왕 부장님께 전해 주세요.

B: 没问题，交给我吧。  
   Méi wèntí, jiāo gěi wǒ ba.  
   문제없어요, 제게 맡기세요.

A: 这件事就拜托您了。  
   Zhè jiàn shì jiù bàituō nín le.  
   이 일은 부탁드립니다.

B: 您放心，我一定尽力而为。  
   Nín fàngxīn, wǒ yídìng jìnlì ér wéi.
