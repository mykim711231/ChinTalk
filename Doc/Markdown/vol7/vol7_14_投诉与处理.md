第 十 四 课 : 14. 投诉与处理 Tóusù yǔ chǔlǐ (불만·처리)

## 本文 (본문)

我要投诉。  
Wǒ yào tóusù.  
불만을 제기하겠습니다.

这件衣服有质量问题。  
Zhè jiàn yīfu yǒu zhìliàng wèntí.  
이 옷은 품질 문제가 있어요.

我买的商品有瑕疵。  
Wǒ mǎi de shāngpǐn yǒu xiácī.  
제가 산 상품에 하자가 있어요.

可以退货吗？  
Kěyǐ tuìhuò ma?  
반품할 수 있나요?

请出示您的发票。  
Qǐng chūshì nín de fāpiào.  
영수증을 제시해 주세요.

我们会尽快为您处理。  
Wǒmen huì jǐnkuài wèi nín chǔlǐ.  
저희가 최대한 빨리 처리해 드리겠습니다.

对不起，给您带来不便。  
Duìbuqǐ, gěi nín dàilái búbiàn.  
죄송합니다, 불편을 끼쳐 드렸습니다.

这是我们的责任。  
Zhè shì wǒmen de zérèn.  
이것은 저희 책임입니다.

我们同意全额退款。  
Wǒmen tóngyì quán'é tuìkuǎn.  
전액 환불에 동의합니다.

请问您还有什么问题吗？  
Qǐngwèn nín hái yǒu shénme wèntí ma?  
다른 문제가 있으신가요?

---

## 主要词汇 (주요 단어)

### 1. 投诉  /  tóusù  /  [동사 (v.)]  /  불만을 제기하다, 항의하다
- 한자 풀이: 投(던질 투) + 诉(하소연할 소) → 불만을 던져 알리다
- 例句: 顾客向商店投诉商品质量问题。
- Pinyin: Gùkè xiàng shāngdiàn tóusù shāngpǐn zhìliàng wèntí.
- 번역: 고객은 상점에 상품 품질 문제를 항의했다.

### 2. 处理  /  chǔlǐ  /  [동사 (v.)]  /  처리하다
- 한자 풀이: 处(처할 처) + 理(다스릴 리) → 사안을 다스리다
- 例句: 我们会尽快处理这个问题。
- Pinyin: Wǒmen huì jǐnkuài chǔlǐ zhège wèntí.
- 번역: 저희가 이 문제를 최대한 빨리 처리하겠습니다.

### 3. 质量  /  zhìliàng  /  [명사 (n.)]  /  품질
- 한자 풀이: 质(바탕 질) + 量(헤아릴 량) → 물건의 바탕과 수준
- 例句: 这批商品的质量很好。
- Pinyin: Zhè pī shāngpǐn de zhìliàng hěn hǎo.
- 번역: 이 상품들의 품질은 아주 좋다.

### 4. 瑕疵  /  xiácī  /  [명사 (n.)]  /  하자, 흠
- 한자 풀이: 瑕(티 하) + 疵(흠 자) → 옥에 난 작은 흠
- 例句: 这件衣服有一点瑕疵。
- Pinyin: Zhè jiàn yīfu yǒu yì diǎn xiácī.
- 번역: 이 옷은 하자가 좀 있다.

### 5. 退货  /  tuìhuò  /  [동사 (v.)]  /  반품하다
- 한자 풀이: 退(물러날 퇴) + 货(재화 화) → 물건을 되돌려 보내다
- 例句: 顾客要求退货。
- Pinyin: Gùkè yāoqiú tuìhuò.
- 번역: 고객은 반품을 요구했다.

### 6. 退款  /  tuìkuǎn  /  [동사·명사 (v./n.)]  /  환불하다, 환불
- 한자 풀이: 退(물러날 퇴) + 款(돈 관) → 돈을 되돌려 주다
- 例句: 我们同意给您全额退款。
- Pinyin: Wǒmen tóngyì gěi nín quán'é tuìkuǎn.
- 번역: 저희가 전액 환불해 드리기로 동의합니다.

|---|---|---|---|

## 语法点 (어법 포인트)

### 1. "我要 + 동사" — 강한 요구 (~하겠습니다)
- 我要投诉。 Wǒ yào tóusù. 불만을 제기하겠습니다.

### 2. "可以 + 동사 + 吗？" — 허락·가능 요청
- 可以退货吗？ Kěyǐ tuìhuò ma? 반품할 수 있나요?

### 3. "会 + 동사" — 약속·보증 (~해 드리겠다)
- 我们会尽快为您处理。 Wǒmen huì jǐnkuài wèi nín chǔlǐ. 저희가 최대한 빨리 처리해 드리겠습니다.

### 4. "给您带来不便" — 정중한 사과
- 对不起，给您带来不便。 Duìbuqǐ, gěi nín dàilái búbiàn. 죄송합니다, 불편을 끼쳐 드렸습니다.

## 应用会话 (응용 회화 - 불만·처리)

A: 你好，我要投诉。  
   Nǐ hǎo, wǒ yào tóusù.  
   안녕하세요, 불만을 제기하겠습니다.

B: 您好，请问有什么问题？  
   Nín hǎo, qǐngwèn yǒu shénme wèntí?  
   안녕하세요, 어떤 문제인가요?

A: 这件衣服有质量问题。  
   Zhè jiàn yīfu yǒu zhìliàng wèntí.  
   이 옷은 품질 문제가 있어요.

B: 请出示您的发票。  
   Qǐng chūshì nín de fāpiào.  
   영수증을 제시해 주세요.

A: 给您。  
   Gěi nín.  
   여기 있습니다.

B: 请问具体是什么问题？  
   Qǐngwèn jùtǐ shì shénme wèntí?  
   구체적으로 어떤 문제인가요?

A: 衣服掉色，还有瑕疵。  
   Yīfu diàosè, hái yǒu xiácī.  
   옷이 탈색되고 하자도 있어요.

B: 对不起，给您带来不便。  
   Duìbuqǐ, gěi nín dàilái búbiàn.  
   죄송합니다, 불편을 끼쳐 드렸습니다.

A: 可以退货吗？  
   Kěyǐ tuìhuò ma?  
   반품할 수 있나요?

B: 可以，我们为您全额退款。  
   Kěyǐ, wǒmen wèi nín quán'é tuìkuǎn.  
   가능합니다, 전액 환불해 드리겠습니다.

A: 好的，谢谢。  
   Hǎo de, xièxie.  
   알겠습니다, 감사합니다.
