第 五 课 : 05. 批评与建议 Pīpíng yǔ jiànyì (지적·제안)

## 本文 (본문)

我提个建议，好吗？  
Wǒ tí ge jiànyì, hǎo ma?  
제안 하나 드려도 될까요?

我觉得这样做不太合适。  
Wǒ juéde zhèyàng zuò bú tài héshì.  
이렇게 하는 건 적절하지 않은 것 같아요.

您不妨换个角度想一想。  
Nín bùfáng huàn ge jiǎodù xiǎng yi xiǎng.  
다른 각도에서 생각해 보시는 게 어떨까요.

建议您先考虑清楚再决定。  
Jiànyì nín xiān kǎolǜ qīngchu zài juédìng.  
먼저 충분히 생각하신 뒤 결정하시길 권합니다.

这里是不是可以再改一改？  
Zhèlǐ shì bu shì kěyǐ zài gǎi yì gǎi?  
여기는 좀 더 고칠 수 있지 않을까요?

依我看，这个问题得早点解决。  
Yī wǒ kàn, zhè ge wèntí děi zǎo diǎn jiějué.  
제 생각엔 이 문제는 빨리 해결해야 합니다.

如果我是您，我就会重新考虑。  
Rúguǒ wǒ shì nín, wǒ jiù huì chóngxīn kǎolǜ.  
제가 당신이라면 다시 생각해 볼 것 같습니다.

我不是批评您，只是提个醒。  
Wǒ bú shì pīpíng nín, zhǐshì tí ge xǐng.  
비판하려는 게 아니라, 그냥 일깨워 드리는 겁니다.

您这么做可能会引起误会。  
Nín zhème zuò kěnéng huì yǐnqǐ wùhuì.  
그렇게 하시면 오해를 불러올 수 있습니다.

恕我直言，这样恐怕行不通。  
Shù wǒ zhíyán, zhèyàng kǒngpà xíng bu tōng.  
솔직히 말씀드리면, 이렇게는 아마 통하지 않을 겁니다.

我有一个不成熟的想法，仅供参考。  
Wǒ yǒu yí ge bù chéngshú de xiǎngfǎ, jǐn gōng cānkǎo.  
미숙한 생각 하나가 있는데, 참고만 하세요.

您的意见很宝贵，我会认真考虑。  
Nín de yìjiàn hěn bǎoguì, wǒ huì rènzhēn kǎolǜ.  
의견 정말 소중합니다, 진지하게 검토하겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 批评  /  pīpíng  /  [동사 (v.)]  /  비판하다, 지적하다
- 한자 풀이: 批(칠 비) + 评(평할 평) → 잘잘못을 평하다
- 例句: 我不是批评您，只是提个醒。
- Pinyin: Wǒ bú shì pīpíng nín, zhǐshì tí ge xǐng.
- 번역: 비판하려는 게 아니라, 그냥 일깨워 드리는 겁니다.

### 2. 建议  /  jiànyì  /  [동사·명사 (v./n.)]  /  제안하다, 제안
- 한자 풀이: 建(세울 건) + 议(의논할 의) → 의견을 세우다
- 例句: 我提个建议，好吗？
- Pinyin: Wǒ tí ge jiànyì, hǎo ma?
- 번역: 제안 하나 드려도 될까요?

### 3. 不妨  /  bùfáng  /  [부사 (adv.)]  /  ~하는 편이 낫다
- 한자 풀이: 不(아닐 불) + 妨(거리낄 방) → 해도 무방하다
- 例句: 您不妨换个角度想一想。
- Pinyin: Nín bùfáng huàn ge jiǎodù xiǎng yi xiǎng.
- 번역: 다른 각도에서 생각해 보시는 게 어떨까요.

### 4. 提醒  /  tíxǐng  /  [동사 (v.)]  /  일깨우다, 주의시키다
- 한자 풀이: 提(들 제) + 醒(깰 성) → 깨우쳐 주다
- 例句: 谢谢您提醒我。
- Pinyin: Xièxie nín tíxǐng wǒ.
- 번역: 일깨워 주셔서 감사합니다.

### 5. 参考  /  cānkǎo  /  [동사 (v.)]  /  참고하다
- 한자 풀이: 参(참여할 참) + 考(생각할 고) → 참고로 살피다
- 例句: 这个方案可以参考。
- Pinyin: Zhè ge fāng'àn kěyǐ cānkǎo.
- 번역: 이 방안은 참고할 만합니다.

### 6. 意见  /  yìjiàn  /  [명사 (n.)]  /  의견
- 한자 풀이: 意(뜻 의) + 见(볼 견) → 보는 바, 견해
- 例句: 您的意见很宝贵。
- Pinyin: Nín de yìjiàn hěn bǎoguì.
- 번역: 의견이 정말 소중합니다.

## 语法点 (어법 포인트)

### 1. "不妨 + 동사" — 완곡한 제안
- 您不妨换个角度想一想。 Nín bùfáng huàn ge jiǎodù xiǎng yi xiǎng. 다른 각도로 생각해 보시는 게 어떨까요.

### 2. "是不是可以……？" — 조심스러운 제안
- 这里是不是可以再改一改？ Zhèlǐ shì bu shì kěyǐ zài gǎi yì gǎi? 여기는 좀 더 고칠 수 있지 않을까요?

### 3. "依我看……" — 의견 제시
- 依我看，这个问题得早点解决。 Yī wǒ kàn, zhè ge wèntí děi zǎo diǎn jiějué. 제 생각엔 이 문제는 빨리 해결해야 합니다.

### 4. "恕我直言" — 직언의 완충 (부정적 평가 완화)
- 恕我直言，这样恐怕行不通。 Shù wǒ zhíyán, zhèyàng kǒngpà xíng bu tōng. 솔직히 말씀드리면 이렇게는 아마 통하지 않을 겁니다.

## 应用会话 (응용 회화 - 지적과 제안)

A: 王经理，我提个建议，好吗？  
   Wáng jīnglǐ, wǒ tí ge jiànyì, hǎo ma?  
   왕 부장님, 제안 하나 드려도 될까요?

B: 请讲。  
   Qǐng jiǎng.  
   말씀하세요.

A: 我觉得这个方案的时间安排不太合理。  
   Wǒ juéde zhè ge fāng'àn de shíjiān ānpái bú tài hélǐ.  
   이 방안의 일정 배분이 좀 비합리적인 것 같습니다.

B: 那您有什么建议？  
   Nà nín yǒu shénme jiànyì?  
   그럼 어떤 제안이 있으세요?

A: 您不妨把期限往后推一周。  
   Nín bùfáng bǎ qīxiàn wǎng hòu tuī yì zhōu.  
   기한을 일주일 뒤로 미뤄 보시는 게 어떨까요.

B: 这个提议有道理。  
   Zhè ge tíyì yǒu dàolǐ.  
   그 제안은 일리가 있네요.

A: 我不是批评，只是提个醒。  
   Wǒ bú shì pīpíng, zhǐshì tí ge xǐng.  
   비판하려는 게 아니라, 그냥 일깨워 드리는 겁니다.

B: 谢谢您的意见，我会认真考虑。  
   Xièxie nín de yìjiàn, wǒ huì rènzhēn kǎolǜ.  
   의견 감사합니다, 진지하게 검토하겠습니다.
