第 十 五 课 : 15. 指令与安排 Zhǐlìng yǔ ānpái (지시·배정)

## 本文 (본문)

请大家安静一下。  
Qǐng dàjiā ānjìng yíxià.  
여러분 잠시 조용히 해 주세요.

请大家按照顺序排队。  
Qǐng dàjiā ànzhào shùnxù páiduì.  
순서대로 줄을 서 주세요.

明天八点准时集合。  
Míngtiān bā diǎn zhǔnshí jíhé.  
내일 8시 정각에 집합하세요.

每个人带好身份证。  
Měi gè rén dài hǎo shēnfènzhèng.  
각자 신분증을 챙기세요.

你负责整理资料。  
Nǐ fùzé zhěnglǐ zīliào.  
네가 자료 정리를 맡아라.

小张负责联系客户。  
Xiǎo Zhāng fùzé liánxì kèhù.  
샤오장은 고객 연락을 맡아라.

请大家按照要求完成任务。  
Qǐng dàjiā ànzhào yāoqiú wánchéng rènwù.  
요구대로 임무를 완수하세요.

有问题请及时报告。  
Yǒu wèntí qǐng jíshí bàogào.  
문제가 있으면 즉시 보고하세요.

这件事由你全权负责。  
Zhè jiàn shì yóu nǐ quánquán fùzé.  
이 일은 네가 전적으로 책임진다.

大家辛苦一下，抓紧时间。  
Dàjiā xīnkǔ yíxià, zhuājǐn shíjiān.  
여러분 수고 좀 해서 시간을 서두릅시다.

---

## 主要词汇 (주요 단어)

### 1. 指令  /  zhǐlìng  /  [명사 (n.)]  /  지시, 명령
- 한자 풀이: 指(가리킬 지) + 令(명령 령) → 가리켜 명령하다
- 例句: 请按照指令执行。
- Pinyin: Qǐng ànzhào zhǐlìng zhíxíng.
- 번역: 지시에 따라 실행하세요.

### 2. 安排  /  ānpái  /  [동사·명사 (v./n.)]  /  배정하다, 안배
- 한자 풀이: 安(편안할 안) + 排(벌일 배) → 질서 있게 벌여 놓다
- 例句: 请合理安排时间。
- Pinyin: Qǐng hélǐ ānpái shíjiān.
- 번역: 시간을 합리적으로 배정하세요.

### 3. 负责  /  fùzé  /  [동사 (v.)]  /  책임지다, 담당하다
- 한자 풀이: 负(질 부) + 责(책임 책) → 책임을 지다
- 例句: 他负责这个项目。
- Pinyin: Tā fùzé zhège xiàngmù.
- 번역: 그가 이 프로젝트를 담당한다.

### 4. 按照  /  ànzhào  /  [개사 (prep.)]  /  ~에 따라
- 한자 풀이: 按(누를 안) + 照(비출 조) → 기준에 비추어 따르다
- 例句: 请按照说明书操作。
- Pinyin: Qǐng ànzhào shuōmíngshū cāozuò.
- 번역: 설명서에 따라 조작하세요.

### 5. 集合  /  jíhé  /  [동사 (v.)]  /  집합하다
- 한자 풀이: 集(모일 집) + 合(합할 합) → 한데 모이다
- 例句: 明天早上八点在学校门口集合。
- Pinyin: Míngtiān zǎoshang bā diǎn zài xuéxiào ménkǒu jíhé.
- 번역: 내일 아침 8시에 학교 정문에서 집합하세요.

### 6. 报告  /  bàogào  /  [동사·명사 (v./n.)]  /  보고하다, 보고
- 한자 풀이: 报(알릴 보) + 告(고할 고) → 사실을 알려 말하다
- 例句: 发现问题请立即报告。
- Pinyin: Fāxiàn wèntí qǐng lìjí bàogào.
- 번역: 문제를 발견하면 즉시 보고하세요.

## 语法点 (어법 포인트)

### 1. "请 + 대중 + 동사" — 정중한 지시
- 请大家安静一下。 Qǐng dàjiā ānjìng yíxià. 여러분 잠시 조용히 해 주세요.
- 请大家按照顺序排队。 Qǐng dàjiā ànzhào shùnxù páiduì. 순서대로 줄을 서 주세요.

### 2. "按照 + 명사 + 동사" — 기준 제시 (~에 따라)
- 请大家按照要求完成任务。 Qǐng dàjiā ànzhào yāoqiú wánchéng rènwù. 요구대로 임무를 완수하세요.

### 3. "由 + 사람 + 负责" — 책임 소재 (~가 담당하다)
- 这件事由你全权负责。 Zhè jiàn shì yóu nǐ quánquán fùzé. 이 일은 네가 전적으로 책임진다.

### 4. "准时 / 及时" — 시간 부사
- 明天八点准时集合。 Míngtiān bā diǎn zhǔnshí jíhé. 내일 8시 정각에 집합하세요.
- 有问题请及时报告。 Yǒu wèntí qǐng jíshí bàogào. 문제가 있으면 즉시 보고하세요.

## 应用会话 (응용 회화 - 지시·배정)

A: 请大家注意，明天有活动。  
   Qǐng dàjiā zhùyì, míngtiān yǒu huódòng.  
   여러분 주목하세요, 내일 행사가 있습니다.

B: 几点集合？  
   Jǐ diǎn jíhé?  
   몇 시에 집합하나요?

A: 明天八点准时集合。  
   Míngtiān bā diǎn zhǔnshí jíhé.  
   내일 8시 정각에 집합하세요.

B: 需要带什么？  
   Xūyào dài shénme?  
   무엇을 가져가야 하나요?

A: 每个人带好身份证。  
   Měi gè rén dài hǎo shēnfènzhèng.  
   각자 신분증을 챙기세요.

B: 明白了，谁负责联系客户？  
   Míngbai le, shéi fùzé liánxì kèhù?  
   알겠습니다, 누가 고객 연락을 담당하나요?

A: 小张负责联系客户。  
   Xiǎo Zhāng fùzé liánxì kèhù.  
   샤오장이 고객 연락을 담당합니다.

B: 有问题怎么办？  
   Yǒu wèntí zěnme bàn?  
   문제가 생기면 어떻게 하나요?

A: 有问题请及时报告。  
   Yǒu wèntí qǐng jíshí bàogào.  
   문제가 있으면 즉시 보고하세요.

B: 好的，我们按照要求完成任务。  
   Hǎo de, wǒmen ànzhào yāoqiú wánchéng rènwù.  
   알겠습니다, 요구대로 임무를 완수하겠습니다.
