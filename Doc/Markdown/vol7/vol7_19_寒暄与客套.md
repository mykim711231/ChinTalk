第 十九 课 : 19. 寒暄与客套 Hánxuān yǔ kètào (인사치레·겸사)

## 本文 (본문)

好久不见，您还是老样子。  
Hǎojiǔ bú jiàn, nín háishi lǎo yàngzi.  
오랜만입니다, 그대로시네요.

哪里哪里，您过奖了。  
Nǎli nǎli, nín guòjiǎng le.  
별말씀을요, 과찬이십니다.

这次多亏了您帮忙。  
Zhè cì duōkuī le nín bāngmáng.  
이번엔 정말 덕분에 도움을 받았습니다.

小事一桩，不足挂齿。  
Xiǎo shì yì zhuāng, bùzú guàchǐ.  
별거 아닙니다, 입에 올릴 것도 못 됩니다.

让您破费了，真不好意思。  
Ràng nín pòfèi le, zhēn bù hǎoyìsi.  
돈을 쓰시게 해서 정말 죄송합니다.

您太客气了，招待不周，请多包涵。  
Nín tài kèqi le, zhāodài bù zhōu, qǐng duō bāohán.  
너무 겸손하십니다, 대접이 부족하니 너그러이 봐 주세요.

今天真是打扰您了。  
Jīntiān zhēnshi dǎrǎo nín le.  
오늘 정말 폐를 끼쳤습니다.

有空常来坐坐。  
Yǒu kòng cháng lái zuòzuo.  
시간 나실 때 자주 들러 주세요.

---

## 主要词汇 (주요 단어)

### 1. 寒暄  /  hánxuān  /  [동사·명사 (v./n.)]  /  인사말을 나누다, 안부 인사
- 한자 풀이: 寒(찰 한) + 暄(따뜻할 훤) → 춥다 덥다 안부를 묻다
- 例句: 他们见面先寒暄了几句。
- Pinyin: Tāmen jiànmiàn xiān hánxuān le jǐ jù.
- 번역: 그들은 만나서 먼저 안부 인사를 몇 마디 나눴습니다.

### 2. 客套  /  kètào  /  [명사·동사 (n./v.)]  /  겸사, 예의상 인사말
- 한자 풀이: 客(손님 객) + 套(틀 투) → 손님 대접용 말투
- 例句: 咱们之间别客套。
- Pinyin: Zánmen zhījiān bié kètào.
- 번역: 우리 사이에 겸사는 하지 맙시다.

### 3. 过奖  /  guòjiǎng  /  [동사 (v.)]  /  과찬하다
- 한자 풀이: 过(지날 과) + 奖(칭찬할 장) → 지나치게 칭찬하다
- 例句: 您过奖了。
- Pinyin: Nín guòjiǎng le.
- 번역: 과찬이십니다.

### 4. 破费  /  pòfèi  /  [동사 (v.)]  /  돈을 쓰다, (남에게) 돈을 쓰게 하다
- 한자 풀이: 破(깨뜨릴 파) + 费(쓸 비) → 지갑을 깨서 쓰다
- 例句: 又让您破费了。
- Pinyin: Yòu ràng nín pòfèi le.
- 번역: 또 돈을 쓰시게 했네요.

### 5. 包涵  /  bāohán  /  [동사 (v.)]  /  너그럽게 이해하다
- 한자 풀이: 包(쌀 포) + 涵(젖을 함) → 감싸서 용서하다
- 例句: 招待不周，请多包涵。
- Pinyin: Zhāodài bù zhōu, qǐng duō bāohán.
- 번역: 대접이 부족하니 너그러이 봐 주세요.

### 6. 打扰  /  dǎrǎo  /  [동사 (v.)]  /  방해하다, 폐를 끼치다
- 한자 풀이: 打(칠 타) + 扰(어지러울 요) → 어지럽게 하다
- 例句: 不好意思，打扰您了。
- Pinyin: Bù hǎoyìsi, dǎrǎo nín le.
- 번역: 죄송합니다, 폐를 끼쳤습니다.

## 语法点 (어법 포인트)

### 1. "哪里哪里" — 겸손한 부정
- 哪里哪里，您过奖了。 Nǎli nǎli, nín guòjiǎng le. 별말씀을요, 과찬이십니다.

### 2. "多亏了 + 사람/것" — 덕분에
- 多亏了您帮忙。 Duōkuī le nín bāngmáng. 당신 도움 덕분입니다.
- 多亏了这场雨。 Duōkuī le zhè chǎng yǔ. 이 비 덕분입니다.

### 3. "让您 + 동사" — (상대에게) ~하게 하다
- 让您破费了。 Ràng nín pòfèi le. 돈을 쓰시게 했습니다.
- 让您久等了。 Ràng nín jiǔ děng le. 오래 기다리게 했습니다.

### 4. "有空 + 동사" — 시간이 나면 ~하다
- 有空常来坐坐。 Yǒu kòng cháng lái zuòzuo. 시간 날 때 자주 오세요.
- 有空一起吃个饭。 Yǒu kòng yìqǐ chī ge fàn. 시간 나면 같이 밥 먹어요.

## 应用会话 (응용 회화 - 인사치레·겸사)

A: 好久不见，最近身体怎么样？  
   Hǎojiǔ bú jiàn, zuìjìn shēntǐ zěnmeyàng?  
   오랜만이에요, 요즘 건강은 어떠세요?

B: 托您的福，一切都好。您呢？  
   Tuō nín de fú, yíqiè dōu hǎo. Nín ne?  
   덕분에 다 좋습니다. 당신은요?

A: 我也挺好。这次多亏了您帮忙。  
   Wǒ yě tǐng hǎo. Zhè cì duōkuī le nín bāngmáng.  
   저도 괜찮아요. 이번엔 정말 덕분에 도움을 받았어요.

B: 小事一桩，不足挂齿。  
   Xiǎo shì yì zhuāng, bùzú guàchǐ.  
   별거 아닙니다, 입에 올릴 것도 못 됩니다.

A: 今天让您破费了，真不好意思。  
   Jīntiān ràng nín pòfèi le, zhēn bù hǎoyìsi.  
   오늘 돈을 쓰시게 해서 정말 죄송해요.

B: 您太客气了，招待不周，请多包涵。  
   Nín tài kèqi le, zhāodài bù zhōu, qǐng duō bāohán.  
   너무 겸손하세요, 대접이 부족하니 너그러이 봐 주세요.

A: 那我先告辞了，打扰您了。  
   Nà wǒ xiān gàocí le, dǎrǎo nín le.  
   그럼 먼저 실례하겠습니다, 폐를 끼쳤어요.

B: 慢走，有空常来坐坐。  
   Màn zǒu, yǒu kòng cháng lái zuòzuo.  
   조심히 가세요, 시간 날 때 자주 들러 주세요.
