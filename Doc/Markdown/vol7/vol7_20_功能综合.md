第 二十 课 : 20. 功能综合 Gōngnéng zōnghé (기능 종합)

## 本文 (본문)

您好，请问您是王经理吗？  
Nín hǎo, qǐngwèn nín shì Wáng jīnglǐ ma?  
안녕하세요, 실례지만 왕 매니저이신가요?

是的，我就是。您是哪位？  
Shì de, wǒ jiù shì. Nín shì nǎ wèi?  
네, 제가 맞습니다. 누구신가요?

我是小李，麻烦您核对一下合同。  
Wǒ shì Xiǎo Lǐ, máfan nín héduì yíxià hétong.  
저는 샤오리입니다, 계약서를 확인해 주세요.

没问题，我保证今天下午给您答复。  
Méi wèntí, wǒ bǎozhèng jīntiān xiàwǔ gěi nín dáfù.  
문제없습니다, 오늘 오후에 답변드리겠다고 보증합니다.

您先别急，我们心平气和地商量。  
Nín xiān bié jí, wǒmen xīnpíng qìhé de shāngliang.  
급해하지 마시고, 우리 차분히 상의합시다.

多亏您提醒，不然我就忘了。  
Duōkuī nín tíxǐng, bùrán wǒ jiù wàng le.  
일깨워 주신 덕분입니다, 아니었으면 잊을 뻔했어요.

哪里哪里，这是应该做的。  
Nǎli nǎli, zhè shì yīnggāi zuò de.  
별말씀을요, 당연히 해야 할 일이지요.

那我们就这么说定了，按时办。  
Nà wǒmen jiù zhème shuō dìng le, ànshí bàn.  
그럼 이렇게 약속하고, 제시간에 처리합시다.

## 主要词汇 (주요 단어)

### 1. 综合  /  zōnghé  /  [동사·형용사 (v./adj.)]  /  종합하다, 종합적인
- 한자 풀이: 综(모을 종) + 合(합할 합) → 모아 합치다
- 例句: 这课是功能综合练习。
- Pinyin: Zhè kè shì gōngnéng zōnghé liànxí.
- 번역: 이 과는 기능 종합 연습입니다.

### 2. 经理  /  jīnglǐ  /  [명사 (n.)]  /  매니저, 지배인
- 한자 풀이: 经(다스릴 경) + 理(다스릴 리) → 일을 맡아 다스리는 사람
- 例句: 王经理在开会。
- Pinyin: Wáng jīnglǐ zài kāihuì.
- 번역: 왕 매니저는 회의 중입니다.

### 3. 合同  /  hétong  /  [명사 (n.)]  /  계약서
- 한자 풀이: 合(합할 합) + 同(한가지 동) → 서로 같게 하다
- 例句: 请核对一下合同内容。
- Pinyin: Qǐng héduì yíxià hétong nèiróng.
- 번역: 계약서 내용을 확인해 주세요.

### 4. 答复  /  dáfù  /  [동사·명사 (v./n.)]  /  답변하다, 답변
- 한자 풀이: 答(대답할 답) + 复(회답할 복) → 대답하다
- 例句: 请尽快给我答复。
- Pinyin: Qǐng jǐnkuài gěi wǒ dáfù.
- 번역: 빨리 답변해 주세요.

### 5. 商量  /  shāngliang  /  [동사 (v.)]  /  상의하다
- 한자 풀이: 商(헤아릴 상) + 量(헤아릴 량) → 서로 의논하다
- 例句: 这件事我们商量一下。
- Pinyin: Zhè jiàn shì wǒmen shāngliang yíxià.
- 번역: 이 일을 우리 상의해 봅시다.

### 6. 提醒  /  tíxǐng  /  [동사 (v.)]  /  일깨워 주다, 상기시키다
- 한자 풀이: 提(끌 제) + 醒(깰 성) → 끌어내어 깨우다
- 例句: 谢谢您提醒我。
- Pinyin: Xièxie nín tíxǐng wǒ.
- 번역: 일깨워 주셔서 감사합니다.

## 语法点 (어법 포인트)

### 1. "请问……吗？" — 정중한 질문
- 请问您是王经理吗？ Qǐngwèn nín shì Wáng jīnglǐ ma? 실례지만 왕 매니저이신가요?

### 2. "保证 + 시간 + 동사" — 언제까지 할 것을 보증
- 我保证今天下午给您答复。 Wǒ bǎozhèng jīntiān xiàwǔ gěi nín dáfù. 오늘 오후에 답변드릴 것을 보증합니다.

### 3. "多亏……不然就……" — 덕분에, 아니었으면 ~했다
- 多亏您提醒，不然我就忘了。 Duōkuī nín tíxǐng, bùrán wǒ jiù wàng le. 일깨워 주신 덕분입니다, 아니었으면 잊었을 거예요.

### 4. "这么说定了" — 이렇게 약속하다
- 那我们就这么说定了。 Nà wǒmen jiù zhème shuō dìng le. 그럼 이렇게 약속합시다.

## 应用会话 (응용 회화 - 기능 종합)

A: 您好，请问您是负责这个项目的王经理吗？  
   Nín hǎo, qǐngwèn nín shì fùzé zhège xiàngmù de Wáng jīnglǐ ma?  
   안녕하세요, 실례지만 이 프로젝트를 맡으신 왕 매니저이신가요?

B: 是的，我就是。请问有什么事？  
   Shì de, wǒ jiù shì. Qǐngwèn yǒu shénme shì?  
   네, 제가 맞습니다. 무슨 일이신가요?

A: 麻烦您核对一下这份合同的日期。  
   Máfan nín héduì yíxià zhè fèn hétong de rìqī.  
   번거롭지만 이 계약서의 날짜를 확인해 주세요.

B: 没问题，我保证明天上午给您答复。  
   Méi wèntí, wǒ bǎozhèng míngtiān shàngwǔ gěi nín dáfù.  
   문제없습니다, 내일 오전에 답변드리겠습니다.

A: 我们别争了，心平气和地商量一下价格吧。  
   Wǒmen bié zhēng le, xīnpíng qìhé de shāngliang yíxià jiàgé ba.  
   우리 그만 다투고, 차분히 가격을 상의해 봅시다.

B: 好，多亏您提醒，不然我就忘了这回事。  
   Hǎo, duōkuī nín tíxǐng, bùrán wǒ jiù wàng le zhè huí shì.  
   좋아요, 일깨워 주셔서 다행입니다, 아니었으면 이 일을 잊을 뻔했어요.

A: 哪里哪里，这是应该做的。  
   Nǎli nǎli, zhè shì yīnggāi zuò de.  
   별말씀을요, 당연히 해야 할 일입니다.

B: 那我们就这么说定了，一定按时办。  
   Nà wǒmen jiù zhème shuō dìng le, yídìng ànshí bàn.  
   그럼 이렇게 약속하고, 반드시 제시간에 처리합시다.
