第 十 三 课 : 13. 咨询与解答 Zīxún yǔ jiědá (상담·해답)

## 本文 (본문)

我想咨询一下。  
Wǒ xiǎng zīxún yíxià.  
잠시 상담하고 싶어요.

请问，这个课程怎么报名？  
Qǐngwèn, zhège kèchéng zěnme bàomíng?  
실례합니다, 이 강좌는 어떻게 신청하나요?

我想了解一下详细情况。  
Wǒ xiǎng liǎojiě yíxià xiángxì qíngkuàng.  
자세한 상황을 좀 알고 싶어요.

报名需要哪些材料？  
Bàomíng xūyào nǎxiē cáiliào?  
신청에 어떤 서류가 필요한가요?

需要带身份证和照片。  
Xūyào dài shēnfènzhèng hé zhàopiàn.  
신분증과 사진을 지참해야 합니다.

报名费是多少？  
Bàomíngfèi shì duōshao?  
신청비는 얼마인가요?

一共两百块。  
Yígòng liǎngbǎi kuài.  
모두 200위안입니다.

有什么问题请随时问我。  
Yǒu shénme wèntí qǐng suíshí wèn wǒ.  
궁금한 점이 있으면 언제든 물어보세요.

请问，几点截止？  
Qǐngwèn, jǐ diǎn jiézhǐ?  
실례합니다, 몇 시에 마감인가요?

好的，我明白了，谢谢。  
Hǎo de, wǒ míngbai le, xièxie.  
알겠습니다, 감사합니다.

---

## 主要词汇 (주요 단어)

### 1. 咨询  /  zīxún  /  [동사 (v.)]  /  상담하다, 문의하다
- 한자 풀이: 咨(물을 자) + 询(물을 순) → 물어서 알아보다
- 例句: 我想咨询一下课程安排。
- Pinyin: Wǒ xiǎng zīxún yíxià kèchéng ānpái.
- 번역: 강좌 일정을 좀 문의하고 싶어요.

### 2. 解答  /  jiědá  /  [동사·명사 (v./n.)]  /  해답하다, 풀이
- 한자 풀이: 解(풀 해) + 答(대답할 답) → 풀어서 답하다
- 例句: 老师耐心地解答学生的问题。
- Pinyin: Lǎoshī nàixīn de jiědá xuésheng de wèntí.
- 번역: 선생님은 인내심 있게 학생의 질문에 답한다.

### 3. 报名  /  bàomíng  /  [동사 (v.)]  /  신청하다, 등록하다
- 한자 풀이: 报(알릴 보) + 名(이름 명) → 이름을 올려 신청하다
- 例句: 我已经报名参加了培训班。
- Pinyin: Wǒ yǐjīng bàomíng cānjiā le péixùnbān.
- 번역: 나는 이미 연수반에 신청했다.

### 4. 详细  /  xiángxì  /  [형용사 (adj.)]  /  상세하다
- 한자 풀이: 详(자세할 상) + 细(가늘 세) → 세밀하고 자세하다
- 例句: 请详细说明一下情况。
- Pinyin: Qǐng xiángxì shuōmíng yíxià qíngkuàng.
- 번역: 상황을 자세히 설명해 주세요.

### 5. 材料  /  cáiliào  /  [명사 (n.)]  /  서류, 자료
- 한자 풀이: 材(재목 재) + 料(재료 료) → 필요한 서류와 자료
- 例句: 报名需要准备哪些材料？
- Pinyin: Bàomíng xūyào zhǔnbèi nǎxiē cáiliào?
- 번역: 신청에 어떤 서류를 준비해야 하나요?

### 6. 截止  /  jiézhǐ  /  [동사 (v.)]  /  마감하다
- 한자 풀이: 截(끊을 절) + 止(그칠 지) → 끊어서 멈추다
- 例句: 报名截止到本周五。
- Pinyin: Bàomíng jiézhǐ dào běnzhōuwǔ.
- 번역: 신청은 이번 주 금요일에 마감됩니다.

## 语法点 (어법 포인트)

### 1. "想 + 동사 + 一下" — 가볍게 시도 (~해 보다)
- 我想咨询一下。 Wǒ xiǎng zīxún yíxià. 잠시 상담하고 싶어요.
- 我想了解一下。 Wǒ xiǎng liǎojiě yíxià. 좀 알아보고 싶어요.

### 2. "请问……" — 공손한 질문 도입
- 请问，这个课程怎么报名？ Qǐngwèn, zhège kèchéng zěnme bàomíng? 실례합니다, 이 강좌는 어떻게 신청하나요?

### 3. "怎么 / 多少" — 의문사 질문
- 怎么报名？ Zěnme bàomíng? 어떻게 신청하나요?
- 报名费是多少？ Bàomíngfèi shì duōshao? 신청비는 얼마인가요?

### 4. "请 + 동사" — 정중한 요청
- 请随时问我。 Qǐng suíshí wèn wǒ. 언제든 물어보세요.

## 应用会话 (응용 회화 - 상담·해답)

A: 您好，我想咨询一下英语课程。  
   Nín hǎo, wǒ xiǎng zīxún yíxià Yīngyǔ kèchéng.  
   안녕하세요, 영어 강좌를 좀 문의하고 싶어요.

B: 好的，请问您想了解什么？  
   Hǎo de, qǐngwèn nín xiǎng liǎojiě shénme?  
   네, 무엇을 알고 싶으세요?

A: 这个课程怎么报名？  
   Zhège kèchéng zěnme bàomíng?  
   이 강좌는 어떻게 신청하나요?

B: 先填写报名表，再交报名费。  
   Xiān tiánxiě bàomíngbiǎo, zài jiāo bàomíngfèi.  
   먼저 신청서를 작성하고 신청비를 내면 됩니다.

A: 报名需要哪些材料？  
   Bàomíng xūyào nǎxiē cáiliào?  
   신청에 어떤 서류가 필요한가요?

B: 需要身份证和两张照片。  
   Xūyào shēnfènzhèng hé liǎng zhāng zhàopiàn.  
   신분증과 사진 두 장이 필요합니다.

A: 报名费是多少？  
   Bàomíngfèi shì duōshao?  
   신청비는 얼마인가요?

B: 一共两百块。  
   Yígòng liǎngbǎi kuài.  
   모두 200위안입니다.

A: 好的，我明白了，谢谢您。  
   Hǎo de, wǒ míngbai le, xièxie nín.  
   알겠습니다, 감사합니다.
