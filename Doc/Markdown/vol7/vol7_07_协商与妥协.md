第 七 课 : 07. 协商与妥协 Xiéshāng yǔ tuǒxié (협의·타협)

## 本文 (본문)

我们商量一下这件事怎么解决吧。  
Wǒmen shāngliang yíxià zhè jiàn shì zěnme jiějué ba.  
우리 이 일을 어떻게 해결할지 상의해 보자.

你有什么想法？  
Nǐ yǒu shénme xiǎngfǎ?  
너는 무슨 생각이 있어?

我觉得这个方案不太合适。  
Wǒ juéde zhège fāng'àn bú tài héshì.  
내 생각엔 이 방안은 그다지 적절하지 않아.

价格方面能不能再便宜一点儿？  
Jiàgé fāngmiàn néng bu néng zài piányi yìdiǎnr?  
가격 면에서 좀 더 싸게 해 주실 수 없을까요?

双方都让一步，事情就好办了。  
Shuāngfāng dōu ràng yí bù, shìqing jiù hǎo bàn le.  
양쪽이 한 걸음씩 양보하면 일이 쉬워져.

这样吧，我们各退一步。  
Zhèyàng ba, wǒmen gè tuì yí bù.  
이렇게 하자, 우리 서로 한 걸음씩 물러서자.

我同意你的看法。  
Wǒ tóngyì nǐ de kànfǎ.  
네 견해에 동의해.

就这么定了。  
Jiù zhème dìng le.  
그렇게 정하자.

如果我们各让一半，怎么样？  
Rúguǒ wǒmen gè ràng yí bàn, zěnmeyàng?  
우리가 절반씩 양보하면 어떨까?

好，那就按你说的办。  
Hǎo, nà jiù àn nǐ shuō de bàn.  
좋아, 그럼 네가 말한 대로 하자.

## 主要词汇 (주요 단어)

### 1. 协商  /  xiéshāng  /  [동사 (v.)]  /  협의하다
- 한자 풀이: 协(합할 협) + 商(상의할 상) → 함께 의논하다
- 例句: 双方经过协商达成了协议。
- Pinyin: Shuāngfāng jīngguò xiéshāng dáchéng le xiéyì.
- 번역: 양측은 협의를 거쳐 합의를 이루었다.

### 2. 妥协  /  tuǒxié  /  [동사 (v.)]  /  타협하다
- 한자 풀이: 妥(온당할 타) + 协(합할 협) → 서로 양보해 합의하다
- 例句: 我们不能再妥协了。
- Pinyin: Wǒmen bù néng zài tuǒxié le.
- 번역: 우리는 더 이상 타협할 수 없다.

### 3. 商量  /  shāngliang  /  [동사 (v.)]  /  상의하다, 의논하다
- 한자 풀이: 商(헤아릴 상) + 量(헤아릴 량) → 서로 의견을 주고받다
- 例句: 我跟家人商量一下。
- Pinyin: Wǒ gēn jiārén shāngliang yíxià.
- 번역: 나는 가족과 상의해 볼게.

### 4. 让步  /  ràngbù  /  [동사 (v.)]  /  양보하다
- 한자 풀이: 让(사양할 양) + 步(걸음 보) → 한 걸음 물러서다
- 例句: 在这一点上我不会让步。
- Pinyin: Zài zhè yìdiǎn shang wǒ bú huì ràngbù.
- 번역: 이 점에 있어서 나는 양보하지 않겠다.

### 5. 方案  /  fāng'àn  /  [명사 (n.)]  /  방안, 계획
- 한자 풀이: 方(방법 방) + 案(안건 안) → 일을 처리하는 방법
- 例句: 这个方案很可行。
- Pinyin: Zhège fāng'àn hěn kěxíng.
- 번역: 이 방안은 실행 가능성이 높다.

### 6. 价格  /  jiàgé  /  [명사 (n.)]  /  가격
- 한자 풀이: 价(값 가) + 格(격식 격) → 물건의 값
- 例句: 价格还可以再商量。
- Pinyin: Jiàgé hái kěyǐ zài shāngliang.
- 번역: 가격은 더 상의할 수 있다.

## 语法点 (어법 포인트)

### 1. "商量 + 一下" — "~에 대해 상의하다" (가벼운 협의 제안)
- 我们商量一下。 Wǒmen shāngliang yíxià. 우리 상의해 보자.
- 咱们商量一下价钱吧。 Zánmen shāngliang yíxià jiàqián ba. 우리 가격을 상의해 보자.

### 2. "能不能 + 동사?" — "~해 주실 수 없을까요?" (완곡한 요청)
- 能不能便宜一点儿？ Néng bu néng piányi yìdiǎnr? 좀 싸게 해 줄 수 없나요?
- 能不能再给我一次机会？ Néng bu néng zài gěi wǒ yí cì jīhuì? 한 번만 더 기회를 줄 수 없나요?

### 3. "各 + 동사 + 一步" — "서로 한 걸음씩 ~하다" (상호 양보)
- 我们各退一步吧。 Wǒmen gè tuì yí bù ba. 우리 서로 한 걸음씩 물러서자.

### 4. "按 + A + 说的办" — "A가 말한 대로 처리하다"
- 就按你说的办。 Jiù àn nǐ shuō de bàn. 네가 말한 대로 하자.

## 应用会话 (응용 회화 - 협상)

A: 老板，这个沙发怎么卖？  
   Lǎobǎn, zhège shāfā zěnme mài?  
   사장님, 이 소파 얼마예요?

B: 三千八，不还价。  
   Sānqiān bā, bù huánjià.  
   삼천팔백 원, 흥정은 안 됩니다.

A: 太贵了，能不能便宜一点儿？  
   Tài guì le, néng bu néng piányi yìdiǎnr?  
   너무 비싸요, 좀 깎아 주시면 안 될까요?

B: 这已经是优惠价了。  
   Zhè yǐjīng shì yōuhuì jià le.  
   이건 이미 할인 가격이에요.

A: 这样吧，三千块，怎么样？  
   Zhèyàng ba, sānqiān kuài, zěnmeyàng?  
   이렇게 하죠, 삼천 원, 어때요?

B: 你再加一点儿，三千二拿走。  
   Nǐ zài jiā yìdiǎnr, sānqiān èr názǒu.  
   조금만 더 얹으세요, 삼천이백 원에 가져가세요.

A: 好，各让一步，三千一，成交！  
   Hǎo, gè ràng yí bù, sānqiān yī, chéngjiāo!  
   좋아요, 서로 한 걸음씩 양보해서 삼천백 원, 거래 성사!

B: 行，就按你说的办。  
   Xíng, jiù àn nǐ shuō de bàn.  
   좋아요, 네가 말한 대로 하죠.
