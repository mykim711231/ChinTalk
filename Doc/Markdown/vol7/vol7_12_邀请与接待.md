第 十 二 课 : 12. 邀请与接待 Yāoqǐng yǔ jiēdài (초대·접대)

## 本文 (본문)

我想邀请你来我家做客。  
Wǒ xiǎng yāoqǐng nǐ lái wǒ jiā zuòkè.  
우리 집에 놀러 오라고 초대하고 싶어요.

你周末有空吗？  
Nǐ zhōumò yǒu kòng ma?  
주말에 시간 있어요?

欢迎光临！  
Huānyíng guānglín!  
어서 오세요!

请进，请进。  
Qǐng jìn, qǐng jìn.  
들어오세요.

请坐，别客气。  
Qǐng zuò, bié kèqi.  
앉으세요, 사양하지 마세요.

请喝茶。  
Qǐng hē chá.  
차 드세요.

这是我的一点心意。  
Zhè shì wǒ de yì diǎn xīnyì.  
이것은 제 작은 성의예요.

谢谢你的盛情款待。  
Xièxie nǐ de shèngqíng kuǎndài.  
따뜻하게 접대해 주셔서 감사해요.

今天就到这里吧，欢迎下次再来。  
Jīntiān jiù dào zhèlǐ ba, huānyíng xiàcì zài lái.  
오늘은 여기까지죠, 다음에 또 오세요.

慢走，路上小心。  
Màn zǒu, lùshang xiǎoxīn.  
조심히 가세요.

---

## 主要词汇 (주요 단어)

### 1. 邀请  /  yāoqǐng  /  [동사 (v.)]  /  초대하다
- 한자 풀이: 邀(맞을 요) + 请(청할 청) → 정중히 오시기를 청하다
- 例句: 我邀请他参加我的生日聚会。
- Pinyin: Wǒ yāoqǐng tā cānjiā wǒ de shēngrì jùhuì.
- 번역: 나는 그를 내 생일 모임에 초대했다.

### 2. 接待  /  jiēdài  /  [동사 (v.)]  /  접대하다, 맞이하다
- 한자 풀이: 接(접할 접) + 待(대접할 대) → 손님을 맞아 대접하다
- 例句: 前台负责接待客人。
- Pinyin: Qiántái fùzé jiēdài kèrén.
- 번역: 프런트 데스크가 손님 접대를 담당한다.

### 3. 做客  /  zuòkè  /  [동사 (v.)]  /  손님으로 방문하다
- 한자 풀이: 做(할 주) + 客(손 객) → 손님이 되어 찾아가다
- 例句: 周末我去朋友家做客。
- Pinyin: Zhōumò wǒ qù péngyou jiā zuòkè.
- 번역: 주말에 나는 친구 집에 놀러 간다.

### 4. 欢迎  /  huānyíng  /  [동사 (v.)]  /  환영하다
- 한자 풀이: 欢(기쁠 환) + 迎(맞을 영) → 기쁘게 맞이하다
- 例句: 欢迎您来我们公司参观。
- Pinyin: Huānyíng nín lái wǒmen gōngsī cānguān.
- 번역: 저희 회사에 방문하신 것을 환영합니다.

### 5. 客气  /  kèqi  /  [형용사 (adj.)]  /  사양하다, 겸손하다
- 한자 풀이: 客(손 객) + 气(기운 기) → 손님처럼 예의를 갖추다
- 例句: 您太客气了。
- Pinyin: Nín tài kèqi le.
- 번역: 너무 겸손하시네요.

### 6. 款待  /  kuǎndài  /  [동사 (v.)]  /  정성껏 접대하다
- 한자 풀이: 款(정성 관) + 待(대접할 대) → 정성을 다해 대접하다
- 例句: 感谢你的盛情款待。
- Pinyin: Gǎnxiè nǐ de shèngqíng kuǎndài.
- 번역: 따뜻하게 접대해 주셔서 감사합니다.

## 语法点 (어법 포인트)

### 1. "邀请 + 사람 + 동사" — 초대 표현
- 我想邀请你来我家做客。 Wǒ xiǎng yāoqǐng nǐ lái wǒ jiā zuòkè. 우리 집에 놀러 오라고 초대하고 싶어요.

### 2. "欢迎 + 동사/명사" — 환영·안내
- 欢迎光临！ Huānyíng guānglín! 어서 오세요!
- 欢迎下次再来。 Huānyíng xiàcì zài lái. 다음에 또 오세요.

### 3. "别客气 / 不用谢" — 사양·응답 표현
- 别客气。 Bié kèqi. 사양하지 마세요.
- 不用谢。 Búyòng xiè. 천만에요.

### 4. "请 + 동사" — 정중한 권유
- 请进。 Qǐng jìn. 들어오세요.
- 请坐，请喝茶。 Qǐng zuò, qǐng hē chá. 앉으세요, 차 드세요.

## 应用会话 (응용 회화 - 초대·접대)

A: 这个周末我搬家，想邀请你来我家做客。  
   Zhège zhōumò wǒ bānjiā, xiǎng yāoqǐng nǐ lái wǒ jiā zuòkè.  
   이번 주말에 이사하는데, 우리 집에 놀러 오라고 초대하고 싶어.

B: 好啊，谢谢你的邀请。  
   Hǎo a, xièxie nǐ de yāoqǐng.  
   좋아, 초대 고마워.

A: 欢迎欢迎！请进，请坐。  
   Huānyíng huānyíng! Qǐng jìn, qǐng zuò.  
   어서 와! 들어와, 앉아.

B: 这是我的一点心意，请收下。  
   Zhè shì wǒ de yì diǎn xīnyì, qǐng shōuxià.  
   이건 내 작은 성의야, 받아 줘.

A: 别客气，还带礼物来。  
   Bié kèqi, hái dài lǐwù lái.  
   사양하지 마, 선물까지 가져오고.

B: 您家布置得真漂亮。  
   Nín jiā bùzhì de zhēn piàoliang.  
   집이 정말 예쁘게 꾸며져 있네.

A: 谢谢夸奖，请喝茶。  
   Xièxie kuājiǎng, qǐng hē chá.  
   칭찬 고마워, 차 마셔.

B: 时间不早了，我先告辞了。  
   Shíjiān bù zǎo le, wǒ xiān gàocí le.  
   시간이 늦었네, 먼저 가 볼게.

A: 慢走，欢迎下次再来！  
   Màn zǒu, huānyíng xiàcì zài lái!  
   조심히 가, 다음에 또 와!
