第 六 课 : 06. 劝说与说服 Quànshuō yǔ shuōfú (설득)

## 本文 (본문)

你应该多休息休息。  
Nǐ yīnggāi duō xiūxi xiūxi.  
너는 좀 더 쉬어야 해.

别担心，事情会好起来的。  
Bié dānxīn, shìqing huì hǎo qǐlái de.  
걱정 마, 일은 곧 좋아질 거야.

我觉得你最好再考虑一下。  
Wǒ juéde nǐ zuìhǎo zài kǎolǜ yíxià.  
내 생각엔 네가 다시 한번 생각해 보는 게 좋겠어.

听我一句劝，别那么拼命。  
Tīng wǒ yí jù quàn, bié nàme pīnmìng.  
내 말 한마디 들어, 그렇게 무리하지 마.

为了你的健康，还是早点儿睡吧。  
Wèile nǐ de jiànkāng, háishi zǎodiǎnr shuì ba.  
네 건강을 위해서라도 좀 일찍 자.

你听我说，这件事没有你想的那么严重。  
Nǐ tīng wǒ shuō, zhè jiàn shì méiyǒu nǐ xiǎng de nàme yánzhòng.  
내 말 들어봐, 이 일은 네가 생각하는 것만큼 심각하지 않아.

要不这样吧，我们先试试看。  
yàobù zhèyàng ba, wǒmen xiān shìshi kàn.  
아니면 이렇게 하자, 우리 먼저 시도해 보자.

相信我，这样做准没错。  
Xiāngxìn wǒ, zhèyàng zuò zhǔn méi cuò.  
나를 믿어, 이렇게 하면 틀림없어.

你就答应吧，不会有问题的。  
Nǐ jiù dāying ba, bú huì yǒu wèntí de.  
그냥 승낙해, 문제없을 거야.

说真的，这个机会很难得。  
Shuō zhēnde, zhège jīhuì hěn nándé.  
정말로, 이 기회는 아주 귀중해.

## 主要词汇 (주요 단어)

### 1. 劝说  /  quànshuō  /  [동사 (v.)]  /  설득하다, 권하다
- 한자 풀이: 劝(권할 권) + 说(말할 설) → 말로 상대를 움직여 권하다
- 例句: 妈妈劝我早点睡觉。
- Pinyin: Māmā quàn wǒ zǎodiǎn shuìjiào.
- 번역: 엄마는 나에게 일찍 자라고 권했다.

### 2. 说服  /  shuōfú  /  [동사 (v.)]  /  설복하다, 납득시키다
- 한자 풀이: 说(말할 설) + 服(복종할 복) → 말로 상대를 납득시키다
- 例句: 他终于说服了老板。
- Pinyin: Tā zhōngyú shuōfú le lǎobǎn.
- 번역: 그는 마침내 사장님을 설득했다.

### 3. 担心  /  dānxīn  /  [동사 (v.)]  /  걱정하다
- 한자 풀이: 担(짊어질 담) + 心(마음 심) → 마음에 짐을 지다
- 例句: 别担心，有我呢。
- Pinyin: Bié dānxīn, yǒu wǒ ne.
- 번역: 걱정 마, 내가 있잖아.

### 4. 考虑  /  kǎolǜ  /  [동사 (v.)]  /  고려하다, 생각하다
- 한자 풀이: 考(생각할 고) + 虑(생각할 려) → 깊이 헤아려 생각하다
- 例句: 请你再考虑考虑。
- Pinyin: Qǐng nǐ zài kǎolǜ kǎolǜ.
- 번역: 다시 한번 고려해 주세요.

### 5. 机会  /  jīhuì  /  [명사 (n.)]  /  기회
- 한자 풀이: 机(때·기회 기) + 会(만날 회) → 좋은 때를 만나다
- 例句: 这是个好机会。
- Pinyin: Zhè shì ge hǎo jīhuì.
- 번역: 이건 좋은 기회야.

### 6. 健康  /  jiànkāng  /  [명사 (n.)]  /  건강
- 한자 풀이: 健(건장할 건) + 康(편안할 강) → 몸이 튼튼하고 편안함
- 例句: 健康比什么都重要。
- Pinyin: Jiànkāng bǐ shénme dōu zhòngyào.
- 번역: 건강이 무엇보다 중요해.

## 语法点 (어법 포인트)

### 1. "应该" — "~해야 한다" (조언·권고)
- 你应该多休息。 Nǐ yīnggāi duō xiūxi. 너는 좀 더 쉬어야 해.
- 你不应该放弃。 Nǐ bù yīnggāi fàngqì. 너는 포기하면 안 돼.

### 2. "别 + 동사" — "~하지 마" (완곡한 권유·충고)
- 别担心！ Bié dānxīn! 걱정하지 마!
- 别熬夜了。 Bié áoyè le. 밤샘 그만해.

### 3. "最好 + 동사" — "~하는 게 제일 좋다" (강한 권유)
- 你最好去医院看看。 Nǐ zuìhǎo qù yīyuàn kànkan. 병원에 가 보는 게 좋겠어.

### 4. "要不 + 제안" — "아니면 ~하는 게 어때?" (대안 제시)
- 要不我们先休息一下？ yàobù wǒmen xiān xiūxi yíxià? 아니면 우리 먼저 좀 쉴까?

## 应用会话 (응용 회화 - 건강)

A: 你最近脸色不太好，是不是太累了？  
   Nǐ zuìjìn liǎnsè bú tài hǎo, shì bu shì tài lèi le?  
   너 요즘 안색이 안 좋아, 너무 피곤한 거 아니야?

B: 是啊，最近加班太多了。  
   Shì a, zuìjìn jiābān tài duō le.  
   응, 요즘 야근이 너무 많아.

A: 听我一句劝，别这么拼命了。  
   Tīng wǒ yí jù quàn, bié zhème pīnmìng le.  
   내 말 한마디 들어, 이렇게 무리하지 마.

B: 可是工作做不完啊。  
   Kěshì gōngzuò zuò bù wán a.  
   그런데 일이 끝나질 않아.

A: 为了你的健康，还是早点儿回家休息吧。  
   Wèile nǐ de jiànkāng, háishi zǎodiǎnr huíjiā xiūxi ba.  
   네 건강을 위해서라도 좀 일찍 집에 가서 쉬어.

B: 你说得对，我也该注意身体了。  
   Nǐ shuō de duì, wǒ yě gāi zhùyì shēntǐ le.  
   네 말이 맞아, 나도 몸을 챙겨야겠어.

A: 要不这样，我帮你把剩下的做完。  
   yàobù zhèyàng, wǒ bāng nǐ bǎ shèngxià de zuò wán.  
   아니면 이렇게 할까, 남은 일 내가 도와서 끝내줄게.

B: 那太麻烦你了，真不好意思。  
   Nà tài máfan nǐ le, zhēn bù hǎoyìsi.  
   그럼 너에게 너무 폐가 되네, 정말 미안해.
