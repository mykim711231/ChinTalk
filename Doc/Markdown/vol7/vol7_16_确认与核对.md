第 十六 课 : 16. 确认与核对 Quèrèn yǔ héduì (확인·대조)

## 本文 (본문)

请确认一下您的个人信息。  
Qǐng quèrèn yíxià nín de gèrén xìnxī.  
개인 정보를 확인해 주세요.

我核对了一遍，号码没有问题。  
Wǒ héduì le yí biàn, hàomǎ méiyǒu wèntí.  
한 번 대조해 봤는데, 번호에 문제가 없어요.

您是说下周三下午两点吗？  
Nín shì shuō xià zhōu sān xiàwǔ liǎng diǎn ma?  
다음 주 수요일 오후 두 시라는 말씀이시죠?

没错，就是这个时间。  
Méi cuò, jiù shì zhège shíjiān.  
맞아요, 바로 이 시간이에요.

麻烦您再说一遍地址。  
Máfan nín zài shuō yí biàn dìzhǐ.  
번거롭지만 주소를 한 번 더 말씀해 주세요.

请核对一下金额，一共三百二十元。  
Qǐng héduì yíxià jīn'é, yígòng sānbǎi èrshí yuán.  
금액을 확인해 주세요, 총 삼백이십 위안입니다.

我再确认一次，账号后四位是五六七八。  
Wǒ zài quèrèn yí cì, zhànghào hòu sì wèi shì wǔ liù qī bā.  
다시 한 번 확인할게요, 계좌번호 뒷 네 자리는 오륙칠팔입니다.

都核对过了，没有遗漏。  
Dōu héduì guò le, méiyǒu yílòu.  
전부 대조했습니다, 빠진 게 없습니다.

---

## 主要词汇 (주요 단어)

### 1. 确认  /  quèrèn  /  [동사 (v.)]  /  확인하다
- 한자 풀이: 确(굳을 확) + 认(알 인) → 확실히 알다
- 例句: 请确认一下您的座位。
- Pinyin: Qǐng quèrèn yíxià nín de zuòwèi.
- 번역: 좌석을 확인해 주세요.

### 2. 核对  /  héduì  /  [동사 (v.)]  /  대조하다
- 한자 풀이: 核(씨 핵) + 对(대할 대) → 서로 맞추어 보다
- 例句: 请核对订单信息。
- Pinyin: Qǐng héduì dìngdān xìnxī.
- 번역: 주문 정보를 대조해 주세요.

### 3. 信息  /  xìnxī  /  [명사 (n.)]  /  정보
- 한자 풀이: 信(믿을 신) + 息(쉴 식) → 알려지는 내용
- 例句: 我确认一下这个信息。
- Pinyin: Wǒ quèrèn yíxià zhège xìnxī.
- 번역: 이 정보를 확인해 볼게요.

### 4. 一遍  /  yí biàn  /  [수량사 (num.)]  /  한 번 (동작 횟수)
- 한자 풀이: 一(하나) + 遍(두루 편) → 처음부터 끝까지 한 차례
- 例句: 请再说一遍。
- Pinyin: Qǐng zài shuō yí biàn.
- 번역: 한 번 더 말해 주세요.

### 5. 遗漏  /  yílòu  /  [동사 (v.)]  /  빠뜨리다, 누락하다
- 한자 풀이: 遗(남길 유) + 漏(샐 루) → 빠져서 남다
- 例句: 检查一遍，别遗漏。
- Pinyin: Jiǎnchá yí biàn, bié yílòu.
- 번역: 한 번 점검해서 빠뜨리지 마세요.

### 6. 没错  /  méi cuò  /  [구어 표현]  /  틀림없다, 맞다
- 한자 풀이: 没(없을 몰) + 错(그르칠 착) → 잘못이 없다
- 例句: 没错，就是今天。
- Pinyin: Méi cuò, jiù shì jīntiān.
- 번역: 맞아요, 바로 오늘이에요.

## 语法点 (어법 포인트)

### 1. "一下" — 동작을 가볍게/한 번
- 请确认一下。 Qǐng quèrèn yíxià. 확인해 주세요.
- 我看一下。 Wǒ kàn yíxià. 좀 볼게요.

### 2. "是……吗？" — 확인을 위한 확인의문문
- 您是说下周三吗？ Nín shì shuō xià zhōu sān ma? 다음 주 수요일이라는 말씀이시죠?
- 是这里吗？ Shì zhèlǐ ma? 여기가 맞나요?

### 3. "再 + 동사" — 다시 한 번
- 请再说一遍。 Qǐng zài shuō yí biàn. 한 번 더 말해 주세요.
- 我再确认一次。 Wǒ zài quèrèn yí cì. 다시 한 번 확인할게요.

### 4. "都 + 동사 + 过了" — 전부 ~했다
- 都核对过了。 Dōu héduì guò le. 전부 대조했습니다.
- 都检查过了。 Dōu jiǎnchá guò le. 전부 점검했습니다.

## 应用会话 (응용 회화 - 확인·대조)

A: 麻烦您再核对一下您的姓名和电话。  
   Máfan nín zài héduì yíxià nín de xìngmíng hé diànhuà.  
   번거롭지만 성함과 전화번호를 다시 대조해 주세요.

B: 好的。姓名金秀贤，电话一三八一二三四五六七八。  
   Hǎo de. Xìngmíng Jīn Xiùxián, diànhuà yāo sān bā yāo èr sān sì wǔ liù qī bā.  
   네. 이름은 김수현, 전화는 138-1234-5678입니다.

A: 确认无误，就是这个号码。  
   Quèrèn wúwù, jiù shì zhège hàomǎ.  
   틀림없이 확인했습니다, 바로 이 번호예요.

B: 金额也对吗？一共多少钱？  
   Jīn'é yě duì ma? Yígòng duōshao qián?  
   금액도 맞나요? 총 얼마인가요?

A: 一共四百五十元，没有遗漏。  
   Yígòng sìbǎi wǔshí yuán, méiyǒu yílòu.  
   총 사백오십 위안이고, 빠진 건 없습니다.

B: 好，那就这么定了。  
   Hǎo, nà jiù zhème dìng le.  
   좋아요, 그럼 이렇게 정하죠.

A: 我再确认一次时间，明天上午十点见。  
   Wǒ zài quèrèn yí cì shíjiān, míngtiān shàngwǔ shí diǎn jiàn.  
   시간을 다시 한 번 확인할게요, 내일 오전 열 시에 봐요.

B: 没错，明天见。  
   Méi cuò, míngtiān jiàn.  
   맞아요, 내일 봐요.
