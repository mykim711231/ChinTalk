第 十七 课 : 17. 承诺与保证 Chéngnuò yǔ bǎozhèng (약속·보증)

## 本文 (본문)

我保证按时完成任务。  
Wǒ bǎozhèng ànshí wánchéng rènwù.  
제시간에 임무를 완수하겠다고 보증합니다.

你放心，我说话算数。  
Nǐ fàngxīn, wǒ shuōhuà suànshù.  
안심하세요, 저는 말을 지킵니다.

我答应你，一定准时到。  
Wǒ dāying nǐ, yídìng zhǔnshí dào.  
약속할게요, 반드시 제시간에 도착하겠습니다.

我可以向你保证，绝不会有问题。  
Wǒ kěyǐ xiàng nǐ bǎozhèng, jué bú huì yǒu wèntí.  
장담컨대, 절대 문제 없을 거예요.

君子一言，驷马难追。  
Jūnzǐ yì yán, sì mǎ nán zhuī.  
군자일언은 사마난추, 한 번 한 말은 되돌릴 수 없습니다.

我向你承诺，这个月底一定交。  
Wǒ xiàng nǐ chéngnuò, zhège yuèdǐ yídìng jiāo.  
약속드립니다, 이번 달 말까지 반드시 제출하겠습니다.

请相信我，我会说到做到。  
Qǐng xiāngxìn wǒ, wǒ huì shuō dào zuò dào.  
저를 믿어 주세요, 말한 대로 꼭 하겠습니다.

既然答应了，就一定会负责到底。  
Jìrán dāying le, jiù yídìng huì fùzé dàodǐ.  
약속했으니, 반드시 끝까지 책임지겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 承诺  /  chéngnuò  /  [동사·명사 (v./n.)]  /  약속하다, 약속
- 한자 풀이: 承(받들 승) + 诺(허락할 낙) → 받아들여 허락하다
- 例句: 我承诺会做到。
- Pinyin: Wǒ chéngnuò huì zuò dào.
- 번역: 약속합니다, 해내겠습니다.

### 2. 保证  /  bǎozhèng  /  [동사·명사 (v./n.)]  /  보증하다, 보증
- 한자 풀이: 保(지킬 보) + 证(증거 증) → 지켜서 증명하다
- 例句: 我保证质量。
- Pinyin: Wǒ bǎozhèng zhìliàng.
- 번역: 품질을 보증합니다.

### 3. 答应  /  dāying  /  [동사 (v.)]  /  승낙하다, 응하다
- 한자 풀이: 答(대답할 답) + 应(응할 응) → 응답하여 들어주다
- 例句: 我答应你的请求。
- Pinyin: Wǒ dāying nǐ de qǐngqiú.
- 번역: 당신의 부탁을 승낙합니다.

### 4. 负责  /  fùzé  /  [동사 (v.)]  /  책임지다
- 한자 풀이: 负(질 부) + 责(책임 책) → 책임을 지다
- 例句: 这件事我负责。
- Pinyin: Zhè jiàn shì wǒ fùzé.
- 번역: 이 일은 제가 책임집니다.

### 5. 说到做到  /  shuō dào zuò dào  /  [숙어]  /  말한 대로 행하다
- 한자 풀이: 说(말할 설) + 到(이를 도) + 做(할 주) → 말한 바를 실천하다
- 例句: 他是个说到做到的人。
- Pinyin: Tā shì ge shuō dào zuò dào de rén.
- 번역: 그는 말한 대로 행하는 사람입니다.

### 6. 算数  /  suànshù  /  [동사 (v.)]  /  (말이) 효력이 있다, 지켜지다
- 한자 풀이: 算(셈할 산) + 数(셀 수) → 셈이 서다, 유효하다
- 例句: 我说话算数。
- Pinyin: Wǒ shuōhuà suànshù.
- 번역: 저는 말을 지킵니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 答应 | dāying | 答을 dǎ(3성)으로 읽거나 应을 yīng(1성)으로 읽음 | 答은 1성(dā), 应은 경성(ying) |
| 保证 | bǎozhèng | 保를 bào(4성), 证을 zhēng(1성)으로 읽음 | 保는 3성(bǎo), 证은 4성(zhèng) |
| 负责 | fùzé | 负를 fù(4성)로 제대로 못 내고 "부"로 짧게 끊음 | 负는 4성(fù), 입술을 둥글게 |
| 不 + 会有 | bú huì yǒu | 不를 bù(4성) 그대로 읽음 | 뒤 会는 4성이라 不이 bú(2성)로 변함 |
| 说话 | shuōhuà | sh를 s로 발음해 "수오" | sh는 혀를 말아서 shuō |

## 语法点 (어법 포인트)

### 1. "保证 + 동작" — 보증·장담
- 我保证准时到。 Wǒ bǎozhèng zhǔnshí dào. 제시간에 도착할 것을 보증합니다.
- 我保证质量。 Wǒ bǎozhèng zhìliàng. 품질을 보증합니다.

### 2. "向 + 사람 + 保证/承诺" — 누구에게 약속하다
- 我向你保证。 Wǒ xiàng nǐ bǎozhèng. 당신에게 보증합니다.
- 我向大家承诺。 Wǒ xiàng dàjiā chéngnuò. 여러분께 약속합니다.

### 3. "一定 + 동사" — 반드시
- 我一定准时到。 Wǒ yídìng zhǔnshí dào. 반드시 제시간에 도착합니다.
- 一定负责到底。 Yídìng fùzé dàodǐ. 반드시 끝까지 책임집니다.

### 4. "既然……就……" — 이미 ~했으니 ~하다
- 既然答应了，就一定做到。 Jìrán dāying le, jiù yídìng zuò dào. 약속했으니 반드시 해냅니다.

## 应用会话 (응용 회화 - 약속·보증)

A: 这件事交给你，能保证完成吗？  
   Zhè jiàn shì jiāo gěi nǐ, néng bǎozhèng wánchéng ma?  
   이 일을 맡기는데, 완수할 수 있다고 보증하나요?

B: 你放心，我保证按时完成。  
   Nǐ fàngxīn, wǒ bǎozhèng ànshí wánchéng.  
   안심하세요, 제시간에 완수하겠습니다.

A: 那好，我说话算数，做到了请你吃饭。  
   Nà hǎo, wǒ shuōhuà suànshù, zuò dào le qǐng nǐ chīfàn.  
   좋아요, 저도 말을 지킵니다, 해내면 밥을 사겠습니다.

B: 君子一言，驷马难追。我一定不会让你失望。  
   Jūnzǐ yì yán, sì mǎ nán zhuī. Wǒ yídìng bú huì ràng nǐ shīwàng.  
   한 번 한 말은 되돌릴 수 없지요. 반드시 실망시키지 않겠습니다.

A: 那我向你承诺，材料这个月底交给你。  
   Nà wǒ xiàng nǐ chéngnuò, cáiliào zhège yuèdǐ jiāo gěi nǐ.  
   그럼 제가 약속드리죠, 자료는 이번 달 말까지 드리겠습니다.

B: 好，说到做到，我们一起努力。  
   Hǎo, shuō dào zuò dào, wǒmen yìqǐ nǔlì.  
   좋아요, 말한 대로 해내면서 함께 힘내요.

A: 相信你，那就这么定了。  
   Xiāngxìn nǐ, nà jiù zhème dìng le.  
   믿을게요, 그럼 이렇게 정하죠.

B: 请放心，我会负责到底。  
   Qǐng fàngxīn, wǒ huì fùzé dàodǐ.  
   안심하세요, 끝까지 책임지겠습니다.
