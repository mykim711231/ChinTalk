第 八 课 : 08. 汇报与总结 Huìbào yǔ zǒngjié (보고·요약)

## 本文 (본문)

我来向大家汇报一下本月的工作。  
Wǒ lái xiàng dàjiā huìbào yíxià běn yuè de gōngzuò.  
제가 여러분께 이번 달 업무를 보고하겠습니다.

这个季度我们的销售额增长了百分之十。  
Zhège jìdù wǒmen de xiāoshòu'é zēngzhǎng le bǎi fēn zhī shí.  
이번 분기에 우리의 매출액은 10퍼센트 증가했습니다.

总体来说，进展很顺利。  
Zǒngtǐ lái shuō, jìnzhǎn hěn shùnlì.  
전체적으로 보면 진행이 순조롭습니다.

首先，我来总结一下刚才的讨论。  
Shǒuxiān, wǒ lái zǒngjié yíxià gāngcái de tǎolùn.  
먼저, 방금의 토론을 요약해 보겠습니다.

总的来说，我们完成了预期的目标。  
Zǒng de lái shuō, wǒmen wánchéng le yùqī de mùbiāo.  
총체적으로 보면, 우리는 예상 목표를 달성했습니다.

目前还存在一些问题。  
Mùqián hái cúnzài yìxiē wèntí.  
현재 아직 몇 가지 문제가 존재합니다.

下面我分三个方面来说明。  
Xiàmian wǒ fēn sān ge fāngmiàn lái shuōmíng.  
다음으로 세 가지 측면으로 나누어 설명하겠습니다.

数据表明，用户的满意度明显提高了。  
Shùjù biǎomíng, yònghù de mǎnyìdù míngxiǎn tígāo le.  
데이터에 따르면 사용자 만족도가 뚜렷하게 높아졌습니다.

最后，希望大家继续努力。  
Zuìhòu, xīwàng dàjiā jìxù nǔlì.  
마지막으로, 여러분 모두 계속 노력해 주시기 바랍니다.

我的汇报到此结束，谢谢大家。  
Wǒ de huìbào dào cǐ jiéshù, xièxie dàjiā.  
제 보고는 여기서 마치겠습니다, 감사합니다.

## 主要词汇 (주요 단어)

### 1. 汇报  /  huìbào  /  [동사 (v.)]  /  보고하다
- 한자 풀이: 汇(모을 회) + 报(알릴 보) → 모아서 윗사람에게 알리다
- 例句: 我向领导汇报了情况。
- Pinyin: Wǒ xiàng lǐngdǎo huìbào le qíngkuàng.
- 번역: 나는 상사에게 상황을 보고했다.

### 2. 总结  /  zǒngjié  /  [동사 (v.)]  /  총괄 요약하다
- 한자 풀이: 总(거느릴 총) + 结(맺을 결) → 전체를 묶어 정리하다
- 例句: 请你总结一下这次的经验。
- Pinyin: Qǐng nǐ zǒngjié yíxià zhè cì de jīngyàn.
- 번역: 이번 경험을 요약해 주세요.

### 3. 进展  /  jìnzhǎn  /  [명사 (n.)]  /  진전, 진행
- 한자 풀이: 进(나아갈 진) + 展(펼 전) → 앞으로 나아가다
- 例句: 事情有了新的进展。
- Pinyin: Shìqing yǒu le xīn de jìnzhǎn.
- 번역: 일에 새로운 진전이 생겼다.

### 4. 目标  /  mùbiāo  /  [명사 (n.)]  /  목표
- 한자 풀이: 目(눈 목) + 标(표할 표) → 눈으로 바라보는 표적
- 例句: 我们顺利完成了目标。
- Pinyin: Wǒmen shùnlì wánchéng le mùbiāo.
- 번역: 우리는 목표를 순조롭게 달성했다.

### 5. 数据  /  shùjù  /  [명사 (n.)]  /  데이터, 수치
- 한자 풀이: 数(셈 수) + 据(근거 거) → 계산의 근거가 되는 수치
- 例句: 这些数据很说明问题。
- Pinyin: Zhèxiē shùjù hěn shuōmíng wèntí.
- 번역: 이 데이터는 문제를 잘 드러낸다.

### 6. 满意  /  mǎnyì  /  [형용사 (adj.)]  /  만족하다
- 한자 풀이: 满(찰 만) + 意(뜻 의) → 마음에 가득 차다
- 例句: 顾客对服务很满意。
- Pinyin: Gùkè duì fúwù hěn mǎnyì.
- 번역: 고객은 서비스에 매우 만족한다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 汇报 | huìbào | h를 탈락시켜 '우이바오' | huì는 기식 있는 '후이', bào 4성 |
| 总结 | zǒngjié | z를 'ㅉ'로, jié를 '졔'로 | zǒng 3성, jié는 혀 낮춘 '졔' 2성 |
| 数据 | shùjù | jù의 ü를 '우'로 발음 | jù는 입술 동그랗게 '쥐' |
| 增长 | zēngzhǎng | z-zh 혼동, zhǎng 3성 오류 | zēng은 '쩡', zhǎng 권설 '쟝' 3성 |
| 满意 | mǎnyì | mǎn의 -n을 -ng으로 발음 | mǎn 끝은 'n', yì는 4성 |

## 语法点 (어법 포인트)

### 1. "来 + 동사 + 一下" — "(이제부터) ~하겠습니다" (발표 도입)
- 我来汇报一下。 Wǒ lái huìbào yíxià. 제가 보고하겠습니다.
- 我来介绍一下。 Wǒ lái jièshào yíxià. 제가 소개하겠습니다.

### 2. "总体来说 / 总的来说" — "전체적으로 보면" (총평)
- 总体来说，进展顺利。 Zǒngtǐ lái shuō, jìnzhǎn shùnlì. 전체적으로 진행이 순조롭다.
- 总的来说，结果不错。 Zǒng de lái shuō, jiéguǒ búcuò. 총체적으로 결과가 좋다.

### 3. "首先…其次…最后…" — "먼저…다음으로…마지막으로" (순서)
- 首先，说明背景；其次，分析数据；最后，提出建议。 Shǒuxiān... Qícì... Zuìhòu...

### 4. "完成了 + 목표" — "목표를 달성하다"
- 我们顺利完成了本月的任务。 Wǒmen shùnlì wánchéng le běn yuè de rènwù. 우리는 이번 달 임무를 순조롭게 완수했다.

## 应用会话 (응용 회화 - 보고)

A: 现在由我向大家汇报这个项目的进展。  
   Xiànzài yóu wǒ xiàng dàjiā huìbào zhège xiàngmù de jìnzhǎn.  
   지금부터 제가 여러분께 이 프로젝트의 진행 상황을 보고하겠습니다.

B: 好的，请开始吧。  
   Hǎo de, qǐng kāishǐ ba.  
   네, 시작하세요.

A: 首先，我们提前两周完成了第一阶段。  
   Shǒuxiān, wǒmen tíqián liǎng zhōu wánchéng le dì-yī jiēduàn.  
   먼저, 우리는 2주 앞당겨 1단계를 완료했습니다.

B: 这真是个好消息。  
   Zhè zhēn shì ge hǎo xiāoxi.  
   정말 좋은 소식이네요.

A: 其次，用户满意度提高了百分之十五。  
   Qícì, yònghù mǎnyìdù tígāo le bǎi fēn zhī shíwǔ.  
   다음으로, 사용자 만족도가 15퍼센트 올랐습니다.

B: 数据看起来很不错。  
   Shùjù kàn qǐlái hěn búcuò.  
   수치가 아주 좋아 보이네요.

A: 不过，成本方面还有待控制。  
   Búguò, chéngběn fāngmiàn hái yǒudài kòngzhì.  
   다만, 비용 측면은 아직 관리가 필요합니다.

B: 那我们下一步要重点解决这个问题。  
   Nà wǒmen xià yí bù yào zhòngdiǎn jiějué zhège wèntí.  
   그럼 다음 단계로 이 문제를 중점적으로 해결해야겠네요.
