第 十七 课 : 17. 即兴发言 Jíxìng fāyán (즉석 발언)

## 本文 (본문)

临时受邀发言，我没有任何准备。  
Línshí shòu yāo fāyán, wǒ méiyǒu rènhé zhǔnbèi.  
갑자기 발언을 부탁받아 아무런 준비가 없습니다.

那我就谈几点不成熟的想法吧。  
Nà wǒ jiù tán jǐ diǎn bù chéngshú de xiǎngfǎ ba.  
그럼 미숙한 생각 몇 가지를 말씀드리겠습니다.

首先，机会总是留给有准备的人。  
Shǒuxiān, jīhuì zǒng shì liú gěi yǒu zhǔnbèi de rén.  
먼저, 기회는 늘 준비된 사람에게 주어집니다.

其次，团队合作比个人能力更重要。  
Qícì, tuánduì hézuò bǐ gèrén nénglì gèng zhòngyào.  
둘째로, 팀워크가 개인 능력보다 더 중요합니다.

另外，遇到问题不要急于下结论。  
Lìngwài, yù dào wèntí bú yào jíyú xià jiélùn.  
그 밖에, 문제가 생기면 성급히 결론 내리지 말아야 합니다.

刚才听了大家的发言，我深受启发。  
Gāngcái tīng le dàjiā de fāyán, wǒ shēn shòu qǐfā.  
방금 여러분의 발언을 듣고 깊은 깨우침을 얻었습니다.

我就先抛砖引玉，说得不对的地方请大家指正。  
Wǒ jiù xiān pāozhuān yǐnyù, shuō de bú duì de dìfang qǐng dàjiā zhǐzhèng.  
제가 우선 초보적인 의견을 내놓겠으니, 잘못 말한 부분은 여러분께서 바로잡아 주십시오.

时间仓促，讲得比较零散，还请大家包涵。  
Shíjiān cāngcù, jiǎng de bǐjiào língsàn, hái qǐng dàjiā bāohán.  
시간이 촉박해 두서없이 말씀드렸으니, 너그러이 양해해 주십시오.

最后，谢谢大家给我这个机会。  
Zuìhòu, xièxie dàjiā gěi wǒ zhè ge jīhuì.  
마지막으로, 이런 기회를 주신 여러분께 감사드립니다.

## 主要词汇 (주요 단어)

### 1. 即兴  /  jíxìng  /  [형용사 (adj.)]  /  즉흥적인, 즉석의
- 한자 풀이: 即(곧 즉) + 兴(일어날 흥) → 그 자리에서 일어난 흥취
- 例句: 他作了一段即兴演讲。
- Pinyin: Tā zuò le yí duàn jíxìng yǎnjiǎng.
- 번역: 그는 즉흥 연설을 했다.

### 2. 临时  /  línshí  /  [형용사·부사 (adj./adv.)]  /  임시의, 갑자기
- 한자 풀이: 临(임할 림) + 时(때 시) → 그때가 되어서
- 例句: 临时接到通知，我就来了。
- Pinyin: Línshí jiē dào tōngzhī, wǒ jiù lái le.
- 번역: 갑자기 통지를 받고 바로 왔습니다.

### 3. 仓促  /  cāngcù  /  [형용사 (adj.)]  /  촉박하다, 서두르는
- 한자 풀이: 仓(곳집 창) + 促(재촉할 촉) → 황급히 서두르다
- 例句: 时间仓促，准备得不够充分。
- Pinyin: Shíjiān cāngcù, zhǔnbèi de bú gòu chōngfèn.
- 번역: 시간이 촉박해서 준비가 충분하지 못했다.

### 4. 抛砖引玉  /  pāozhuān yǐnyù  /  [성어 (idiom)]  /  돌을 던져 구슬을 끌어내다 (겸손한 서두)
- 한자 풀이: 抛(던질 포) + 砖(벽돌 전) + 引(끌 인) + 玉(구슬 옥) → 벽돌을 던져 구슬을 이끌어 내다
- 例句: 我先抛砖引玉，谈谈自己的看法。
- Pinyin: Wǒ xiān pāozhuān yǐnyù, tán tan zìjǐ de kànfǎ.
- 번역: 제가 먼저 초보적인 의견을 내놓고 제 생각을 말해 보겠습니다.

### 5. 启发  /  qǐfā  /  [동사·명사 (v./n.)]  /  깨우치다, 시사(하다)
- 한자 풀이: 启(열 계) + 发(일어날 발) → 열어 일깨우다
- 例句: 大家的发言给了我很多启发。
- Pinyin: Dàjiā de fāyán gěi le wǒ hěn duō qǐfā.
- 번역: 여러분의 발언은 저에게 많은 깨우침을 주었습니다.

### 6. 指正  /  zhǐzhèng  /  [동사 (v.)]  /  바로잡아 주다
- 한자 풀이: 指(가리킬 지) + 正(바를 정) → 가리켜 바로잡다
- 例句: 讲得不对的地方，请大家指正。
- Pinyin: Jiǎng de bú duì de dìfang, qǐng dàjiā zhǐzhèng.
- 번역: 잘못 말한 부분은 여러분께서 바로잡아 주십시오.

## 语法点 (어법 포인트)

### 1. "临时…" — 갑자기 / 임시로
- 我临时说几句。 Wǒ línshí shuō jǐ jù. 제가 갑자기 몇 말씀 드리겠습니다.

### 2. "就…吧" — 그냥 ~하자 (가벼운 제안)
- 那我就谈几点想法吧。 Nà wǒ jiù tán jǐ diǎn xiǎngfǎ ba. 그럼 제가 생각 몇 가지를 말씀드리죠.

### 3. "比…更…" — 비교 표현
- 合作比个人能力更重要。 Hézuò bǐ gèrén nénglì gèng zhòngyào. 협력이 개인 능력보다 더 중요하다.

### 4. "不要急于…" — 서둘러 ~하지 마라
- 不要急于下结论。 Bú yào jíyú xià jiélùn. 성급히 결론 내리지 마라.

## 应用会话 (응용 회화 - 즉석 발언)

A: 下面请张先生即兴说几句吧。  
   Xiàmian qǐng Zhāng xiānsheng jíxìng shuō jǐ jù ba.  
   다음은 장 선생님께서 즉석에서 몇 말씀 해주시겠습니다.

B: 好，我临时说几句，讲得不好请大家见谅。  
   Hǎo, wǒ línshí shuō jǐ jù, jiǎng de bù hǎo qǐng dàjiā jiànliàng.  
   네, 갑자기 몇 말씀 드리는데 잘 못해도 양해 부탁드립니다.

A: 您太谦虚了，我们洗耳恭听。  
   Nín tài qiānxū le, wǒmen xǐ'ěr gōng tīng.  
   너무 겸손하십니다, 저희가 귀 기울여 듣겠습니다.

B: 首先，我认为团队合作最重要。  
   Shǒuxiān, wǒ rènwéi tuánduì hézuò zuì zhòngyào.  
   먼저, 저는 팀워크가 가장 중요하다고 봅니다.

A: 说得好，能具体谈谈吗？  
   Shuō de hǎo, néng jùtǐ tán tan ma?  
   좋은 말씀입니다, 구체적으로 말씀해 주시겠어요?

B: 其次，遇到问题不要急于下结论。  
   Qícì, yù dào wèntí bú yào jíyú xià jiélùn.  
   다음으로, 문제가 생기면 성급히 결론 내리지 말아야 합니다.

A: 很有道理，还有别的想法吗？  
   Hěn yǒu dàolǐ, hái yǒu bié de xiǎngfǎ ma?  
   일리가 있습니다, 다른 생각도 있으신가요?

B: 我就先抛砖引玉，还请大家多多指正。  
   Wǒ jiù xiān pāozhuān yǐnyù, hái qǐng dàjiā duōduō zhǐzhèng.  
   제가 우선 초보적인 의견을 내놓겠으니, 여러분께서 많이 지적해 주십시오.
