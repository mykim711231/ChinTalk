第 十二 课 : 12. 归纳总结 Guīnà zǒngjié (정리·요약)

## 本文 (본문)

总而言之，这次会议的讨论非常充分。  
Zǒng ér yán zhī, zhè cì huìyì de tǎolùn fēicháng chōngfèn.  
요컨대, 이번 회의의 토론은 매우 충실했다.

总的来看，今年的经济增长保持稳定。  
Zǒng de lái kàn, jīnnián de jīngjì zēngzhǎng bǎochí wěndìng.  
전반적으로 보면, 올해 경제 성장은 안정을 유지하고 있다.

从整体上看，教育质量有了明显提高。  
Cóng zhěngtǐ shàng kàn, jiàoyù zhìliàng yǒu le míngxiǎn tígāo.  
전체적으로 보면, 교육의 질이 눈에 띄게 향상되었다.

综上所述，我们可以得出以下结论。  
Zōng shàng suǒ shù, wǒmen kěyǐ déchū yǐxià jiélùn.  
이상을 종합하면, 우리는 다음과 같은 결론을 얻을 수 있다.

换句话说，这个方案是可行的。  
Huàn jù huà shuō, zhè ge fāng'àn shì kěxíng de.  
바꿔 말하면, 이 방안은 실행 가능하다.

简而言之，合作比竞争更有利于长远发展。  
Jiǎn ér yán zhī, hézuò bǐ jìngzhēng gèng yǒulì yú chángyuǎn fāzhǎn.  
간단히 말해, 협력이 경쟁보다 장기 발전에 더 유리하다.

总之，环境保护需要全社会的共同努力。  
Zǒngzhī, huánjìng bǎohù xūyào quán shèhuì de gòngtóng nǔlì.  
요컨대, 환경 보호는 사회 전체의 공동 노력이 필요하다.

由此看来，问题并没有想象中那么严重。  
Yóu cǐ kàn lái, wèntí bìng méiyǒu xiǎngxiàng zhōng nàme yánzhòng.  
이로 보아, 문제는 생각했던 것만큼 심각하지 않다.

归纳起来，主要有三个方面的原因。  
Guīnà qǐlái, zhǔyào yǒu sān ge fāngmiàn de yuányīn.  
정리해 보면, 주로 세 가지 측면의 원인이 있다.

---
## 主要词汇 (주요 단어)

### 1. 总之  /  zǒngzhī  /  [접속사 (conj.)]  /  요컨대, 한마디로
- 한자 풀이: 总(거느릴 총) + 之(갈 지) → 전체를 묶어 말함
- 例句: 总之，我们要按时完成任务。
- Pinyin: Zǒngzhī, wǒmen yào ànshí wánchéng rènwù.
- 번역: 요컨대, 우리는 제시간에 임무를 완수해야 한다.

### 2. 总而言之  /  zǒng ér yán zhī  /  [접속사 (conj.)]  /  요컨대, 총괄해서 말하면
- 한자 풀이: 总(총) + 而(말이을 이) + 言(말씀 언) + 之(지) → 종합하여 말함
- 例句: 总而言之，这是一次成功的活动。
- Pinyin: Zǒng ér yán zhī, zhè shì yí cì chénggōng de huódòng.
- 번역: 요컨대, 이것은 성공적인 행사였다.

### 3. 综上所述  /  zōng shàng suǒ shù  /  [접속사 (conj.)]  /  이상을 종합하면
- 한자 풀이: 综(모을 종) + 上(위 상) + 所(바 소) + 述(지을 술) → 위 내용을 종합
- 例句: 综上所述，我建议先试点再推广。
- Pinyin: Zōng shàng suǒ shù, wǒ jiànyì xiān shìdiǎn zài tuīguǎng.
- 번역: 이상을 종합하면, 먼저 시범 시행 후 확대하기를 제안한다.

### 4. 换句话说  /  huàn jù huà shuō  /  [부사구 (phr.)]  /  바꿔 말하면
- 한자 풀이: 换(바꿀 환) + 句(글귀 구) + 话(말 화) + 说(말할 설) → 다른 말로 하면
- 例句: 换句话说，成本太高了。
- Pinyin: Huàn jù huà shuō, chéngběn tài gāo le.
- 번역: 바꿔 말하면, 비용이 너무 높다.

### 5. 简而言之  /  jiǎn ér yán zhī  /  [접속사 (conj.)]  /  간단히 말하면
- 한자 풀이: 简(간단할 간) + 而(이) + 言(언) + 之(지) → 간략하게 말함
- 例句: 简而言之，我们需要更多的数据。
- Pinyin: Jiǎn ér yán zhī, wǒmen xūyào gèng duō de shùjù.
- 번역: 간단히 말하면, 우리는 더 많은 데이터가 필요하다.

### 6. 归纳  /  guīnà  /  [동사 (v.)]  /  귀납하다, 정리하다
- 한자 풀이: 归(돌아갈 귀) + 纳(들일 납) → 모아서 정리함
- 例句: 请把大家的意见归纳一下。
- Pinyin: Qǐng bǎ dàjiā de yìjiàn guīnà yíxià.
- 번역: 모두의 의견을 정리해 주세요.

## 语法点 (어법 포인트)

### 1. "总之 / 总而言之" — 총괄 요약
- 总之，我们赢了。 Zǒngzhī, wǒmen yíng le. 요컨대, 우리가 이겼다.
- 앞선 여러 내용을 한마디로 묶어 결론을 내릴 때 쓴다.

### 2. "综上所述 / 概括起来" — 문어적 요약
- 综上所述，这个计划是合理的。 Zōng shàng suǒ shù, zhè ge jìhuà shì hélǐ de. 이상을 종합하면 이 계획은 합리적이다.
- 보고서나 발표에서 위 내용을 정리할 때 주로 사용한다.

### 3. "换句话说 / 也就是说" — 바꿔 말하기
- 换句话说，你不反对这个提议。 Huàn jù huà shuō, nǐ bù fǎnduì zhè ge tíyì. 바꿔 말하면, 너는 이 제안에 반대하지 않는 거다.
- 앞 내용을 더 쉽고 분명한 말로 다시 표현할 때 쓴다.

### 4. "由此看来 / 由此可见" — 추론 도출
- 由此看来，市场需求还会增长。 Yóu cǐ kàn lái, shìchǎng xūqiú hái huì zēngzhǎng. 이로 보아, 시장 수요는 더 늘어날 것이다.
- 앞서 제시한 사실이나 근거로부터 결론을 이끌어낼 때 쓴다.

## 应用会话 (응용 회화 - 회의 정리와 결론)

A: 大家讨论了一个多小时，我来总结一下。  
   Dàjiā tǎolùn le yí ge duō xiǎoshí, wǒ lái zǒngjié yíxià.  
   다들 한 시간 넘게 토론했으니, 제가 정리하겠습니다.

B: 好，请讲。  
   Hǎo, qǐng jiǎng.  
   좋습니다, 말씀하세요.

A: 总的来说，大家对新方案基本认可。  
   Zǒng de lái shuō, dàjiā duì xīn fāng'àn jīběn rènkě.  
   대체로 말해, 다들 새 방안을 기본적으로 인정하고 있습니다.

B: 换句话说，可以进入下一阶段了？  
   Huàn jù huà shuō, kěyǐ jìnrù xià yí jiēduàn le?  
   바꿔 말하면, 다음 단계로 넘어갈 수 있다는 뜻인가요?

A: 概括起来说，只差经费预算这一项还没定。  
   Gàikuò qǐlái shuō, zhǐ chà jīngfèi yùsuàn zhè yí xiàng hái méi dìng.  
   개괄하면, 경비 예산 항목 하나만 아직 정해지지 않았습니다.

B: 由此看来，本周就能敲定整个计划。  
   Yóu cǐ kàn lái, běn zhōu jiù néng qiāodìng zhěng gè jìhuà.  
   이로 보아, 이번 주에 전체 계획을 확정할 수 있겠네요.

A: 简而言之，明天我再跟财务确认一下。  
   Jiǎn ér yán zhī, míngtiān wǒ zài gēn cáiwù quèrèn yíxià.  
   간단히 말해, 내일 제가 재무팀에 다시 확인하겠습니다.

B: 总而言之，会议很有效率，谢谢大家。  
   Zǒng ér yán zhī, huìyì hěn yǒu xiàolǜ, xièxie dàjiā.  
   요컨대, 회의가 매우 효율적이었습니다. 모두 감사합니다.
