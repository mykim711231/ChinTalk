第 十八 课 : 18. 数据表达 Shùjù biǎodá (수치·통계 표현)

## 本文 (본문)

根据最新统计，我们的用户数量已经突破了一千万。  
Gēnjù zuìxīn tǒngjì, wǒmen de yònghù shùliàng yǐjīng tūpò le yìqiān wàn.  
최신 통계에 따르면, 우리의 사용자 수는 이미 천만 명을 돌파했습니다.

与去年同期相比，增长了百分之十五。  
Yǔ qùnián tóngqī xiāngbǐ, zēngzhǎng le bǎi fēn zhī shíwǔ.  
지난해 같은 기간과 비교해 15퍼센트 늘었습니다.

其中，移动端用户占了将近七成。  
Qízhōng, yídòng duān yònghù zhàn le jiāngjìn qī chéng.  
그중 모바일 사용자가 거의 70퍼센트를 차지합니다.

人均使用时长约为每天四十分钟。  
Rénjūn shǐyòng shícháng yuē wéi měi tiān sìshí fēnzhōng.  
1인당 이용 시간은 하루 약 40분입니다.

满意度调查显示，八成以上用户表示满意。  
Mǎnyìdù diàochá xiǎnshì, bā chéng yǐshàng yònghù biǎoshì mǎnyì.  
만족도 조사에 따르면 80퍼센트 이상의 사용자가 만족한다고 답했습니다.

不过，也有百分之三的用户提出了投诉。  
Búguò, yě yǒu bǎi fēn zhī sān de yònghù tíchū le tóusù.  
다만 3퍼센트의 사용자는 불만을 제기했습니다.

这一数字比上季度下降了零点五个百分点。  
Zhè yí shùzì bǐ shàng jìdù xiàjiàng le líng diǎn wǔ gè bǎifēndiǎn.  
이 수치는 지난 분기보다 0.5퍼센트포인트 하락했습니다.

总体来看，发展势头保持稳定。  
Zǒngtǐ lái kàn, fāzhǎn shìtóu bǎochí wěndìng.  
전반적으로 보면 발전 추세는 안정을 유지하고 있습니다.

预计到年底，规模还会再翻一番。  
Yùjì dào niándǐ, guīmó hái huì zài fān yì fān.  
연말까지 규모는 두 배로 더 늘어날 전망입니다.

## 主要词汇 (주요 단어)

### 1. 统计  /  tǒngjì  /  [명사·동사 (n./v.)]  /  통계, 집계하다
- 한자 풀이: 统(거느릴 통) + 计(셀 계) → 묶어서 세다
- 例句: 这是最新的统计数据。
- Pinyin: Zhè shì zuìxīn de tǒngjì shùjù.
- 번역: 이것은 최신 통계 데이터입니다.

### 2. 突破  /  tūpò  /  [동사 (v.)]  /  돌파하다
- 한자 풀이: 突(갑자기 돌) + 破(깨뜨릴 파) → 뚫고 나아가다
- 例句: 销售额突破了历史纪录。
- Pinyin: Xiāoshòu'é tūpò le lìshǐ jìlù.
- 번역: 판매액이 역사적 기록을 돌파했다.

### 3. 增长  /  zēngzhǎng  /  [동사 (v.)]  /  증가하다, 성장하다
- 한자 풀이: 增(더할 증) + 长(자랄 장) → 더하고 자라다
- 例句: 经济保持稳定增长。
- Pinyin: Jīngjì bǎochí wěndìng zēngzhǎng.
- 번역: 경제가 안정적인 성장을 유지한다.

### 4. 百分比  /  bǎifēnbǐ  /  [명사 (n.)]  /  백분율
- 한자 풀이: 百(일백 백) + 分(나눌 분) + 比(견줄 비) → 백으로 나눈 비율
- 例句: 请用百分比来表示这个比例。
- Pinyin: Qǐng yòng bǎifēnbǐ lái biǎoshì zhè ge bǐlì.
- 번역: 이 비율을 백분율로 나타내 주세요.

### 5. 百分点  /  bǎifēndiǎn  /  [명사 (n.)]  /  퍼센트포인트
- 한자 풀이: 百(일백 백) + 分(나눌 분) + 点(점 점) → 백분율의 한 단위
- 例句: 占比下降了三个百分点。
- Pinyin: Zhànbǐ xiàjiàng le sān gè bǎifēndiǎn.
- 번역: 점유율이 3퍼센트포인트 하락했다.

### 6. 翻番  /  fānfān  /  [동사 (v.)]  /  두 배로 늘다
- 한자 풀이: 翻(뒤집을 번) + 番(번 번) → 배로 늘리다
- 例句: 市场规模翻了一番。
- Pinyin: Shìchǎng guīmó fān le yì fān.
- 번역: 시장 규모가 두 배로 늘었다.

|---|---|---|---|
| 数据 | shùjù | jù를 '주'로, u를 'ㅜ'로 뭉개 읽음 | 무기음 "쥐(jù)" 4성, 입술 둥글게 |

## 语法点 (어법 포인트)

### 1. "据统计" / "根据…" — 통계·근거 제시
- 根据统计，用户突破了一千万。 Gēnjù tǒngjì, yònghù tūpò le yìqiān wàn. 통계에 따르면 사용자가 천만을 돌파했다.

### 2. "与…相比" — ~와 비교하면
- 与去年相比增长了百分之十五。 Yǔ qùnián xiāngbǐ zēngzhǎng le bǎi fēn zhī shíwǔ. 작년과 비교해 15퍼센트 증가했다.

### 3. "占了…成 / 百分之…" — 비율 표현
- 移动端用户占了将近七成。 Yídòng duān yònghù zhàn le jiāngjìn qī chéng. 모바일 사용자가 거의 7할을 차지한다.

### 4. "翻一番" — 두 배가 되다
- 规模还会再翻一番。 Guīmó hái huì zài fān yì fān. 규모가 두 배로 더 늘 것이다.

## 应用会话 (응용 회화 - 수치·통계 표현)

A: 这份数据你看了吗？  
   Zhè fèn shùjù nǐ kàn le ma?  
   이 자료 봤어?

B: 看了，用户数突破了一千万。  
   Kàn le, yònghùshù tūpò le yìqiān wàn.  
   봤어, 사용자 수가 천만을 돌파했더라.

A: 与去年同期相比增长了多少？  
   Yǔ qùnián tóngqī xiāngbǐ zēngzhǎng le duōshao?  
   작년 같은 기간과 비교해 얼마나 늘었어?

B: 增长了百分之十五。  
   Zēngzhǎng le bǎi fēn zhī shíwǔ.  
   15퍼센트 늘었어.

A: 那满意度怎么样？  
   Nà mǎnyìdù zěnmeyàng?  
   그럼 만족도는 어때?

B: 八成以上用户表示满意。  
   Bā chéng yǐshàng yònghù biǎoshì mǎnyì.  
   80퍼센트 이상 사용자가 만족한다고 했어.

A: 有没有需要改进的地方？  
   Yǒu méi yǒu xūyào gǎijìn de dìfang?  
   개선할 점은 없어?

B: 投诉率下降了零点五个百分点。  
   Tóusùlǜ xiàjiàng le líng diǎn wǔ gè bǎifēndiǎn.  
   불만율이 0.5퍼센트포인트 하락했어.

A: 看来整体势头不错。  
   Kànlái zhěngtǐ shìtóu búcuò.  
   전체적으로 흐름이 좋아 보이네.

B: 对，预计年底规模还会翻一番。  
   Duì, yùjì niándǐ guīmó hái huì fān yì fān.  
   맞아, 연말엔 규모가 두 배로 늘 거야.
