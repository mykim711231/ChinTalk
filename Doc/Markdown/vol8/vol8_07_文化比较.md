第 七 课 : 07. 文化比较 Wénhuà bǐjiào (문화 비교)

## 本文 (본문)

不同的国家有不同的文化习惯。  
Bù tóng de guójiā yǒu bù tóng de wénhuà xíguàn.  
나라마다 서로 다른 문화 습관이 있다.

了解这些差异，有助于减少误会。  
Liǎojiě zhèxiē chāyì, yǒuzhùyú jiǎnshǎo wùhuì.  
이런 차이를 알면 오해를 줄이는 데 도움이 된다.

比如说，中国人见面时常常握手。  
Bǐrú shuō, Zhōngguó rén jiànmiàn shí chángcháng wòshǒu.  
예를 들어 중국인은 만날 때 자주 악수를 한다.

而韩国人见面时往往会鞠躬。  
Ér Hánguó rén jiànmiàn shí wǎngwǎng huì jūgōng.  
반면 한국인은 만날 때 흔히 절을 한다.

在餐桌上，中国人喜欢用筷子，也习惯劝菜。  
Zài cānzhuō shang, Zhōngguó rén xǐhuan yòng kuàizi, yě xíguàn quàn cài.  
식탁에서 중국인은 젓가락을 쓰며 음식을 권하는 것을 좋아한다.

韩国人则比较注重餐桌礼仪，喝酒时会侧身。  
Hánguó rén zé bǐjiào zhùzhòng cānzhuō lǐyí, hē jiǔ shí huì cèshēn.  
한국인은 식사 예절을 비교적 중시하며 술을 마실 때 몸을 옆으로 돌린다.

在时间观念上，两个国家也有不同。  
Zài shíjiān guānniàn shang, liǎng gè guójiā yě yǒu bù tóng.  
시간 관념에 있어서도 두 나라는 차이가 있다.

一般来说，中国人比较灵活，韩国人更讲求准时。  
Yìbān lái shuō, Zhōngguó rén bǐjiào línghuó, Hánguó rén gèng jiǎngqiú zhǔnshí.  
일반적으로 중국인은 비교적 유연하고, 한국인은 정시를 더 중시한다.

但是，随着交流的增加，这些差异正在慢慢缩小。  
Dànshì, suízhe jiāoliú de zēngjiā, zhèxiē chāyì zhèngzài mànman suōxiǎo.  
그러나 교류가 늘어나면서 이런 차이는 점점 줄어들고 있다.

我们应该尊重彼此的文化，而不是妄加评判。  
Wǒmen yīnggāi zūnzhòng bǐcǐ de wénhuà, ér bú shì wàngjiā píngpàn.  
우리는 서로의 문화를 존중해야 하며 함부로 판단해서는 안 된다.

## 主要词汇 (주요 단어)

### 1. 文化  /  wénhuà  /  [명사 (n.)]  /  문화
- 한자 풀이: 文(글월 문) + 化(될 화) → 문명의 총칭, 삶의 방식
- 例句: 每个国家都有自己的文化。
- Pinyin: Měi gè guójiā dōu yǒu zìjǐ de wénhuà.
- 번역: 나라마다 각자의 문화가 있다.

### 2. 差异  /  chāyì  /  [명사 (n.)]  /  차이
- 한자 풀이: 差(다를 차) + 异(다를 이) → 서로 다른 점
- 例句: 中韩文化有很多差异。
- Pinyin: Zhōng-Hán wénhuà yǒu hěn duō chāyì.
- 번역: 한중 문화에는 많은 차이가 있다.

### 3. 误会  /  wùhuì  /  [명사·동사 (n./v.)]  /  오해
- 한자 풀이: 误(그르칠 오) + 会(깨달을 회) → 잘못 이해함
- 例句: 沟通不够容易产生误会。
- Pinyin: Gōutōng bú gòu róngyì chǎnshēng wùhuì.
- 번역: 소통이 부족하면 오해가 생기기 쉽다.

### 4. 礼仪  /  lǐyí  /  [명사 (n.)]  /  예절, 예의
- 한자 풀이: 礼(예도 례) + 仪(거동 의) → 예의와 규범
- 例句: 餐桌礼仪反映一个人的修养。
- Pinyin: Cānzhuō lǐyí fǎnyìng yí gè rén de xiūyǎng.
- 번역: 식사 예절은 한 사람의 교양을 반영한다.

### 5. 观念  /  guānniàn  /  [명사 (n.)]  /  관념
- 한자 풀이: 观(볼 관) + 念(생각 념) → 머릿속에 자리 잡은 생각
- 例句: 时间观念对工作很重要。
- Pinyin: Shíjiān guānniàn duì gōngzuò hěn zhòngyào.
- 번역: 시간 관념은 업무에 매우 중요하다.

### 6. 尊重  /  zūnzhòng  /  [동사 (v.)]  /  존중하다
- 한자 풀이: 尊(높을 존) + 重(무거울 중) → 높이 여겨 소중히 대하다
- 例句: 我们应该尊重不同的文化。
- Pinyin: Wǒmen yīnggāi zūnzhòng bù tóng de wénhuà.
- 번역: 우리는 서로 다른 문화를 존중해야 한다.

## 语法点 (어법 포인트)

### 1. "比如说……" — 예를 들면
- 比如说，中国人见面时常常握手。 Bǐrú shuō, Zhōngguó rén jiànmiàn shí chángcháng wòshǒu. 예를 들어 중국인은 만날 때 자주 악수를 한다.

### 2. "……而……" — ~하는 반면, ~하다 (대비)
- 中国人见面握手，而韩国人见面鞠躬。 Zhōngguó rén jiànmiàn wòshǒu, ér Hánguó rén jiànmiàn jūgōng. 중국인은 만나면 악수를 하는 반면, 한국인은 절을 한다.

### 3. "……则……" — ~은(는) (반면에) ~하다
- 韩国人则比较注重餐桌礼仪。 Hánguó rén zé bǐjiào zhùzhòng cānzhuō lǐyí. 한국인은 (반면에) 식사 예절을 비교적 중시한다.

### 4. "一般来说……" — 일반적으로 말하면
- 一般来说，韩国人更讲求准时。 Yìbān lái shuō, Hánguó rén gèng jiǎngqiú zhǔnshí. 일반적으로 말하면 한국인은 정시를 더 중시한다.

## 应用会话 (응용 회화 - 문화 비교)

A: 你在中国生活了一段时间，感觉文化差异大吗？  
   Nǐ zài Zhōngguó shēnghuó le yí duàn shíjiān, gǎnjué wénhuà chāyì dà ma?  
   중국에서 한동안 살았는데 문화 차이가 크다고 느껴?

B: 挺大的，尤其是在餐桌礼仪方面。  
   Tǐng dà de, yóuqí shì zài cānzhuō lǐyí fāngmiàn.  
   꽤 커, 특히 식사 예절 쪽에서.

A: 比如说呢？  
   Bǐrú shuō ne?  
   예를 들면?

B: 中国人喜欢劝菜，热情地让你多吃。  
   Zhōngguó rén xǐhuan quàn cài, rèqíng de ràng nǐ duō chī.  
   중국인은 음식을 권하면서 열정적으로 많이 먹으라고 해.

A: 韩国人则更注重长幼有序。  
   Hánguó rén zé gèng zhùzhòng zhǎngyòu yǒuxù.  
   한국인은 연장자와 연소자의 순서를 더 중시하지.

B: 对，所以一开始我有些不适应。  
   Duì, suǒyǐ yì kāishǐ wǒ yǒuxiē bú shìyìng.  
   맞아, 그래서 처음엔 좀 적응이 안 됐어.

A: 但你现在应该习惯了吧？  
   Dàn nǐ xiànzài yīnggāi xíguàn le ba?  
   하지만 지금은 익숙해졌지?

B: 是啊，我们应该尊重彼此的文化差异。  
   Shì a, wǒmen yīnggāi zūnzhòng bǐcǐ de wénhuà chāyì.  
   응, 우리는 서로의 문화 차이를 존중해야 해.

A: 没错，交流多了，误会自然就少了。  
   Méi cuò, jiāoliú duō le, wùhuì zìrán jiù shǎo le.  
   맞아, 교류가 많아지면 오해도 자연히 줄어들지.
