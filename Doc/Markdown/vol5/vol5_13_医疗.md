第 十三 课 : 13. 医疗 Yīliáo (의료)

## 本文 (본문)

您哪里不舒服？  
Nín nǎlǐ bù shūfu?  
어디가 불편하신가요?

我头疼，还有点儿发烧。  
Wǒ tóuténg, hái yǒudiǎnr fāshāo.  
머리가 아프고 열도 좀 있어요.

这样多久了？  
Zhèyàng duō jiǔ le?  
이렇게 된 지 얼마나 됐나요?

从昨天晚上开始。  
Cóng zuótiān wǎnshang kāishǐ.  
어젯밤부터 시작됐습니다.

我先给您量一下体温。  
Wǒ xiān gěi nín liáng yíxià tǐwēn.  
먼저 체온을 재 드리겠습니다.

三十八度五，需要打针吗？  
Sānshíbā dù wǔ, xūyào dǎzhēn ma?  
38.5도인데, 주사를 맞아야 하나요?

不用打针，先开点药。  
Búyòng dǎzhēn, xiān kāi diǎn yào.  
주사는 필요 없고, 우선 약을 처방해 드리겠습니다.

这个药一天吃几次？  
Zhè ge yào yì tiān chī jǐ cì?  
이 약은 하루에 몇 번 먹나요?

一天三次，饭后服用。  
Yì tiān sān cì, fàn hòu fúyòng.  
하루 세 번, 식후에 복용하세요.

需要住院吗？  
Xūyào zhùyuàn ma?  
입원이 필요한가요?

不用，在家休息几天就好。  
Búyòng, zài jiā xiūxi jǐ tiān jiù hǎo.  
필요 없습니다, 집에서 며칠 쉬면 됩니다.

多喝水，注意休息。  
Duō hē shuǐ, zhùyì xiūxi.  
물을 많이 마시고 휴식을 취하세요.

## 主要词汇 (주요 단어)

### 1. 医疗  /  yīliáo  /  [명사 (n.)]  /  의료
- 한자 풀이: 医(의원 의) + 疗(병 고칠 료) → 병을 치료하는 일
- 例句: 医疗条件越来越好了。
- Pinyin: Yīliáo tiáojiàn yuè lái yuè hǎo le.
- 번역: 의료 여건이 점점 더 좋아지고 있습니다.

### 2. 不舒服  /  bù shūfu  /  [형용사 (adj.)]  /  불편하다, 아프다
- 한자 풀이: 不(아닐 부) + 舒(펼 서) + 服(따를 복) → 몸이 편하지 않다
- 例句: 我今天有点儿不舒服。
- Pinyin: Wǒ jīntiān yǒudiǎnr bù shūfu.
- 번역: 저는 오늘 좀 몸이 불편합니다.

### 3. 发烧  /  fāshāo  /  [동사 (v.)]  /  열이 나다
- 한자 풀이: 发(일어날 발) + 烧(사를 소) → 열이 오르다
- 例句: 他发烧到三十九度。
- Pinyin: Tā fāshāo dào sānshíjiǔ dù.
- 번역: 그는 열이 39도까지 올랐습니다.

### 4. 体温  /  tǐwēn  /  [명사 (n.)]  /  체온
- 한자 풀이: 体(몸 체) + 温(따뜻할 온) → 몸의 온도
- 例句: 请帮我量一下体温。
- Pinyin: Qǐng bāng wǒ liáng yíxià tǐwēn.
- 번역: 체온 좀 재 주세요.

### 5. 打针  /  dǎzhēn  /  [동사 (v.)]  /  주사를 맞다
- 한자 풀이: 打(칠 타) + 针(바늘 침) → 주사를 놓다
- 例句: 孩子怕打针。
- Pinyin: Háizi pà dǎzhēn.
- 번역: 아이는 주사를 무서워합니다.

### 6. 服用  /  fúyòng  /  [동사 (v.)]  /  복용하다
- 한자 풀이: 服(따를 복) + 用(쓸 용) → 약을 먹다
- 例句: 这个药请饭后服用。
- Pinyin: Zhè ge yào qǐng fàn hòu fúyòng.
- 번역: 이 약은 식후에 복용하세요.

## 语法点 (어법 포인트)

### 1. "哪里 + 불편하다" — 증상 묻기
- 您哪里不舒服？ Nín nǎlǐ bù shūfu? 어디가 불편하신가요?

### 2. "从 + 시간 + 开始" — ~부터 시작하다
- 从昨天晚上开始。 Cóng zuótiān wǎnshang kāishǐ. 어젯밤부터 시작하다.

### 3. "一天 + 횟수" — 빈도 표현
- 一天三次。 Yì tiān sān cì. 하루 세 번.

### 4. "不用" — ~할 필요 없다
- 不用打针。 Búyòng dǎzhēn. 주사 맞을 필요 없다.

## 应用会话 (응용 회화 - 의료)

A: 您好，请问挂哪个科？  
   Nín hǎo, qǐngwèn guà nǎ ge kē?  
   안녕하세요, 어느 과에 접수하시겠어요?

B: 我咳嗽，还有点儿发烧。  
   Wǒ késou, hái yǒudiǎnr fāshāo.  
   기침이 나고 열도 좀 있어요.

A: 那挂内科吧。请先量体温。  
   Nà guà nèikē ba. Qǐng xiān liáng tǐwēn.  
   그럼 내과로 접수하세요. 먼저 체온을 재 주세요.

B: 好的，三十七度八。  
   Hǎo de, sānshíqī dù bā.  
   네, 37.8도입니다.

A: 最近有没有过敏史？  
   Zuìjìn yǒu méiyǒu guòmǐn shǐ?  
   최근 알레르기 병력이 있으신가요?

B: 没有。医生，我需要打针吗？  
   Méiyǒu. Yīshēng, wǒ xūyào dǎzhēn ma?  
   없습니다. 의사 선생님, 주사 맞아야 하나요?

A: 不用，先吃药观察两天。  
   Búyòng, xiān chī yào guānchá liǎng tiān.  
   필요 없습니다, 우선 약을 먹으며 이틀 지켜봅시다.

B: 好的，谢谢医生。  
   Hǎo de, xièxie yīshēng.  
   알겠습니다, 감사합니다.

A: 多喝水，注意保暖。  
   Duō hē shuǐ, zhùyì bǎonuǎn.  
   물을 많이 마시고 보온에 신경 쓰세요.
