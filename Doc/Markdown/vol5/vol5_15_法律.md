第 十五 课 : 15. 法律 Fǎlǜ (법률)

## 本文 (본문)

我想咨询一个法律问题。  
Wǒ xiǎng zīxún yí ge fǎlǜ wèntí.  
법률 문제를 하나 상담하고 싶습니다.

请说，我会尽力帮您解答。  
Qǐng shuō, wǒ huì jìnlì bāng nín jiědá.  
말씀해 보세요, 최선을 다해 답해 드리겠습니다.

签合同需要注意什么？  
Qiān hétong xūyào zhùyì shénme?  
계약을 맺을 때 무엇을 주의해야 하나요?

要仔细阅读每一条款。  
Yào zǐxì yuèdú měi yì tiáokuǎn.  
모든 조항을 꼼꼼히 읽어야 합니다.

如果对方违约怎么办？  
Rúguǒ duìfāng wéiyuē zěnme bàn?  
상대방이 위약하면 어떻게 하나요?

可以要求对方赔偿损失。  
Kěyǐ yāoqiú duìfāng péicháng sǔnshī.  
상대방에게 손해 배상을 요구할 수 있습니다.

起诉需要什么材料？  
Qǐsù xūyào shénme cáiliào?  
소송에는 어떤 자료가 필요합니까?

需要合同和相关的证据。  
Xūyào hétong hé xiāngguān de zhèngjù.  
계약서와 관련 증거가 필요합니다.

律师费大概多少？  
Lǜshī fèi dàgài duōshao?  
변호사 비용은 대략 얼마입니까?

要看案子的复杂程度。  
Yào kàn ànzi de fùzá chéngdù.  
사건의 복잡한 정도에 따라 다릅니다.

我们应该尊重法律，遵守法律。  
Wǒmen yīnggāi zūnzhòng fǎlǜ, zūnshǒu fǎlǜ.  
우리는 법률을 존중하고 준수해야 합니다.

您说得对，谢谢您的解答。  
Nín shuō de duì, xièxie nín de jiědá.  
맞는 말씀입니다, 답변 감사합니다.

## 主要词汇 (주요 단어)

### 1. 法律  /  fǎlǜ  /  [명사 (n.)]  /  법률
- 한자 풀이: 法(법 법) + 律(법칙 률) → 사회가 정한 규칙
- 例句: 法律面前人人平等。
- Pinyin: Fǎlǜ miànqián rénrén píngděng.
- 번역: 법 앞에 만인이 평등합니다.

### 2. 咨询  /  zīxún  /  [동사 (v.)]  /  상담하다
- 한자 풀이: 咨(물을 자) + 询(물을 순) → 의견을 묻다
- 例句: 我想咨询律师。
- Pinyin: Wǒ xiǎng zīxún lǜshī.
- 번역: 변호사와 상담하고 싶습니다.

### 3. 起诉  /  qǐsù  /  [동사 (v.)]  /  소송을 제기하다
- 한자 풀이: 起(일어날 기) + 诉(고할 소) → 법원에 고소하다
- 例句: 他向法院提起了诉讼。
- Pinyin: Tā xiàng fǎyuàn tíqǐ le sùsòng.
- 번역: 그는 법원에 소송을 제기했습니다.

### 4. 证据  /  zhèngjù  /  [명사 (n.)]  /  증거
- 한자 풀이: 证(증거 증) + 据(의거할 거) → 사실을 입증하는 자료
- 例句: 证据不足，无法立案。
- Pinyin: Zhèngjù bùzú, wúfǎ lì'àn.
- 번역: 증거가 부족하여 입건할 수 없습니다.

### 5. 律师  /  lǜshī  /  [명사 (n.)]  /  변호사
- 한자 풀이: 律(법률 률) + 师(스승 사) → 법률을 전문으로 하는 사람
- 例句: 他请了一位律师。
- Pinyin: Tā qǐng le yí wèi lǜshī.
- 번역: 그는 변호사를 한 명 선임했습니다.

### 6. 遵守  /  zūnshǒu  /  [동사 (v.)]  /  준수하다
- 한자 풀이: 遵(좇을 준) + 守(지킬 수) → 규칙을 지키다
- 例句: 人人都要遵守法律。
- Pinyin: Rénrén dōu yào zūnshǒu fǎlǜ.
- 번역: 모든 사람이 법을 지켜야 합니다.

## 语法点 (어법 포인트)

### 1. "如果…怎么办" — 어떻게 하지
- 如果对方违约怎么办？ Rúguǒ duìfāng wéiyuē zěnme bàn? 상대방이 위약하면 어떻게 하나요?

### 2. "需要 + 명사" — ~가 필요하다
- 需要相关的证据。 Xūyào xiāngguān de zhèngjù. 관련 증거가 필요하다.

### 3. "可以 + 동사" — ~할 수 있다
- 可以要求赔偿。 Kěyǐ yāoqiú péicháng. 배상을 요구할 수 있다.

### 4. "应该" — ~해야 한다
- 应该尊重法律。 Yīnggāi zūnzhòng fǎlǜ. 법률을 존중해야 한다.

## 应用会话 (응용 회화 - 법률)

A: 律师您好，我想咨询一下。  
   Lǜshī nín hǎo, wǒ xiǎng zīxún yíxià.  
   변호사님 안녕하세요, 상담 좀 하고 싶습니다.

B: 请坐，说说您的情况。  
   Qǐng zuò, shuō shuo nín de qíngkuàng.  
   앉으세요, 상황을 말씀해 보세요.

A: 对方公司一直拖欠货款。  
   Duìfāng gōngsī yìzhí tuōqiàn huòkuǎn.  
   상대 회사가 계속 대금을 연체하고 있습니다.

B: 合同和送货单都保存了吗？  
   Hétong hé sònghuòdān dōu bǎocún le ma?  
   계약서와 납품서는 모두 보관하고 있나요?

A: 都保存好了。  
   Dōu bǎocún hǎo le.  
   모두 잘 보관하고 있습니다.

B: 那您可以向法院起诉。  
   Nà nín kěyǐ xiàng fǎyuàn qǐsù.  
   그럼 법원에 소송을 제기할 수 있습니다.

A: 胜诉的可能性大吗？  
   Shèngsù de kěnéngxìng dà ma?  
   승소 가능성이 큰가요?

B: 证据齐全的话，机会很大。  
   Zhèngjù qíquán de huà, jīhuì hěn dà.  
   증거가 완비되면 가능성이 큽니다.

A: 好的，我明白了，谢谢您。  
   Hǎo de, wǒ míngbai le, xièxie nín.  
   알겠습니다, 감사합니다.
