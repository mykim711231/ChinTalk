第 二 课 : 02. 绩效 Jìxiào (성과·실적)

## 本文 (본문)

又到了季度绩效考核的时间了。  
Yòu dào le jìdù jìxiào kǎohé de shíjiān le.  
또 분기 인사고과 시기가 되었네요.

你的年度目标完成得怎么样？  
Nǐ de niándù mùbiāo wánchéng de zěnmeyàng?  
당신의 연간 목표는 어느 정도 달성했나요?

我已经完成了百分之八十。  
Wǒ yǐjīng wánchéng le bǎi fēn zhī bāshí.  
저는 이미 80%를 달성했습니다.

你觉得哪些方面做得比较好？  
Nǐ juéde nǎxiē fāngmiàn zuò de bǐjiào hǎo?  
어떤 부분을 잘했다고 생각하나요?

团队协作方面我做得不错。  
Tuánduì xiézuò fāngmiàn wǒ zuò de búcuò.  
팀 협업 면에서 잘했습니다.

有什么需要改进的地方吗？  
Yǒu shénme xūyào gǎijìn de dìfang ma?  
개선해야 할 점이 있나요?

时间管理还有待提高。  
Shíjiān guǎnlǐ hái yǒudài tígāo.  
시간 관리가 아직 더 개선되어야 합니다.

领导对你的评价很高。  
Lǐngdǎo duì nǐ de píngjià hěn gāo.  
상사가 당신을 높게 평가하고 있습니다.

这次绩效奖金有多少？  
Zhè cì jìxiào jiǎngjīn yǒu duōshao?  
이번 성과급은 얼마나 되나요?

大约相当于一个月的工资。  
Dàyuē xiāngdāng yú yí ge yuè de gōngzī.  
대략 한 달 월급에 해당합니다.

明年的目标是什么？  
Míngnián de mùbiāo shì shénme?  
내년 목표는 무엇입니까?

争取业绩增长百分之二十。  
Zhēngqǔ yèjì zēngzhǎng bǎi fēn zhī èrshí.  
실적 20% 성장을 목표로 하겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 绩效  /  jìxiào  /  [명사 (n.)]  /  성과, 실적
- 한자 풀이: 绩(길쌈할 적) + 效(본받을 효) → 일의 성과와 효과
- 例句: 公司的绩效比去年好。
- Pinyin: Gōngsī de jìxiào bǐ qùnián hǎo.
- 번역: 회사의 실적이 작년보다 좋습니다.

### 2. 考核  /  kǎohé  /  [동사 (v.)]  /  심사·평가하다
- 한자 풀이: 考(상고할 고) + 核(씨 핵) → 자세히 살펴 평가하다
- 例句: 公司每年进行一次考核。
- Pinyin: Gōngsī měi nián jìnxíng yí cì kǎohé.
- 번역: 회사는 매년 한 번 평가를 진행합니다.

### 3. 目标  /  mùbiāo  /  [명사 (n.)]  /  목표
- 한자 풀이: 目(눈 목) + 标(표할 표) → 겨냥하는 표적
- 例句: 我们要达成今年的目标。
- Pinyin: Wǒmen yào dáchéng jīnnián de mùbiāo.
- 번역: 우리는 올해 목표를 달성해야 합니다.

### 4. 完成  /  wánchéng  /  [동사 (v.)]  /  완성하다, 달성하다
- 한자 풀이: 完(완전할 완) + 成(이룰 성) → 일을 끝까지 이루다
- 例句: 他完成了所有任务。
- Pinyin: Tā wánchéng le suǒyǒu rènwù.
- 번역: 그는 모든 임무를 완수했습니다.

### 5. 改进  /  gǎijìn  /  [동사 (v.)]  /  개선하다
- 한자 풀이: 改(고칠 개) + 进(나아갈 진) → 고쳐서 더 나아지다
- 例句: 我们需要改进工作方法。
- Pinyin: Wǒmen xūyào gǎijìn gōngzuò fāngfǎ.
- 번역: 우리는 업무 방식을 개선해야 합니다.

### 6. 奖金  /  jiǎngjīn  /  [명사 (n.)]  /  상금, 보너스
- 한자 풀이: 奖(장려할 장) + 金(쇠 금) → 격려로 주는 돈
- 例句: 年终奖金很丰厚。
- Pinyin: Niánzhōng jiǎngjīn hěn fēnghòu.
- 번역: 연말 보너스가 아주 두둑합니다.

## 语法点 (어법 포인트)

### 1. "百分之 + 숫자" — 퍼센트 표현
- 百分之八十。 Bǎi fēn zhī bāshí. 80퍼센트.
- 百分之二十。 Bǎi fēn zhī èrshí. 20퍼센트.

### 2. "相当于" — ~에 상당하다
- 相当于一个月的工资。 Xiāngdāng yú yí ge yuè de gōngzī. 한 달 월급에 해당하다.

### 3. "还有待" — 아직 ~해야 하다
- 时间管理还有待提高。 Shíjiān guǎnlǐ hái yǒudài tígāo. 시간 관리는 아직 개선이 필요하다.

### 4. "得 + 정도보어" — 상태·정도 설명
- 做得不错。 Zuò de búcuò. 잘했다.
- 完成得怎么样？ Wánchéng de zěnmeyàng? 어느 정도 달성했나요?

## 应用会话 (응용 회화 - 업무)

A: 又到年底考核了，你紧张吗？  
   Yòu dào niándǐ kǎohé le, nǐ jǐnzhāng ma?  
   또 연말 평가가 돌아왔네요, 긴장되나요?

B: 有一点儿，不过目标基本完成了。  
   Yǒu yìdiǎnr, búguò mùbiāo jīběn wánchéng le.  
   조금 긴장되지만 목표는 거의 달성했습니다.

A: 领导对你的表现怎么评价？  
   Lǐngdǎo duì nǐ de biǎoxiàn zěnme píngjià?  
   상사가 당신의 성과를 어떻게 평가했나요?

B: 他说我的执行力和团队协作都很强。  
   Tā shuō wǒ de zhíxínglì hé tuánduì xiézuò dōu hěn qiáng.  
   실행력과 팀 협업이 모두 뛰어나다고 하셨습니다.

A: 那绩效奖金应该不少吧？  
   Nà jìxiào jiǎngjīn yīnggāi bù shǎo ba?  
   그럼 성과급이 꽤 되겠네요?

B: 听说相当于两个月的工资。  
   Tīngshuō xiāngdāng yú liǎng ge yuè de gōngzī.  
   들리기로는 두 달 월급에 해당한다고 합니다.

A: 恭喜你！明年有什么计划？  
   Gōngxǐ nǐ! Míngnián yǒu shénme jìhuà?  
   축하해요! 내년 계획은 뭐예요?

B: 争取再上一层楼。  
   Zhēngqǔ zài shàng yì céng lóu.  
   한 단계 더 도약하는 것을 목표로 하겠습니다.
