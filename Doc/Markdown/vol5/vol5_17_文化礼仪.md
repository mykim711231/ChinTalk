第 十七 课 : 17. 文化礼仪 Wénhuà lǐyí (문화·예절)

## 本文 (본문)

中国人见面一般怎么打招呼？  
Zhōngguórén jiànmiàn yìbān zěnme dǎ zhāohu?  
중국인들은 만나면 보통 어떻게 인사하나요?

以前握手，现在也流行点头。  
Yǐqián wòshǒu, xiànzài yě liúxíng diǎntóu.  
예전에는 악수를 했고, 지금은 고개 숙임도 유행합니다.

送礼物有什么讲究吗？  
Sòng lǐwù yǒu shénme jiǎngjiu ma?  
선물을 줄 때 주의할 점이 있나요?

送钟表不合适，因为谐音是"送终"。  
Sòng zhōngbiǎo bù héshì, yīnwèi xiéyīn shì "sòngzhōng".  
시계를 선물하는 것은 적절하지 않습니다, 발음이 "送终(장례를 지키다)"과 같기 때문입니다.

吃饭时要注意什么礼仪？  
Chīfàn shí yào zhùyì shénme lǐyí?  
식사할 때 어떤 예절을 지켜야 하나요?

等长辈先动筷子。  
Děng zhǎngbèi xiān dòng kuàizi.  
어른이 먼저 젓가락을 드실 때까지 기다립니다.

给客人倒茶只倒七分满。  
Gěi kèrén dào chá zhǐ dào qī fēn mǎn.  
손님께 차는 7부만 따릅니다.

拜访别人家要带点小礼物。  
Bàifǎng biérén jiā yào dài diǎn xiǎo lǐwù.  
남의 집에 방문할 때는 작은 선물을 챙겨야 합니다.

数字"四"和"八"有什么讲究？  
Shùzì "sì" hé "bā" yǒu shénme jiǎngjiu?  
숫자 4와 8에는 어떤 의미가 있나요?

"四"不吉利，"八"代表发财。  
"Sì" bù jílì, "bā" dàibiǎo fācái.  
4는 불길하고, 8은 재물을 모음(부자가 됨)을 상징합니다.

我们应该尊重不同的文化习俗。  
Wǒmen yīnggāi zūnzhòng bùtóng de wénhuà xísú.  
우리는 서로 다른 문화 풍습을 존중해야 합니다.

入乡随俗很重要。  
Rù xiāng suí sú hěn zhòngyào.  
그곳에 가면 그곳 풍속을 따르는 것이 중요합니다.

## 主要词汇 (주요 단어)

### 1. 礼仪  /  lǐyí  /  [명사 (n.)]  /  예절
- 한자 풀이: 礼(예도 례) + 仪(거동 의) → 예의와 몸가짐
- 例句: 我们要讲究餐桌礼仪。
- Pinyin: Wǒmen yào jiǎngjiu cānzhuō lǐyí.
- 번역: 우리는 식탁 예절을 중시해야 합니다.

### 2. 讲究  /  jiǎngjiu  /  [명사 (n.)]  /  신경 쓰는 점, 유의점
- 한자 풀이: 讲(말할 강) + 究(궁구할 구) → 따지는 세부 사항
- 例句: 喝茶有很多讲究。
- Pinyin: Hē chá yǒu hěn duō jiǎngjiu.
- 번역: 차 마시기에는 여러 유의점이 있습니다.

### 3. 拜访  /  bàifǎng  /  [동사 (v.)]  /  방문하다
- 한자 풀이: 拜(절할 배) + 访(찾을 방) → 예를 갖추어 찾아가다
- 例句: 我明天去拜访一位老师。
- Pinyin: Wǒ míngtiān qù bàifǎng yí wèi lǎoshī.
- 번역: 내일 한 선생님을 방문할 예정입니다.

### 4. 长辈  /  zhǎngbèi  /  [명사 (n.)]  /  어른, 웃어른
- 한자 풀이: 长(어른 장) + 辈(무리 배) → 나이가 많은 윗사람
- 例句: 要尊敬长辈。
- Pinyin: Yào zūnjìng zhǎngbèi.
- 번역: 어른을 존경해야 합니다.

### 5. 吉利  /  jílì  /  [형용사 (adj.)]  /  길하다
- 한자 풀이: 吉(길할 길) + 利(이로울 리) → 운이 좋고 이롭다
- 例句: "八"是个吉利的数字。
- Pinyin: "Bā" shì ge jílì de shùzì.
- 번역: "8"은 길한 숫자입니다.

### 6. 习俗  /  xísú  /  [명사 (n.)]  /  풍습, 관습
- 한자 풀이: 习(익힐 습) + 俗(풍속 속) → 오래 이어온 풍속
- 例句: 各地有不同的习俗。
- Pinyin: Gè dì yǒu bùtóng de xísú.
- 번역: 지역마다 다른 풍습이 있습니다.

|---|---|---|---|

## 语法点 (어법 포인트)

### 1. "一般" — 보통
- 见面一般怎么打招呼？ Jiànmiàn yìbān zěnme dǎ zhāohu? 만나면 보통 어떻게 인사하나요?

### 2. "有什么讲究" — 무슨 유의점이 있나
- 送礼物有什么讲究？ Sòng lǐwù yǒu shénme jiǎngjiu? 선물에 무슨 유의점이 있나요?

### 3. "因为…" — 이유 표현
- 不合适，因为谐音是"送终"。 Bù héshì, yīnwèi xiéyīn shì "sòngzhōng". 적절하지 않다, 발음이 "送终"과 같기 때문이다.

### 4. "入乡随俗" — 성어 (그 고장에 가면 그 고장 풍속을 따른다)
- 入乡随俗很重要。 Rù xiāng suí sú hěn zhòngyào. 그곳 풍속을 따르는 것이 중요하다.

## 应用会话 (응용 회화 - 문화·예절)

A: 我第一次去中国朋友家做客，要注意什么？  
   Wǒ dì yī cì qù Zhōngguó péngyou jiā zuòkè, yào zhùyì shénme?  
   중국 친구 집에 처음 방문하는데, 무엇을 주의해야 하나요?

B: 最好带点小礼物，比如水果。  
   Zuì hǎo dài diǎn xiǎo lǐwù, bǐrú shuǐguǒ.  
   과일 같은 작은 선물을 챙기는 게 좋아요.

A: 吃饭时有什么礼仪？  
   Chīfàn shí yǒu shénme lǐyí?  
   식사할 때 어떤 예절이 있나요?

B: 等主人先动筷子，不要大声说话。  
   Děng zhǔrén xiān dòng kuàizi, bú yào dà shēng shuōhuà.  
   주인이 먼저 젓가락을 들 때까지 기다리고, 큰 소리로 말하지 마세요.

A: 可以送钟表当礼物吗？  
   Kěyǐ sòng zhōngbiǎo dàng lǐwù ma?  
   시계를 선물로 드려도 되나요?

B: 最好别送，中国人觉得不吉利。  
   Zuì hǎo bié sòng, Zhōngguórén juéde bù jílì.  
   가급적 마세요, 중국인들은 불길하게 여깁니다.

A: 原来如此，谢谢你的提醒。  
   Yuánlái rúcǐ, xièxie nǐ de tíxǐng.  
   그렇군요, 알려줘서 고마워요.

B: 不客气，入乡随俗就好。  
   Bú kèqi, rù xiāng suí sú jiù hǎo.  
   천만에요, 그곳 풍속에 따르면 됩니다.
