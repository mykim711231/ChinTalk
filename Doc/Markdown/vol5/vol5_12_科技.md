第 十二 课 : 12. 科技 Kējì (IT·기술)

## 本文 (본문)

最近人工智能发展得非常快。  
Zuìjìn réngōng zhìnéng fāzhǎn de fēicháng kuài.  
최근 인공지능이 아주 빠르게 발전하고 있습니다.

你用过最新的AI工具吗？  
Nǐ yòng guo zuì xīn de AI gōngjù ma?  
최신 AI 도구를 사용해 보셨나요?

我每天用AI助手写报告。  
Wǒ měi tiān yòng AI zhùshǒu xiě bàogào.  
저는 매일 AI 비서로 보고서를 씁니다.

大数据对商业决策帮助很大。  
Dà shùjù duì shāngyè juécè bāngzhù hěn dà.  
빅데이터는 비즈니스 의사결정에 큰 도움이 됩니다.

信息安全越来越受重视。  
Xìnxī ānquán yuè lái yuè shòu zhòngshì.  
정보 보안이 점점 더 중요시되고 있습니다.

我们公司正在推进数字化转型。  
Wǒmen gōngsī zhèngzài tuījìn shùzìhuà zhuǎnxíng.  
우리 회사는 디지털 전환을 추진 중입니다.

云计算能降低运营成本。  
Yún jìsuàn néng jiàngdī yùnyíng chéngběn.  
클라우드 컴퓨팅은 운영 비용을 낮출 수 있습니다.

你怎么看待自动驾驶？  
Nǐ zěnme kàndài zìdòng jiàshǐ?  
자율주행을 어떻게 보시나요?

技术还不成熟，需要时间。  
Jìshù hái bù chéngshú, xūyào shíjiān.  
기술이 아직 성숙하지 않아 시간이 필요합니다.

我们的新系统运行得很稳定。  
Wǒmen de xīn xìtǒng yùnxíng de hěn wěndìng.  
우리 새 시스템은 매우 안정적으로 운영됩니다.

这个软件怎么安装？  
Zhè ge ruǎnjiàn zěnme ānzhuāng?  
이 소프트웨어는 어떻게 설치하나요?

按照提示一步步操作就行。  
Ànzhào tíshì yí bù bù cāozuò jiù xíng.  
안내에 따라 한 단계씩 조작하면 됩니다.

## 主要词汇 (주요 단어)

### 1. 科技  /  kējì  /  [명사 (n.)]  /  과학 기술
- 한자 풀이: 科(과목 과) + 技(재주 기) → 과학과 기술
- 例句: 科技改变了我们的生活。
- Pinyin: Kējì gǎibiàn le wǒmen de shēnghuó.
- 번역: 과학 기술은 우리의 삶을 바꾸었습니다.

### 2. 人工智能  /  réngōng zhìnéng  /  [명사 (n.)]  /  인공지능
- 한자 풀이: 人(사람 인) + 工(장인 공) + 智(지혜 지) + 能(능할 능) → 사람이 만든 지능
- 例句: 人工智能正在改变各行各业。
- Pinyin: Réngōng zhìnéng zhèngzài gǎibiàn gè háng gè yè.
- 번역: 인공지능이 각 산업 분야를 바꾸고 있습니다.

### 3. 大数据  /  dà shùjù  /  [명사 (n.)]  /  빅데이터
- 한자 풀이: 大(큰 대) + 数(셈 수) + 据(의거할 거) → 대규모 데이터
- 例句: 大数据帮助企业分析用户。
- Pinyin: Dà shùjù bāngzhù qǐyè fēnxī yònghù.
- 번역: 빅데이터는 기업이 사용자를 분석하도록 돕습니다.

### 4. 数字化  /  shùzìhuà  /  [동사 (v.)]  /  디지털화하다
- 한자 풀이: 数(셈 수) + 字(글자 자) + 化(될 화) → 디지털 방식으로 바꾸다
- 例句: 公司正在推进数字化转型。
- Pinyin: Gōngsī zhèngzài tuījìn shùzìhuà zhuǎnxíng.
- 번역: 회사가 디지털 전환을 추진 중입니다.

### 5. 安全  /  ānquán  /  [명사 (n.)]  /  안전, 보안
- 한자 풀이: 安(편안 안) + 全(온전할 전) → 위험 없이 온전함
- 例句: 网络安全非常重要。
- Pinyin: Wǎngluò ānquán fēicháng zhòngyào.
- 번역: 네트워크 보안은 매우 중요합니다.

### 6. 技术  /  jìshù  /  [명사 (n.)]  /  기술
- 한자 풀이: 技(재주 기) + 术(꾀 술) → 어떤 일을 하는 방법
- 例句: 我们掌握了核心技术。
- Pinyin: Wǒmen zhǎngwò le héxīn jìshù.
- 번역: 우리는 핵심 기술을 보유하고 있습니다.

## 语法点 (어법 포인트)

### 1. "得 + 정도보어" — 상태·정도 설명
- 发展得非常快。 Fāzhǎn de fēicháng kuài. 매우 빠르게 발전하다.

### 2. "对 + 대상 + 帮助" — ~에 도움이 되다
- 大数据对决策帮助很大。 Dà shùjù duì juécè bāngzhù hěn dà. 빅데이터는 의사결정에 큰 도움이 된다.

### 3. "越来越 + 형용사" — 점점 더 ~하다
- 越来越受重视。 Yuè lái yuè shòu zhòngshì. 점점 더 중시되다.

### 4. "按照 + 명사" — ~에 따라
- 按照提示操作。 Ànzhào tíshì cāozuò. 안내에 따라 조작하다.

## 应用会话 (응용 회화 - IT·기술)

A: 听说你们公司在开发一款新应用？  
   Tīngshuō nǐmen gōngsī zài kāifā yì kuǎn xīn yìngyòng?  
   듣자 하니 회사에서 새 앱을 개발 중이라면서요?

B: 对，一款基于人工智能的翻译软件。  
   Duì, yì kuǎn jīyú réngōng zhìnéng de fānyì ruǎnjiàn.  
   네, 인공지능 기반의 번역 소프트웨어예요.

A: 它有什么特别的功能？  
   Tā yǒu shénme tèbié de gōngnéng?  
   어떤 특별한 기능이 있나요?

B: 可以实时翻译三十多种语言。  
   Kěyǐ shíshí fānyì sānshí duō zhǒng yǔyán.  
   서른 가지가 넘는 언어를 실시간으로 번역할 수 있어요.

A: 数据安全有保障吗？  
   Shùjù ānquán yǒu bǎozhàng ma?  
   데이터 보안은 보장되나요?

B: 有，我们用了最新的加密技术。  
   Yǒu, wǒmen yòng le zuì xīn de jiāmì jìshù.  
   네, 최신 암호화 기술을 사용했습니다.

A: 什么时候上线？  
   Shénme shíhou shàngxiàn?  
   언제 출시되나요?

B: 预计下个月，先做小范围测试。  
   Yùjì xià ge yuè, xiān zuò xiǎo fànwéi cèshì.  
   다음 달 예정이며, 먼저 소규모 테스트를 진행합니다.

A: 期待你们的成果。  
   Qīdài nǐmen de chéngguǒ.  
   여러분의 성과가 기대됩니다.
