第 十六 课 : 16. 房地产 Fángdìchǎn (부동산)

## 本文 (본문)

最近房价怎么样？  
Zuìjìn fángjià zěnmeyàng?  
요즘 집값이 어떤가요?

一线城市的房价还是很贵。  
Yīxiàn chéngshì de fángjià háishì hěn guì.  
1선 도시의 집값은 여전히 비쌉니다.

你打算买房还是租房？  
Nǐ dǎsuàn mǎi fáng háishì zū fáng?  
집을 살 계획인가요, 세를 낼 계획인가요?

我打算贷款买一套小户型。  
Wǒ dǎsuàn dàikuǎn mǎi yí tào xiǎo hùxíng.  
저는 대출로 작은 평형 집을 살 계획입니다.

首付一般要多少？  
Shǒufù yìbān yào duōshao?  
계약금은 보통 얼마나 필요하나요?

一般要付总价的三成。  
Yìbān yào fù zǒngjià de sān chéng.  
보통 총가의 30%를 내야 합니다.

这个地段交通方便吗？  
Zhè ge dìduàn jiāotōng fāngbiàn ma?  
이 지역은 교통이 편리한가요?

出门就是地铁站，很方便。  
Chūmén jiù shì dìtiě zhàn, hěn fāngbiàn.  
문만 나서면 지하철역이라 아주 편리합니다.

房价还会涨吗？  
Fángjià hái huì zhǎng ma?  
집값이 더 오를까요?

谁也说不准，要看政策。  
Shuí yě shuō bu zhǔn, yào kàn zhèngcè.  
누구도 단정하기 어렵고, 정책을 봐야 합니다.

租房合同要注意什么？  
Zū fáng hétong yào zhùyì shénme?  
임대차 계약 때 무엇을 주의해야 하나요?

看清楚租金和押金条款。  
Kàn qīngchu zūjīn hé yājīn tiáokuǎn.  
월세와 보증금 조항을 명확히 확인하세요.

## 主要词汇 (주요 단어)

### 1. 房地产  /  fángdìchǎn  /  [명사 (n.)]  /  부동산
- 한자 풀이: 房(집 방) + 地(땅 지) + 产(재산 산) → 토지와 건물 재산
- 例句: 他在房地产公司上班。
- Pinyin: Tā zài fángdìchǎn gōngsī shàngbān.
- 번역: 그는 부동산 회사에 다닙니다.

### 2. 房价  /  fángjià  /  [명사 (n.)]  /  집값
- 한자 풀이: 房(집 방) + 价(값 가) → 집의 가격
- 例句: 这里的房价很高。
- Pinyin: Zhèlǐ de fángjià hěn gāo.
- 번역: 이곳의 집값은 아주 높습니다.

### 3. 首付  /  shǒufù  /  [명사 (n.)]  /  계약금, 초기 납입금(다운페이먼트)
- 한자 풀이: 首(머리 수) + 付(줄 부) → 처음 내는 돈
- 例句: 首付我已经准备好了。
- Pinyin: Shǒufù wǒ yǐjīng zhǔnbèi hǎo le.
- 번역: 계약금은 제가 이미 준비해 두었습니다.

### 4. 地段  /  dìduàn  /  [명사 (n.)]  /  위치, 지대
- 한자 풀이: 地(땅 지) + 段(구분 단) → 땅의 구역
- 例句: 这个地段很繁华。
- Pinyin: Zhè ge dìduàn hěn fánhuá.
- 번역: 이 지역은 아주 번화합니다.

### 5. 贷款  /  dàikuǎn  /  [명사 (n.)]  /  대출
- 한자 풀이: 贷(빌릴 대) + 款(돈 관) → 빌린 돈
- 例句: 我申请了住房贷款。
- Pinyin: Wǒ shēnqǐng le zhùfáng dàikuǎn.
- 번역: 저는 주택 대출을 신청했습니다.

### 6. 租金  /  zūjīn  /  [명사 (n.)]  /  임대료, 월세
- 한자 풀이: 租(세낼 조) + 金(돈 금) → 빌리는 대가
- 例句: 每月租金三千元。
- Pinyin: Měi yuè zūjīn sānqiān yuán.
- 번역: 월세는 매달 3천 위안입니다.

## 语法点 (어법 포인트)

### 1. "是…还是…" — 선택 의문문
- 买房还是租房？ Mǎi fáng háishì zū fáng? 집을 사나요, 세를 내나요?

### 2. "一般" — 보통
- 首付一般要三成。 Shǒufù yìbān yào sān chéng. 계약금은 보통 30%가 필요하다.

### 3. "谁也说不准" — 누구도 단정할 수 없다
- 房价谁也说不准。 Fángjià shuí yě shuō bu zhǔn. 집값은 누구도 단정할 수 없다.

### 4. "要 + 동사" — ~해야 한다
- 要看政策。 Yào kàn zhèngcè. 정책을 봐야 한다.

## 应用会话 (응용 회화 - 부동산)

A: 您想看什么样的房子？  
   Nín xiǎng kàn shénme yàng de fángzi?  
   어떤 집을 보시고 싶으세요?

B: 我想看一套两室一厅的房子。  
   Wǒ xiǎng kàn yí tào liǎng shì yì tīng de fángzi.  
   방 두 개에 거실 하나인 집을 보고 싶어요.

A: 这个小区交通很方便，离地铁很近。  
   Zhè ge xiǎoqū jiāotōng hěn fāngbiàn, lí dìtiě hěn jìn.  
   이 단지는 교통이 편리하고 지하철과 가깝습니다.

B: 租金大概多少？  
   Zūjīn dàgài duōshao?  
   월세는 대략 얼마인가요?

A: 每月六千，押金是两个月租金。  
   Měi yuè liùqiān, yājīn shì liǎng ge yuè zūjīn.  
   매달 6천 위안이고 보증금은 두 달 치 월세입니다.

B: 可以月付吗？  
   Kěyǐ yuè fù ma?  
   매달 낼 수 있나요?

A: 可以，签一年合同就行。  
   Kěyǐ, qiān yì nián hétong jiù xíng.  
   가능합니다, 1년 계약을 맺으면 됩니다.

B: 好的，我再考虑一下。  
   Hǎo de, wǒ zài kǎolǜ yíxià.  
   알겠습니다, 좀 더 생각해 볼게요.
