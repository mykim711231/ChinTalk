第 九 课 : 09. 贸易 Màoyì (무역)

## 本文 (본문)

贵公司主要经营什么产品？  
Guì gōngsī zhǔyào jīngyíng shénme chǎnpǐn?  
귀사는 주로 어떤 제품을 취급하나요?

我们主要做进出口贸易。  
Wǒmen zhǔyào zuò jìnchūkǒu màoyì.  
저희는 주로 수출입 무역을 합니다.

这批货要出口到哪个国家？  
Zhè pī huò yào chūkǒu dào nǎ ge guójiā?  
이 물품은 어느 나라로 수출하나요?

主要出口到欧洲和美国。  
Zhǔyào chūkǒu dào Ōuzhōu hé Měiguó.  
주로 유럽과 미국으로 수출합니다.

海关关税税率是多少？  
Hǎiguān guānshuì shuìlǜ shì duōshao?  
세관 관세율은 얼마입니까?

大约百分之六。  
Dàyuē bǎi fēn zhī liù.  
대략 6%입니다.

这批货物的装运日期定了吗？  
Zhè pī huòwù de zhuāngyùn rìqī dìng le ma?  
이 화물의 선적일은 정해졌나요?

下个月十号装船。  
Xià ge yuè shí hào zhuāng chuán.  
다음 달 10일에 선적합니다.

付款方式是信用证还是电汇？  
Fùkuǎn fāngshì shì xìnyòngzhèng háishì diànhuì?  
결제 방식은 신용장입니까, 아니면 전신환입니까?

我们建议用信用证结算。  
Wǒmen jiànyì yòng xìnyòngzhèng jiésuàn.  
저희는 신용장 결제를 권합니다.

这批订单的总金额是多少？  
Zhè pī dìngdān de zǒng jīn'é shì duōshao?  
이번 주문의 총금액은 얼마입니까?

总共一百二十万美元。  
Zǒnggòng yìbǎi èrshí wàn měiyuán.  
총 120만 달러입니다.

## 主要词汇 (주요 단어)

### 1. 贸易  /  màoyì  /  [명사 (n.)]  /  무역
- 한자 풀이: 贸(무역할 무) + 易(바꿀 역) → 물건을 서로 바꾸다
- 例句: 国际贸易越来越频繁。
- Pinyin: Guójì màoyì yuè lái yuè pínfán.
- 번역: 국제 무역이 점점 더 활발해지고 있습니다.

### 2. 进出口  /  jìnchūkǒu  /  [명사 (n.)]  /  수출입
- 한자 풀이: 进(들 진) + 出(날 출) + 口(입구 구) → 수입과 수출
- 例句: 公司有进出口经营权。
- Pinyin: Gōngsī yǒu jìnchūkǒu jīngyíng quán.
- 번역: 회사는 수출입 경영권을 보유하고 있습니다.

### 3. 关税  /  guānshuì  /  [명사 (n.)]  /  관세
- 한자 풀이: 关(관문 관) + 税(세금 세) → 통관 때 내는 세금
- 例句: 关税提高了百分之三。
- Pinyin: Guānshuì tígāo le bǎi fēn zhī sān.
- 번역: 관세가 3% 인상되었습니다.

### 4. 装运  /  zhuāngyùn  /  [동사 (v.)]  /  선적·운송하다
- 한자 풀이: 装(꾸밀 장) + 运(옮길 운) → 물건을 싣고 운송하다
- 例句: 货物明天装运。
- Pinyin: Huòwù míngtiān zhuāngyùn.
- 번역: 화물은 내일 선적합니다.

### 5. 信用证  /  xìnyòngzhèng  /  [명사 (n.)]  /  신용장
- 한자 풀이: 信(믿을 신) + 用(쓸 용) + 证(증거 증) → 은행이 보증하는 결제 증서
- 例句: 我们使用信用证付款。
- Pinyin: Wǒmen shǐyòng xìnyòngzhèng fùkuǎn.
- 번역: 저희는 신용장으로 결제합니다.

### 6. 结算  /  jiésuàn  /  [동사 (v.)]  /  정산하다
- 한자 풀이: 结(맺을 결) + 算(셈할 산) → 거래 금액을 정산하다
- 例句: 月底统一结算。
- Pinyin: Yuèdǐ tǒngyī jiésuàn.
- 번역: 월말에 일괄 결제합니다.

## 语法点 (어법 포인트)

### 1. "主要 + 동사" — 주로 ~하다
- 主要做进出口贸易。 Zhǔyào zuò jìnchūkǒu màoyì. 주로 수출입 무역을 하다.

### 2. "是…还是…" — 선택 의문문
- 是信用证还是电汇？ Shì xìnyòngzhèng háishì diànhuì? 신용장인가요, 전신환인가요?

### 3. "出口到 + 장소" — ~로 수출하다
- 出口到欧洲。 Chūkǒu dào Ōuzhōu. 유럽으로 수출하다.

### 4. "总共" — 총, 합계
- 总共一百二十万美元。 Zǒnggòng yìbǎi èrshí wàn měiyuán. 총 120만 달러.

## 应用会话 (응용 회화 - 무역)

A: 您好，这批货最快什么时候能发出？  
   Nín hǎo, zhè pī huò zuì kuài shénme shíhou néng fāchū?  
   안녕하세요, 이 화물은 언제 가장 빨리 보낼 수 있나요?

B: 下周三可以装船。  
   Xià zhōusān kěyǐ zhuāng chuán.  
   다음 주 수요일에 선적할 수 있습니다.

A: 从上海港出发吗？  
   Cóng Shànghǎi gǎng chūfā ma?  
   상하이 항구에서 출발하나요?

B: 是的，海运到欧洲大概要一个月。  
   Shì de, hǎiyùn dào Ōuzhōu dàgài yào yí ge yuè.  
   네, 해운으로 유럽까지 대략 한 달 걸립니다.

A: 付款方式上能不能再灵活一点？  
   Fùkuǎn fāngshì shang néng bu néng zài línghuó yìdiǎn?  
   결제 방식을 조금 더 유연하게 할 수 있나요?

B: 我们可以接受三成预付款。  
   Wǒmen kěyǐ jiēshòu sān chéng yùfùkuǎn.  
   30% 선금을 받을 수 있습니다.

A: 关税由谁承担？  
   Guānshuì yóu shuí chéngdān?  
   관세는 누가 부담하나요?

B: 按合同，由买方承担。  
   Àn hétong, yóu mǎifāng chéngdān.  
   계약에 따라 구매자가 부담합니다.

A: 明白了，我们尽快安排付款。  
   Míngbai le, wǒmen jǐnkuài ānpái fùkuǎn.  
   알겠습니다, 최대한 빨리 결제를 진행하겠습니다.
