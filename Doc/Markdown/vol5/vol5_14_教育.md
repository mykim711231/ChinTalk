第 十四 课 : 14. 教育 Jiàoyù (교육)

## 本文 (본문)

孩子上几年级了？  
Háizi shàng jǐ niánjí le?  
아이가 몇 학년이에요?

今年上初三，明年要中考了。  
Jīnnián shàng chūsān, míngnián yào zhōngkǎo le.  
올해 중학교 3학년이고 내년에 고입시험을 봐요.

学习压力大吗？  
Xuéxí yālì dà ma?  
학업 스트레스가 큰가요?

挺大的，每天作业很多。  
Tǐng dà de, měi tiān zuòyè hěn duō.  
꽤 커요, 매일 숙제가 아주 많아요.

你觉得课外辅导有必要吗？  
Nǐ juéde kèwài fǔdǎo yǒu bìyào ma?  
과외가 필요하다고 생각하나요?

因人而异，不能盲目跟风。  
Yīn rén ér yì, bù néng mángmù gēnfēng.  
사람마다 달라서 무작정 따라 해서는 안 돼요.

家长应该怎么帮助孩子？  
Jiāzhǎng yīnggāi zěnme bāngzhù háizi?  
학부모는 아이를 어떻게 도와야 하나요?

多鼓励，少批评。  
Duō gǔlì, shǎo pīpíng.  
많이 격려하고 적게 비판하세요.

现在很重视素质教育。  
Xiànzài hěn zhòngshì sùzhì jiàoyù.  
요즘은 소질 교육(전인 교육)을 중시합니다.

除了成绩，还要培养兴趣。  
Chúle chéngjì, hái yào péiyǎng xìngqù.  
성적 외에 흥미도 길러야 합니다.

出国留学值得吗？  
Chūguó liúxué zhíde ma?  
유학은 가치가 있나요?

看个人情况和家庭条件。  
Kàn gèrén qíngkuàng hé jiātíng tiáojiàn.  
개인 상황과 가정 형편을 봐야 합니다.

## 主要词汇 (주요 단어)

### 1. 教育  /  jiàoyù  /  [명사 (n.)]  /  교육
- 한자 풀이: 教(가르칠 교) + 育(기를 육) → 가르치고 기르다
- 例句: 教育是国家的根本。
- Pinyin: Jiàoyù shì guójiā de gēnběn.
- 번역: 교육은 국가의 근본입니다.

### 2. 压力  /  yālì  /  [명사 (n.)]  /  스트레스, 압박
- 한자 풀이: 压(누를 압) + 力(힘 력) → 눌리는 힘
- 例句: 工作压力很大。
- Pinyin: Gōngzuò yālì hěn dà.
- 번역: 업무 스트레스가 아주 큽니다.

### 3. 作业  /  zuòyè  /  [명사 (n.)]  /  숙제, 과제
- 한자 풀이: 作(지을 작) + 业(일 업) → 해야 할 과제
- 例句: 今天的作业很多。
- Pinyin: Jīntiān de zuòyè hěn duō.
- 번역: 오늘 숙제가 아주 많습니다.

### 4. 辅导  /  fǔdǎo  /  [동사 (v.)]  /  지도하다, 과외하다
- 한자 풀이: 辅(도울 보) + 导(이끌 도) → 도와 이끌다
- 例句: 老师课后辅导学生。
- Pinyin: Lǎoshī kè hòu fǔdǎo xuésheng.
- 번역: 선생님이 수업 후 학생을 지도합니다.

### 5. 鼓励  /  gǔlì  /  [동사 (v.)]  /  격려하다
- 한자 풀이: 鼓(북 고) + 励(힘쓸 려) → 북돋워 힘을 내게 하다
- 例句: 多鼓励孩子。
- Pinyin: Duō gǔlì háizi.
- 번역: 아이를 많이 격려하세요.

### 6. 兴趣  /  xìngqù  /  [명사 (n.)]  /  흥미, 취미
- 한자 풀이: 兴(일어날 흥) + 趣(달릴 취) → 마음이 끌리는 것
- 例句: 他对音乐很有兴趣。
- Pinyin: Tā duì yīnyuè hěn yǒu xìngqù.
- 번역: 그는 음악에 관심이 많습니다.

## 语法点 (어법 포인트)

### 1. "挺 + 형용사 + 的" — 꽤 ~하다
- 挺大的。 Tǐng dà de. 꽤 크다.

### 2. "因人而异" — 사람마다 다르다 (성어)
- 因人而异。 Yīn rén ér yì. 사람마다 다르다.

### 3. "除了…，还…" — ~외에 또한 ~
- 除了成绩，还要培养兴趣。 Chúle chéngjì, hái yào péiyǎng xìngqù. 성적 외에 흥미도 길러야 한다.

### 4. "应该" — ~해야 한다
- 家长应该多鼓励孩子。 Jiāzhǎng yīnggāi duō gǔlì háizi. 학부모는 아이를 많이 격려해야 한다.

## 应用会话 (응용 회화 - 교육)

A: 你家孩子学习怎么样？  
   Nǐ jiā háizi xuéxí zěnmeyàng?  
   댁의 아이는 공부를 잘하나요?

B: 还可以，就是压力挺大的。  
   Hái kěyǐ, jiùshì yālì tǐng dà de.  
   괜찮아요, 다만 스트레스가 꽤 커요.

A: 报课外辅导班了吗？  
   Bào kèwài fǔdǎo bān le ma?  
   과외 학원은 다니나요?

B: 报了数学和英语两个班。  
   Bào le shùxué hé yīngyǔ liǎng ge bān.  
   수학과 영어 두 개 학원에 다녀요.

A: 我觉得没必要报太多。  
   Wǒ juéde méi bìyào bào tài duō.  
   너무 많이 보낼 필요는 없다고 생각해요.

B: 我也担心孩子太累。  
   Wǒ yě dānxīn háizi tài lèi.  
   저도 아이가 너무 힘들까 걱정돼요.

A: 除了成绩，兴趣也很重要。  
   Chúle chéngjì, xìngqù yě hěn zhòngyào.  
   성적 외에 흥미도 중요해요.

B: 对，周末我会带他去学画画。  
   Duì, zhōumò wǒ huì dài tā qù xué huà huà.  
   맞아요, 주말에 그림 배우러 데려갈 거예요.

A: 这样安排挺好的。  
   Zhèyàng ānpái tǐng hǎo de.  
   그렇게 계획하는 것 좋네요.
