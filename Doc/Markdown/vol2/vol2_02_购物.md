第 二 课 : 02. 购物 Gòuwù (쇼핑)

## 本文 (본문)

我想买一件衣服。  
Wǒ xiǎng mǎi yí jiàn yīfu.  
저는 옷 한 벌을 사고 싶어요.

这件衣服多少钱？  
Zhè jiàn yīfu duōshao qián?  
이 옷은 얼마예요?

我可以试试吗？  
Wǒ kěyǐ shìshi ma?  
입어 봐도 될까요?

试衣间在哪儿？  
Shìyījiān zài nǎr?  
탈의실이 어디예요?

这个颜色很好看。  
Zhège yánsè hěn hǎokàn.  
이 색깔은 아주 예뻐요.

有没有大一点的？  
Yǒu méiyǒu dà yìdiǎn de?  
조금 더 큰 것 있어요?

太贵了。  
Tài guì le.  
너무 비싸요.

可以便宜一点吗？  
Kěyǐ piányi yìdiǎn ma?  
좀 깎아 주실 수 있나요?

我要这件。  
Wǒ yào zhè jiàn.  
이걸로 할게요.

收银台在哪儿？  
Shōuyíntái zài nǎr?  
계산대가 어디예요?

---

## 主要词汇 (주요 단어)

### 1. 买  /  mǎi  /  [동사 (v.)]  /  사다
- 한자 풀이: 买(살 매) → 돈을 주고 물건을 얻다
- 例句: 我想买一件衣服。
- Pinyin: Wǒ xiǎng mǎi yí jiàn yīfu.
- 번역: 저는 옷 한 벌을 사고 싶어요.

### 2. 衣服  /  yīfu  /  [명사 (n.)]  /  옷, 의복
- 한자 풀이: 衣(옷 의) + 服(옷 복) → 입는 물건의 총칭
- 例句: 这件衣服很漂亮。
- Pinyin: Zhè jiàn yīfu hěn piàoliang.
- 번역: 이 옷은 아주 예쁘다.

### 3. 试  /  shì  /  [동사 (v.)]  /  시험해 보다, 입어 보다
- 한자 풀이: 试(시험할 시) → 직접 해 보고 확인하다
- 例句: 我可以试试吗？
- Pinyin: Wǒ kěyǐ shìshi ma?
- 번역: 입어 봐도 될까요?

### 4. 颜色  /  yánsè  /  [명사 (n.)]  /  색깔
- 한자 풀이: 颜(얼굴 안) + 色(빛 색) → 사물의 빛깔
- 例句: 你喜欢什么颜色？
- Pinyin: Nǐ xǐhuan shénme yánsè?
- 번역: 무슨 색깔을 좋아하세요?

### 5. 贵  /  guì  /  [형용사 (adj.)]  /  비싸다
- 한자 풀이: 贵(귀할 귀) → 값이 높다
- 例句: 这个太贵了。
- Pinyin: Zhège tài guì le.
- 번역: 이건 너무 비싸요.

### 6. 便宜  /  piányi  /  [형용사 (adj.)]  /  싸다
- 한자 풀이: 便(편할 편) + 宜(마땅할 의) → 값이 낮다
- 例句: 这件衣服很便宜。
- Pinyin: Zhè jiàn yīfu hěn piányi.
- 번역: 이 옷은 아주 싸요.

|---|---|---|---|
| 一件 | yí jiàn | 一을 yī(1성)로 그대로 읽음 | 一은 뒤 4성 앞에서 2성(yí)으로 변함 |

## 语法点 (어법 포인트)

### 1. "可以 ... 吗？" — 허락 구하기
- 我可以试试吗？ Wǒ kěyǐ shìshi ma? 입어 봐도 될까요?
- 可以便宜一点吗？ Kěyǐ piányi yìdiǎn ma? 좀 깎아 주실 수 있나요?

### 2. "有没有" — 유무 묻기
- 有没有大一点的？ Yǒu méiyǒu dà yìdiǎn de? 더 큰 것 있나요?
- 有没有别的颜色？ Yǒu méiyǒu bié de yánsè? 다른 색깔 있나요?

### 3. "太 + 형용사 + 了" — 지나침 표현
- 太贵了。 Tài guì le. 너무 비싸요.
- 太大了。 Tài dà le. 너무 커요.

### 4. "一点" — 조금
- 便宜一点 piányi yìdiǎn 조금 싸게
- 大一点 dà yìdiǎn 조금 크게

## 应用会话 (응용 회화 - 일상)

A: 欢迎光临！想买什么？  
   Huānyíng guānglín! Xiǎng mǎi shénme?  
   어서 오세요! 무엇을 찾으세요?

B: 我想买一件外套。  
   Wǒ xiǎng mǎi yí jiàn wàitào.  
   저는 겉옷을 하나 사고 싶어요.

A: 这件怎么样？可以试试。  
   Zhè jiàn zěnmeyàng? Kěyǐ shìshi.  
   이건 어때요? 입어 보세요.

B: 有没有黑色的？  
   Yǒu méiyǒu hēisè de?  
   검은색 있나요?

A: 有，给您。  
   Yǒu, gěi nín.  
   있어요, 여기 있습니다.

B: 这件多少钱？  
   Zhè jiàn duōshao qián?  
   이건 얼마예요?

A: 五百块钱。  
   Wǔ bǎi kuài qián.  
   500위안입니다.

B: 太贵了，能便宜一点吗？  
   Tài guì le, néng piányi yìdiǎn ma?  
   너무 비싸요, 좀 깎아 주실 수 있나요?

A: 那四百五吧。  
   Nà sì bǎi wǔ ba.  
   그럼 450위안으로 하죠.
