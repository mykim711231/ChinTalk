第 九 课 : 09. 邮局 Yóujú (우체국)

## 本文 (본문)

我要寄一封信。  
Wǒ yào jì yì fēng xìn.  
편지 한 통을 부치려고 해요.

寄到韩国要多少钱？  
Jì dào Hánguó yào duōshao qián?  
한국까지 보내는 데 얼마예요?

请给我几张邮票。  
Qǐng gěi wǒ jǐ zhāng yóupiào.  
우표 몇 장 주세요.

我要寄一个包裹。  
Wǒ yào jì yí gè bāoguǒ.  
소포 하나를 부치려고 해요.

寄航空还是平邮？  
Jì hángkōng háishì píngyóu?  
항공편으로 보낼까요, 일반 우편으로 보낼까요?

大概几天到？  
Dàgài jǐ tiān dào?  
대략 며칠 걸려요?

请填一下这个单子。  
Qǐng tián yíxià zhège dānzi.  
이 양식을 작성해 주세요.

我想买几张明信片。  
Wǒ xiǎng mǎi jǐ zhāng míngxìnpiàn.  
엽서 몇 장을 사고 싶어요.

## 主要词汇 (주요 단어)

### 1. 邮局  /  yóujú  /  [명사 (n.)]  /  우체국
- 한자 풀이: 邮(우편 우) + 局(관청 국) → 우편 업무 기관
- 例句: 我去邮局寄信。
- Pinyin: Wǒ qù yóujú jìxìn.
- 번역: 저는 우체국에 가서 편지를 부쳐요.

### 2. 寄  /  jì  /  [동사 (v.)]  /  부치다, 보내다
- 한자 풀이: 寄(부칠 기) → 우편으로 보내다
- 例句: 我要寄一封信。
- Pinyin: Wǒ yào jì yì fēng xìn.
- 번역: 편지 한 통을 부치려고 해요.

### 3. 邮票  /  yóupiào  /  [명사 (n.)]  /  우표
- 한자 풀이: 邮(우편) + 票(표) → 우편 요금 표지
- 例句: 请给我几张邮票。
- Pinyin: Qǐng gěi wǒ jǐ zhāng yóupiào.
- 번역: 우표 몇 장 주세요.

### 4. 包裹  /  bāoguǒ  /  [명사 (n.)]  /  소포
- 한자 풀이: 包(쌀 포) + 裹(쌀 과) → 싸서 보내는 짐
- 例句: 我要寄一个包裹。
- Pinyin: Wǒ yào jì yí gè bāoguǒ.
- 번역: 소포 하나를 부치려고 해요.

### 5. 航空  /  hángkōng  /  [명사 (n.)]  /  항공
- 한자 풀이: 航(배 항) + 空(하늘 공) → 항공편
- 例句: 寄航空还是平邮？
- Pinyin: Jì hángkōng háishì píngyóu?
- 번역: 항공편으로 보낼까요, 일반 우편으로 보낼까요?

### 6. 明信片  /  míngxìnpiàn  /  [명사 (n.)]  /  엽서
- 한자 풀이: 明(밝을 명) + 信(편지 신) + 片(조각 편) → 그림엽서
- 例句: 我想买几张明信片。
- Pinyin: Wǒ xiǎng mǎi jǐ zhāng míngxìnpiàn.
- 번역: 엽서 몇 장을 사고 싶어요.

|---|---|---|---|

## 语法点 (어법 포인트)

### 1. "寄到 + 장소 + 要多少钱？" — 우편 요금 묻기
- 寄到韩国要多少钱？ Jì dào Hánguó yào duōshao qián? 한국까지 보내는 데 얼마예요?
- 寄到北京要多少钱？ Jì dào Běijīng yào duōshao qián? 베이징까지 얼마예요?

### 2. "还是" — 선택 의문 (A인가 B인가)
- 寄航空还是平邮？ Jì hángkōng háishì píngyóu? 항공편인가요, 일반 우편인가요?
- 要快还是要便宜？ Yào kuài háishì yào piányi? 빨리 보낼까요, 싸게 보낼까요?

### 3. "请给我 + 수량 + 명사" — 수량 요청
- 请给我几张邮票。 Qǐng gěi wǒ jǐ zhāng yóupiào. 우표 몇 장 주세요.
- 请给我一个信封。 Qǐng gěi wǒ yí gè xìnfēng. 봉투 하나 주세요.

### 4. "大概 + 몇 + 시간" — 대략적인 시간
- 大概几天到？ Dàgài jǐ tiān dào? 대략 며칠 걸려요?
- 大概一个星期到。 Dàgài yí gè xīngqī dào. 대략 일주일 걸려요.

## 应用会话 (응용 회화 - 일상)

A: 我要寄一封信。  
   Wǒ yào jì yì fēng xìn.  
   편지 한 통을 부치려고 해요.

B: 寄到哪里？  
   Jì dào nǎlǐ?  
   어디로 보내시나요?

A: 寄到韩国。  
   Jì dào Hánguó.  
   한국으로요.

B: 请给我，再买张邮票。  
   Qǐng gěi wǒ, zài mǎi zhāng yóupiào.  
   주세요, 그리고 우표 한 장 사세요.

A: 好的，邮票多少钱一张？  
   Hǎo de, yóupiào duōshao qián yì zhāng?  
   네, 우표는 한 장에 얼마예요?

B: 两块五。  
   Liǎng kuài wǔ.  
   2.5위안입니다.

A: 大概几天到？  
   Dàgài jǐ tiān dào?  
   대략 며칠 걸려요?

B: 大概一个星期。  
   Dàgài yí gè xīngqī.  
   대략 일주일이에요.
