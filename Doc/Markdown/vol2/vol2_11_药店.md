第 十一 课 : 11. 药店 Yàodiàn (약국)

## 本文 (본문)

附近有药店吗？  
Fùjìn yǒu yàodiàn ma?  
근처에 약국이 있나요?

我要买感冒药。  
Wǒ yào mǎi gǎnmàoyào.  
감기약을 사려고 해요.

我头疼。  
Wǒ tóuténg.  
머리가 아파요.

这个药怎么吃？  
Zhège yào zěnme chī?  
이 약은 어떻게 먹나요?

一天吃几次？  
Yì tiān chī jǐ cì?  
하루에 몇 번 먹나요?

一次吃两片。  
Yí cì chī liǎng piàn.  
한 번에 두 알씩 먹어요.

饭后吃。  
Fàn hòu chī.  
식후에 드세요.

需要处方吗？

처방전이 필요한가요?

## 主要词汇 (주요 단어)

### 1. 药店  /  yàodiàn  /  [명사 (n.)]  /  약국
- 한자 풀이: 药(약 약) + 店(가게 점) → 약을 파는 가게
- 例句: 附近有药店吗？
- Pinyin: Fùjìn yǒu yàodiàn ma?
- 번역: 근처에 약국이 있나요?

### 2. 药  /  yào  /  [명사 (n.)]  /  약
- 한자 풀이: 药(약 약) → 병을 고치는 물질
- 例句: 这个药怎么吃？
- Pinyin: Zhège yào zěnme chī?
- 번역: 이 약은 어떻게 먹나요?

### 3. 感冒药  /  gǎnmàoyào  /  [명사 (n.)]  /  감기약
- 한자 풀이: 感冒(감기) + 药(약) → 감기에 쓰는 약
- 例句: 我要买感冒药。
- Pinyin: Wǒ yào mǎi gǎnmàoyào.
- 번역: 감기약을 사려고 해요.

### 4. 头疼  /  tóuténg  /  [형용사 (adj.)]  /  머리가 아프다
- 한자 풀이: 头(머리 두) + 疼(아플 동) → 머리가 아프다
- 例句: 我头疼。
- Pinyin: Wǒ tóuténg.
- 번역: 머리가 아파요.

### 5. 处方  /  chǔfāng  /  [명사 (n.)]  /  처방전
- 한자 풀이: 处(곳 처) + 方(방법 방) → 의사의 약 처방
- 例句: 需要处方吗？
- Pinyin: Xūyào chǔfāng ma?
- 번역: 처방전이 필요한가요?

### 6. 片  /  piàn  /  [양사 (m.)]  /  알, 조각 (알약 단위)
- 한자 풀이: 片(조각 편) → 알약을 세는 단위
- 例句: 一次吃两片。
- Pinyin: Yí cì chī liǎng piàn.
- 번역: 한 번에 두 알씩 먹어요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 附近 | fùjìn | f를 ㅍ/ㅎ처럼 읽음 | 윗니를 아랫입술에 대고 f 소리 |
| 怎么 | zěnme | 么을 mō(1성)으로 읽음 | 么는 경성(me)으로 가볍게 |
| 一天 | yì tiān | 一을 yī(1성)로 그대로 읽음 | 一은 1성(비4성) 앞에서 4성(yì)으로 변함 |
| 一次 | yí cì | 一을 yī(1성)로 그대로 읽음 | 一은 뒤 4성 앞에서 2성(yí)으로 변함 |
| 处方 | chǔfāng | ch를 ㅊ처럼 '처'로 읽음 | 혀를 말아 권설음 ch로 '추'(3성) |

## 语法点 (어법 포인트)

### 1. "怎么 + 동사" — 방법 묻기
- 这个药怎么吃？ Zhège yào zěnme chī? 이 약은 어떻게 먹나요?
- 怎么去药店？ Zěnme qù yàodiàn? 약국에 어떻게 가나요?

### 2. "一天 ... 几次" — 횟수 표현
- 一天吃几次？ Yì tiān chī jǐ cì? 하루에 몇 번 먹나요?
- 一天吃三次。 Yì tiān chī sān cì. 하루에 세 번 먹어요.

### 3. "一次 + 수량" — 한 번의 분량
- 一次吃两片。 Yí cì chī liǎng piàn. 한 번에 두 알씩 먹어요.
- 一次吃一片。 Yí cì chī yí piàn. 한 번에 한 알씩 먹어요.

### 4. "需要 ... 吗？" — 필요 여부 묻기
- 需要处方吗？ Xūyào chǔfāng ma? 처방전이 필요한가요?
- 需要喝水吗？ Xūyào hē shuǐ ma? 물을 마셔야 하나요?

## 应用会话 (응용 회화 - 일상)

A: 你好，我要买感冒药。  
   Nǐ hǎo, wǒ yào mǎi gǎnmàoyào.  
   안녕하세요, 감기약을 사려고 해요.

B: 你哪里不舒服？  
   Nǐ nǎlǐ bù shūfu?  
   어디가 불편하세요?

A: 我头疼，还有点儿咳嗽。  
   Wǒ tóuténg, hái yǒudiǎnr késou.  
   머리가 아프고 기침도 좀 해요.

B: 那吃这个药吧。  
   Nà chī zhège yào ba.  
   그럼 이 약을 드세요.

A: 这个药怎么吃？  
   Zhège yào zěnme chī?  
   이 약은 어떻게 먹나요?

B: 一天三次，一次两片，饭后吃。  
   Yì tiān sān cì, yí cì liǎng piàn, fàn hòu chī.  
   하루 세 번, 한 번에 두 알씩 식후에 드세요.

A: 需要处方吗？  
   Xūyào chǔfāng ma?  
   처방전이 필요한가요?

B: 不需要。  
   Bù xūyào.  
   필요 없어요.
