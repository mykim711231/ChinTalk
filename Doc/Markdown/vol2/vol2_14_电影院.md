第 十四 课 : 14. 电影院 Diànyǐngyuàn (영화관)

## 本文 (본문)

我们去看电影吧。  
Wǒmen qù kàn diànyǐng ba.  
우리 영화 보러 가요.

你想看什么电影？  
Nǐ xiǎng kàn shénme diànyǐng?  
무슨 영화 보고 싶어요?

我买两张电影票。  
Wǒ mǎi liǎng zhāng diànyǐngpiào.  
영화표 두 장 살게요.

几点开演？  
Jǐ diǎn kāiyǎn?  
몇 시에 상영하나요?

我要坐中间的位置。  
Wǒ yào zuò zhōngjiān de wèizhi.  
가운데 자리에 앉고 싶어요.

电影很好看。  
Diànyǐng hěn hǎokàn.  
영화가 아주 재미있어요.

我要一桶爆米花。  
Wǒ yào yì tǒng bàomǐhuā.  
팝콘 한 통 주세요.

还有票吗？  
Hái yǒu piào ma?  
아직 표가 있나요?

---

## 主要词汇 (주요 단어)

### 1. 电影  /  diànyǐng  /  [명사 (n.)]  /  영화
- 한자 풀이: 电(전기 전) + 影(그림자 영) → 영사되는 영상
- 例句: 我们去看电影吧。
- Pinyin: Wǒmen qù kàn diànyǐng ba.
- 번역: 우리 영화 보러 가요.

### 2. 电影院  /  diànyǐngyuàn  /  [명사 (n.)]  /  영화관
- 한자 풀이: 电影(영화) + 院(집 원) → 영화 상영 건물
- 例句: 电影院在哪儿？
- Pinyin: Diànyǐngyuàn zài nǎr?
- 번역: 영화관이 어디예요?

### 3. 票  /  piào  /  [명사 (n.)]  /  표, 티켓
- 한자 풀이: 票(표 표) → 입장 증명 표
- 例句: 还有票吗？
- Pinyin: Hái yǒu piào ma?
- 번역: 아직 표가 있나요?

### 4. 开演  /  kāiyǎn  /  [동사 (v.)]  /  상영이 시작되다
- 한자 풀이: 开(열 개) + 演(공연할 연) → 공연·상영이 시작되다
- 例句: 几点开演？
- Pinyin: Jǐ diǎn kāiyǎn?
- 번역: 몇 시에 상영하나요?

### 5. 位置  /  wèizhi  /  [명사 (n.)]  /  위치, 자리
- 한자 풀이: 位(자리 위) + 置(둘 치) → 자리, 장소
- 例句: 我要坐中间的位置。
- Pinyin: Wǒ yào zuò zhōngjiān de wèizhi.
- 번역: 가운데 자리에 앉고 싶어요.

### 6. 爆米花  /  bàomǐhuā  /  [명사 (n.)]  /  팝콘
- 한자 풀이: 爆(터질 폭) + 米(쌀) + 花(꽃) → 튀긴 옥수수
- 例句: 我要一桶爆米花。
- Pinyin: Wǒ yào yì tǒng bàomǐhuā.
- 번역: 팝콘 한 통 주세요.

## 语法点 (어법 포인트)

### 1. "我们 + 동작 + 吧" — 함께 ~하자 (권유)
- 我们去看电影吧。 Wǒmen qù kàn diànyǐng ba. 우리 영화 보러 가요.
- 我们买票吧。 Wǒmen mǎi piào ba. 우리 표 사자.

### 2. "几点 + 동작？" — 시간 묻기
- 几点开演？ Jǐ diǎn kāiyǎn? 몇 시에 상영하나요?
- 几点开始？ Jǐ diǎn kāishǐ? 몇 시에 시작하나요?

### 3. "我要 + 수량 + 명사" — 수량 요청
- 我买两张电影票。 Wǒ mǎi liǎng zhāng diànyǐngpiào. 영화표 두 장 살게요.
- 我要一桶爆米花。 Wǒ yào yì tǒng bàomǐhuā. 팝콘 한 통 주세요.

### 4. "还有 ... 吗？" — 남은 것 묻기
- 还有票吗？ Hái yǒu piào ma? 아직 표가 있나요?
- 还有位置吗？ Hái yǒu wèizhi ma? 아직 자리가 있나요?

## 应用会话 (응용 회화 - 일상)

A: 你想看什么电影？  
   Nǐ xiǎng kàn shénme diànyǐng?  
   무슨 영화 보고 싶어요?

B: 我想看喜剧片。  
   Wǒ xiǎng kàn xǐjùpiàn.  
   저는 코미디 영화 보고 싶어요.

A: 好，我买两张票。  
   Hǎo, wǒ mǎi liǎng zhāng piào.  
   좋아요, 표 두 장 살게요.

B: 几点开演？  
   Jǐ diǎn kāiyǎn?  
   몇 시에 상영하나요?

A: 晚上八点。  
   Wǎnshang bā diǎn.  
   저녁 8시요.

B: 我要坐中间的位置。  
   Wǒ yào zuò zhōngjiān de wèizhi.  
   가운데 자리에 앉고 싶어요.

A: 好的，我们买中间的吧。  
   Hǎo de, wǒmen mǎi zhōngjiān de ba.  
   네, 우리 가운데로 사요.

B: 再买一桶爆米花吧。  
   Zài mǎi yì tǒng bàomǐhuā ba.  
   그리고 팝콘 한 통도 사요.
