第 八 课 : 08. 银行 Yínháng (은행)

## 本文 (본문)

我要取钱。  
Wǒ yào qǔqián.  
돈을 찾으려고 해요.

请排队。  
Qǐng páiduì.  
줄을 서 주세요.

我要兑换人民币。  
Wǒ yào duìhuàn rénmínbì.  
위안화로 환전하려고 해요.

今天的汇率是多少？  
Jīntiān de huìlǜ shì duōshao?  
오늘 환율은 얼마예요?

我要开一个账户。  
Wǒ yào kāi yí gè zhànghù.  
계좌를 하나 열려고 해요.

请出示您的身份证。  
Qǐng chūshì nín de shēnfènzhèng.  
신분증을 보여 주세요.

取款机在哪儿？  
Qǔkuǎnjī zài nǎr?  
현금 인출기가 어디예요?

请在这里签字。  
Qǐng zài zhèlǐ qiānzì.  
여기에 서명해 주세요.

---

## 主要词汇 (주요 단어)

### 1. 银行  /  yínháng  /  [명사 (n.)]  /  은행
- 한자 풀이: 银(은 은) + 行(상점 항) → 돈을 다루는 기관
- 例句: 我去银行取钱。
- Pinyin: Wǒ qù yínháng qǔqián.
- 번역: 저는 은행에 가서 돈을 찾아요.

### 2. 取钱  /  qǔqián  /  [동사 (v.)]  /  돈을 찾다
- 한자 풀이: 取(취할 취) + 钱(돈 전) → 돈을 인출하다
- 例句: 我要取钱。
- Pinyin: Wǒ yào qǔqián.
- 번역: 돈을 찾으려고 해요.

### 3. 兑换  /  duìhuàn  /  [동사 (v.)]  /  환전하다
- 한자 풀이: 兑(바꿀 태) + 换(바꿀 환) → 통화를 바꾸다
- 例句: 我要兑换人民币。
- Pinyin: Wǒ yào duìhuàn rénmínbì.
- 번역: 위안화로 환전하려고 해요.

### 4. 汇率  /  huìlǜ  /  [명사 (n.)]  /  환율
- 한자 풀이: 汇(모일 회) + 率(비율 률) → 화폐 교환 비율
- 例句: 今天的汇率是多少？
- Pinyin: Jīntiān de huìlǜ shì duōshao?
- 번역: 오늘 환율은 얼마예요?

### 5. 账户  /  zhànghù  /  [명사 (n.)]  /  계좌
- 한자 풀이: 账(장부 장) + 户(집 호) → 금융 거래 계좌
- 例句: 我要开一个账户。
- Pinyin: Wǒ yào kāi yí gè zhànghù.
- 번역: 계좌를 하나 열려고 해요.

### 6. 签字  /  qiānzì  /  [동사 (v.)]  /  서명하다
- 한자 풀이: 签(서명할 첨) + 字(글자 자) → 이름을 쓰다
- 例句: 请在这里签字。
- Pinyin: Qǐng zài zhèlǐ qiānzì.
- 번역: 여기에 서명해 주세요.

## 语法点 (어법 포인트)

### 1. "要 + 동사" — 하려고 하다
- 我要取钱。 Wǒ yào qǔqián. 돈을 찾으려고 해요.
- 我要开一个账户。 Wǒ yào kāi yí gè zhànghù. 계좌를 열려고 해요.

### 2. "请 + 동사" — 정중한 요청
- 请排队。 Qǐng páiduì. 줄을 서 주세요.
- 请在这里签字。 Qǐng zài zhèlǐ qiānzì. 여기에 서명해 주세요.

### 3. "是多少？" — 숫자/수량 묻기
- 今天的汇率是多少？ Jīntiān de huìlǜ shì duōshao? 오늘 환율은 얼마예요?
- 手续费是多少？ Shǒuxùfèi shì duōshao? 수수료는 얼마예요?

### 4. "出示" — (신분증 등을) 제시하다
- 请出示您的身份证。 Qǐng chūshì nín de shēnfènzhèng. 신분증을 보여 주세요.
- 请出示您的护照。 Qǐng chūshì nín de hùzhào. 여권을 보여 주세요.

## 应用会话 (응용 회화 - 일상)

A: 您好，我要兑换人民币。  
   Nín hǎo, wǒ yào duìhuàn rénmínbì.  
   안녕하세요, 위안화로 환전하려고 해요.

B: 好的，您要换多少钱？  
   Hǎo de, nín yào huàn duōshao qián?  
   네, 얼마를 환전하시겠어요?

A: 今天的汇率是多少？  
   Jīntiān de huìlǜ shì duōshao?  
   오늘 환율은 얼마예요?

B: 一美元换七块二。  
   Yì měiyuán huàn qī kuài èr.  
   1달러에 7.2위안입니다.

A: 那我要换一百美元。  
   Nà wǒ yào huàn yì bǎi měiyuán.  
   그럼 100달러를 환전할게요.

B: 请出示您的护照。  
   Qǐng chūshì nín de hùzhào.  
   여권을 보여 주세요.

A: 给您。  
   Gěi nín.  
   여기요.

B: 好的，这是您的钱，请点一下。  
   Hǎo de, zhè shì nín de qián, qǐng diǎn yíxià.  
   네, 여기 돈입니다, 확인해 보세요.
