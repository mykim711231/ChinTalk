第 十 课 : 10. 看病 Kànbìng (병원 진료)

## 本文 (본문)

我身体不舒服。  
Wǒ shēntǐ bù shūfu.  
몸이 불편해요.

我要看医生。  
Wǒ yào kàn yīshēng.  
진료를 받으려고 해요.

请帮我挂号。  
Qǐng bāng wǒ guàhào.  
접수를 도와주세요.

我发烧了。  
Wǒ fāshāo le.  
열이 나요.

我头疼，还咳嗽。  
Wǒ tóuténg, hái késou.  
머리가 아프고 기침도 해요.

我感冒了。  
Wǒ gǎnmào le.  
감기에 걸렸어요.

严重吗？  
Yánzhòng ma?  
심한가요?

请多喝水，多休息。  
Qǐng duō hē shuǐ, duō xiūxi.  
물을 많이 마시고 많이 쉬세요.

---

## 主要词汇 (주요 단어)

### 1. 看病  /  kànbìng  /  [동사 (v.)]  /  진료받다
- 한자 풀이: 看(볼 간) + 病(병 병) → 병을 진찰받다
- 例句: 我去医院看病。
- Pinyin: Wǒ qù yīyuàn kànbìng.
- 번역: 저는 병원에 진료받으러 가요.

### 2. 医生  /  yīshēng  /  [명사 (n.)]  /  의사
- 한자 풀이: 医(의원 의) + 生(생도 생) → 진료하는 사람
- 例句: 我要看医生。
- Pinyin: Wǒ yào kàn yīshēng.
- 번역: 진료를 받으려고 해요.

### 3. 挂号  /  guàhào  /  [동사 (v.)]  /  접수하다
- 한자 풀이: 挂(걸 괘) + 号(번호 호) → 진료 번호를 받다
- 例句: 请帮我挂号。
- Pinyin: Qǐng bāng wǒ guàhào.
- 번역: 접수를 도와주세요.

### 4. 发烧  /  fāshāo  /  [동사 (v.)]  /  열이 나다
- 한자 풀이: 发(날 발) + 烧(사를 소) → 열이 오르다
- 例句: 我发烧了。
- Pinyin: Wǒ fāshāo le.
- 번역: 열이 나요.

### 5. 感冒  /  gǎnmào  /  [동사 (v.)]  /  감기에 걸리다
- 한자 풀이: 感(느낄 감) + 冒(무릅쓸 모) → 감기에 걸리다
- 例句: 我感冒了。
- Pinyin: Wǒ gǎnmào le.
- 번역: 감기에 걸렸어요.

### 6. 严重  /  yánzhòng  /  [형용사 (adj.)]  /  심하다
- 한자 풀이: 严(엄할 엄) + 重(무거울 중) → 정도가 심하다
- 例句: 严重吗？
- Pinyin: Yánzhòng ma?
- 번역: 심한가요?

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 舒服 | shūfu | 服를 fú(2성)로 강하게 읽음 | 服는 경성(fu)으로 가볍게 |
| 发烧 | fāshāo | f를 ㅍ처럼, sh를 ㅅ처럼 읽음 | f는 윗니+아랫입술, sh는 권설음 |
| 咳嗽 | késou | 嗽를 sòu(4성)로 읽음 | 嗽는 경성(sou)으로 가볍게 |
| 严重 | yánzhòng | zh를 ㅈ처럼 '중'으로 읽음 | 혀를 말아 권설음 zh로 '쫑'(4성) |

## 语法点 (어법 포인트)

### 1. "我 + 증상 + 了" — 증상 표현
- 我发烧了。 Wǒ fāshāo le. 열이 나요.
- 我感冒了。 Wǒ gǎnmào le. 감기에 걸렸어요.

### 2. "请 + 동작" — 정중한 요청
- 请帮我挂号。 Qǐng bāng wǒ guàhào. 접수를 도와주세요.
- 请多喝水，多休息。 Qǐng duō hē shuǐ, duō xiūxi. 물을 많이 마시고 많이 쉬세요.

### 3. "严重吗？" — 상태 묻기
- 严重吗？ Yánzhòng ma? 심한가요?
- 不严重。 Bù yánzhòng. 심하지 않아요.

### 4. "多 + 동사" — 많이 ~하다
- 多喝水 duō hē shuǐ 물을 많이 마시다
- 多休息 duō xiūxi 많이 쉬다

## 应用会话 (응용 회화 - 일상)

A: 医生，我身体不舒服。  
   Yīshēng, wǒ shēntǐ bù shūfu.  
   의사 선생님, 몸이 불편해요.

B: 哪里不舒服？  
   Nǎlǐ bù shūfu?  
   어디가 불편하세요?

A: 我头疼，还咳嗽。  
   Wǒ tóuténg, hái késou.  
   머리가 아프고 기침도 해요.

B: 发烧吗？  
   Fāshāo ma?  
   열이 나나요?

A: 有一点儿。  
   Yǒu yìdiǎnr.  
   조금 나요.

B: 你感冒了。要多喝水，多休息。  
   Nǐ gǎnmào le. Yào duō hē shuǐ, duō xiūxi.  
   감기에 걸렸네요. 물을 많이 마시고 많이 쉬세요.

A: 严重吗？  
   Yánzhòng ma?  
   심한가요?

B: 不严重，吃点药就好了。  
   Bù yánzhòng, chī diǎnr yào jiù hǎo le.  
   심하지 않아요, 약 좀 먹으면 나아요.
