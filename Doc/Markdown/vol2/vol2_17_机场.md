第 十七 课 : 17. 机场 Jīchǎng (공항)

## 本文 (본문)

我要去机场。  
Wǒ yào qù jīchǎng.  
공항에 가려고 해요.

我的航班是几点？  
Wǒ de hángbān shì jǐ diǎn?  
제 항공편은 몇 시예요?

请出示您的护照。  
Qǐng chūshì nín de hùzhào.  
여권을 보여 주세요.

我要托运行李。  
Wǒ yào tuōyùn xíngli.  
짐을 부치려고 해요.

登机口在哪儿？  
Dēngjīkǒu zài nǎr?  
탑승구가 어디예요?

请把行李放上安检机。  
Qǐng bǎ xíngli fàng shang ānjiǎnjī.  
짐을 보안 검색대에 올려 주세요.

飞机要起飞了。  
Fēijī yào qǐfēi le.  
비행기가 이륙하려고 해요.

飞机晚点了。  
Fēijī wǎndiǎn le.  
비행기가 연착됐어요.

---

## 主要词汇 (주요 단어)

### 1. 机场  /  jīchǎng  /  [명사 (n.)]  /  공항
- 한자 풀이: 机(비행기 기) + 场(마당 장) → 비행기 이착륙장
- 例句: 我要去机场。
- Pinyin: Wǒ yào qù jīchǎng.
- 번역: 공항에 가려고 해요.

### 2. 航班  /  hángbān  /  [명사 (n.)]  /  항공편
- 한자 풀이: 航(배 항) + 班(나눌 반) → 운항하는 비행기 편
- 例句: 我的航班是几点？
- Pinyin: Wǒ de hángbān shì jǐ diǎn?
- 번역: 제 항공편은 몇 시예요?

### 3. 托运  /  tuōyùn  /  [동사 (v.)]  /  (짐을) 부치다
- 한자 풀이: 托(맡길 탁) + 运(운반할 운) → 짐을 맡겨 운반하다
- 例句: 我要托运行李。
- Pinyin: Wǒ yào tuōyùn xíngli.
- 번역: 짐을 부치려고 해요.

### 4. 登机口  /  dēngjīkǒu  /  [명사 (n.)]  /  탑승구
- 한자 풀이: 登机(탑승) + 口(입구) → 비행기 탑승 입구
- 例句: 登机口在哪儿？
- Pinyin: Dēngjīkǒu zài nǎr?
- 번역: 탑승구가 어디예요?

### 5. 安检  /  ānjiǎn  /  [명사 (n.)]  /  보안 검사
- 한자 풀이: 安(안전할 안) + 检(검사할 검) → 안전 검사
- 例句: 请把行李放上安检机。
- Pinyin: Qǐng bǎ xíngli fàng shang ānjiǎnjī.
- 번역: 짐을 보안 검색대에 올려 주세요.

### 6. 起飞  /  qǐfēi  /  [동사 (v.)]  /  이륙하다
- 한자 풀이: 起(일어날 기) + 飞(날 비) → 이륙하다
- 例句: 飞机要起飞了。
- Pinyin: Fēijī yào qǐfēi le.
- 번역: 비행기가 이륙하려고 해요.

## 语法点 (어법 포인트)

### 1. "要 + 동사" — 하려고 하다
- 我要去机场。 Wǒ yào qù jīchǎng. 공항에 가려고 해요.
- 我要托运行李。 Wǒ yào tuōyùn xíngli. 짐을 부치려고 해요.

### 2. "请 + 동사" — 정중한 요청
- 请出示您的护照。 Qǐng chūshì nín de hùzhào. 여권을 보여 주세요.
- 请把行李放上安检机。 Qǐng bǎ xíngli fàng shang ānjiǎnjī. 짐을 보안 검색대에 올려 주세요.

### 3. "是几点？" — 시간 묻기
- 我的航班是几点？ Wǒ de hángbān shì jǐ diǎn? 제 항공편은 몇 시예요?
- 几点起飞？ Jǐ diǎn qǐfēi? 몇 시에 이륙하나요?

### 4. "... 在哪儿？" — 장소 묻기
- 登机口在哪儿？ Dēngjīkǒu zài nǎr? 탑승구가 어디예요?
- 安检在哪儿？ Ānjiǎn zài nǎr? 보안 검색대가 어디예요?

## 应用会话 (응용 회화 - 일상)

A: 您好，请出示您的护照。  
   Nín hǎo, qǐng chūshì nín de hùzhào.  
   안녕하세요, 여권을 보여 주세요.

B: 好的，给您。  
   Hǎo de, gěi nín.  
   네, 여기요.

A: 您要托运行李吗？  
   Nín yào tuōyùn xíngli ma?  
   짐을 부치시겠어요?

B: 是的，托运这件。  
   Shì de, tuōyùn zhè jiàn.  
   네, 이걸 부칠게요.

A: 好的，登机口是B12。  
   Hǎo de, dēngjīkǒu shì B12.  
   네, 탑승구는 B12입니다.

B: 登机口在哪儿？  
   Dēngjīkǒu zài nǎr?  
   탑승구가 어디예요?

A: 请直走，然后左转。  
   Qǐng zhí zǒu, ránhòu zuǒ zhuǎn.  
   직진하신 다음 좌회전하세요.

B: 谢谢。  
   Xièxie.  
   감사합니다.
