第 十九 课 : 19. 洗衣店 Xǐyīdiàn (세탁소)

## 本文 (본문)

我要洗衣服。  
Wǒ yào xǐ yīfu.  
옷을 세탁하려고 해요.

请帮我洗这件衬衫。  
Qǐng bāng wǒ xǐ zhè jiàn chènshān.  
이 셔츠를 세탁해 주세요.

要干洗还是水洗？  
Yào gānxǐ háishì shuǐxǐ?  
드라이클리닝으로 할까요, 물세탁으로 할까요?

这件要干洗。  
Zhè jiàn yào gānxǐ.  
이건 드라이클리닝으로 해 주세요.

什么时候能取？  
Shénme shíhou néng qǔ?  
언제 찾을 수 있나요?

请熨一下。  
Qǐng yùn yíxià.  
다림질을 해 주세요.

洗一件衣服多少钱？  
Xǐ yí jiàn yīfu duōshao qián?  
옷 한 벌 세탁하는 데 얼마예요?

请给我一张收据。  
Qǐng gěi wǒ yì zhāng shōujù.  
영수증 한 장 주세요.

## 主要词汇 (주요 단어)

### 1. 洗衣店  /  xǐyīdiàn  /  [명사 (n.)]  /  세탁소
- 한자 풀이: 洗(씻을 세) + 衣(옷) + 店(가게) → 옷을 세탁하는 가게
- 例句: 我去洗衣店洗衣服。
- Pinyin: Wǒ qù xǐyīdiàn xǐ yīfu.
- 번역: 저는 세탁소에 가서 옷을 세탁해요.

### 2. 洗  /  xǐ  /  [동사 (v.)]  /  씻다, 세탁하다
- 한자 풀이: 洗(씻을 세) → 물로 씻다
- 例句: 我要洗衣服。
- Pinyin: Wǒ yào xǐ yīfu.
- 번역: 옷을 세탁하려고 해요.

### 3. 干洗  /  gānxǐ  /  [동사 (v.)]  /  드라이클리닝하다
- 한자 풀이: 干(마를 간) + 洗(씻을 세) → 물 없이 세탁하다
- 例句: 这件要干洗。
- Pinyin: Zhè jiàn yào gānxǐ.
- 번역: 이건 드라이클리닝으로 해 주세요.

### 4. 水洗  /  shuǐxǐ  /  [동사 (v.)]  /  물세탁하다
- 한자 풀이: 水(물 수) + 洗(씻을 세) → 물로 세탁하다
- 例句: 这件可以水洗。
- Pinyin: Zhè jiàn kěyǐ shuǐxǐ.
- 번역: 이건 물세탁해도 돼요.

### 5. 熨  /  yùn  /  [동사 (v.)]  /  다림질하다
- 한자 풀이: 熨(다릴 위) → 다리미로 펴다
- 例句: 请熨一下。
- Pinyin: Qǐng yùn yíxià.
- 번역: 다림질을 해 주세요.

### 6. 取  /  qǔ  /  [동사 (v.)]  /  찾아오다, 수령하다
- 한자 풀이: 取(취할 취) → 가져오다
- 例句: 什么时候能取？
- Pinyin: Shénme shíhou néng qǔ?
- 번역: 언제 찾을 수 있나요?

## 语法点 (어법 포인트)

### 1. "请帮我 + 동작" — 도움 요청
- 请帮我洗这件衬衫。 Qǐng bāng wǒ xǐ zhè jiàn chènshān. 이 셔츠를 세탁해 주세요.
- 请帮我熨一下。 Qǐng bāng wǒ yùn yíxià. 다림질 좀 해 주세요.

### 2. "要 A 还是 B？" — 선택 의문
- 要干洗还是水洗？ Yào gānxǐ háishì shuǐxǐ? 드라이클리닝인가요, 물세탁인가요?
- 要今天还是明天？ Yào jīntiān háishì míngtiān? 오늘인가요, 내일인가요?

### 3. "什么时候能 ...？" — 가능 시점 묻기
- 什么时候能取？ Shénme shíhou néng qǔ? 언제 찾을 수 있나요?
- 什么时候能好？ Shénme shíhou néng hǎo? 언제 다 돼요?

### 4. "... 多少钱？" — 가격 묻기
- 洗一件衣服多少钱？ Xǐ yí jiàn yīfu duōshao qián? 옷 한 벌 세탁하는 데 얼마예요?
- 熨一件多少钱？ Yùn yí jiàn duōshao qián? 한 벌 다림질에 얼마예요?

## 应用会话 (응용 회화 - 일상)

A: 你好，我要洗衣服。  
   Nǐ hǎo, wǒ yào xǐ yīfu.  
   안녕하세요, 옷을 세탁하려고 해요.

B: 好的，请把衣服给我。  
   Hǎo de, qǐng bǎ yīfu gěi wǒ.  
   네, 옷을 주세요.

B: 这件要干洗还是水洗？  
   Zhè jiàn yào gānxǐ háishì shuǐxǐ?  
   이건 드라이클리닝으로 할까요, 물세탁으로 할까요?

A: 这件要干洗。  
   Zhè jiàn yào gānxǐ.  
   이건 드라이클리닝으로 해 주세요.

B: 好的。  
   Hǎo de.  
   네.

A: 什么时候能取？  
   Shénme shíhou néng qǔ?  
   언제 찾을 수 있나요?

B: 后天下午。  
   Hòutiān xiàwǔ.  
   모레 오후에요.

A: 洗一件衣服多少钱？  
   Xǐ yí jiàn yīfu duōshao qián?  
   옷 한 벌 세탁하는 데 얼마예요?

B: 二十块钱。  
   Èrshí kuài qián.  
   20위안입니다.
