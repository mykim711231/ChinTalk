第 十五 课 : 15. 订位 Dìngwèi (레스토랑 예약)

## 本文 (본문)

我想订位。  
Wǒ xiǎng dìngwèi.  
자리를 예약하고 싶어요.

请问几位？  
Qǐngwèn jǐ wèi?  
몇 분이세요?

我们一共五个人。  
Wǒmen yígòng wǔ gè rén.  
저희는 모두 다섯 명이에요.

我想订今晚的位子。  
Wǒ xiǎng dìng jīnwǎn de wèizi.  
오늘 저녁 자리를 예약하고 싶어요.

请订六点的。  
Qǐng dìng liù diǎn de.  
6시로 예약해 주세요.

有靠窗的位子吗？  
Yǒu kào chuāng de wèizi ma?  
창가 자리가 있나요?

可以订包间吗？  
Kěyǐ dìng bāojiān ma?  
룸(개인실) 예약이 가능한가요?

我姓金。  
Wǒ xìng Jīn.  
저는 성이 김입니다.

---

## 主要词汇 (주요 단어)

### 1. 订位  /  dìngwèi  /  [동사 (v.)]  /  자리를 예약하다
- 한자 풀이: 订(정할 정) + 位(자리 위) → 자리를 예약하다
- 例句: 我想订位。
- Pinyin: Wǒ xiǎng dìngwèi.
- 번역: 자리를 예약하고 싶어요.

### 2. 位  /  wèi  /  [양사 (m.)]  /  분 (사람 존칭 단위)
- 한자 풀이: 位(자리 위) → 사람을 세는 공손한 단위
- 例句: 请问几位？
- Pinyin: Qǐngwèn jǐ wèi?
- 번역: 몇 분이세요?

### 3. 位子  /  wèizi  /  [명사 (n.)]  /  자리, 좌석
- 한자 풀이: 位(자리) + 子(접미사) → 앉는 자리
- 例句: 有靠窗的位子吗？
- Pinyin: Yǒu kào chuāng de wèizi ma?
- 번역: 창가 자리가 있나요?

### 4. 靠窗  /  kào chuāng  /  [형용사 (adj.)]  /  창가의
- 한자 풀이: 靠(기댈 고) + 窗(창 창) → 창에 가까운
- 例句: 请给我靠窗的位子。
- Pinyin: Qǐng gěi wǒ kào chuāng de wèizi.
- 번역: 창가 자리를 주세요.

### 5. 包间  /  bāojiān  /  [명사 (n.)]  /  룸, 개인실
- 한자 풀이: 包(쌀 포) + 间(방 간) → 별도로 나눈 방
- 例句: 可以订包间吗？
- Pinyin: Kěyǐ dìng bāojiān ma?
- 번역: 룸 예약이 가능한가요?

### 6. 姓  /  xìng  /  [동사 (v.)]  /  성(姓)이 ~이다
- 한자 풀이: 姓(성 성) → 성을 나타내다
- 例句: 我姓金。
- Pinyin: Wǒ xìng Jīn.
- 번역: 저는 성이 김입니다.

## 语法点 (어법 포인트)

### 1. "想 + 동사" — 하고 싶다
- 我想订位。 Wǒ xiǎng dìngwèi. 자리를 예약하고 싶어요.
- 我想订今晚的位子。 Wǒ xiǎng dìng jīnwǎn de wèizi. 오늘 저녁 자리를 예약하고 싶어요.

### 2. "请问几位？" — 인원 묻기
- 请问几位？ Qǐngwèn jǐ wèi? 몇 분이세요?
- 我们一共五个人。 Wǒmen yígòng wǔ gè rén. 저희는 모두 다섯 명이에요.

### 3. "有 ... 吗？" — 유무 묻기
- 有靠窗的位子吗？ Yǒu kào chuāng de wèizi ma? 창가 자리가 있나요?
- 有包间吗？ Yǒu bāojiān ma? 룸이 있나요?

### 4. "可以 ... 吗？" — 가능 여부 묻기
- 可以订包间吗？ Kěyǐ dìng bāojiān ma? 룸 예약이 가능한가요?
- 可以订六点吗？ Kěyǐ dìng liù diǎn ma? 6시로 예약할 수 있나요?

## 应用会话 (응용 회화 - 일상)

A: 您好，我想订位。  
   Nín hǎo, wǒ xiǎng dìngwèi.  
   안녕하세요, 자리를 예약하고 싶어요.

B: 好的，请问几位？  
   Hǎo de, qǐngwèn jǐ wèi?  
   네, 몇 분이세요?

A: 我们一共五个人。  
   Wǒmen yígòng wǔ gè rén.  
   저희는 모두 다섯 명이에요.

B: 什么时候来？  
   Shénme shíhou lái?  
   언제 오시나요?

A: 今晚六点。  
   Jīnwǎn liù diǎn.  
   오늘 저녁 6시요.

B: 好的。  
   Hǎo de.  
   네.

A: 有靠窗的位子吗？  
   Yǒu kào chuāng de wèizi ma?  
   창가 자리가 있나요?

B: 有，我给您留。  
   Yǒu, wǒ gěi nín liú.  
   있어요, 남겨 드릴게요.

A: 谢谢，我姓金。  
   Xièxie, wǒ xìng Jīn.  
   감사합니다, 저는 성이 김입니다.
