第 十六 课 : 16. 咖啡馆 Kāfēiguǎn (카페)

## 本文 (본문)

我想喝一杯咖啡。  
Wǒ xiǎng hē yì bēi kāfēi.  
커피 한 잔 마시고 싶어요.

请问您要什么咖啡？  
Qǐngwèn nín yào shénme kāfēi?  
어떤 커피를 드릴까요?

我要一杯拿铁。  
Wǒ yào yì bēi nátiě.  
라떼 한 잔 주세요.

要热的还是冰的？  
Yào rè de háishì bīng de?  
따뜻한 걸로 할까요, 아이스로 할까요?

我要冰的。  
Wǒ yào bīng de.  
아이스로 할게요.

加糖吗？  
Jiā táng ma?  
설탕 넣어 드릴까요?

不加糖。  
Bù jiā táng.  
설탕 넣지 마세요.

一共多少钱？  
Yígòng duōshao qián?  
전부 얼마예요?

---

## 主要词汇 (주요 단어)

### 1. 咖啡  /  kāfēi  /  [명사 (n.)]  /  커피
- 한자 풀이: 咖啡(커피의 음역) → 커피
- 例句: 我想喝一杯咖啡。
- Pinyin: Wǒ xiǎng hē yì bēi kāfēi.
- 번역: 커피 한 잔 마시고 싶어요.

### 2. 咖啡馆  /  kāfēiguǎn  /  [명사 (n.)]  /  카페
- 한자 풀이: 咖啡(커피) + 馆(집 관) → 커피를 파는 곳
- 例句: 我们去咖啡馆吧。
- Pinyin: Wǒmen qù kāfēiguǎn ba.
- 번역: 우리 카페에 가요.

### 3. 拿铁  /  nátiě  /  [명사 (n.)]  /  라떼
- 한자 풀이: 拿铁(latte의 음역) → 우유를 넣은 커피
- 例句: 我要一杯拿铁。
- Pinyin: Wǒ yào yì bēi nátiě.
- 번역: 라떼 한 잔 주세요.

### 4. 热  /  rè  /  [형용사 (adj.)]  /  뜨겁다, 따뜻하다
- 한자 풀이: 热(더울 열) → 온도가 높다
- 例句: 我要热的。
- Pinyin: Wǒ yào rè de.
- 번역: 따뜻한 걸로 할게요.

### 5. 冰  /  bīng  /  [명사 (n.)]  /  얼음 / [형용사] 차갑다
- 한자 풀이: 冰(얼음 빙) → 차갑게 얼린
- 例句: 我要冰的。
- Pinyin: Wǒ yào bīng de.
- 번역: 아이스로 할게요.

### 6. 加糖  /  jiā táng  /  [동사 (v.)]  /  설탕을 넣다
- 한자 풀이: 加(더할 가) + 糖(설탕 당) → 설탕을 첨가하다
- 例句: 加糖吗？
- Pinyin: Jiā táng ma?
- 번역: 설탕 넣어 드릴까요?

## 语法点 (어법 포인트)

### 1. "要 + 음료" — 주문하기
- 我要一杯拿铁。 Wǒ yào yì bēi nátiě. 라떼 한 잔 주세요.
- 我要一杯咖啡。 Wǒ yào yì bēi kāfēi. 커피 한 잔 주세요.

### 2. "要 A 还是 B？" — 선택 의문
- 要热的还是冰的？ Yào rè de háishì bīng de? 따뜻한 걸로 할까요, 아이스로 할까요?
- 要咖啡还是茶？ Yào kāfēi háishì chá? 커피로 할까요, 차로 할까요?

### 3. "加 ... 吗？" — 첨가 여부 묻기
- 加糖吗？ Jiā táng ma? 설탕 넣어 드릴까요?
- 加牛奶吗？ Jiā niúnǎi ma? 우유 넣어 드릴까요?

### 4. "不 + 동사" — 부정
- 不加糖。 Bù jiā táng. 설탕 넣지 마세요.
- 不加热。 Bù jiā rè. 뜨겁게 하지 마세요.

## 应用会话 (응용 회화 - 일상)

A: 欢迎光临！请问您要什么咖啡？  
   Huānyíng guānglín! Qǐngwèn nín yào shénme kāfēi?  
   어서 오세요! 어떤 커피를 드릴까요?

B: 我要一杯拿铁。  
   Wǒ yào yì bēi nátiě.  
   라떼 한 잔 주세요.

A: 要热的还是冰的？  
   Yào rè de háishì bīng de?  
   따뜻한 걸로 할까요, 아이스로 할까요?

B: 我要冰的。  
   Wǒ yào bīng de.  
   아이스로 할게요.

A: 加糖吗？  
   Jiā táng ma?  
   설탕 넣어 드릴까요?

B: 不加糖。  
   Bù jiā táng.  
   설탕 넣지 마세요.

A: 好的，一共二十五块。  
   Hǎo de, yígòng èrshíwǔ kuài.  
   네, 전부 25위안입니다.

B: 谢谢。  
   Xièxie.  
   감사합니다.
