第 七 课 : 07. 入住酒店 Rùzhù jiǔdiàn (호텔 체크인)

## 本文 (본문)

我要办理入住。  
Wǒ yào bànlǐ rùzhù.  
체크인을 하려고 해요.

我预订了房间。  
Wǒ yùdìng le fángjiān.  
방을 예약했어요.

请出示您的护照。  
Qǐng chūshì nín de hùzhào.  
여권을 보여 주세요.

我的房间在几楼？  
Wǒ de fángjiān zài jǐ lóu?  
제 방은 몇 층이에요?

电梯在哪儿？  
Diàntī zài nǎr?  
엘리베이터가 어디예요?

房卡给您。  
Fángkǎ gěi nín.  
룸카드 여기 있습니다.

请问早餐几点开始？  
Qǐngwèn zǎocān jǐ diǎn kāishǐ?  
아침 식사는 몇 시부터인가요?

我要退房。  
Wǒ yào tuìfáng.  
체크아웃하려고 해요.

---

## 主要词汇 (주요 단어)

### 1. 入住  /  rùzhù  /  [동사 (v.)]  /  체크인하다, 숙박하다
- 한자 풀이: 入(들 입) + 住(살 주) → 숙소에 들어와 머물다
- 例句: 我要办理入住。
- Pinyin: Wǒ yào bànlǐ rùzhù.
- 번역: 체크인을 하려고 해요.

### 2. 预订  /  yùdìng  /  [동사 (v.)]  /  예약하다
- 한자 풀이: 预(미리 예) + 订(정할 정) → 미리 정하다
- 例句: 我预订了房间。
- Pinyin: Wǒ yùdìng le fángjiān.
- 번역: 방을 예약했어요.

### 3. 房间  /  fángjiān  /  [명사 (n.)]  /  방, 객실
- 한자 풀이: 房(방 방) + 间(사이 간) → 방 하나
- 例句: 我的房间在几楼？
- Pinyin: Wǒ de fángjiān zài jǐ lóu?
- 번역: 제 방은 몇 층이에요?

### 4. 房卡  /  fángkǎ  /  [명사 (n.)]  /  룸카드
- 한자 풀이: 房(방) + 卡(카드) → 객실 출입 카드
- 例句: 房卡给您。
- Pinyin: Fángkǎ gěi nín.
- 번역: 룸카드 여기 있습니다.

### 5. 退房  /  tuìfáng  /  [동사 (v.)]  /  체크아웃하다
- 한자 풀이: 退(물러날 퇴) + 房(방) → 방을 비우고 나가다
- 例句: 我要退房。
- Pinyin: Wǒ yào tuìfáng.
- 번역: 체크아웃하려고 해요.

### 6. 护照  /  hùzhào  /  [명사 (n.)]  /  여권
- 한자 풀이: 护(보호할 호) + 照(증명할 조) → 해외여행 신분증
- 例句: 请出示您的护照。
- Pinyin: Qǐng chūshì nín de hùzhào.
- 번역: 여권을 보여 주세요.

## 语法点 (어법 포인트)

### 1. "要 + 동작" — 하려고 하다
- 我要办理入住。 Wǒ yào bànlǐ rùzhù. 체크인을 하려고 해요.
- 我要退房。 Wǒ yào tuìfáng. 체크아웃하려고 해요.

### 2. "请 + 동작" — 정중한 요청
- 请出示您的护照。 Qǐng chūshì nín de hùzhào. 여권을 보여 주세요.
- 请填一下表格。 Qǐng tián yíxià biǎogé. 양식을 작성해 주세요.

### 3. "在几楼？" — 층수 묻기
- 我的房间在几楼？ Wǒ de fángjiān zài jǐ lóu? 제 방은 몇 층이에요?
- 餐厅在几楼？ Cāntīng zài jǐ lóu? 식당은 몇 층이에요?

### 4. "几点 + 동작" — 시간 묻기
- 早餐几点开始？ Zǎocān jǐ diǎn kāishǐ? 아침 식사는 몇 시에 시작하나요?
- 几点退房？ Jǐ diǎn tuìfáng? 몇 시에 체크아웃하나요?

## 应用会话 (응용 회화 - 일상)

A: 您好，我要办理入住。  
   Nín hǎo, wǒ yào bànlǐ rùzhù.  
   안녕하세요, 체크인하려고 해요.

B: 好的，请出示您的护照。  
   Hǎo de, qǐng chūshì nín de hùzhào.  
   네, 여권을 보여 주세요.

A: 给您。我预订了房间。  
   Gěi nín. Wǒ yùdìng le fángjiān.  
   여기요. 방을 예약했어요.

B: 好的，这是您的房卡。  
   Hǎo de, zhè shì nín de fángkǎ.  
   네, 여기 룸카드입니다.

A: 我的房间在几楼？  
   Wǒ de fángjiān zài jǐ lóu?  
   제 방은 몇 층이에요?

B: 在五楼，电梯在左边。  
   Zài wǔ lóu, diàntī zài zuǒbiān.  
   5층이고, 엘리베이터는 왼쪽에 있어요.

A: 请问早餐几点开始？  
   Qǐngwèn zǎocān jǐ diǎn kāishǐ?  
   아침 식사는 몇 시부터인가요?

B: 早上七点到九点。  
   Zǎoshang qī diǎn dào jiǔ diǎn.  
   아침 7시부터 9시까지입니다.
