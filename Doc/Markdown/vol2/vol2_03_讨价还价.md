第 三 课 : 03. 讨价还价 Tǎojià huánjià (가격 흥정)

## 本文 (본문)

这个多少钱？  
Zhège duōshao qián?  
이건 얼마예요?

太贵了！  
Tài guì le!  
너무 비싸요!

能便宜一点吗？  
Néng piányi yìdiǎn ma?  
좀 깎아 주실 수 있나요?

最低多少钱？  
Zuìdī duōshao qián?  
최저가가 얼마예요?

便宜点吧，老板！  
Piányi diǎnr ba, lǎobǎn!  
좀 깎아 주세요, 사장님!

这个价太贵了。  
Zhège jià tài guì le.  
이 가격은 너무 비싸요.

一口价，五十块。  
Yìkǒujià, wǔshí kuài.  
에누리 없는 가격, 50위안.

我再看看吧。  
Wǒ zài kànkan ba.  
좀 더 둘러볼게요.

好，成交！  
Hǎo, chéngjiāo!  
좋아요, 거래 성사!

---

## 主要词汇 (주요 단어)

### 1. 便宜  /  piányi  /  [형용사 (adj.)]  /  싸다
- 한자 풀이: 便(편할 편) + 宜(마땅할 의) → 값이 낮다
- 例句: 能便宜一点吗？
- Pinyin: Néng piányi yìdiǎn ma?
- 번역: 좀 깎아 주실 수 있나요?

### 2. 贵  /  guì  /  [형용사 (adj.)]  /  비싸다
- 한자 풀이: 贵(귀할 귀) → 값이 높다
- 例句: 这个太贵了。
- Pinyin: Zhège tài guì le.
- 번역: 이건 너무 비싸요.

### 3. 老板  /  lǎobǎn  /  [명사 (n.)]  /  사장님, 주인
- 한자 풀이: 老(늙을 로) + 板(널빤지 판) → 가게 주인을 부르는 말
- 例句: 老板，这个多少钱？
- Pinyin: Lǎobǎn, zhège duōshao qián?
- 번역: 사장님, 이건 얼마예요?

### 4. 价  /  jià  /  [명사 (n.)]  /  가격, 값
- 한자 풀이: 价(값 가) → 물건의 값
- 例句: 这个价太高了。
- Pinyin: Zhège jià tài gāo le.
- 번역: 이 가격은 너무 높아요.

### 5. 最低  /  zuìdī  /  [형용사 (adj.)]  /  최저의
- 한자 풀이: 最(가장 최) + 低(낮을 저) → 가장 낮은
- 例句: 最低多少钱？
- Pinyin: Zuìdī duōshao qián?
- 번역: 최저가는 얼마예요?

### 6. 成交  /  chéngjiāo  /  [동사 (v.)]  /  거래가 성사되다
- 한자 풀이: 成(이룰 성) + 交(사귈 교) → 거래가 이루어지다
- 例句: 好，成交！
- Pinyin: Hǎo, chéngjiāo!
- 번역: 좋아요, 거래 성사!

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 便宜 | piányi | 宜를 yí(2성)로 읽음 | 宜는 경성(yi)으로 가볍게 |
| 太贵了 | tài guì le | 了를 liǎo로 발음 | 了는 경성(le)으로 가볍게 |
| 一口价 | yìkǒujià | 一을 yī(1성)로 그대로 읽음 | 一은 뒤 3성 앞에서 4성(yì)으로 변함 |
| 便宜点儿 | piányi diǎnr | 儿를 따로 '얼'로 발음 | 儿化로 diǎnr 한 음절로 굴려 발음 |
| 算了 | suànle | 了를 liǎo로 발음 | 了는 경성(le)으로 가볍게 |

## 语法点 (어법 포인트)

### 1. "能 + 동사 ... 吗？" — 가능성/허락 묻기
- 能便宜一点吗？ Néng piányi yìdiǎn ma? 좀 깎아 주실 수 있나요?
- 能再低一点吗？ Néng zài dī yìdiǎn ma? 좀 더 낮춰 주실 수 있나요?

### 2. "太 + 형용사 + 了" — 지나침
- 太贵了。 Tài guì le. 너무 비싸요.
- 太贵了，买不起。 Tài guì le, mǎi bu qǐ. 너무 비싸서 못 사요.

### 3. "一点" / "点儿" — 조금 (흥정 표현)
- 便宜一点 piányi yìdiǎn 조금 싸게
- 便宜点儿 piányi diǎnr 조금 싸게 (구어체)

### 4. "再 + 동사" — (일단) 더 ~하다
- 我再看看吧。 Wǒ zài kànkan ba. 좀 더 둘러볼게요.
- 我再想想。 Wǒ zài xiǎngxiang. 좀 더 생각해 볼게요.

## 应用会话 (응용 회화 - 일상)

A: 老板，这个包多少钱？  
   Lǎobǎn, zhège bāo duōshao qián?  
   사장님, 이 가방 얼마예요?

B: 两百块。  
   Liǎng bǎi kuài.  
   200위안입니다.

A: 太贵了！能便宜一点吗？  
   Tài guì le! Néng piányi yìdiǎn ma?  
   너무 비싸요! 좀 깎아 주실 수 있나요?

B: 那你说多少钱？  
   Nà nǐ shuō duōshao qián?  
   그럼 얼마를 원하세요?

A: 一百块，行不行？  
   Yì bǎi kuài, xíng bu xíng?  
   100위안, 괜찮나요?

B: 一百五，不能再少了。  
   Yì bǎi wǔ, bù néng zài shǎo le.  
   150위안, 더는 못 깎아요.

A: 那好吧，我买了。  
   Nà hǎo ba, wǒ mǎi le.  
   그럼 좋아요, 살게요.

B: 好的，成交！  
   Hǎo de, chéngjiāo!  
   좋아요, 거래 성사!
