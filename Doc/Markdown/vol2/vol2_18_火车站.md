第 十八 课 : 18. 火车站 Huǒchēzhàn (기차역)

## 本文 (본문)

我要买火车票。  
Wǒ yào mǎi huǒchēpiào.  
기차표를 사려고 해요.

我要一张去北京的高铁票。  
Wǒ yào yì zhāng qù Běijīng de gāotiě piào.  
베이징행 고속열차 표 한 장 주세요.

几点的车？  
Jǐ diǎn de chē?  
몇 시 차인가요?

我要坐下一班。  
Wǒ yào zuò xià yì bān.  
다음 편을 타려고 해요.

在哪个站台？  
Zài nǎge zhàntái?  
몇 번 승강장이에요?

火车要开了。  
Huǒchē yào kāi le.  
기차가 출발하려고 해요.

请出示您的车票。  
Qǐng chūshì nín de chēpiào.  
차표를 보여 주세요.

我想买卧铺票。  
Wǒ xiǎng mǎi wòpù piào.  
침대차 표를 사고 싶어요.

## 主要词汇 (주요 단어)

### 1. 火车站  /  huǒchēzhàn  /  [명사 (n.)]  /  기차역
- 한자 풀이: 火车(기차) + 站(역) → 기차가 서는 곳
- 例句: 我去火车站。
- Pinyin: Wǒ qù huǒchēzhàn.
- 번역: 저는 기차역에 가요.

### 2. 火车票  /  huǒchēpiào  /  [명사 (n.)]  /  기차표
- 한자 풀이: 火车(기차) + 票(표) → 기차 승차권
- 例句: 我要买火车票。
- Pinyin: Wǒ yào mǎi huǒchēpiào.
- 번역: 기차표를 사려고 해요.

### 3. 高铁  /  gāotiě  /  [명사 (n.)]  /  고속열차
- 한자 풀이: 高(높을 고) + 铁(철도) → 고속철도
- 例句: 我坐高铁去北京。
- Pinyin: Wǒ zuò gāotiě qù Běijīng.
- 번역: 저는 고속열차로 베이징에 가요.

### 4. 站台  /  zhàntái  /  [명사 (n.)]  /  승강장
- 한자 풀이: 站(역) + 台(받침대) → 열차를 타는 곳
- 例句: 在哪个站台？
- Pinyin: Zài nǎge zhàntái?
- 번역: 몇 번 승강장이에요?

### 5. 卧铺  /  wòpù  /  [명사 (n.)]  /  침대차
- 한자 풀이: 卧(누울 와) + 铺(깔 포) → 누워 가는 칸
- 例句: 我想买卧铺票。
- Pinyin: Wǒ xiǎng mǎi wòpù piào.
- 번역: 침대차 표를 사고 싶어요.

### 6. 车票  /  chēpiào  /  [명사 (n.)]  /  차표, 승차권
- 한자 풀이: 车(차) + 票(표) → 승차권
- 例句: 请出示您的车票。
- Pinyin: Qǐng chūshì nín de chēpiào.
- 번역: 차표를 보여 주세요.

## 语法点 (어법 포인트)

### 1. "我要一张 ... 的票" — 표 구매
- 我要一张去北京的高铁票。 Wǒ yào yì zhāng qù Běijīng de gāotiě piào. 베이징행 고속열차 표 한 장 주세요.
- 我要一张卧铺票。 Wǒ yào yì zhāng wòpù piào. 침대차 표 한 장 주세요.

### 2. "几点的车？" — 출발 시간 묻기
- 几点的车？ Jǐ diǎn de chē? 몇 시 차인가요?
- 有早一点的车吗？ Yǒu zǎo yìdiǎn de chē ma? 더 이른 차가 있나요?

### 3. "在哪个 + 장소？" — 위치 묻기
- 在哪个站台？ Zài nǎge zhàntái? 몇 번 승강장이에요?
- 在哪个候车室？ Zài nǎge hòuchēshì? 어느 대합실이에요?

### 4. "要 ... 了" — 곧 ~하려 하다
- 火车要开了。 Huǒchē yào kāi le. 기차가 출발하려고 해요.
- 车要来了。 Chē yào lái le. 차가 곧 와요.

## 应用会话 (응용 회화 - 일상)

A: 我要买一张去北京的高铁票。  
   Wǒ yào mǎi yì zhāng qù Běijīng de gāotiě piào.  
   베이징행 고속열차 표 한 장 사려고 해요.

B: 几点的车？  
   Jǐ diǎn de chē?  
   몇 시 차인가요?

A: 有下午三点的吗？  
   Yǒu xiàwǔ sān diǎn de ma?  
   오후 3시 차 있나요?

B: 有，在四号站台。  
   Yǒu, zài sì hào zhàntái.  
   있어요, 4번 승강장이에요.

A: 好的，谢谢。  
   Hǎo de, xièxie.  
   네, 감사합니다.

B: 火车要开了，请快一点。  
   Huǒchē yào kāi le, qǐng kuài yìdiǎn.  
   기차가 곧 출발해요, 서둘러 주세요.

A: 四号站台，对吗？  
   Sì hào zhàntái, duì ma?  
   4번 승강장이 맞나요?

B: 对，请直走。  
   Duì, qǐng zhí zǒu.  
   네, 직진하세요.
