第 一 课 : 01. 点菜 Diǎncài (주문하기)

## 本文 (본문)

服务员，请给我菜单。  
Fúwùyuán, qǐng gěi wǒ càidān.  
종업원, 메뉴 주세요.

你们想吃什么？  
Nǐmen xiǎng chī shénme?  
여러분 뭐 드시고 싶어요?

我想吃北京烤鸭。  
Wǒ xiǎng chī Běijīng kǎoyā.  
저는 베이징 오리구이를 먹고 싶어요.

我不吃辣。  
Wǒ bù chī là.  
저는 매운 것을 안 먹어요.

请给我一碗米饭。  
Qǐng gěi wǒ yì wǎn mǐfàn.  
밥 한 공기 주세요.

我们要两个菜。  
Wǒmen yào liǎng gè cài.  
저희는 요리 두 개를 주문할게요.

这个菜多少钱？  
Zhège cài duōshao qián?  
이 요리는 얼마예요?

太辣了！  
Tài là le!  
너무 맵다!

请给我一杯水。  
Qǐng gěi wǒ yì bēi shuǐ.  
물 한 잔 주세요.

买单！  
Mǎidān!  
계산해 주세요!

---

## 主要词汇 (주요 단어)

### 1. 菜单  /  càidān  /  [명사 (n.)]  /  메뉴, 메뉴판
- 한자 풀이: 菜(나물 채) + 单(목록 단) → 요리 이름을 적은 목록
- 例句: 请给我菜单。
- Pinyin: Qǐng gěi wǒ càidān.
- 번역: 메뉴 주세요.

### 2. 点菜  /  diǎncài  /  [동사 (v.)]  /  음식을 주문하다
- 한자 풀이: 点(점찍을 점) + 菜(요리 채) → 먹을 음식을 고르다
- 例句: 我们点菜吧。
- Pinyin: Wǒmen diǎncài ba.
- 번역: 우리 주문합시다.

### 3. 辣  /  là  /  [형용사 (adj.)]  /  맵다
- 한자 풀이: 辛(매울 신) + 束(묶을 속) → 혀가 아린 맛
- 例句: 这个菜很辣。
- Pinyin: Zhège cài hěn là.
- 번역: 이 요리는 아주 맵다.

### 4. 米饭  /  mǐfàn  /  [명사 (n.)]  /  밥, 쌀밥
- 한자 풀이: 米(쌀 미) + 饭(밥 반) → 쌀로 지은 밥
- 例句: 我要一碗米饭。
- Pinyin: Wǒ yào yì wǎn mǐfàn.
- 번역: 밥 한 공기 주세요.

### 5. 服务员  /  fúwùyuán  /  [명사 (n.)]  /  종업원, 서비스 직원
- 한자 풀이: 服(복종할 복) + 务(일 무) + 员(직원 원) → 손님을 돕는 사람
- 例句: 服务员，买单！
- Pinyin: Fúwùyuán, mǎidān!
- 번역: 종업원, 계산해 주세요!

### 6. 买单  /  mǎidān  /  [동사 (v.)]  /  계산하다
- 한자 풀이: 买(살 매) + 单(계산서 단) → 비용을 지불하다
- 例句: 我想买单。
- Pinyin: Wǒ xiǎng mǎidān.
- 번역: 계산하고 싶어요.

## 语法点 (어법 포인트)

### 1. "请" + 동작 — 정중한 요청
- 请给我菜单。 Qǐng gěi wǒ càidān. 메뉴 주세요.
- 请坐。 Qǐng zuò. 앉으세요.

### 2. "给 + 사람 + 사물" — ~에게 ~을 주다
- 请给我一杯水。 Qǐng gěi wǒ yì bēi shuǐ. 물 한 잔 주세요.
- 给我菜单。 Gěi wǒ càidān. 메뉴 주세요.

### 3. "多少" — 가격 묻기
- 这个菜多少钱？ Zhège cài duōshao qián? 이 요리는 얼마예요?
- 一共多少钱？ Yígòng duōshao qián? 전부 얼마예요?

### 4. 수량사 "个", "碗", "杯"
- 两个菜 liǎng gè cài 요리 두 개
- 一碗米饭 yì wǎn mǐfàn 밥 한 공기
- 一杯水 yì bēi shuǐ 물 한 잔

## 应用会话 (응용 회화 - 일상)

A: 服务员，请给我菜单。  
   Fúwùyuán, qǐng gěi wǒ càidān.  
   종업원, 메뉴 주세요.

B: 好的，这是菜单。  
   Hǎo de, zhè shì càidān.  
   네, 여기 메뉴입니다.

A: 你们这里有什么特色菜？  
   Nǐmen zhèlǐ yǒu shénme tèsè cài?  
   이곳에는 어떤 대표 요리가 있나요?

B: 北京烤鸭很有名。  
   Běijīng kǎoyā hěn yǒumíng.  
   베이징 오리구이가 아주 유명해요.

A: 那我要一只烤鸭，一碗米饭。  
   Nà wǒ yào yì zhī kǎoyā, yì wǎn mǐfàn.  
   그럼 오리구이 한 마리랑 밥 한 공기 주세요.

B: 好的，请稍等。  
   Hǎo de, qǐng shāoděng.  
   네, 잠시만 기다려 주세요.

A: 服务员，买单！  
   Fúwùyuán, mǎidān!  
   종업원, 계산해 주세요!

B: 一共两百块钱。  
   Yígòng liǎng bǎi kuài qián.  
   전부 200위안입니다.
