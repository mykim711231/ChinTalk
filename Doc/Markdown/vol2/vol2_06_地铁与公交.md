第 六 课 : 06. 地铁与公交 Dìtiě yǔ gōngjiāo (지하철과 버스)

## 本文 (본문)

请问，地铁站怎么走？  
Qǐngwèn, dìtiězhàn zěnme zǒu?  
실례합니다, 지하철역이 어떻게 가나요?

我坐地铁去市中心。  
Wǒ zuò dìtiě qù shì zhōngxīn.  
저는 지하철 타고 시내에 가요.

去火车站坐几号线？  
Qù huǒchēzhàn zuò jǐ hào xiàn?  
기차역 가려면 몇 호선을 타야 하나요?

要换乘吗？  
Yào huànchéng ma?  
환승해야 하나요?

在下一站换乘。  
Zài xià yí zhàn huànchéng.  
다음 역에서 환승하세요.

公交车来了。  
Gōngjiāochē lái le.  
버스가 왔어요.

这路车去不去火车站？  
Zhè lù chē qù bu qù huǒchēzhàn?  
이 버스 기차역에 가나요?

请刷公交卡。  
Qǐng shuā gōngjiāokǎ.  
교통카드를 찍어 주세요.

下一站下车。  
Xià yí zhàn xiàchē.  
다음 역에서 내리세요.

---

## 主要词汇 (주요 단어)

### 1. 地铁  /  dìtiě  /  [명사 (n.)]  /  지하철
- 한자 풀이: 地(땅 지) + 铁(쇠 철) → 지하를 달리는 전철
- 例句: 我坐地铁上班。
- Pinyin: Wǒ zuò dìtiě shàngbān.
- 번역: 저는 지하철로 출근해요.

### 2. 公交  /  gōngjiāo  /  [명사 (n.)]  /  버스 (대중교통)
- 한자 풀이: 公(공공 공) + 交(사귈 교) → 공공 교통수단
- 例句: 我坐公交去学校。
- Pinyin: Wǒ zuò gōngjiāo qù xuéxiào.
- 번역: 저는 버스 타고 학교에 가요.

### 3. 换乘  /  huànchéng  /  [동사 (v.)]  /  환승하다
- 한자 풀이: 换(바꿀 환) + 乘(탈 승) → 다른 노선으로 갈아타다
- 例句: 在下一站换乘。
- Pinyin: Zài xià yí zhàn huànchéng.
- 번역: 다음 역에서 환승하세요.

### 4. 站  /  zhàn  /  [명사 (n.)]  /  역, 정류장
- 한자 풀이: 站(설 참) → 차가 서는 곳
- 例句: 下一站下车。
- Pinyin: Xià yí zhàn xiàchē.
- 번역: 다음 역에서 내리세요.

### 5. 刷卡  /  shuākǎ  /  [동사 (v.)]  /  카드를 찍다
- 한자 풀이: 刷(문지를 쇄) + 卡(카드) → 카드를 기계에 대다
- 例句: 请刷公交卡。
- Pinyin: Qǐng shuā gōngjiāokǎ.
- 번역: 교통카드를 찍어 주세요.

### 6. 下车  /  xiàchē  /  [동사 (v.)]  /  내리다
- 한자 풀이: 下(내릴 하) + 车(차) → 차에서 내리다
- 例句: 我要下车。
- Pinyin: Wǒ yào xiàchē.
- 번역: 저 내릴게요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 怎么 | zěnme | 么을 mō(1성)으로 읽음 | 么는 경성(me)으로 가볍게 |
| 下一站 | xià yí zhàn | 一을 yī(1성)로 그대로 읽음 | 一은 뒤 4성 앞에서 2성(yí)으로 변함 |
| 刷卡 | shuākǎ | sh를 ㅅ처럼 '수아'로 읽음 | 혀를 말아 권설음 sh로 '슈아' |
| 换乘 | huànchéng | h를 ㅎ, ch를 ㅊ처럼 읽음 | h는 '허', ch는 혀 말아 권설음 |

## 语法点 (어법 포인트)

### 1. "坐 + 교통수단 + 去 + 장소" — 교통수단 이용
- 我坐地铁去市中心。 Wǒ zuò dìtiě qù shì zhōngxīn. 저는 지하철 타고 시내에 가요.
- 我坐公交去学校。 Wǒ zuò gōngjiāo qù xuéxiào. 저는 버스 타고 학교에 가요.

### 2. "几号线" — 지하철 노선 묻기
- 去火车站坐几号线？ Qù huǒchēzhàn zuò jǐ hào xiàn? 기차역 가려면 몇 호선을 타야 하나요?
- 坐二号线。 Zuò èr hào xiàn. 2호선을 타세요.

### 3. "要 ... 吗？" — 필요 여부 묻기
- 要换乘吗？ Yào huànchéng ma? 환승해야 하나요?
- 要刷卡吗？ Yào shuākǎ ma? 카드 찍어야 하나요?

### 4. "在 + 장소 + 동작" — 장소에서 동작
- 在下一站换乘。 Zài xià yí zhàn huànchéng. 다음 역에서 환승하세요.
- 在下一站下车。 Zài xià yí zhàn xiàchē. 다음 역에서 내리세요.

## 应用会话 (응용 회화 - 일상)

A: 请问，去火车站坐几号线？  
   Qǐngwèn, qù huǒchēzhàn zuò jǐ hào xiàn?  
   실례합니다, 기차역 가려면 몇 호선을 타야 하나요?

B: 坐二号线。  
   Zuò èr hào xiàn.  
   2호선을 타세요.

A: 要换乘吗？  
   Yào huànchéng ma?  
   환승해야 하나요?

B: 要，在下一站换乘三号线。  
   Yào, zài xià yí zhàn huànchéng sān hào xiàn.  
   네, 다음 역에서 3호선으로 환승하세요.

A: 好的，谢谢！  
   Hǎo de, xièxie!  
   네, 감사합니다!

B: 不客气。  
   Bú kèqi.  
   천만에요.

A: 请问这路车去不去火车站？  
   Qǐngwèn zhè lù chē qù bu qù huǒchēzhàn?  
   실례합니다, 이 버스 기차역에 가나요?

B: 去，请上车。  
   Qù, qǐng shàngchē.  
   가요, 타세요.
