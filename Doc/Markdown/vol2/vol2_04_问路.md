第 四 课 : 04. 问路 Wènlù (길 묻기)

## 本文 (본문)

请问，地铁站在哪儿？  
Qǐngwèn, dìtiězhàn zài nǎr?  
실례합니다, 지하철역이 어디예요?

我迷路了。  
Wǒ mílù le.  
제가 길을 잃었어요.

直走，然后左转。  
Zhí zǒu, ránhòu zuǒ zhuǎn.  
직진한 다음 좌회전하세요.

在红绿灯那儿右转。  
Zài hónglǜdēng nàr yòu zhuǎn.  
신호등에서 우회전하세요.

离这儿远吗？  
Lí zhèr yuǎn ma?  
여기서 먼가요?

走路要多久？  
Zǒulù yào duōjiǔ?  
걸어서 얼마나 걸려요?

要过马路吗？  
Yào guò mǎlù ma?  
길을 건너야 하나요?

就在前面。  
Jiù zài qiánmiàn.  
바로 앞에 있어요.

谢谢您的帮助。  
Xièxie nín de bāngzhù.  
도움 주셔서 감사합니다.

---

## 主要词汇 (주요 단어)

### 1. 请问  /  qǐngwèn  /  [동사 (v.)]  /  실례지만 묻다
- 한자 풀이: 请(청할 청) + 问(물을 문) → 정중하게 묻다
- 例句: 请问，地铁站在哪儿？
- Pinyin: Qǐngwèn, dìtiězhàn zài nǎr?
- 번역: 실례합니다, 지하철역이 어디예요?

### 2. 迷路  /  mílù  /  [동사 (v.)]  /  길을 잃다
- 한자 풀이: 迷(미혹할 미) + 路(길 로) → 길을 헤매다
- 例句: 我迷路了。
- Pinyin: Wǒ mílù le.
- 번역: 제가 길을 잃었어요.

### 3. 直走  /  zhí zǒu  /  [동사 (v.)]  /  직진하다
- 한자 풀이: 直(곧을 직) + 走(걸을 주) → 곧장 걷다
- 例句: 直走，然后左转。
- Pinyin: Zhí zǒu, ránhòu zuǒ zhuǎn.
- 번역: 직진한 다음 좌회전하세요.

### 4. 左转  /  zuǒ zhuǎn  /  [동사 (v.)]  /  좌회전하다
- 한자 풀이: 左(왼쪽 좌) + 转(돌 전) → 왼쪽으로 돌다
- 例句: 请左转。
- Pinyin: Qǐng zuǒ zhuǎn.
- 번역: 좌회전하세요.

### 5. 右转  /  yòu zhuǎn  /  [동사 (v.)]  /  우회전하다
- 한자 풀이: 右(오른쪽 우) + 转(돌 전) → 오른쪽으로 돌다
- 例句: 右转就到了。
- Pinyin: Yòu zhuǎn jiù dào le.
- 번역: 우회전하면 바로 도착해요.

### 6. 远  /  yuǎn  /  [형용사 (adj.)]  /  멀다
- 한자 풀이: 远(멀 원) → 거리가 멀다
- 例句: 离这儿远吗？
- Pinyin: Lí zhèr yuǎn ma?
- 번역: 여기서 먼가요?

## 语法点 (어법 포인트)

### 1. "请问，... 在哪儿？" — 장소 묻기
- 请问，地铁站在哪儿？ Qǐngwèn, dìtiězhàn zài nǎr? 실례합니다, 지하철역이 어디예요?
- 请问，洗手间在哪儿？ Qǐngwèn, xǐshǒujiān zài nǎr? 실례합니다, 화장실이 어디예요?

### 2. "离 + 장소 + 远/近" — 거리 표현
- 离这儿远吗？ Lí zhèr yuǎn ma? 여기서 먼가요?
- 离这儿很近。 Lí zhèr hěn jìn. 여기서 아주 가까워요.

### 3. "直走 / 左转 / 右转" — 길 안내
- 直走，然后左转。 Zhí zǒu, ránhòu zuǒ zhuǎn. 직진한 다음 좌회전하세요.
- 在红绿灯那儿右转。 Zài hónglǜdēng nàr yòu zhuǎn. 신호등에서 우회전하세요.

### 4. "要 + 동작 + 多久？" — 소요 시간 묻기
- 走路要多久？ Zǒulù yào duōjiǔ? 걸어서 얼마나 걸려요?
- 坐车要多久？ Zuòchē yào duōjiǔ? 차 타고 얼마나 걸려요?

## 应用会话 (응용 회화 - 일상)

A: 请问，火车站在哪儿？  
   Qǐngwèn, huǒchēzhàn zài nǎr?  
   실례합니다, 기차역이 어디예요?

B: 直走，然后在红绿灯左转。  
   Zhí zǒu, ránhòu zài hónglǜdēng zuǒ zhuǎn.  
   직진한 다음 신호등에서 좌회전하세요.

A: 离这儿远吗？  
   Lí zhèr yuǎn ma?  
   여기서 먼가요?

B: 不远，走路十分钟。  
   Bù yuǎn, zǒulù shí fēnzhōng.  
   멀지 않아요, 걸어서 10분이에요.

A: 要过马路吗？  
   Yào guò mǎlù ma?  
   길을 건너야 하나요?

B: 对，过了马路就到了。  
   Duì, guò le mǎlù jiù dào le.  
   네, 길을 건너면 바로 도착해요.

A: 谢谢您的帮助！  
   Xièxie nín de bāngzhù!  
   도움 주셔서 감사합니다!

B: 不客气。  
   Bú kèqi.  
   천만에요.
