第 十二 课 : 12. 理发 Lǐfà (미용실)

## 本文 (본문)

我想理发。  
Wǒ xiǎng lǐfà.  
이발을 하고 싶어요.

请剪短一点。  
Qǐng jiǎn duǎn yìdiǎn.  
조금 짧게 잘라 주세요.

我想换个发型。  
Wǒ xiǎng huàn gè fàxíng.  
헤어스타일을 바꾸고 싶어요.

先洗头吧。  
Xiān xǐtóu ba.  
먼저 머리를 감을게요.

不要剪太短。  
Bú yào jiǎn tài duǎn.  
너무 짧게 자르지 마세요.

我想烫发。  
Wǒ xiǎng tàngfà.  
파마를 하고 싶어요.

染发多少钱？  
Rǎnfà duōshao qián?  
염색은 얼마예요?

剪个头发多少钱？  
Jiǎn gè tóufa duōshao qián?  
머리 자르는 데 얼마예요?

---

## 主要词汇 (주요 단어)

### 1. 理发  /  lǐfà  /  [동사 (v.)]  /  이발하다, 머리를 손질하다
- 한자 풀이: 理(다스릴 리) + 发(털 발) → 머리를 다듬다
- 例句: 我想理发。
- Pinyin: Wǒ xiǎng lǐfà.
- 번역: 이발을 하고 싶어요.

### 2. 剪  /  jiǎn  /  [동사 (v.)]  /  자르다
- 한자 풀이: 剪(자를 전) → 가위로 자르다
- 例句: 请剪短一点。
- Pinyin: Qǐng jiǎn duǎn yìdiǎn.
- 번역: 조금 짧게 잘라 주세요.

### 3. 发型  /  fàxíng  /  [명사 (n.)]  /  헤어스타일
- 한자 풀이: 发(머리카락) + 型(모양 형) → 머리 모양
- 例句: 我想换个发型。
- Pinyin: Wǒ xiǎng huàn gè fàxíng.
- 번역: 헤어스타일을 바꾸고 싶어요.

### 4. 洗头  /  xǐtóu  /  [동사 (v.)]  /  머리를 감다
- 한자 풀이: 洗(씻을 세) + 头(머리) → 머리를 씻다
- 例句: 先洗头吧。
- Pinyin: Xiān xǐtóu ba.
- 번역: 먼저 머리를 감을게요.

### 5. 烫发  /  tàngfà  /  [동사 (v.)]  /  파마하다
- 한자 풀이: 烫(데일 탕) + 发(머리카락) → 머리를 파마하다
- 例句: 我想烫发。
- Pinyin: Wǒ xiǎng tàngfà.
- 번역: 파마를 하고 싶어요.

### 6. 染发  /  rǎnfà  /  [동사 (v.)]  /  염색하다
- 한자 풀이: 染(물들일 염) + 发(머리카락) → 머리를 염색하다
- 例句: 染发多少钱？
- Pinyin: Rǎnfà duōshao qián?
- 번역: 염색은 얼마예요?

|---|---|---|---|
| 不要 | bú yào | 不을 bù(4성)로 그대로 읽음 | 不은 뒤 4성 앞에서 2성(bú)으로 변함 |

## 语法点 (어법 포인트)

### 1. "请 + 동사" — 정중한 요청
- 请剪短一点。 Qǐng jiǎn duǎn yìdiǎn. 조금 짧게 잘라 주세요.
- 请洗头。 Qǐng xǐtóu. 머리 감아 주세요.

### 2. "不要 + 동사" — 금지/요청 부정
- 不要剪太短。 Bú yào jiǎn tài duǎn. 너무 짧게 자르지 마세요.
- 不要太贵。 Bú yào tài guì. 너무 비싸지 않게 해 주세요.

### 3. "想 + 동사" — 하고 싶다
- 我想理发。 Wǒ xiǎng lǐfà. 이발하고 싶어요.
- 我想烫发。 Wǒ xiǎng tàngfà. 파마하고 싶어요.

### 4. "... 多少钱？" — 가격 묻기
- 染发多少钱？ Rǎnfà duōshao qián? 염색은 얼마예요?
- 剪个头发多少钱？ Jiǎn gè tóufa duōshao qián? 머리 자르는 데 얼마예요?

## 应用会话 (응용 회화 - 일상)

A: 您好，我想理发。  
   Nín hǎo, wǒ xiǎng lǐfà.  
   안녕하세요, 이발하고 싶어요.

B: 好的，想剪什么样的？  
   Hǎo de, xiǎng jiǎn shénme yàng de?  
   네, 어떤 스타일로 자르시겠어요?

A: 请剪短一点，不要太短。  
   Qǐng jiǎn duǎn yìdiǎn, bú yào tài duǎn.  
   조금 짧게 잘라 주세요, 너무 짧지는 않게요.

B: 好的，先洗头吧。  
   Hǎo de, xiān xǐtóu ba.  
   네, 먼저 머리를 감을게요.

A: 剪个头发多少钱？  
   Jiǎn gè tóufa duōshao qián?  
   머리 자르는 데 얼마예요?

B: 三十块。  
   Sānshí kuài.  
   30위안입니다.

A: 好的，谢谢。  
   Hǎo de, xièxie.  
   네, 감사해요.

B: 不客气。  
   Bú kèqi.  
   천만에요.
