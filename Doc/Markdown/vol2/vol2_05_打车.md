第 五 课 : 05. 打车 Dǎchē (택시 타기)

## 本文 (본문)

师傅，去机场。  
Shīfu, qù jīchǎng.  
기사님, 공항으로 가 주세요.

请打开后备箱。  
Qǐng dǎkāi hòubèixiāng.  
트렁크를 열어 주세요.

去火车站要多少钱？  
Qù huǒchēzhàn yào duōshao qián?  
기차역까지 얼마예요?

请打表。  
Qǐng dǎbiǎo.  
미터기 켜 주세요.

大概多久到？  
Dàgài duōjiǔ dào?  
대략 얼마나 걸려요?

能快一点吗？  
Néng kuài yìdiǎn ma?  
좀 빨리 가 주실 수 있나요?

我赶时间。  
Wǒ gǎn shíjiān.  
저는 시간이 촉박해요.

请在这里停。  
Qǐng zài zhèlǐ tíng.  
여기서 세워 주세요.

请给我发票。  
Qǐng gěi wǒ fāpiào.  
영수증 주세요.

---

## 主要词汇 (주요 단어)

### 1. 打车  /  dǎchē  /  [동사 (v.)]  /  택시를 타다
- 한자 풀이: 打(칠 타) + 车(차 차) → 택시를 잡아 타다
- 例句: 我们打车去机场。
- Pinyin: Wǒmen dǎchē qù jīchǎng.
- 번역: 우리는 택시 타고 공항에 가요.

### 2. 师傅  /  shīfu  /  [명사 (n.)]  /  기사님, 아저씨 (존칭)
- 한자 풀이: 师(스승 사) + 傅(스승 부) → 기술자를 부르는 존칭
- 例句: 师傅，去机场。
- Pinyin: Shīfu, qù jīchǎng.
- 번역: 기사님, 공항으로 가 주세요.

### 3. 打表  /  dǎbiǎo  /  [동사 (v.)]  /  미터기를 켜다
- 한자 풀이: 打(칠 타) + 表(계기 표) → 요금 미터기를 작동시키다
- 例句: 请打表。
- Pinyin: Qǐng dǎbiǎo.
- 번역: 미터기 켜 주세요.

### 4. 停  /  tíng  /  [동사 (v.)]  /  멈추다, 정차하다
- 한자 풀이: 停(머무를 정) → 움직임을 멈추다
- 例句: 请在这里停。
- Pinyin: Qǐng zài zhèlǐ tíng.
- 번역: 여기서 세워 주세요.

### 5. 发票  /  fāpiào  /  [명사 (n.)]  /  영수증, 영수증 발행
- 한자 풀이: 发(보낼 발) + 票(표 표) → 지불 증명 서류
- 例句: 请给我发票。
- Pinyin: Qǐng gěi wǒ fāpiào.
- 번역: 영수증 주세요.

### 6. 赶时间  /  gǎn shíjiān  /  [동사 (v.)]  /  시간이 촉박하다
- 한자 풀이: 赶(급히 갈 간) + 时间(시간) → 시간에 쫓기다
- 例句: 我赶时间。
- Pinyin: Wǒ gǎn shíjiān.
- 번역: 저는 시간이 촉박해요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 师傅 | shīfu | 傅를 fù(4성)로 강하게 읽음 | 傅는 경성(fu)으로 가볍게, sh는 권설음 |
| 去 | qù | q를 'ㅊ'처럼 '추'로 읽음 | 혀를 입천장에 대고 '취'(ü, 4성) |

## 语法点 (어법 포인트)

### 1. "去 + 목적지" — 목적지 표현
- 师傅，去机场。 Shīfu, qù jīchǎng. 기사님, 공항으로 가 주세요.
- 去火车站。 Qù huǒchēzhàn. 기차역으로 가 주세요.

### 2. "请 + 동작" — 정중한 요청
- 请打表。 Qǐng dǎbiǎo. 미터기 켜 주세요.
- 请在这里停。 Qǐng zài zhèlǐ tíng. 여기서 세워 주세요.

### 3. "要 + 시간/비용" — 소요 묻기
- 去火车站要多少钱？ Qù huǒchēzhàn yào duōshao qián? 기차역까지 얼마예요?
- 大概多久到？ Dàgài duōjiǔ dào? 대략 얼마나 걸려요?

### 4. "能 ... 吗？" — 요청/가능 묻기
- 能快一点吗？ Néng kuài yìdiǎn ma? 좀 빨리 가 주실 수 있나요?
- 能给我发票吗？ Néng gěi wǒ fāpiào ma? 영수증 주실 수 있나요?

## 应用会话 (응용 회화 - 일상)

A: 师傅，去机场。  
   Shīfu, qù jīchǎng.  
   기사님, 공항으로 가 주세요.

B: 好的，请系好安全带。  
   Hǎo de, qǐng jì hǎo ānquándài.  
   네, 안전벨트 매 주세요.

A: 大概多久到？  
   Dàgài duōjiǔ dào?  
   대략 얼마나 걸려요?

B: 不堵车的话，四十分钟。  
   Bù dǔchē de huà, sìshí fēnzhōng.  
   막히지 않으면 40분이에요.

A: 我赶时间，能快一点吗？  
   Wǒ gǎn shíjiān, néng kuài yìdiǎn ma?  
   시간이 촉박해서 좀 빨리 가 주실 수 있나요?

B: 好，我尽量。  
   Hǎo, wǒ jìnliàng.  
   네, 최대한 빨리 가 볼게요.

A: 请在这里停。  
   Qǐng zài zhèlǐ tíng.  
   여기서 세워 주세요.

B: 到了，一共八十块。  
   Dào le, yígòng bāshí kuài.  
   도착했습니다, 전부 80위안입니다.
