第 十八 课 : 18. 旅行计划 Lǚxíng jìhuà (여행 계획)

## 本文 (본문)

你打算去哪里旅行？  
Nǐ dǎsuàn qù nǎlǐ lǚxíng?  
어디로 여행 갈 계획이에요?

我打算去云南。  
Wǒ dǎsuàn qù Yúnnán.  
윈난성에 갈 계획이에요.

什么时候出发？  
Shénme shíhou chūfā?  
언제 출발해요?

下个月十号。  
Xià ge yuè shí hào.  
다음 달 10일이에요.

去几天？  
Qù jǐ tiān?  
며칠 가요?

大概一个星期。  
Dàgài yí ge xīngqī.  
대략 일주일이에요.

你的预算是多少？  
Nǐ de yùsuàn shì duōshao?  
예산은 얼마예요?

大概五千元。  
Dàgài wǔqiān yuán.  
대략 5,000위안이에요.

你订好酒店了吗？  
Nǐ dìng hǎo jiǔdiàn le ma?  
호텔은 예약했나요?

已经订好了。  
Yǐjīng dìng hǎo le.  
이미 예약했어요.

祝你玩得开心！  
Zhù nǐ wán de kāixīn!  
즐겁게 놀다 오세요!

## 主要词汇 (주요 단어)

### 1. 计划  /  jìhuà  /  [명사 (n.)]  /  계획
- 한자 풀이: 计(셈 계) + 划(그을 획) → 미리 세우는 셈
- 例句: 这是我的旅行计划。
- Pinyin: Zhè shì wǒ de lǚxíng jìhuà.
- 번역: 이건 제 여행 계획이에요.

### 2. 打算  /  dǎsuàn  /  [동사 (v.)]  /  계획하다, 예정이다
- 한자 풀이: 打(칠 타) + 算(셈 산) → 미리 셈하다
- 例句: 我打算去云南。
- Pinyin: Wǒ dǎsuàn qù Yúnnán.
- 번역: 윈난성에 갈 계획이에요.

### 3. 预算  /  yùsuàn  /  [명사 (n.)]  /  예산
- 한자 풀이: 预(미리 예) + 算(셈 산) → 미리 정한 돈
- 例句: 你的预算是多少？
- Pinyin: Nǐ de yùsuàn shì duōshao?
- 번역: 예산은 얼마예요?

### 4. 出发  /  chūfā  /  [동사 (v.)]  /  출발하다
- 한자 풀이: 出(날 출) + 发(쏠 발) → 길을 떠나다
- 例句: 什么时候出发？
- Pinyin: Shénme shíhou chūfā?
- 번역: 언제 출발해요?

### 5. 已经  /  yǐjīng  /  [부사 (adv.)]  /  이미
- 한자 풀이: 已(이미 이) + 经(지날 경) → 이미 지나가다
- 例句: 我已经订好了。
- Pinyin: Wǒ yǐjīng dìng hǎo le.
- 번역: 이미 예약했어요.

### 6. 开心  /  kāixīn  /  [형용사 (adj.)]  /  기쁘다, 즐겁다
- 한자 풀이: 开(열 개) + 心(마음 심) → 마음이 열리다, 기쁘다
- 例句: 祝你玩得开心！
- Pinyin: Zhù nǐ wán de kāixīn!
- 번역: 즐겁게 놀다 오세요!

## 语法点 (어법 포인트)

### 1. "打算 + 동사" — ~할 계획이다
- 我打算去云南。 Wǒ dǎsuàn qù Yúnnán. 윈난성에 갈 계획이에요.

### 2. "什么时候…？" — 언제 ~하나요?
- 什么时候出发？ Shénme shíhou chūfā? 언제 출발해요?

### 3. "…好了吗？" — ~을 다 했나요? (완료 확인)
- 你订好酒店了吗？ Nǐ dìng hǎo jiǔdiàn le ma? 호텔은 예약했나요?

### 4. "祝你…" — ~하길 바라다 (기원)
- 祝你玩得开心！ Zhù nǐ wán de kāixīn! 즐겁게 놀다 오세요!
