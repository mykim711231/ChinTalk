第 十九 课 : 19. 和导游对话 Hé dǎoyóu duìhuà (가이드와 대화)

## 本文 (본문)

你是我们的导游吗？  
Nǐ shì wǒmen de dǎoyóu ma?  
당신이 우리 가이드인가요?

是的，我叫小王。  
Shì de, wǒ jiào Xiǎo Wáng.  
네, 저는 샤오왕이라고 합니다.

我们今天去哪儿？  
Wǒmen jīntiān qù nǎr?  
우리 오늘 어디 가요?

上午去长城。  
Shàngwǔ qù Chángchéng.  
오전에는 만리장성에 가요.

这里的历史很悠久。  
Zhèlǐ de lìshǐ hěn yōujiǔ.  
이곳은 역사가 아주 오래됐어요.

请跟紧队伍。  
Qǐng gēnjǐn duìwu.  
대열을 잘 따라오세요.

我们几点集合？  
Wǒmen jǐ diǎn jíhé?  
우리 몇 시에 모여요?

下午四点集合。  
Xiàwǔ sì diǎn jíhé.  
오후 4시에 모여요.

有自由活动时间吗？  
Yǒu zìyóu huódòng shíjiān ma?  
자유 시간이 있나요?

可以自己参观一个小时。  
Kěyǐ zìjǐ cānguān yí ge xiǎoshí.  
한 시간 동안 자유롭게 관람할 수 있어요.

## 主要词汇 (주요 단어)

### 1. 导游  /  dǎoyóu  /  [명사 (n.)]  /  가이드, 안내원
- 한자 풀이: 导(인도할 도) + 游(놀 유) → 여행을 인도하는 사람
- 例句: 你是我们的导游吗？
- Pinyin: Nǐ shì wǒmen de dǎoyóu ma?
- 번역: 당신이 우리 가이드인가요?

### 2. 集合  /  jíhé  /  [동사 (v.)]  /  모이다, 집합하다
- 한자 풀이: 集(모을 집) + 合(합할 합) → 한데 모이다
- 例句: 我们几点集合？
- Pinyin: Wǒmen jǐ diǎn jíhé?
- 번역: 우리 몇 시에 모여요?

### 3. 历史  /  lìshǐ  /  [명사 (n.)]  /  역사
- 한자 풀이: 历(지낼 력) + 史(사기 사) → 지나온 일의 기록
- 例句: 这里的历史很悠久。
- Pinyin: Zhèlǐ de lìshǐ hěn yōujiǔ.
- 번역: 이곳은 역사가 아주 오래됐어요.

### 4. 队伍  /  duìwu  /  [명사 (n.)]  /  대열, 무리
- 한자 풀이: 队(무리 대) + 伍(대오 오) → 줄지어 선 사람들
- 例句: 请跟紧队伍。
- Pinyin: Qǐng gēnjǐn duìwu.
- 번역: 대열을 잘 따라오세요.

### 5. 自由活动  /  zìyóu huódòng  /  [명사 (n.)]  /  자유 활동
- 한자 풀이: 自由(자유) + 活动(활동) → 스스로 하는 활동
- 例句: 有自由活动时间吗？
- Pinyin: Yǒu zìyóu huódòng shíjiān ma?
- 번역: 자유 시간이 있나요?

### 6. 参观  /  cānguān  /  [동사 (v.)]  /  관람하다
- 한자 풀이: 参(참여할 참) + 观(볼 관) → 둘러보다
- 例句: 可以自己参观一个小时。
- Pinyin: Kěyǐ zìjǐ cānguān yí ge xiǎoshí.
- 번역: 한 시간 동안 자유롭게 관람할 수 있어요.

## 语法点 (어법 포인트)

### 1. "是…吗？" — ~인가요?
- 你是我们的导游吗？ Nǐ shì wǒmen de dǎoyóu ma? 당신이 우리 가이드인가요?

### 2. "叫 + 이름" — ~라고 하다 (자칭)
- 我叫小王。 Wǒ jiào Xiǎo Wáng. 저는 샤오왕이라고 해요.

### 3. "几点 + 동사？" — 몇 시에 ~하나요?
- 我们几点集合？ Wǒmen jǐ diǎn jíhé? 우리 몇 시에 모여요?

### 4. "可以 + 동사 + 시간" — ~동안 ~할 수 있다
- 可以自己参观一个小时。 Kěyǐ zìjǐ cānguān yí ge xiǎoshí. 한 시간 동안 자유롭게 관람할 수 있어요.

## 应用会话 (응용 회화)

A: 你好，你是我们的导游吗？  
   Nǐ hǎo, nǐ shì wǒmen de dǎoyóu ma?  
   안녕하세요, 당신이 우리 가이드인가요?

B: 是的，我叫小王。欢迎你们！  
   Shì de, wǒ jiào Xiǎo Wáng. Huānyíng nǐmen!  
   네, 저는 샤오왕이라고 해요. 환영합니다!

A: 我们今天去哪儿？  
   Wǒmen jīntiān qù nǎr?  
   우리 오늘 어디 가요?

B: 上午去长城，这里的历史很悠久。  
   Shàngwǔ qù Chángchéng, zhèlǐ de lìshǐ hěn yōujiǔ.  
   오전에는 만리장성에 가요, 이곳은 역사가 아주 오래됐어요.

A: 我们几点集合？  
   Wǒmen jǐ diǎn jíhé?  
   우리 몇 시에 모여요?

B: 下午四点集合。  
   Xiàwǔ sì diǎn jíhé.  
   오후 4시에 모여요.

A: 有自由活动时间吗？  
   Yǒu zìyóu huódòng shíjiān ma?  
   자유 시간이 있나요?

B: 有，可以自己参观一个小时。请跟紧队伍。  
   Yǒu, kěyǐ zìjǐ cānguān yí ge xiǎoshí. Qǐng gēnjǐn duìwu.  
   네, 한 시간 동안 자유롭게 관람할 수 있어요. 대열을 잘 따라오세요.
