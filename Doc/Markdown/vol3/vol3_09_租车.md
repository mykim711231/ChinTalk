第 九 课 : 09. 租车 Zūchē (렌터카)

## 本文 (본문)

我想租一辆车。  
Wǒ xiǎng zū yí liàng chē.  
차 한 대를 빌리고 싶어요.

您要租几天？  
Nín yào zū jǐ tiān?  
며칠 빌리시나요?

租三天。  
Zū sān tiān.  
3일 빌릴게요.

一天多少钱？  
Yì tiān duōshao qián?  
하루에 얼마예요?

一天两百元。  
Yì tiān liǎngbǎi yuán.  
하루에 200위안이에요.

需要押金吗？  
Xūyào yājīn ma?  
보증금이 필요한가요?

需要一千元押金。  
Xūyào yìqiān yuán yājīn.  
보증금 1,000위안이 필요해요.

请出示您的驾照。  
Qǐng chūshì nín de jiàzhào.  
운전면허증을 제시해 주세요.

这是国际驾照。  
Zhè shì guójì jiàzhào.  
이건 국제 운전면허증이에요.

车加满油了吗？  
Chē jiā mǎn yóu le ma?  
차에 기름이 가득 차 있나요?

是的，请在这里签字。  
Shì de, qǐng zài zhèlǐ qiānzì.  
네, 여기에 서명해 주세요.

---

## 主要词汇 (주요 단어)

### 1. 租  /  zū  /  [동사 (v.)]  /  빌리다, 임대하다
- 한자 풀이: 禾(벼 화) + 且(또 차) → 곡식으로 대가를 치르고 빌리다
- 例句: 我想租一辆车。
- Pinyin: Wǒ xiǎng zū yí liàng chē.
- 번역: 차 한 대를 빌리고 싶어요.

### 2. 押金  /  yājīn  /  [명사 (n.)]  /  보증금
- 한자 풀이: 押(누를 압) + 金(쇠 금) → 담보로 맡기는 돈
- 例句: 需要押金吗？
- Pinyin: Xūyào yājīn ma?
- 번역: 보증금이 필요한가요?

### 3. 驾照  /  jiàzhào  /  [명사 (n.)]  /  운전면허증
- 한자 풀이: 驾(멍에 가) + 照(비칠 조) → 운전 자격증
- 例句: 请出示您的驾照。
- Pinyin: Qǐng chūshì nín de jiàzhào.
- 번역: 운전면허증을 제시해 주세요.

### 4. 加油  /  jiāyóu  /  [동사 (v.)]  /  주유하다, 힘내다
- 한자 풀이: 加(더할 가) + 油(기름 유) → 기름을 넣다
- 例句: 请加满油。
- Pinyin: Qǐng jiā mǎn yóu.
- 번역: 기름을 가득 채워 주세요.

### 5. 签字  /  qiānzì  /  [동사 (v.)]  /  서명하다
- 한자 풀이: 签(찌를 첨) + 字(글자 자) → 이름을 쓰다
- 例句: 请在这里签字。
- Pinyin: Qǐng zài zhèlǐ qiānzì.
- 번역: 여기에 서명해 주세요.

### 6. 还车  /  huánchē  /  [동사 (v.)]  /  차를 반납하다
- 한자 풀이: 还(돌아올 환) + 车(수레 거) → 차를 돌려주다
- 例句: 我明天还车。
- Pinyin: Wǒ míngtiān huánchē.
- 번역: 내일 차를 반납해요.

## 语法点 (어법 포인트)

### 1. "租 + 양사 + 명사" — ~를 빌리다
- 我想租一辆车。 Wǒ xiǎng zū yí liàng chē. 차 한 대를 빌리고 싶어요.

### 2. "需要…吗？" — ~이 필요한가요?
- 需要押金吗？ Xūyào yājīn ma? 보증금이 필요한가요?

### 3. "一天 + 가격" — 하루당 가격
- 一天两百元。 Yì tiān liǎngbǎi yuán. 하루에 200위안이에요.

### 4. "请出示…" — ~을 제시해 주세요
- 请出示您的驾照。 Qǐng chūshì nín de jiàzhào. 운전면허증을 제시해 주세요.
