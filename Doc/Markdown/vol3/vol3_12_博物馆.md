第 十二 课 : 12. 博物馆 Bówùguǎn (박물관)

## 本文 (본문)

博物馆在哪儿？  
Bówùguǎn zài nǎr?  
박물관이 어디예요?

在市中心。  
Zài shìzhōngxīn.  
시내 중심에 있어요.

博物馆几点开门？  
Bówùguǎn jǐ diǎn kāimén?  
박물관은 몇 시에 문을 열어요?

上午九点开门。  
Shàngwǔ jiǔ diǎn kāimén.  
오전 9시에 열어요.

门票多少钱？  
Ménpiào duōshao qián?  
입장료는 얼마예요?

学生可以免费参观。  
Xuésheng kěyǐ miǎnfèi cānguān.  
학생은 무료로 관람할 수 있어요.

里面可以拍照吗？  
Lǐmiàn kěyǐ pāizhào ma?  
안에서 사진을 찍어도 되나요?

不可以开闪光灯。  
Bù kěyǐ kāi shǎnguāngdēng.  
플래시는 켜면 안 돼요.

这些展品真精美！  
Zhèxiē zhǎnpǐn zhēn jīngměi!  
이 전시품들은 정말 정교해요!

这里还有讲解员吗？  
Zhèlǐ hái yǒu jiǎngjiěyuán ma?  
여기 해설사도 있나요?

---

## 主要词汇 (주요 단어)

### 1. 博物馆  /  bówùguǎn  /  [명사 (n.)]  /  박물관
- 한자 풀이: 博(넓을 박) + 物(물건 물) + 馆(집 관) → 유물을 모은 곳
- 例句: 博物馆在市中心。
- Pinyin: Bówùguǎn zài shìzhōngxīn.
- 번역: 박물관은 시내 중심에 있어요.

### 2. 参观  /  cānguān  /  [동사 (v.)]  /  관람하다
- 한자 풀이: 参(참여할 참) + 观(볼 관) → 둘러보다
- 例句: 我们参观博物馆。
- Pinyin: Wǒmen cānguān bówùguǎn.
- 번역: 우리는 박물관을 관람해요.

### 3. 免费  /  miǎnfèi  /  [형용사 (adj.)]  /  무료이다
- 한자 풀이: 免(면할 면) + 费(쓸 비) → 비용을 면제하다
- 例句: 这里免费参观。
- Pinyin: Zhèlǐ miǎnfèi cānguān.
- 번역: 여기는 무료로 관람해요.

### 4. 展品  /  zhǎnpǐn  /  [명사 (n.)]  /  전시품
- 한자 풀이: 展(펼 전) + 品(물건 품) → 전시한 물건
- 例句: 这些展品很精美。
- Pinyin: Zhèxiē zhǎnpǐn hěn jīngměi.
- 번역: 이 전시품들은 아주 정교해요.

### 5. 闪光灯  /  shǎnguāngdēng  /  [명사 (n.)]  /  플래시
- 한자 풀이: 闪(번쩍일 섬) + 光(빛 광) + 灯(등 등) → 번쩍이는 등
- 例句: 请不要开闪光灯。
- Pinyin: Qǐng bú yào kāi shǎnguāngdēng.
- 번역: 플래시를 켜지 마세요.

### 6. 讲解员  /  jiǎngjiěyuán  /  [명사 (n.)]  /  해설사
- 한자 풀이: 讲(말할 강) + 解(풀 해) + 员(사람 원) → 설명해 주는 사람
- 例句: 讲解员讲得很好。
- Pinyin: Jiǎngjiěyuán jiǎng de hěn hǎo.
- 번역: 해설사가 설명을 아주 잘해요.

## 语法点 (어법 포인트)

### 1. "在哪儿？" — 어디에 있어요?
- 博物馆在哪儿？ Bówùguǎn zài nǎr? 박물관이 어디예요?

### 2. "几点 + 동사？" — 몇 시에 ~하나요?
- 博物馆几点开门？ Bówùguǎn jǐ diǎn kāimén? 박물관은 몇 시에 열어요?

### 3. "可以/不可以 + 동사" — 해도 되다 / 안 되다
- 里面可以拍照吗？ Lǐmiàn kěyǐ pāizhào ma? 안에서 사진 찍어도 되나요?
- 不可以开闪光灯。 Bù kěyǐ kāi shǎnguāngdēng. 플래시는 켜면 안 돼요.

### 4. "还有…吗？" — 또 ~이 있나요?
- 这里还有讲解员吗？ Zhèlǐ hái yǒu jiǎngjiěyuán ma? 여기 해설사도 있나요?

## 应用会话 (응용 회화)

A: 请问，博物馆在哪儿？  
   Qǐngwèn, bówùguǎn zài nǎr?  
   실례지만, 박물관이 어디예요?

B: 在市中心，很近。  
   Zài shìzhōngxīn, hěn jìn.  
   시내 중심에 있어요, 아주 가까워요.

A: 博物馆几点开门？门票多少钱？  
   Bówùguǎn jǐ diǎn kāimén? Ménpiào duōshao qián?  
   박물관은 몇 시에 열어요? 입장료는 얼마예요?

B: 上午九点开门。学生可以免费参观。  
   Shàngwǔ jiǔ diǎn kāimén. Xuésheng kěyǐ miǎnfèi cānguān.  
   오전 9시에 열어요. 학생은 무료로 관람할 수 있어요.

A: 里面可以拍照吗？  
   Lǐmiàn kěyǐ pāizhào ma?  
   안에서 사진을 찍어도 되나요?

B: 可以，但不可以用闪光灯。  
   Kěyǐ, dàn bù kěyǐ yòng shǎnguāngdēng.  
   네, 하지만 플래시는 쓰면 안 돼요.

A: 好的，谢谢。  
   Hǎo de, xièxie.  
   네, 감사합니다.
