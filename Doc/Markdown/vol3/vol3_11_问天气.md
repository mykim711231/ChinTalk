第 十一 课 : 11. 问天气 Wèn tiānqì (날씨 묻기)

## 本文 (본문)

今天天气怎么样？  
Jīntiān tiānqì zěnmeyàng?  
오늘 날씨 어떠세요?

今天很晴朗。  
Jīntiān hěn qínglǎng.  
오늘은 아주 맑아요.

温度是多少？  
Wēndù shì duōshao?  
기온은 몇 도예요?

二十摄氏度。  
Èrshí shèshìdù.  
20도예요.

明天会下雨吗？  
Míngtiān huì xiàyǔ ma?  
내일 비가 올까요?

可能会下雨。  
Kěnéng huì xiàyǔ.  
비가 올 수도 있어요.

别忘了带伞。  
Bié wàng le dài sǎn.  
우산 챙기는 거 잊지 마세요.

刮风了，有点儿冷。  
Guāfēng le, yǒudiǎnr lěng.  
바람이 불어서 좀 추워요.

夏天很热。  
Xiàtiān hěn rè.  
여름은 아주 더워요.

我喜欢秋天的天气。  
Wǒ xǐhuan qiūtiān de tiānqì.  
가을 날씨가 좋아요.

---

## 主要词汇 (주요 단어)

### 1. 天气  /  tiānqì  /  [명사 (n.)]  /  날씨
- 한자 풀이: 天(하늘 천) + 气(기운 기) → 하늘의 기운, 날씨
- 例句: 今天天气很好。
- Pinyin: Jīntiān tiānqì hěn hǎo.
- 번역: 오늘 날씨가 아주 좋아요.

### 2. 晴朗  /  qínglǎng  /  [형용사 (adj.)]  /  맑다
- 한자 풀이: 晴(갤 청) + 朗(밝을 랑) → 하늘이 맑고 밝다
- 例句: 今天很晴朗。
- Pinyin: Jīntiān hěn qínglǎng.
- 번역: 오늘은 아주 맑아요.

### 3. 温度  /  wēndù  /  [명사 (n.)]  /  기온, 온도
- 한자 풀이: 温(따뜻할 온) + 度(법도 도) → 차갑고 더운 정도
- 例句: 温度是多少？
- Pinyin: Wēndù shì duōshao?
- 번역: 기온은 몇 도예요?

### 4. 下雨  /  xiàyǔ  /  [동사 (v.)]  /  비가 오다
- 한자 풀이: 下(내릴 하) + 雨(비 우) → 비가 내리다
- 例句: 今天下雨了。
- Pinyin: Jīntiān xiàyǔ le.
- 번역: 오늘 비가 왔어요.

### 5. 伞  /  sǎn  /  [명사 (n.)]  /  우산
- 한자 풀이: 伞의 상형 문자 → 우산 모양을 본뜸
- 例句: 我带伞了。
- Pinyin: Wǒ dài sǎn le.
- 번역: 우산을 가져왔어요.

### 6. 季节  /  jìjié  /  [명사 (n.)]  /  계절
- 한자 풀이: 季(계절 계) + 节(마디 절) → 일 년의 나눔
- 例句: 你最喜欢哪个季节？
- Pinyin: Nǐ zuì xǐhuan nǎge jìjié?
- 번역: 가장 좋아하는 계절은 언제예요?

## 语法点 (어법 포인트)

### 1. "天气怎么样？" — 날씨가 어떠한가?
- 今天天气怎么样？ Jīntiān tiānqì zěnmeyàng? 오늘 날씨 어떠세요?

### 2. "会 + 동사" — ~할 것이다 (미래 추측)
- 明天会下雨吗？ Míngtiān huì xiàyǔ ma? 내일 비가 올까요?

### 3. "可能" — 아마, ~일 수도 있다
- 可能会下雨。 Kěnéng huì xiàyǔ. 비가 올 수도 있어요.

### 4. "别忘了…" — ~하는 것을 잊지 마세요
- 别忘了带伞。 Bié wàng le dài sǎn. 우산 챙기는 거 잊지 마세요.

## 应用会话 (응용 회화)

A: 今天天气怎么样？  
   Jīntiān tiānqì zěnmeyàng?  
   오늘 날씨 어떠세요?

B: 今天很晴朗，适合出去玩。  
   Jīntiān hěn qínglǎng, shìhé chūqu wán.  
   오늘은 아주 맑아서 나들이하기 좋아요.

A: 温度是多少？  
   Wēndù shì duōshao?  
   기온은 몇 도예요?

B: 二十摄氏度，很舒服。  
   Èrshí shèshìdù, hěn shūfu.  
   20도라서 아주 쾌적해요.

A: 明天会下雨吗？  
   Míngtiān huì xiàyǔ ma?  
   내일 비가 올까요?

B: 可能会下雨，别忘了带伞。  
   Kěnéng huì xiàyǔ, bié wàng le dài sǎn.  
   비가 올 수도 있으니 우산 잊지 마세요.

A: 好的，谢谢提醒。  
   Hǎo de, xièxie tíxǐng.  
   네, 알려줘서 고마워요.
