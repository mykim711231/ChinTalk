第 六 课 : 06. 纪念品 Jìniànpǐn (기념품 구매)

## 本文 (본문)

我想买一些纪念品。  
Wǒ xiǎng mǎi yìxiē jìniànpǐn.  
기념품을 좀 사고 싶어요.

这个多少钱？  
Zhège duōshao qián?  
이건 얼마예요?

这个五十元。  
Zhège wǔshí yuán.  
이건 50위안이에요.

可以便宜一点吗？  
Kěyǐ piányi yìdiǎn ma?  
조금 깎아 주실 수 있나요?

好吧，四十五元。  
Hǎo ba, sìshíwǔ yuán.  
좋아요, 45위안이에요.

这是送给朋友的礼物。  
Zhè shì sòng gěi péngyou de lǐwù.  
이건 친구에게 줄 선물이에요.

请帮我包起来。  
Qǐng bāng wǒ bāo qǐlai.  
포장해 주세요.

一共多少钱？  
Yígòng duōshao qián?  
전부 얼마예요?

一共一百二十元。  
Yígòng yìbǎi èrshí yuán.  
전부 120위안이에요.

---

## 主要词汇 (주요 단어)

### 1. 纪念品  /  jìniànpǐn  /  [명사 (n.)]  /  기념품
- 한자 풀이: 纪念(기념) + 品(물건 품) → 기념으로 사는 물건
- 例句: 我买了很多纪念品。
- Pinyin: Wǒ mǎi le hěn duō jìniànpǐn.
- 번역: 기념품을 많이 샀어요.

### 2. 便宜  /  piányi  /  [형용사 (adj.)]  /  싸다
- 한자 풀이: 便(편할 편) + 宜(마땅 의) → 값이 싸고 알맞다
- 例句: 这个很便宜。
- Pinyin: Zhège hěn piányi.
- 번역: 이건 아주 싸요.

### 3. 礼物  /  lǐwù  /  [명사 (n.)]  /  선물
- 한자 풀이: 礼(예절 례) + 物(물건 물) → 예의로 주는 물건
- 例句: 这是送给朋友的礼物。
- Pinyin: Zhè shì sòng gěi péngyou de lǐwù.
- 번역: 이건 친구에게 줄 선물이에요.

### 4. 包  /  bāo  /  [동사 (v.)]  /  포장하다
- 한자 풀이: 勹(싸다 포) + 巳 → 싸서 감싸다
- 例句: 请帮我包起来。
- Pinyin: Qǐng bāng wǒ bāo qǐlai.
- 번역: 포장해 주세요.

### 5. 送  /  sòng  /  [동사 (v.)]  /  보내다, 선물하다
- 한자 풀이: 辶(쉬엄쉬엄 갈 착) + 关(관계할 관) → 보내다
- 例句: 我把礼物送给妈妈。
- Pinyin: Wǒ bǎ lǐwù sòng gěi māma.
- 번역: 엄마에게 선물을 드려요.

### 6. 一共  /  yígòng  /  [부사 (adv.)]  /  전부, 합계
- 한자 풀이: 一(한 일) + 共(함께 공) → 모두 합쳐
- 例句: 一共多少钱？
- Pinyin: Yígòng duōshao qián?
- 번역: 전부 얼마예요?

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 便宜 | piányi | 宜를 2성(yí)으로 읽음 | 宜는 경성(yi) |
| 一共 | yígòng | 一을 4성(yì)으로 읽음 | 4성(gòng) 앞의 一은 2성(yí) |
| 一些 | yìxiē | 一을 1성(yī)으로 읽음 | 1·2·3성 앞의 一은 4성(yì) |
| 包起来 | bāo qǐlai | 起来를 qǐlái(3·2) 그대로 | 来는 경성, qǐlai |
| 纪念品 | jìniànpǐn | j를 "지"로, -n 종성 놓침 | j 구개음, niàn 정확히 |

## 语法点 (어법 포인트)

### 1. "便宜一点" — 조금 싸게
- 可以便宜一点吗？ Kěyǐ piányi yìdiǎn ma? 조금 깎아 주실 수 있나요?

### 2. "送给 + 사람" — ~에게 선물하다
- 这是送给朋友的礼物。 Zhè shì sòng gěi péngyou de lǐwù. 이건 친구에게 줄 선물이에요.

### 3. "帮 + 사람 + 동사" — ~를 도와 ~하다
- 请帮我包起来。 Qǐng bāng wǒ bāo qǐlai. 포장해 주세요.

### 4. "一共" — 합계, 전부
- 一共多少钱？ Yígòng duōshao qián? 전부 얼마예요?

## 应用会话 (응용 회화)

A: 你好，我想买一些纪念品。  
   Nǐ hǎo, wǒ xiǎng mǎi yìxiē jìniànpǐn.  
   안녕하세요, 기념품을 좀 사고 싶어요.

B: 好的，您看这个怎么样？  
   Hǎo de, nín kàn zhège zěnmeyàng?  
   네, 이건 어떠세요?

A: 这个多少钱？  
   Zhège duōshao qián?  
   이건 얼마예요?

B: 这个五十元。  
   Zhège wǔshí yuán.  
   이건 50위안이에요.

A: 可以便宜一点吗？  
   Kěyǐ piányi yìdiǎn ma?  
   조금 깎아 주실 수 있나요?

B: 好吧，四十五元。  
   Hǎo ba, sìshíwǔ yuán.  
   좋아요, 45위안이에요.

A: 这是送给朋友的礼物，请帮我包起来。  
   Zhè shì sòng gěi péngyou de lǐwù, qǐng bāng wǒ bāo qǐlai.  
   이건 친구에게 줄 선물이에요, 포장해 주세요.

B: 好的，一共四十五元。  
   Hǎo de, yígòng sìshíwǔ yuán.  
   네, 전부 45위안이에요.
