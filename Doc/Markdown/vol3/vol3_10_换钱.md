第 十 课 : 10. 换钱 Huànqián (환전)

## 本文 (본문)

我想换钱。  
Wǒ xiǎng huàn qián.  
환전하고 싶어요.

您要换什么钱？  
Nín yào huàn shénme qián?  
어떤 돈으로 바꾸시나요?

我要把美元换成人民币。  
Wǒ yào bǎ měiyuán huàn chéng rénmínbì.  
달러를 위안화로 바꾸고 싶어요.

今天的汇率是多少？  
Jīntiān de huìlǜ shì duōshao?  
오늘 환율은 얼마인가요?

一美元换七元人民币。  
Yì měiyuán huàn qī yuán rénmínbì.  
1달러에 7위안이에요.

我换五百美元。  
Wǒ huàn wǔbǎi měiyuán.  
500달러 환전할게요.

请给我一些零钱。  
Qǐng gěi wǒ yìxiē língqián.  
잔돈을 좀 주세요.

这是您的钱，请点一下。  
Zhè shì nín de qián, qǐng diǎn yí xià.  
여기 돈이에요, 세어 보세요.

好的，没问题。  
Hǎo de, méi wèntí.  
네, 문제없어요.

---

## 主要词汇 (주요 단어)

### 1. 换钱  /  huànqián  /  [동사 (v.)]  /  환전하다
- 한자 풀이: 换(바꿀 환) + 钱(돈 전) → 돈을 바꾸다
- 例句: 我想换钱。
- Pinyin: Wǒ xiǎng huàn qián.
- 번역: 환전하고 싶어요.

### 2. 汇率  /  huìlǜ  /  [명사 (n.)]  /  환율
- 한자 풀이: 汇(모을 회) + 率(비율 률) → 화폐 교환 비율
- 例句: 今天的汇率是多少？
- Pinyin: Jīntiān de huìlǜ shì duōshao?
- 번역: 오늘 환율은 얼마인가요?

### 3. 人民币  /  rénmínbì  /  [명사 (n.)]  /  위안화
- 한자 풀이: 人民(백성) + 币(돈 폐) → 중국의 화폐
- 例句: 我用人民币付款。
- Pinyin: Wǒ yòng rénmínbì fùkuǎn.
- 번역: 위안화로 결제해요.

### 4. 美元  /  měiyuán  /  [명사 (n.)]  /  달러
- 한자 풀이: 美(아름다울 미) + 元(으뜸 원) → 미국의 화폐 단위
- 例句: 一美元等于多少人民币？
- Pinyin: Yì měiyuán děngyú duōshao rénmínbì?
- 번역: 1달러는 몇 위안인가요?

### 5. 零钱  /  língqián  /  [명사 (n.)]  /  잔돈
- 한자 풀이: 零(조각 령) + 钱(돈 전) → 작은 단위의 돈
- 例句: 请给我一些零钱。
- Pinyin: Qǐng gěi wǒ yìxiē língqián.
- 번역: 잔돈을 좀 주세요.

### 6. 点  /  diǎn  /  [동사 (v.)]  /  세다, 확인하다
- 한자 풀이: 灬(불 화) + 占(점할 점) → 하나하나 짚다
- 例句: 请点一下。
- Pinyin: Qǐng diǎn yí xià.
- 번역: 한번 세어 보세요.

## 语法点 (어법 포인트)

### 1. "把 + A + 换成 + B" — A를 B로 바꾸다
- 把美元换成人民币。 Bǎ měiyuán huàn chéng rénmínbì. 달러를 위안화로 바꾸다.

### 2. "一 + 단위 + 换 + 가격" — 1단위당 환율
- 一美元换七元人民币。 Yì měiyuán huàn qī yuán rénmínbì. 1달러에 7위안이에요.

### 3. "给 + 사람 + 명사" — ~에게 ~을 주다
- 请给我一些零钱。 Qǐng gěi wǒ yìxiē língqián. 잔돈을 좀 주세요.

### 4. "动词 + 一下" — 잠깐 ~하다
- 请点一下。 Qǐng diǎn yí xià. 한번 세어 보세요.
