第 十四 课 : 14. 商场 Shāngchǎng (쇼핑몰)

## 本文 (본문)

我们一起去商场吧。  
Wǒmen yìqǐ qù shāngchǎng ba.  
우리 같이 쇼핑몰에 가요.

商场在哪儿？  
Shāngchǎng zài nǎr?  
쇼핑몰이 어디예요?

就在地铁站对面。  
Jiù zài dìtiě zhàn duìmiàn.  
지하철역 맞은편에 있어요.

商场几点关门？  
Shāngchǎng jǐ diǎn guānmén?  
쇼핑몰은 몇 시에 문을 닫아요?

晚上十点关门。  
Wǎnshang shí diǎn guānmén.  
밤 10시에 닫아요.

我想买一双鞋。  
Wǒ xiǎng mǎi yì shuāng xié.  
신발 한 켤레를 사고 싶어요.

请问试衣间在哪儿？  
Qǐngwèn shìyījiān zài nǎr?  
실례지만 탈의실이 어디예요?

这件衣服有别的颜色吗？  
Zhè jiàn yīfu yǒu bié de yánsè ma?  
이 옷은 다른 색깔이 있나요?

这个码数太大了。  
Zhège mǎshù tài dà le.  
이 사이즈는 너무 커요.

请给我小一号的。  
Qǐng gěi wǒ xiǎo yí hào de.  
한 치수 작은 걸 주세요.

## 主要词汇 (주요 단어)

### 1. 商场  /  shāngchǎng  /  [명사 (n.)]  /  쇼핑몰, 백화점
- 한자 풀이: 商(장사 상) + 场(마당 장) → 물건을 파는 곳
- 例句: 商场很大。
- Pinyin: Shāngchǎng hěn dà.
- 번역: 쇼핑몰이 아주 커요.

### 2. 试衣间  /  shìyījiān  /  [명사 (n.)]  /  탈의실
- 한자 풀이: 试(시험할 시) + 衣(옷 의) + 间(사이 간) → 옷 입어보는 방
- 例句: 试衣间在那边。
- Pinyin: Shìyījiān zài nàbiān.
- 번역: 탈의실은 저쪽에 있어요.

### 3. 颜色  /  yánsè  /  [명사 (n.)]  /  색깔
- 한자 풀이: 颜(얼굴 안) + 色(빛 색) → 빛깔
- 例句: 我喜欢这个颜色。
- Pinyin: Wǒ xǐhuan zhège yánsè.
- 번역: 이 색깔이 좋아요.

### 4. 码数  /  mǎshù  /  [명사 (n.)]  /  사이즈, 치수
- 한자 풀이: 码(자 마) + 数(수 수) → 크기 표시 숫자
- 例句: 这个码数合适吗？
- Pinyin: Zhège mǎshù héshì ma?
- 번역: 이 사이즈 맞나요?

### 5. 鞋  /  xié  /  [명사 (n.)]  /  신발
- 한자 풀이: 革(가죽 혁) + 圭(홀 규) → 발에 신는 것
- 例句: 这双鞋很好看。
- Pinyin: Zhè shuāng xié hěn hǎokàn.
- 번역: 이 신발 아주 예뻐요.

### 6. 合适  /  héshì  /  [형용사 (adj.)]  /  알맞다
- 한자 풀이: 合(합할 합) + 适(맞을 적) → 꼭 맞다
- 例句: 这件衣服很合适。
- Pinyin: Zhè jiàn yīfu hěn héshì.
- 번역: 이 옷은 아주 잘 맞아요.

## 语法点 (어법 포인트)

### 1. "对面" — 맞은편
- 就在地铁站对面。 Jiù zài dìtiě zhàn duìmiàn. 지하철역 맞은편에 있어요.

### 2. "量词 + 衣服/鞋" — 件/双
- 这件衣服 / 一双鞋。 Zhè jiàn yīfu / yì shuāng xié. 이 옷 / 신발 한 켤레.

### 3. "太 + 형용사 + 了" — 너무 ~하다
- 这个码数太大了。 Zhège mǎshù tài dà le. 이 사이즈는 너무 커요.

### 4. "别的 + 명사" — 다른 ~
- 有别的颜色吗？ Yǒu bié de yánsè ma? 다른 색깔이 있나요?

## 应用会话 (응용 회화)

A: 我们一起去商场吧。  
   Wǒmen yìqǐ qù shāngchǎng ba.  
   우리 같이 쇼핑몰에 가요.

B: 好啊，商场在哪儿？  
   Hǎo a, shāngchǎng zài nǎr?  
   좋아요, 쇼핑몰이 어디예요?

A: 就在地铁站对面，晚上十点关门。  
   Jiù zài dìtiě zhàn duìmiàn, wǎnshang shí diǎn guānmén.  
   지하철역 맞은편이에요, 밤 10시에 닫아요.

B: 我想买一双鞋。  
   Wǒ xiǎng mǎi yì shuāng xié.  
   신발 한 켤레를 사고 싶어요.

A: 这件衣服有别的颜色吗？  
   Zhè jiàn yīfu yǒu bié de yánsè ma?  
   이 옷은 다른 색깔이 있나요?

B: 有，还有红色和蓝色。  
   Yǒu, hái yǒu hóngsè hé lánsè.  
   네, 빨간색과 파란색도 있어요.

A: 这个码数太大了，请给我小一号的。  
   Zhège mǎshù tài dà le, qǐng gěi wǒ xiǎo yí hào de.  
   이 사이즈는 너무 커요, 한 치수 작은 걸 주세요.

B: 好的，请稍等。  
   Hǎo de, qǐng shāo děng.  
   네, 잠시만요.
