第 七 课 : 07. 在餐厅 Zài cāntīng (식당에서)

## 本文 (본문)

请问几位？  
Qǐngwèn jǐ wèi?  
몇 분이세요?

两位。  
Liǎng wèi.  
두 명이에요.

请给我菜单。  
Qǐng gěi wǒ càidān.  
메뉴판 주세요.

您想吃什么？  
Nín xiǎng chī shénme?  
뭐 드시고 싶으세요?

我要一份宫保鸡丁。  
Wǒ yào yí fèn gōngbǎo jīdīng.  
궁바오지딩 하나 주세요.

再要一碗米饭。  
Zài yào yì wǎn mǐfàn.  
그리고 밥 한 공기도 주세요.

不要辣。  
Bú yào là.  
맵지 않게 해주세요.

请慢用。  
Qǐng màn yòng.  
맛있게 드세요.

很好吃！  
Hěn hǎochī!  
정말 맛있어요!

买单。  
Mǎidān.  
계산해 주세요.

---

## 主要词汇 (주요 단어)

### 1. 菜单  /  càidān  /  [명사 (n.)]  /  메뉴판
- 한자 풀이: 菜(나물 채) + 单(홑 단) → 요리 목록
- 例句: 请给我菜单。
- Pinyin: Qǐng gěi wǒ càidān.
- 번역: 메뉴판 주세요.

### 2. 点菜  /  diǎncài  /  [동사 (v.)]  /  주문하다
- 한자 풀이: 点(점 점) + 菜(나물 채) → 요리를 고르다
- 例句: 请问可以点菜吗？
- Pinyin: Qǐngwèn kěyǐ diǎncài ma?
- 번역: 실례지만 주문할 수 있나요?

### 3. 米饭  /  mǐfàn  /  [명사 (n.)]  /  밥
- 한자 풀이: 米(쌀 미) + 饭(밥 반) → 쌀로 지은 밥
- 例句: 一碗米饭。
- Pinyin: Yì wǎn mǐfàn.
- 번역: 밥 한 공기.

### 4. 辣  /  là  /  [형용사 (adj.)]  /  맵다
- 한자 풀이: 辛(매울 신) + 束(묶을 속) → 매운 맛
- 例句: 我不吃辣。
- Pinyin: Wǒ bù chī là.
- 번역: 저는 매운 걸 못 먹어요.

### 5. 好吃  /  hǎochī  /  [형용사 (adj.)]  /  맛있다
- 한자 풀이: 好(좋을 호) + 吃(먹을 식) → 맛이 좋다
- 例句: 这个菜很好吃。
- Pinyin: Zhège cài hěn hǎochī.
- 번역: 이 요리 정말 맛있어요.

### 6. 买单  /  mǎidān  /  [동사 (v.)]  /  계산하다
- 한자 풀이: 买(살 매) + 单(홑 단) → 영수증을 사다, 계산하다
- 例句: 服务员，买单。
- Pinyin: Fúwùyuán, mǎidān.
- 번역: 종업원, 계산해 주세요.

## 语法点 (어법 포인트)

### 1. "几位？" — 몇 분이세요?
- 请问几位？ Qǐngwèn jǐ wèi? 몇 분이세요?
- 两位。 Liǎng wèi. 두 명이에요.

### 2. "要 + 음식" — ~를 주세요 (주문)
- 我要一份宫保鸡丁。 Wǒ yào yí fèn gōngbǎo jīdīng. 궁바오지딩 하나 주세요.

### 3. "不要 + 명사/형용사" — ~하지 않게
- 不要辣。 Bú yào là. 맵지 않게 해주세요.

### 4. "请慢用" — 맛있게 드세요
- 请慢用。 Qǐng màn yòng. 맛있게 드세요.

## 应用会话 (응용 회화)

A: 欢迎光临！请问几位？  
   Huānyíng guānglín! Qǐngwèn jǐ wèi?  
   어서 오세요! 몇 분이세요?

B: 两位。  
   Liǎng wèi.  
   두 명이에요.

A: 请坐。这是菜单。  
   Qǐng zuò. Zhè shì càidān.  
   앉으세요. 메뉴판입니다.

B: 我要一份宫保鸡丁，再要一碗米饭。  
   Wǒ yào yí fèn gōngbǎo jīdīng, zài yào yì wǎn mǐfàn.  
   궁바오지딩 하나랑 밥 한 공기 주세요.

A: 要辣吗？  
   Yào là ma?  
   맵게 해드릴까요?

B: 不要辣。  
   Bú yào là.  
   맵지 않게요.

A: 好的，请稍等。  
   Hǎo de, qǐng shāo děng.  
   네, 잠시만요.

B: 谢谢。  
   Xièxie.  
   감사합니다.
