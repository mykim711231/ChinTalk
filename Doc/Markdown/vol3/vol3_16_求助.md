第 十六 课 : 16. 求助 Qiúzhù (도움 요청)

## 本文 (본문)

请问，您能帮我吗？  
Qǐngwèn, nín néng bāng wǒ ma?  
실례지만, 저를 도와주실 수 있나요?

当然，有什么需要帮忙的？  
Dāngrán, yǒu shénme xūyào bāngmáng de?  
물론이죠, 무엇을 도와드릴까요?

我的手机没电了。  
Wǒ de shǒujī méi diàn le.  
휴대폰 배터리가 다 됐어요.

能借用一下充电器吗？  
Néng jièyòng yíxià chōngdiànqì ma?  
충전기를 잠깐 빌릴 수 있을까요?

可以，给您。  
Kěyǐ, gěi nín.  
네, 여기 있어요.

这里有无线网络吗？  
Zhèlǐ yǒu wúxiàn wǎngluò ma?  
여기 와이파이가 있나요?

密码是多少？  
Mìmǎ shì duōshao?  
비밀번호가 뭐예요?

请问卫生间在哪儿？  
Qǐngwèn wèishēngjiān zài nǎr?  
실례지만 화장실이 어디예요?

在左边。  
Zài zuǒbiān.  
왼쪽에 있어요.

谢谢您帮忙。  
Xièxie nín bāngmáng.  
도와주셔서 감사합니다.

---

## 主要词汇 (주요 단어)

### 1. 帮忙  /  bāngmáng  /  [동사 (v.)]  /  돕다
- 한자 풀이: 帮(도울 방) + 忙(바쁠 망) → 남의 일을 돕다
- 例句: 谢谢您帮忙。
- Pinyin: Xièxie nín bāngmáng.
- 번역: 도와주셔서 감사합니다.

### 2. 手机  /  shǒujī  /  [명사 (n.)]  /  휴대폰
- 한자 풀이: 手(손 수) + 机(기계 기) → 손에 들고 쓰는 기계
- 例句: 我的手机没电了。
- Pinyin: Wǒ de shǒujī méi diàn le.
- 번역: 휴대폰 배터리가 다 됐어요.

### 3. 充电器  /  chōngdiànqì  /  [명사 (n.)]  /  충전기
- 한자 풀이: 充(채울 충) + 电(전기 전) + 器(그릇 기) → 전기를 채우는 기구
- 例句: 能借用一下充电器吗？
- Pinyin: Néng jièyòng yíxià chōngdiànqì ma?
- 번역: 충전기를 잠깐 빌릴 수 있을까요?

### 4. 密码  /  mìmǎ  /  [명사 (n.)]  /  비밀번호
- 한자 풀이: 密(빽빽할 밀) + 码(자 마) → 비밀 숫자
- 例句: 密码是多少？
- Pinyin: Mìmǎ shì duōshao?
- 번역: 비밀번호가 뭐예요?

### 5. 无线网络  /  wúxiàn wǎngluò  /  [명사 (n.)]  /  와이파이, 무선 네트워크
- 한자 풀이: 无(없을 무) + 线(줄 선) + 网络(그물 망) → 선이 없는 통신망
- 例句: 这里有无线网络吗？
- Pinyin: Zhèlǐ yǒu wúxiàn wǎngluò ma?
- 번역: 여기 와이파이가 있나요?

### 6. 卫生间  /  wèishēngjiān  /  [명사 (n.)]  /  화장실
- 한자 풀이: 卫(지킬 위) + 生(날 생) + 间(사이 간) → 위생을 위한 방
- 例句: 卫生间在左边。
- Pinyin: Wèishēngjiān zài zuǒbiān.
- 번역: 화장실은 왼쪽에 있어요.

## 语法点 (어법 포인트)

### 1. "能 + 동사 + 吗？" — ~할 수 있나요?
- 您能帮我吗？ Nín néng bāng wǒ ma? 저를 도와주실 수 있나요?
- 能借用一下吗？ Néng jièyòng yíxià ma? 잠깐 빌릴 수 있을까요?

### 2. "没 + 명사 + 了" — ~이 다 되었다
- 手机没电了。 Shǒujī méi diàn le. 휴대폰 배터리가 다 됐어요.

### 3. "有 + 명사 + 吗？" — ~이 있나요?
- 这里有无线网络吗？ Zhèlǐ yǒu wúxiàn wǎngluò ma? 여기 와이파이가 있나요?

### 4. "在 + 방향" — ~쪽에 있다
- 卫生间在左边。 Wèishēngjiān zài zuǒbiān. 화장실은 왼쪽에 있어요.

## 应用会话 (응용 회화)

A: 请问，您能帮我吗？  
   Qǐngwèn, nín néng bāng wǒ ma?  
   실례지만, 저를 도와주실 수 있나요?

B: 当然，有什么需要帮忙的？  
   Dāngrán, yǒu shénme xūyào bāngmáng de?  
   물론이죠, 무엇을 도와드릴까요?

A: 我的手机没电了，能借用一下充电器吗？  
   Wǒ de shǒujī méi diàn le, néng jièyòng yíxià chōngdiànqì ma?  
   휴대폰 배터리가 다 됐어요, 충전기를 잠깐 빌릴 수 있을까요?

B: 可以，给您。  
   Kěyǐ, gěi nín.  
   네, 여기 있어요.

A: 这里有无线网络吗？密码是多少？  
   Zhèlǐ yǒu wúxiàn wǎngluò ma? Mìmǎ shì duōshao?  
   여기 와이파이가 있나요? 비밀번호가 뭐예요?

B: 有，密码是一二三四五六。  
   Yǒu, mìmǎ shì yī èr sān sì wǔ liù.  
   네, 비밀번호는 123456이에요.

A: 请问卫生间在哪儿？  
   Qǐngwèn wèishēngjiān zài nǎr?  
   실례지만 화장실이 어디예요?

B: 在左边。  
   Zài zuǒbiān.  
   왼쪽에 있어요.
