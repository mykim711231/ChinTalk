第 十五 课 : 15. 紧急情况 Jǐnjí qíngkuàng (긴급 상황)

## 本文 (본문)

帮帮我！  
Bāngbang wǒ!  
도와주세요!

发生什么事了？  
Fāshēng shénme shì le?  
무슨 일이 생겼나요?

我的包被偷了。  
Wǒ de bāo bèi tōu le.  
가방을 도둑맞았어요.

我要报警。  
Wǒ yào bàojǐng.  
경찰에 신고해야 해요.

请马上来。  
Qǐng mǎshàng lái.  
바로 와 주세요.

别担心，我帮你。  
Bié dānxīn, wǒ bāng nǐ.  
걱정 마세요, 제가 도와드릴게요.

请告诉我您的姓名。  
Qǐng gàosu wǒ nín de xìngmíng.  
성함을 알려 주세요.

这是紧急电话号码。  
Zhè shì jǐnjí diànhuà hàomǎ.  
이건 긴급 전화번호예요.

请叫救护车！  
Qǐng jiào jiùhùchē!  
구급차를 불러 주세요!

现在安全了。  
Xiànzài ānquán le.  
이제 안전해요.

---

## 主要词汇 (주요 단어)

### 1. 紧急  /  jǐnjí  /  [형용사 (adj.)]  /  긴급하다
- 한자 풀이: 紧(팽팽할 긴) + 急(급할 급) → 몹시 급하다
- 例句: 这是紧急情况。
- Pinyin: Zhè shì jǐnjí qíngkuàng.
- 번역: 이건 긴급 상황이에요.

### 2. 报警  /  bàojǐng  /  [동사 (v.)]  /  경찰에 신고하다
- 한자 풀이: 报(알릴 보) + 警(경계할 경) → 경찰에 알리다
- 例句: 我要报警。
- Pinyin: Wǒ yào bàojǐng.
- 번역: 경찰에 신고해야 해요.

### 3. 偷  /  tōu  /  [동사 (v.)]  /  훔치다
- 한자 풀이: 亻(사람 인) + 俞 → 남의 것을 몰래 가져가다
- 例句: 我的包被偷了。
- Pinyin: Wǒ de bāo bèi tōu le.
- 번역: 가방을 도둑맞았어요.

### 4. 马上  /  mǎshàng  /  [부사 (adv.)]  /  곧, 즉시
- 한자 풀이: 马(말 마) + 上(위 상) → 말을 타고 달려가듯 즉시
- 例句: 请马上来。
- Pinyin: Qǐng mǎshàng lái.
- 번역: 바로 와 주세요.

### 5. 救护车  /  jiùhùchē  /  [명사 (n.)]  /  구급차
- 한자 풀이: 救(구할 구) + 护(보호할 호) + 车(수레 거) → 환자를 실어 나르는 차
- 例句: 请叫救护车！
- Pinyin: Qǐng jiào jiùhùchē!
- 번역: 구급차를 불러 주세요!

### 6. 安全  /  ānquán  /  [형용사 (adj.)]  /  안전하다
- 한자 풀이: 安(편안 안) + 全(온전할 전) → 위험이 없다
- 例句: 现在安全了。
- Pinyin: Xiànzài ānquán le.
- 번역: 이제 안전해요.

## 语法点 (어법 포인트)

### 1. "被 + 동사" — ~당하다 (수동태)
- 我的包被偷了。 Wǒ de bāo bèi tōu le. 가방을 도둑맞았어요.

### 2. "发生什么事了？" — 무슨 일이 생겼나요?
- 发生什么事了？ Fāshēng shénme shì le? 무슨 일이 생겼나요?

### 3. "请 + 동사" — ~해 주세요 (긴급 요청)
- 请叫救护车！ Qǐng jiào jiùhùchē! 구급차를 불러 주세요!

### 4. "别担心" — 걱정하지 마세요
- 别担心，我帮你。 Bié dānxīn, wǒ bāng nǐ. 걱정 마세요, 제가 도와드릴게요.

## 应用会话 (응용 회화)

A: 帮帮我！发生什么事了？  
   Bāngbang wǒ! Fāshēng shénme shì le?  
   도와주세요! 무슨 일이 생겼나요?

B: 我的包被偷了。  
   Wǒ de bāo bèi tōu le.  
   가방을 도둑맞았어요.

A: 别担心，我们马上报警。  
   Bié dānxīn, wǒmen mǎshàng bàojǐng.  
   걱정 마세요, 바로 경찰에 신고해요.

B: 好的，请马上来。  
   Hǎo de, qǐng mǎshàng lái.  
   네, 바로 와 주세요.

A: 请告诉我您的姓名和地址。  
   Qǐng gàosu wǒ nín de xìngmíng hé dìzhǐ.  
   성함과 주소를 알려 주세요.

B: 我姓金，住在阳光酒店。  
   Wǒ xìng Jīn, zhù zài Yángguāng jiǔdiàn.  
   저는 김 씨이고, 썬샤인 호텔에 묵고 있어요.

A: 好的，请在这里等一下。  
   Hǎo de, qǐng zài zhèlǐ děng yí xià.  
   네, 여기서 잠시만 기다려 주세요.

B: 谢谢。  
   Xièxie.  
   감사합니다.
