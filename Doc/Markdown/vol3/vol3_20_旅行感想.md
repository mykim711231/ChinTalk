第 二十 课 : 20. 旅行感想 Lǚxíng gǎnxiǎng (여행 감상)

## 本文 (본문)

这次旅行怎么样？  
Zhè cì lǚxíng zěnmeyàng?  
이번 여행 어땠어요?

非常开心！  
Fēicháng kāixīn!  
정말 즐거웠어요!

你去了哪些地方？  
Nǐ qù le nǎxiē dìfang?  
어떤 곳에 갔어요?

我去了长城和故宫。  
Wǒ qù le Chángchéng hé Gùgōng.  
만리장성과 자금성에 갔어요.

你最喜欢哪个景点？  
Nǐ zuì xǐhuan nǎge jǐngdiǎn?  
가장 좋아하는 관광지는 어디예요?

我最喜欢长城。  
Wǒ zuì xǐhuan Chángchéng.  
저는 만리장성이 제일 좋았어요.

长城真壮观！  
Chángchéng zhēn zhuàngguān!  
만리장성은 정말 웅장해요!

你吃了什么美食？  
Nǐ chī le shénme měishí?  
어떤 맛있는 음식을 먹었어요?

我吃了北京烤鸭。  
Wǒ chī le Běijīng kǎoyā.  
베이징 오리구이를 먹었어요.

味道好极了！  
Wèidào hǎo jí le!  
맛이 아주 좋았어요!

下次我还想来。  
Xià cì wǒ hái xiǎng lái.  
다음에 또 오고 싶어요.

---

## 主要词汇 (주요 단어)

### 1. 旅行  /  lǚxíng  /  [동사 (v.)]  /  여행하다
- 한자 풀이: 旅(나그네 려) + 行(다닐 행) → 멀리 다니다
- 例句: 这次旅行很开心。
- Pinyin: Zhè cì lǚxíng hěn kāixīn.
- 번역: 이번 여행 아주 즐거웠어요.

### 2. 感想  /  gǎnxiǎng  /  [명사 (n.)]  /  감상, 느낌
- 한자 풀이: 感(느낄 감) + 想(생각 상) → 느끼고 생각한 것
- 例句: 你有什么旅行感想？
- Pinyin: Nǐ yǒu shénme lǚxíng gǎnxiǎng?
- 번역: 어떤 여행 감상이 있나요?

### 3. 壮观  /  zhuàngguān  /  [형용사 (adj.)]  /  웅장하다
- 한자 풀이: 壮(장할 장) + 观(볼 관) → 보기에 웅장하다
- 例句: 长城真壮观！
- Pinyin: Chángchéng zhēn zhuàngguān!
- 번역: 만리장성은 정말 웅장해요!

### 4. 美食  /  měishí  /  [명사 (n.)]  /  맛있는 음식
- 한자 풀이: 美(아름다울 미) + 食(밥 식) → 맛있는 음식
- 例句: 你吃了什么美食？
- Pinyin: Nǐ chī le shénme měishí?
- 번역: 어떤 맛있는 음식을 먹었어요?

### 5. 味道  /  wèidào  /  [명사 (n.)]  /  맛
- 한자 풀이: 味(맛 미) + 道(길 도) → 음식의 맛
- 例句: 味道好极了！
- Pinyin: Wèidào hǎo jí le!
- 번역: 맛이 아주 좋았어요!

### 6. 开心  /  kāixīn  /  [형용사 (adj.)]  /  즐겁다, 기쁘다
- 한자 풀이: 开(열 개) + 心(마음 심) → 마음이 열리다
- 例句: 非常开心！
- Pinyin: Fēicháng kāixīn!
- 번역: 정말 즐거웠어요!

## 语法点 (어법 포인트)

### 1. "这次…怎么样？" — 이번 ~은 어땠나요?
- 这次旅行怎么样？ Zhè cì lǚxíng zěnmeyàng? 이번 여행 어땠어요?

### 2. "最 + 동사/형용사" — 가장 ~하다
- 你最喜欢哪个景点？ Nǐ zuì xǐhuan nǎge jǐngdiǎn? 가장 좋아하는 관광지는 어디예요?

### 3. "真 + 형용사" — 정말 ~하다
- 长城真壮观！ Chángchéng zhēn zhuàngguān! 만리장성은 정말 웅장해요!

### 4. "…好极了" — 아주 ~하다 (감탄)
- 味道好极了！ Wèidào hǎo jí le! 맛이 아주 좋았어요!
