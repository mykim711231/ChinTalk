第 三 课 : 03. 订酒店 Dìng jiǔdiàn (호텔 예약)

## 本文 (본문)

我想订一个房间。  
Wǒ xiǎng dìng yí ge fángjiān.  
방 하나를 예약하고 싶어요.

请问您要几间房？  
Qǐngwèn nín yào jǐ jiān fáng?  
실례지만 방이 몇 개 필요하세요?

一间双人房。  
Yì jiān shuāngrén fáng.  
더블룸 하나요.

住几个晚上？  
Zhù jǐ ge wǎnshang?  
며칠 묵으시나요?

住三个晚上。  
Zhù sān ge wǎnshang.  
3박이요.

一晚多少钱？  
Yì wǎn duōshao qián?  
하루에 얼마예요?

一晚三百元。  
Yì wǎn sānbǎi yuán.  
하루에 300위안입니다.

含早餐吗？  
Hán zǎocān ma?  
아침 식사가 포함되나요?

含早餐。  
Hán zǎocān.  
아침 식사가 포함됩니다.

可以刷卡吗？  
Kěyǐ shuākǎ ma?  
카드 결제 되나요?

没问题。  
Méi wèntí.  
문제없어요.

## 主要词汇 (주요 단어)

### 1. 房间  /  fángjiān  /  [명사 (n.)]  /  방, 객실
- 한자 풀이: 房(방 방) + 间(사이 간) → 집 안의 칸막이 공간
- 例句: 我想订一个房间。
- Pinyin: Wǒ xiǎng dìng yí ge fángjiān.
- 번역: 방 하나를 예약하고 싶어요.

### 2. 酒店  /  jiǔdiàn  /  [명사 (n.)]  /  호텔
- 한자 풀이: 酒(술 주) + 店(가게 점) → 숙박을 제공하는 가게
- 例句: 这家酒店很好。
- Pinyin: Zhè jiā jiǔdiàn hěn hǎo.
- 번역: 이 호텔은 아주 좋아요.

### 3. 双人房  /  shuāngrén fáng  /  [명사 (n.)]  /  더블룸, 2인실
- 한자 풀이: 双(쌍 쌍) + 人(사람 인) + 房(방 방) → 두 사람이 쓰는 방
- 例句: 我要一间双人房。
- Pinyin: Wǒ yào yì jiān shuāngrén fáng.
- 번역: 더블룸 하나 주세요.

### 4. 早餐  /  zǎocān  /  [명사 (n.)]  /  아침 식사
- 한자 풀이: 早(이를 조) + 餐(밥 찬) → 아침에 먹는 밥
- 例句: 早餐很丰盛。
- Pinyin: Zǎocān hěn fēngshèng.
- 번역: 아침 식사가 아주 푸짐해요.

### 5. 刷卡  /  shuākǎ  /  [동사 (v.)]  /  카드로 결제하다
- 한자 풀이: 刷(쓸 쇄) + 卡(카드 카) → 카드를 긁다
- 例句: 可以刷卡吗？
- Pinyin: Kěyǐ shuākǎ ma?
- 번역: 카드 결제 되나요?

### 6. 含  /  hán  /  [동사 (v.)]  /  포함하다
- 한자 풀이: 今(이제 금) + 口(입 구) → 입에 머금다, 포함하다
- 例句: 房价含早餐。
- Pinyin: Fángjià hán zǎocān.
- 번역: 숙박비에 아침 식사가 포함돼요.

## 语法点 (어법 포인트)

### 1. "几 + 양사" — 몇 (개/개수) 의문
- 您要几间房？ Nín yào jǐ jiān fáng? 방이 몇 개 필요하세요?
- 住几个晚上？ Zhù jǐ ge wǎnshang? 며칠 묵으세요?

### 2. "一晚/一个 + 단위" — 하룻밤당
- 一晚多少钱？ Yì wǎn duōshao qián? 하루에 얼마예요?
- 一晚三百元。 Yì wǎn sānbǎi yuán. 하루에 300위안입니다.

### 3. "含" — 포함하다
- 含早餐吗？ Hán zǎocān ma? 아침 식사 포함인가요?

### 4. "可以…吗？" — ~할 수 있나요?
- 可以刷卡吗？ Kěyǐ shuākǎ ma? 카드 결제 되나요?

## 应用会话 (응용 회화)

A: 你好，我想订一个房间。  
   Nǐ hǎo, wǒ xiǎng dìng yí ge fángjiān.  
   안녕하세요, 방 하나를 예약하고 싶어요.

B: 好的，请问要几间房？  
   Hǎo de, qǐngwèn yào jǐ jiān fáng?  
   네, 방이 몇 개 필요하세요?

A: 一间双人房。  
   Yì jiān shuāngrén fáng.  
   더블룸 하나요.

B: 住几个晚上？  
   Zhù jǐ ge wǎnshang?  
   며칠 묵으세요?

A: 住两个晚上。一晚多少钱？  
   Zhù liǎng ge wǎnshang. Yì wǎn duōshao qián?  
   이틀이요. 하루에 얼마예요?

B: 一晚三百元，含早餐。  
   Yì wǎn sānbǎi yuán, hán zǎocān.  
   하루 300위안이고, 아침 식사가 포함돼요.

A: 可以刷卡吗？  
   Kěyǐ shuākǎ ma?  
   카드 결제 되나요?

B: 没问题。请出示您的护照。  
   Méi wèntí. Qǐng chūshì nín de hùzhào.  
   문제없어요. 여권을 제시해 주세요.
