第 五 课 : 05. 拍照 Pāizhào (사진 촬영)

## 本文 (본문)

请帮我拍张照片。  
Qǐng bāng wǒ pāi zhāng zhàopiàn.  
사진 한 장 찍어 주세요.

好的，看这里。  
Hǎo de, kàn zhèlǐ.  
네, 여기를 보세요.

准备好了吗？  
Zhǔnbèi hǎo le ma?  
준비됐나요?

准备好了。  
Zhǔnbèi hǎo le.  
준비됐어요.

一二三，笑一笑！  
Yī èr sān, xiào yí xiào!  
하나 둘 셋, 웃으세요!

照片拍得怎么样？  
Zhàopiàn pāi de zěnmeyàng?  
사진은 어떻게 나왔어요?

拍得很好。  
Pāi de hěn hǎo.  
아주 잘 나왔어요.

我们合影吧。  
Wǒmen héyǐng ba.  
우리 같이 찍어요.

可以再拍一张吗？  
Kěyǐ zài pāi yì zhāng ma?  
한 장 더 찍어도 되나요?

没问题。  
Méi wèntí.  
문제없어요.

---

## 主要词汇 (주요 단어)

### 1. 拍照  /  pāizhào  /  [동사 (v.)]  /  사진을 찍다
- 한자 풀이: 拍(칠 박) + 照(비칠 조) → 사진을 찍다
- 例句: 我想拍照。
- Pinyin: Wǒ xiǎng pāizhào.
- 번역: 사진을 찍고 싶어요.

### 2. 照片  /  zhàopiàn  /  [명사 (n.)]  /  사진
- 한자 풀이: 照(비칠 조) + 片(조각 편) → 찍은 이미지
- 例句: 这张照片很好看。
- Pinyin: Zhè zhāng zhàopiàn hěn hǎokàn.
- 번역: 이 사진 정말 예뻐요.

### 3. 准备  /  zhǔnbèi  /  [동사 (v.)]  /  준비하다
- 한자 풀이: 准(준할 준) + 备(갖출 비) → 미리 갖추다
- 例句: 准备好了吗？
- Pinyin: Zhǔnbèi hǎo le ma?
- 번역: 준비됐나요?

### 4. 合影  /  héyǐng  /  [명사 (n.)]  /  단체 사진
- 한자 풀이: 合(합할 합) + 影(그림자 영) → 함께 찍은 사진
- 例句: 我们合影吧。
- Pinyin: Wǒmen héyǐng ba.
- 번역: 우리 같이 찍어요.

### 5. 笑  /  xiào  /  [동사 (v.)]  /  웃다
- 한자 풀이: 竹(대 죽) + 夭(일찍 죽을 요) → 웃는 모습
- 例句: 请笑一笑。
- Pinyin: Qǐng xiào yí xiào.
- 번역: 웃어 보세요.

### 6. 拍  /  pāi  /  [동사 (v.)]  /  찍다, 치다
- 한자 풀이: 扌(손 수) + 白(흰 백) → 손으로 두드리다
- 例句: 拍得很好。
- Pinyin: Pāi de hěn hǎo.
- 번역: 아주 잘 찍었어요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 拍照 | pāizhào | p를 "ㅂ"처럼, zh 평음화 | p는 강한 송기음, zh 혀 말아 |
| 照片 | zhàopiàn | zh를 "ㅉ"로 평음화 | 혀를 말아 권설음 zhào |
| 准备 | zhǔnbèi | zh 평음화, 准 3성 놓침 | zhǔn 3성, 혀를 말아 |
| 一二三 | yī èr sān | 二를 "얼"로 읽음 | èr는 혀를 말아 권설음 |
| 笑一笑 | xiào yí xiào | 一을 1성(yī)으로 읽음 | 4성(笑) 앞의 一은 2성(yí) |

## 语法点 (어법 포인트)

### 1. "请帮我…" — ~을 도와주세요
- 请帮我拍张照片。 Qǐng bāng wǒ pāi zhāng zhàopiàn. 사진 한 장 찍어 주세요.

### 2. "…好了吗？" — ~됐나요? (완료 확인)
- 准备好了吗？ Zhǔnbèi hǎo le ma? 준비됐나요?

### 3. "动词 + 得 + 怎么样" — 어떻게 ~했나요? (결과)
- 拍得怎么样？ Pāi de zěnmeyàng? 어떻게 찍혔어요?

### 4. "再 + 동사" — 다시/한 번 더 ~하다
- 可以再拍一张吗？ Kěyǐ zài pāi yì zhāng ma? 한 장 더 찍어도 되나요?

## 应用会话 (응용 회화)

   Nǐ hǎo, qǐng bāng wǒ pāi zhāng zhàopiàn hǎo ma?  
   안녕하세요, 사진 한 장 찍어 주시겠어요?

B: 好的，看这里。  
   Hǎo de, kàn zhèlǐ.  
   네, 여기를 보세요.

A: 准备好了吗？  
   Zhǔnbèi hǎo le ma?  
   준비됐나요?

B: 好了。一二三，笑一笑！  
   Hǎo le. Yī èr sān, xiào yí xiào!  
   됐어요. 하나 둘 셋, 웃으세요!

A: 谢谢！照片拍得怎么样？  
   Xièxie! Zhàopiàn pāi de zěnmeyàng?  
   감사합니다! 사진은 어떻게 나왔어요?

B: 拍得很好。  
   Pāi de hěn hǎo.  
   아주 잘 나왔어요.

A: 那我们一起合影吧。  
   Nà wǒmen yìqǐ héyǐng ba.  
   그럼 우리 같이 찍어요.

   Hǎo a!  
   좋아요!
