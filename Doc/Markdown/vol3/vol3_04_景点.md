第 四 课 : 04. 景点 Jǐngdiǎn (관광지)

## 本文 (본문)

这个城市有哪些景点？  
Zhège chéngshì yǒu nǎxiē jǐngdiǎn?  
이 도시에는 어떤 관광지가 있나요?

故宫很有名。  
Gùgōng hěn yǒumíng.  
자금성은 아주 유명해요.

那里离这儿远吗？  
Nàlǐ lí zhèr yuǎn ma?  
거기가 여기서 먼가요?

不太远，坐地铁很方便。  
Bú tài yuǎn, zuò dìtiě hěn fāngbiàn.  
그렇게 멀지 않아요, 지하철 타면 편리해요.

门票多少钱？  
Ménpiào duōshao qián?  
입장료는 얼마예요?

成人票六十元。  
Chéngrén piào liùshí yuán.  
성인 표는 60위안이에요.

这里真漂亮！  
Zhèlǐ zhēn piàoliang!  
여기 정말 예뻐요!

我可以拍照片吗？  
Wǒ kěyǐ pāi zhàopiàn ma?  
사진을 찍어도 되나요?

当然可以。  
Dāngrán kěyǐ.  
물론이죠.

我们走吧。  
Wǒmen zǒu ba.  
우리 가요.

## 主要词汇 (주요 단어)

### 1. 景点  /  jǐngdiǎn  /  [명사 (n.)]  /  관광지, 명소
- 한자 풀이: 景(경치 경) + 点(점 점) → 경치 좋은 곳
- 例句: 这个景点很有名。
- Pinyin: Zhège jǐngdiǎn hěn yǒumíng.
- 번역: 이 관광지는 아주 유명해요.

### 2. 有名  /  yǒumíng  /  [형용사 (adj.)]  /  유명하다
- 한자 풀이: 有(있을 유) + 名(이름 명) → 이름이 있다, 알려져 있다
- 例句: 长城很有名。
- Pinyin: Chángchéng hěn yǒumíng.
- 번역: 만리장성은 아주 유명해요.

### 3. 门票  /  ménpiào  /  [명사 (n.)]  /  입장권
- 한자 풀이: 门(문 문) + 票(표 표) → 들어가는 표
- 例句: 我在买门票。
- Pinyin: Wǒ zài mǎi ménpiào.
- 번역: 입장권을 사고 있어요.

### 4. 方便  /  fāngbiàn  /  [형용사 (adj.)]  /  편리하다
- 한자 풀이: 方(모 방) + 便(편할 편) → 편하고 쉬움
- 例句: 坐地铁很方便。
- Pinyin: Zuò dìtiě hěn fāngbiàn.
- 번역: 지하철 타는 게 편리해요.

### 5. 漂亮  /  piàoliang  /  [형용사 (adj.)]  /  아름답다, 예쁘다
- 한자 풀이: 漂(떠다닐 표) + 亮(밝을 량) → 반짝이고 아름답다
- 例句: 这里真漂亮！
- Pinyin: Zhèlǐ zhēn piàoliang!
- 번역: 여기 정말 예뻐요!

### 6. 拍照  /  pāizhào  /  [동사 (v.)]  /  사진을 찍다
- 한자 풀이: 拍(칠 박) + 照(비칠 조) → 사진을 찍다
- 例句: 我们一起拍照吧。
- Pinyin: Wǒmen yìqǐ pāizhào ba.
- 번역: 우리 같이 사진 찍어요.

## 语法点 (어법 포인트)

### 1. "哪些" — 어떤 것들 (복수 의문)
- 有哪些景点？ Yǒu nǎxiē jǐngdiǎn? 어떤 관광지가 있나요?

### 2. "离…远吗？" — ~에서 먼가요?
- 那里离这儿远吗？ Nàlǐ lí zhèr yuǎn ma? 거기가 여기서 먼가요?

### 3. "真 + 형용사" — 정말 ~하다
- 这里真漂亮！ Zhèlǐ zhēn piàoliang! 여기 정말 예뻐요!

### 4. "可以…吗？" — ~해도 되나요?
- 我可以拍照吗？ Wǒ kěyǐ pāizhào ma? 사진 찍어도 되나요?

## 应用会话 (응용 회화)

A: 这个城市有哪些著名的景点？  
   Zhège chéngshì yǒu nǎxiē zhùmíng de jǐngdiǎn?  
   이 도시에는 어떤 유명한 관광지가 있나요?

B: 故宫和天坛都很有名。  
   Gùgōng hé Tiāntán dōu hěn yǒumíng.  
   자금성과 천단이 모두 유명해요.

A: 那里离这儿远吗？  
   Nàlǐ lí zhèr yuǎn ma?  
   거기가 여기서 먼가요?

B: 不太远，坐地铁二十分钟。  
   Bú tài yuǎn, zuò dìtiě èrshí fēnzhōng.  
   그렇게 멀지 않아요, 지하철로 20분이에요.

A: 门票多少钱？  
   Ménpiào duōshao qián?  
   입장료는 얼마예요?

B: 成人票六十元。  
   Chéngrén piào liùshí yuán.  
   성인 표는 60위안이에요.

A: 好，我们明天去吧！  
   Hǎo, wǒmen míngtiān qù ba!  
   좋아요, 우리 내일 가요!

B: 好的，明天见！  
   Hǎo de, míngtiān jiàn!  
   네, 내일 봐요!
