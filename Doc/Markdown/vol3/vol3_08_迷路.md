第 八 课 : 08. 迷路 Mílù (길을 잃다)

## 本文 (본문)

我迷路了。  
Wǒ mílù le.  
길을 잃었어요.

请问，这条路怎么走？  
Qǐngwèn, zhè tiáo lù zěnme zǒu?  
실례지만, 이 길 어떻게 가나요?

一直往前走。  
Yìzhí wǎng qián zǒu.  
쭉 앞으로 가세요.

在十字路口左转。  
Zài shízì lùkǒu zuǒ zhuǎn.  
사거리에서 왼쪽으로 꺾으세요.

往前走一百米。  
Wǎng qián zǒu yìbǎi mǐ.  
앞으로 100미터 가세요.

就在地铁站旁边。  
Jiù zài dìtiě zhàn pángbiān.  
지하철역 옆에 있어요.

离这里远吗？  
Lí zhèlǐ yuǎn ma?  
여기서 먼가요?

走路大概十分钟。  
Zǒulù dàgài shí fēnzhōng.  
걸어서 대략 10분이에요.

谢谢你的帮助。  
Xièxie nǐ de bāngzhù.  
도와줘서 고마워요.

不客气。  
Bú kèqi.  
천만에요.

---

## 主要词汇 (주요 단어)

### 1. 迷路  /  mílù  /  [동사 (v.)]  /  길을 잃다
- 한자 풀이: 迷(미혹할 미) + 路(길 로) → 길을 헤매다
- 例句: 我迷路了。
- Pinyin: Wǒ mílù le.
- 번역: 길을 잃었어요.

### 2. 一直  /  yìzhí  /  [부사 (adv.)]  /  곧장, 계속
- 한자 풀이: 一(한 일) + 直(곧을 직) → 곧게 계속
- 例句: 一直往前走。
- Pinyin: Yìzhí wǎng qián zǒu.
- 번역: 쭉 앞으로 가세요.

### 3. 十字路口  /  shízì lùkǒu  /  [명사 (n.)]  /  사거리
- 한자 풀이: 十字(열 십) + 路口(갈림길) → 길이 십자로 교차하는 곳
- 例句: 在十字路口左转。
- Pinyin: Zài shízì lùkǒu zuǒ zhuǎn.
- 번역: 사거리에서 왼쪽으로 꺾으세요.

### 4. 转  /  zhuǎn  /  [동사 (v.)]  /  돌다, 방향을 바꾸다
- 한자 풀이: 车(수레 거) + 专(오로지 전) → 수레를 돌리다
- 例句: 请右转。
- Pinyin: Qǐng yòu zhuǎn.
- 번역: 오른쪽으로 꺾으세요.

### 5. 旁边  /  pángbiān  /  [명사 (n.)]  /  옆, 곁
- 한자 풀이: 旁(곁 방) + 边(가 변) → 곁, 옆쪽
- 例句: 银行在超市旁边。
- Pinyin: Yínháng zài chāoshì pángbiān.
- 번역: 은행은 마트 옆에 있어요.

### 6. 帮助  /  bāngzhù  /  [동사 (v.)]  /  돕다
- 한자 풀이: 帮(도울 방) + 助(도울 조) → 돕다
- 例句: 谢谢你的帮助。
- Pinyin: Xièxie nǐ de bāngzhù.
- 번역: 도와줘서 고마워요.

|---|---|---|---|
| 不客气 | bú kèqi | 不을 4성, 气를 4성(qì) | 不은 4성(客) 앞 2성(bú), 气는 경성(qi) |

## 语法点 (어법 포인트)

### 1. "往 + 방향 + 走" — ~쪽으로 가다
- 一直往前走。 Yìzhí wǎng qián zǒu. 쭉 앞으로 가세요.
- 往前走一百米。 Wǎng qián zǒu yìbǎi mǐ. 앞으로 100미터 가세요.

### 2. "在 + 장소 + 동사" — ~에서 ~하다
- 在十字路口左转。 Zài shízì lùkǒu zuǒ zhuǎn. 사거리에서 왼쪽으로 꺾으세요.

### 3. "就 + 동사" — 바로 ~하다
- 就在地铁站旁边。 Jiù zài dìtiě zhàn pángbiān. 지하철역 바로 옆에 있어요.

### 4. "大概" — 대략, 약
- 走路大概十分钟。 Zǒulù dàgài shí fēnzhōng. 걸어서 대략 10분이에요.

## 应用会话 (응용 회화)

A: 你好，我迷路了。请问这条路怎么走？  
   Nǐ hǎo, wǒ mílù le. Qǐngwèn zhè tiáo lù zěnme zǒu?  
   안녕하세요, 길을 잃었어요. 이 길 어떻게 가나요?

B: 一直往前走，在十字路口左转。  
   Yìzhí wǎng qián zǒu, zài shízì lùkǒu zuǒ zhuǎn.  
   쭉 앞으로 가서 사거리에서 왼쪽으로 꺾으세요.

A: 离这里远吗？  
   Lí zhèlǐ yuǎn ma?  
   여기서 먼가요?

B: 不远，走路大概十分钟。  
   Bù yuǎn, zǒulù dàgài shí fēnzhōng.  
   멀지 않아요, 걸어서 대략 10분이에요.

A: 谢谢你的帮助。  
   Xièxie nǐ de bāngzhù.  
   도와줘서 고마워요.

B: 不客气。  
   Bú kèqi.  
   천만에요.
