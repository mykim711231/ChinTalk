第 十七 课 : 17. 出境 Chūjìng (출국)

## 本文 (본문)

我要去机场。  
Wǒ yào qù jīchǎng.  
공항에 가야 해요.

请出示您的护照和机票。  
Qǐng chūshì nín de hùzhào hé jīpiào.  
여권과 항공권을 제시해 주세요.

办理登机手续需要什么？  
Bànlǐ dēngjī shǒuxù xūyào shénme?  
탑승 수속을 하려면 무엇이 필요한가요?

您的行李超重了。  
Nín de xíngli chāozhòng le.  
짐이 중량을 초과했어요.

托运这件行李。  
Tuōyùn zhè jiàn xíngli.  
이 짐을 위탁하세요.

登机口在哪儿？  
Dēngjīkǒu zài nǎr?  
탑승구가 어디예요?

在二十号登机口。  
Zài èrshí hào dēngjīkǒu.  
20번 탑승구에 있어요.

几点开始登机？  
Jǐ diǎn kāishǐ dēngjī?  
몇 시에 탑승을 시작하나요?

请提前三十分钟到登机口。  
Qǐng tíqián sānshí fēnzhōng dào dēngjīkǒu.  
30분 전에 탑승구로 와 주세요.

祝您旅途愉快！  
Zhù nín lǚtú yúkuài!  
즐거운 여행 되세요!

---

## 主要词汇 (주요 단어)

### 1. 出境  /  chūjìng  /  [동사 (v.)]  /  출국하다
- 한자 풀이: 出(날 출) + 境(지경 경) → 국경 밖으로 나가다
- 例句: 我在办理出境手续。
- Pinyin: Wǒ zài bànlǐ chūjìng shǒuxù.
- 번역: 출국 수속을 하고 있어요.

### 2. 登机  /  dēngjī  /  [동사 (v.)]  /  탑승하다
- 한자 풀이: 登(오를 등) + 机(기계 기) → 비행기에 오르다
- 例句: 几点开始登机？
- Pinyin: Jǐ diǎn kāishǐ dēngjī?
- 번역: 몇 시에 탑승을 시작하나요?

### 3. 行李  /  xíngli  /  [명사 (n.)]  /  짐, 수하물
- 한자 풀이: 行(다닐 행) + 李(오얏 리) → 여행할 때 나르는 짐
- 例句: 您的行李超重了。
- Pinyin: Nín de xíngli chāozhòng le.
- 번역: 짐이 중량을 초과했어요.

### 4. 托运  /  tuōyùn  /  [동사 (v.)]  /  수하물로 부치다
- 한자 풀이: 托(맡길 탁) + 运(운전할 운) → 짐을 맡겨 보내다
- 例句: 托运这件行李。
- Pinyin: Tuōyùn zhè jiàn xíngli.
- 번역: 이 짐을 위탁하세요.

### 5. 登机口  /  dēngjīkǒu  /  [명사 (n.)]  /  탑승구
- 한자 풀이: 登机(탑승) + 口(입 구) → 비행기에 타는 입구
- 例句: 登机口在二十号。
- Pinyin: Dēngjīkǒu zài èrshí hào.
- 번역: 탑승구는 20번이에요.

### 6. 超重  /  chāozhòng  /  [동사 (v.)]  /  중량을 초과하다
- 한자 풀이: 超(뛰어넘을 초) + 重(무거울 중) → 무게가 넘치다
- 例句: 行李超重了。
- Pinyin: Xíngli chāozhòng le.
- 번역: 짐이 중량을 초과했어요.

## 语法点 (어법 포인트)

### 1. "办理 + 수속" — 수속을 하다
- 办理登机手续。 Bànlǐ dēngjī shǒuxù. 탑승 수속을 하다.

### 2. "…超重了" — 중량을 초과했다
- 您的行李超重了。 Nín de xíngli chāozhòng le. 짐이 중량을 초과했어요.

### 3. "几点开始…？" — 몇 시에 ~을 시작하나요?
- 几点开始登机？ Jǐ diǎn kāishǐ dēngjī? 몇 시에 탑승을 시작하나요?

### 4. "提前" — 미리, 앞당겨서
- 请提前三十分钟到登机口。 Qǐng tíqián sānshí fēnzhōng dào dēngjīkǒu. 30분 전에 탑승구로 와 주세요.

## 应用会话 (응용 회화)

A: 你好，我要去机场，办理登机手续。  
   Nǐ hǎo, wǒ yào qù jīchǎng, bànlǐ dēngjī shǒuxù.  
   안녕하세요, 공항에 가서 탑승 수속을 하려고 해요.

B: 请出示您的护照和机票。  
   Qǐng chūshì nín de hùzhào hé jīpiào.  
   여권과 항공권을 제시해 주세요.

A: 给您。登机口在哪儿？  
   Gěi nín. Dēngjīkǒu zài nǎr?  
   여기요. 탑승구가 어디예요?

B: 在二十号登机口。您的行李超重了，请托运这件行李。  
   Zài èrshí hào dēngjīkǒu. Nín de xíngli chāozhòng le, qǐng tuōyùn zhè jiàn xíngli.  
   20번 탑승구예요. 짐이 중량을 초과했으니 이 짐을 위탁하세요.

A: 好的。几点开始登机？  
   Hǎo de. Jǐ diǎn kāishǐ dēngjī?  
   네. 몇 시에 탑승을 시작하나요?

B: 请提前三十分钟到登机口。  
   Qǐng tíqián sānshí fēnzhōng dào dēngjīkǒu.  
   30분 전에 탑승구로 와 주세요.

A: 好的，谢谢。  
   Hǎo de, xièxie.  
   네, 감사합니다.

B: 祝您旅途愉快！  
   Zhù nín lǚtú yúkuài!  
   즐거운 여행 되세요!
