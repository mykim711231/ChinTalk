第 十三 课 : 13. 公园 Gōngyuán (공원)

## 本文 (본문)

这个公园真大！  
Zhège gōngyuán zhēn dà!  
이 공원 정말 넓어요!

公园里有湖。  
Gōngyuán lǐ yǒu hú.  
공원 안에 호수가 있어요.

我们可以坐船。  
Wǒmen kěyǐ zuò chuán.  
우리는 배를 탈 수 있어요.

那边有很多花。  
Nàbiān yǒu hěn duō huā.  
저쪽에 꽃이 많아요.

我们散散步吧。  
Wǒmen sànsàn bù ba.  
우리 산책해요.

空气很新鲜。  
Kōngqì hěn xīnxiān.  
공기가 아주 맑아요.

很多人在这里锻炼。  
Hěn duō rén zài zhèlǐ duànliàn.  
많은 사람들이 여기서 운동해요.

树下很凉快。  
Shù xià hěn liángkuai.  
나무 아래는 아주 시원해요.

我们休息一会儿吧。  
Wǒmen xiūxi yíhuìr ba.  
우리 잠깐 쉬어요.

这里太美了！  
Zhèlǐ tài měi le!  
여기 정말 아름다워요!

## 主要词汇 (주요 단어)

### 1. 公园  /  gōngyuán  /  [명사 (n.)]  /  공원
- 한자 풀이: 公(공평할 공) + 园(동산 원) → 누구나 쓰는 정원
- 例句: 我们去公园玩。
- Pinyin: Wǒmen qù gōngyuán wán.
- 번역: 우리 공원에 놀러 가요.

### 2. 湖  /  hú  /  [명사 (n.)]  /  호수
- 한자 풀이: 氵(물 수) + 胡(턱밑살 호) → 넓은 물
- 例句: 湖里有很多鱼。
- Pinyin: Hú lǐ yǒu hěn duō yú.
- 번역: 호수에 물고기가 많아요.

### 3. 散步  /  sànbù  /  [동사 (v.)]  /  산책하다
- 한자 풀이: 散(흩을 산) + 步(걸음 보) → 천천히 걷다
- 例句: 我们散散步吧。
- Pinyin: Wǒmen sànsàn bù ba.
- 번역: 우리 산책해요.

### 4. 空气  /  kōngqì  /  [명사 (n.)]  /  공기
- 한자 풀이: 空(빌 공) + 气(기운 기) → 하늘의 기운
- 例句: 空气很新鲜。
- Pinyin: Kōngqì hěn xīnxiān.
- 번역: 공기가 아주 맑아요.

### 5. 锻炼  /  duànliàn  /  [동사 (v.)]  /  운동하다, 단련하다
- 한자 풀이: 锻(쇠불릴 단) + 炼(달굴 련) → 몸을 단련하다
- 例句: 我每天锻炼身体。
- Pinyin: Wǒ měitiān duànliàn shēntǐ.
- 번역: 매일 운동을 해요.

### 6. 凉快  /  liángkuai  /  [형용사 (adj.)]  /  시원하다
- 한자 풀이: 凉(서늘할 량) + 快(쾌할 쾌) → 서늘하고 쾌적하다
- 例句: 树下很凉快。
- Pinyin: Shù xià hěn liángkuai.
- 번역: 나무 아래는 아주 시원해요.

## 语法点 (어법 포인트)

### 1. "真 + 형용사" — 정말 ~하다
- 这个公园真大！ Zhège gōngyuán zhēn dà! 이 공원 정말 넓어요!

### 2. "…里/…下" — ~안에 / ~아래에 (위치)
- 公园里有湖。 Gōngyuán lǐ yǒu hú. 공원 안에 호수가 있어요.
- 树下很凉快。 Shù xià hěn liángkuai. 나무 아래는 시원해요.

### 3. "我们 + 동사 + 吧" — 우리 ~하자 (제안)
- 我们散散步吧。 Wǒmen sànsàn bù ba. 우리 산책해요.

### 4. "太 + 형용사 + 了" — 정말 ~하다
- 这里太美了！ Zhèlǐ tài měi le! 여기 정말 아름다워요!

## 应用会话 (응용 회화)

A: 这个公园真大！  
   Zhège gōngyuán zhēn dà!  
   이 공원 정말 넓어요!

B: 是啊，公园里还有一个湖。  
   Shì a, gōngyuán lǐ hái yǒu yí ge hú.  
   그러게요, 공원 안에 호수도 있어요.

A: 我们可以坐船吗？  
   Wǒmen kěyǐ zuò chuán ma?  
   배를 탈 수 있나요?

B: 可以，那边就可以坐。  
   Kěyǐ, nàbiān jiù kěyǐ zuò.  
   네, 저쪽에서 탈 수 있어요.

A: 我们先散散步吧，空气很新鲜。  
   Wǒmen xiān sànsàn bù ba, kōngqì hěn xīnxiān.  
   먼저 산책해요, 공기가 아주 맑아요.

B: 好，树下很凉快。  
   Hǎo, shù xià hěn liángkuai.  
   좋아요, 나무 아래는 아주 시원해요.

A: 这里太美了！  
   Zhèlǐ tài měi le!  
   여기 정말 아름다워요!
