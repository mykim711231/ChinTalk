第 十七 课 : 17. 下单 Xiàdān (주문·발주)

## 本文 (본문)

我们决定下单了。  
Wǒmen juédìng xiàdān le.  
저희는 주문하기로 결정했습니다.

我们要订购五百件。  
Wǒmen yào dìnggòu wǔbǎi jiàn.  
저희는 500개를 주문하려고 합니다.

这是订单。  
Zhè shì dìngdān.  
이것은 주문서입니다.

请确认一下数量。  
Qǐng quèrèn yíxià shùliàng.  
수량을 확인해 주세요.

付款方式是电汇。  
Fùkuǎn fāngshì shì diànhuì.  
결제 방식은 전신 송금입니다.

我们预付百分之三十的定金。  
Wǒmen yùfù bǎi fēn zhī sānshí de dìngjīn.  
저희는 30%의 선금을 지불합니다.

什么时候可以发货？  
Shénme shíhou kěyǐ fāhuò?  
언제 발송할 수 있나요?

收到定金后一周内发货。  
Shōudào dìngjīn hòu yì zhōu nèi fāhuò.  
선금을 받은 후 일주일 안에 발송합니다.

---

## 主要词汇 (주요 단어)

### 1. 下单  /  xiàdān  /  [동사 (v.)]  /  주문하다
- 한자 풀이: 下(내릴 하) + 单(문서 단) → 주문서를 내다
- 例句: 我在网上下单了。
- Pinyin: Wǒ zài wǎngshang xiàdān le.
- 번역: 나는 인터넷에서 주문했다.

### 2. 订购  /  dìnggòu  /  [동사 (v.)]  /  주문 구매하다
- 한자 풀이: 订(정할 정) + 购(살 구) → 정하여 사다
- 例句: 我们订购了一批货。
- Pinyin: Wǒmen dìnggòu le yì pī huò.
- 번역: 우리는 물건 한 묶음을 주문했다.

### 3. 订单  /  dìngdān  /  [명사 (n.)]  /  주문서
- 한자 풀이: 订(정할 정) + 单(문서 단) → 주문 문서
- 例句: 订单已经确认了。
- Pinyin: Dìngdān yǐjīng quèrèn le.
- 번역: 주문서는 이미 확인되었다.

### 4. 确认  /  quèrèn  /  [동사 (v.)]  /  확인하다
- 한자 풀이: 确(굳을 확) + 认(알 인) → 확실히 알다
- 例句: 请确认订单信息。
- Pinyin: Qǐng quèrèn dìngdān xìnxī.
- 번역: 주문 정보를 확인해 주세요.

### 5. 付款  /  fùkuǎn  /  [동사 (v.)]  /  대금을 지불하다
- 한자 풀이: 付(줄 부) + 款(돈 관) → 돈을 내다
- 例句: 请及时付款。
- Pinyin: Qǐng jíshí fùkuǎn.
- 번역: 제때 대금을 지불해 주세요.

### 6. 发货  /  fāhuò  /  [동사 (v.)]  /  발송하다
- 한자 풀이: 发(보낼 발) + 货(물건 화) → 물건을 보내다
- 例句: 我们明天发货。
- Pinyin: Wǒmen míngtiān fāhuò.
- 번역: 우리는 내일 발송한다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 五百 | wǔbǎi | 五·百 모두 3성 그대로 | 3성+3성 변화, 앞 五는 2성(wú bǎi) |
| 确认 | quèrèn | q를 'ㅋ'처럼, 确 4성 놓침 | q는 혀를 입천장에 대고 부드럽게, 确是 4성 |
| 数量 | shùliàng | sh를 'ㅅ'으로, 数 4성 놓침 | sh는 권설음, 数是 4성(shù) |

| 百分之三十 | bǎi fēn zhī sānshí | zh를 'ㅈ'으로, 十 2성 놓침 | zh는 권설음, 十은 2성(shí) |

## 语法点 (어법 포인트)

### 1. "决定 + 동사" — ~하기로 결정하다
- 我们决定下单了。 Wǒmen juédìng xiàdān le. 주문하기로 결정했습니다.

### 2. "要 + 동사" — ~하려고 하다
- 我们要订购五百件。 Wǒmen yào dìnggòu wǔbǎi jiàn. 500개를 주문하려고 합니다.

### 3. "请确认 + 명사" — ~을 확인해 주세요
- 请确认一下数量。 Qǐng quèrèn yíxià shùliàng. 수량을 확인해 주세요.

### 4. "什么时候 + 동사？" — 언제 ~하나요?
- 什么时候可以发货？ Shénme shíhou kěyǐ fāhuò? 언제 발송할 수 있나요?

## 应用会话 (응용 회화 - 비즈니스)

A: 您好，我们决定下单了。  
   Nín hǎo, wǒmen juédìng xiàdān le.  
   안녕하세요, 주문하기로 결정했습니다.

B: 太好了，您要订购多少？  
   Tài hǎo le, nín yào dìnggòu duōshao?  
   정말 좋습니다, 얼마나 주문하시겠어요?

A: 我们要订购五百件。  
   Wǒmen yào dìnggòu wǔbǎi jiàn.  
   500개를 주문하려고 합니다.

B: 好的，请确认一下订单。  
   Hǎo de, qǐng quèrèn yíxià dìngdān.  
   네, 주문서를 확인해 주세요.

A: 付款方式是电汇。  
   Fùkuǎn fāngshì shì diànhuì.  
   결제 방식은 전신 송금입니다.

B: 我们收到定金后一周内发货。  
   Wǒmen shōudào dìngjīn hòu yì zhōu nèi fāhuò.  
   선금을 받은 후 일주일 안에 발송합니다.

A: 好的，我们马上付定金。  
   Hǎo de, wǒmen mǎshàng fù dìngjīn.  
   네, 바로 선금을 지불하겠습니다.

B: 感谢您的订单！  
   Gǎnxiè nín de dìngdān!  
   주문해 주셔서 감사합니다!
