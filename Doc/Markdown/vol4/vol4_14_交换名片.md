第 十四 课 : 14. 交换名片 Jiāohuàn míngpiàn (명함 교환)

## 本文 (본문)

您好，这是我的名片。  
Nín hǎo, zhè shì wǒ de míngpiàn.  
안녕하세요, 이것은 제 명함입니다.

请多关照。  
Qǐng duō guānzhào.  
잘 부탁드립니다.

可以给我一张您的名片吗？  
Kěyǐ gěi wǒ yì zhāng nín de míngpiàn ma?  
당신의 명함 한 장 주실 수 있나요?

当然可以，请收下。  
Dāngrán kěyǐ, qǐng shōuxià.  
물론입니다, 받아 주세요.

很高兴认识您。  
Hěn gāoxìng rènshi nín.  
만나서 반갑습니다.

这是我的联系方式。  
Zhè shì wǒ de liánxì fāngshì.  
이것은 저의 연락처입니다.

以后请多联系。  
Yǐhòu qǐng duō liánxì.  
앞으로 자주 연락합시다.

我们改天再详谈。  
Wǒmen gǎitiān zài xiángtán.  
다음에 다시 자세히 이야기합시다.

---

## 主要词汇 (주요 단어)

### 1. 名片  /  míngpiàn  /  [명사 (n.)]  /  명함
- 한자 풀이: 名(이름 명) + 片(조각 편) → 이름이 적힌 조각
- 例句: 请给我一张名片。
- Pinyin: Qǐng gěi wǒ yì zhāng míngpiàn.
- 번역: 명함 한 장 주세요.

### 2. 交换  /  jiāohuàn  /  [동사 (v.)]  /  교환하다
- 한자 풀이: 交(사귈 교) + 换(바꿀 환) → 서로 바꾸다
- 例句: 我们交换一下意见。
- Pinyin: Wǒmen jiāohuàn yíxià yìjiàn.
- 번역: 우리 의견을 교환해 봅시다.

### 3. 关照  /  guānzhào  /  [동사 (v.)]  /  돌보다, 신경 써 주다
- 한자 풀이: 关(관계할 관) + 照(비출 조) → 돌봐 주다
- 例句: 请多关照。
- Pinyin: Qǐng duō guānzhào.
- 번역: 잘 부탁드립니다.

### 4. 收下  /  shōuxià  /  [동사 (v.)]  /  받아 두다
- 한자 풀이: 收(거둘 수) + 下(아래 하) → 받아 들이다
- 例句: 请收下这份礼物。
- Pinyin: Qǐng shōuxià zhè fèn lǐwù.
- 번역: 이 선물을 받아 주세요.

### 5. 认识  /  rènshi  /  [동사 (v.)]  /  알다, 아는 사이가 되다
- 한자 풀이: 认(알 인) + 识(알 식) → 알아보다
- 例句: 认识您很高兴。
- Pinyin: Rènshi nín hěn gāoxìng.
- 번역: 당신을 알게 되어 기쁩니다.

### 6. 联系  /  liánxì  /  [동사 (v.)]  /  연락하다
- 한자 풀이: 联(이을 연) + 系(맬 계) → 이어 묶다
- 例句: 我们保持联系。
- Pinyin: Wǒmen bǎochí liánxì.
- 번역: 우리 연락을 유지합시다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 关照 | guānzhào | zh를 'ㅈ'으로, 照 4성 놓침 | zh는 권설음, 照는 4성(zhào) |
| 认识 | rènshi | 识를 2성(shí)으로 | 认识의 识는 경성(shi) |
| 交换 | jiāohuàn | j를 'ㅈ'으로, 换 4성 놓침 | j는 무기음, 换은 4성(huàn) |
| 详谈 | xiángtán | x를 'ㅆ'으로 강하게 | x는 혀를 입천장 가까이 대고 부드럽게 |
| 名片 | míngpiàn | 名 2성 놓침 | 名은 2성(míng), 片은 4성(piàn) |

## 语法点 (어법 포인트)

### 1. "这是 + 명사" — 이것은 ~입니다
- 这是我的名片。 Zhè shì wǒ de míngpiàn. 이것은 제 명함입니다.

### 2. "可以 + 동사 + 吗？" — ~해도 될까요?
- 可以给我一张名片吗？ Kěyǐ gěi wǒ yì zhāng míngpiàn ma? 명함 한 장 주실 수 있나요?

### 3. "请多关照" — 잘 부탁드립니다 (관용어)
- 初次见面，请多关照。 Chūcì jiànmiàn, qǐng duō guānzhào. 처음 뵙겠습니다, 잘 부탁드립니다.

### 4. "很高兴 + 동사" — ~해서 기쁘다
- 很高兴认识您。 Hěn gāoxìng rènshi nín. 만나서 반갑습니다.
