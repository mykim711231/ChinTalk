第 十三 课 : 13. 商务宴请 Shāngwù yànqǐng (비즈니스 식사)

## 本文 (본문)

欢迎光临，请坐。  
Huānyíng guānglín, qǐng zuò.  
어서 오세요, 앉으세요.

今晚我请客。  
Jīnwǎn wǒ qǐngkè.  
오늘 저녁은 제가 대접하겠습니다.

您想吃什么菜？  
Nín xiǎng chī shénme cài?  
어떤 음식을 드시고 싶으세요?

来几个特色菜吧。  
Lái jǐ ge tèsè cài ba.  
특색 요리 몇 가지를 시키죠.

别客气，请随便吃。  
Bié kèqi, qǐng suíbiàn chī.  
사양하지 마시고 편하게 드세요.

我敬您一杯。  
Wǒ jìng nín yì bēi.  
한 잔 올리겠습니다.

干杯！  
Gānbēi!  
건배!

祝我们合作愉快！  
Zhù wǒmen hézuò yúkuài!  
저희 협력이 즐겁기를 바랍니다!

谢谢您的款待。  
Xièxie nín de kuǎndài.  
대접해 주셔서 감사합니다.

---

## 主要词汇 (주요 단어)

### 1. 宴请  /  yànqǐng  /  [동사 (v.)]  /  연회를 열어 대접하다
- 한자 풀이: 宴(잔치 연) + 请(청할 청) → 잔치로 초대하다
- 例句: 我们宴请了客户。
- Pinyin: Wǒmen yànqǐng le kèhù.
- 번역: 우리는 거래처를 대접했다.

### 2. 请客  /  qǐngkè  /  [동사 (v.)]  /  한턱내다, 대접하다
- 한자 풀이: 请(청할 청) + 客(손 객) → 손님을 대접하다
- 例句: 今天我请客。
- Pinyin: Jīntiān wǒ qǐngkè.
- 번역: 오늘은 내가 대접한다.

### 3. 菜  /  cài  /  [명사 (n.)]  /  요리, 반찬
- 한자 풀이: 艹(풀 초) + 采(캘 채) → 식물 음식
- 例句: 这道菜很好吃。
- Pinyin: Zhè dào cài hěn hǎochī.
- 번역: 이 요리는 아주 맛있다.

### 4. 敬  /  jìng  /  [동사 (v.)]  /  (술을) 올리다, 공경하다
- 한자 풀이: 苟 + 攵 → 공경하여 대접하다
- 例句: 我敬您一杯。
- Pinyin: Wǒ jìng nín yì bēi.
- 번역: 한 잔 올리겠습니다.

### 5. 干杯  /  gānbēi  /  [동사 (v.)]  /  건배하다
- 한자 풀이: 干(마를 간) + 杯(잔 배) → 잔을 비우다
- 例句: 来，干杯！
- Pinyin: Lái, gānbēi!
- 번역: 자, 건배!

### 6. 款待  /  kuǎndài  /  [동사 (v.)]  /  후하게 대접하다
- 한자 풀이: 款(정성 관) + 待(대접할 대) → 정성껏 대접하다
- 例句: 谢谢您的款待。
- Pinyin: Xièxie nín de kuǎndài.
- 번역: 대접해 주셔서 감사합니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 请客 | qǐngkè | q를 'ㅋ'처럼 과하게 | q는 혀를 입천장에 대고 부드럽게, 请은 3성 |
| 别客气 | bié kèqi | 气를 4성(qì)으로 | 客气의 气는 경성(qi) |
| 一杯 | yì bēi | 一을 1성(yī)으로 | 一은 1성 앞에서 4성(yì bēi) |
| 特色菜 | tèsè cài | t를 'ㄷ'으로 무기음화 | t는 송기음(ㅌ), 特·色 모두 4성 |
| 愉快 | yúkuài | yu를 '유'로 발음 | yu(=ü)는 입술을 둥글게, 愉는 2성 |

## 语法点 (어법 포인트)

### 1. "欢迎光临" — 어서 오세요 (관용어)
- 欢迎光临，请坐。 Huānyíng guānglín, qǐng zuò. 어서 오세요, 앉으세요.

### 2. "别 + 동사" — ~하지 마세요
- 别客气，请随便吃。 Bié kèqi, qǐng suíbiàn chī. 사양하지 말고 편하게 드세요.

### 3. "敬 + 사람 + 一杯" — ~에게 한 잔 올리다
- 我敬您一杯。 Wǒ jìng nín yì bēi. 한 잔 올리겠습니다.

### 4. "祝 + 절" — ~하기를 바라다
- 祝我们合作愉快！ Zhù wǒmen hézuò yúkuài! 우리 협력이 즐겁기를 바랍니다!

A: 别客气，今晚我请客。  
   Bié kèqi, jīnwǎn wǒ qǐngkè.  
   사양 마세요, 오늘 저녁은 제가 대접합니다.

   Nín xiǎng chī shénme cài?

   Lái jǐ ge tèsè cài ba.
