第 五 课 : 05. 电子邮件 Diànzǐ yóujiàn (이메일)

## 本文 (본문)

我每天都要收发电子邮件。  
Wǒ měitiān dōu yào shōufā diànzǐ yóujiàn.  
저는 매일 이메일을 주고받아야 합니다.

这是我的电子邮箱地址。  
Zhè shì wǒ de diànzǐ yóuxiāng dìzhǐ.  
이것은 제 이메일 주소입니다.

请给我发一封邮件。  
Qǐng gěi wǒ fā yì fēng yóujiàn.  
저에게 이메일 한 통을 보내 주세요.

我收到了您的邮件。  
Wǒ shōudào le nín de yóujiàn.  
저는 당신의 이메일을 받았습니다.

附件已经发过去了。  
Fùjiàn yǐjīng fā guòqù le.  
첨부 파일은 이미 보냈습니다.

请查收。  
Qǐng cháshōu.  
확인해 주세요.

如果有问题，请随时联系我。  
Rúguǒ yǒu wèntí, qǐng suíshí liánxì wǒ.  
문제가 있으면 언제든지 저에게 연락해 주세요.

期待您的回复。  
Qīdài nín de huífù.  
당신의 답장을 기다리겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 电子邮件  /  diànzǐ yóujiàn  /  [명사 (n.)]  /  이메일
- 한자 풀이: 电子(전자) + 邮件(우편물) → 전자 우편
- 例句: 请用电子邮件联系。
- Pinyin: Qǐng yòng diànzǐ yóujiàn liánxì.
- 번역: 이메일로 연락해 주세요.

### 2. 邮箱  /  yóuxiāng  /  [명사 (n.)]  /  메일함, 이메일 주소
- 한자 풀이: 邮(우편 우) + 箱(상자 상) → 우편물을 담는 상자
- 例句: 你的邮箱是多少？
- Pinyin: Nǐ de yóuxiāng shì duōshao?
- 번역: 당신의 이메일 주소는 무엇인가요?

### 3. 附件  /  fùjiàn  /  [명사 (n.)]  /  첨부 파일
- 한자 풀이: 附(붙을 부) + 件(물건 건) → 덧붙이는 것
- 例句: 请查看附件。
- Pinyin: Qǐng chákàn fùjiàn.
- 번역: 첨부 파일을 확인해 주세요.

### 4. 发  /  fā  /  [동사 (v.)]  /  보내다
- 한자 풀이: 癶(걸을 발) + 又 → 내보내다
- 例句: 我发邮件给你。
- Pinyin: Wǒ fā yóujiàn gěi nǐ.
- 번역: 내가 너에게 이메일을 보낸다.

### 5. 收到  /  shōudào  /  [동사 (v.)]  /  받다
- 한자 풀이: 收(거둘 수) + 到(이를 도) → 받아 들이다
- 例句: 我收到了合同。
- Pinyin: Wǒ shōudào le hétong.
- 번역: 나는 계약서를 받았다.

### 6. 回复  /  huífù  /  [동사 (v.)]  /  답장하다
- 한자 풀이: 回(돌아올 회) + 复(회복할 복) → 답을 보내다
- 例句: 请尽快回复。
- Pinyin: Qǐng jǐnkuài huífù.
- 번역: 가능한 한 빨리 답장해 주세요.

## 语法点 (어법 포인트)

### 1. "给 + 사람 + 동사" — ~에게 ~해 주다
- 请给我发一封邮件。 Qǐng gěi wǒ fā yì fēng yóujiàn. 저에게 이메일 한 통을 보내 주세요.

### 2. "已经 + 동사" — 이미 ~했다
- 附件已经发过去了。 Fùjiàn yǐjīng fā guòqù le. 첨부 파일은 이미 보냈습니다.

### 3. "请 + 동사" — ~해 주세요 (요청)
- 请查收。 Qǐng cháshōu. 확인해 주세요.

### 4. "如果 + 조건" — 만약 ~라면
- 如果有问题，请随时联系我。 Rúguǒ yǒu wèntí, qǐng suíshí liánxì wǒ. 문제가 있으면 언제든지 저에게 연락하세요.

   당신의 이메일 주소는 무엇인가요?

   Wǒ de yóuxiāng shì wang@mail.com.  
   제 이메일은 wang@mail.com입니다.

A: 好的，我马上把合同发给你。  
   Hǎo de, wǒ mǎshàng bǎ hétong fā gěi nǐ.  
   네, 바로 계약서를 보내 드릴게요.

B: 谢谢，我会注意查收。  
   Xièxie, wǒ huì zhùyì cháshōu.  
   감사합니다, 확인해 보겠습니다.

   Hǎo de, yǒu wèntí wǒ huì liánxì nǐ.  
   네, 문제가 있으면 연락드리겠습니다.

A: 期待您的回复。  
   Qīdài nín de huífù.  
   당신의 답장을 기다리겠습니다.

B: 我会尽快回复的。  
   Wǒ huì jǐnkuài huífù de.  
   가능한 한 빨리 답장드리겠습니다.
