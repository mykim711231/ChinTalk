第 十一 课 : 11. 合同 Hétong (계약)

## 本文 (본문)

这是合同草案。  
Zhè shì hétong cǎo'àn.  
이것은 계약서 초안입니다.

请您仔细看一下条款。  
Qǐng nín zǐxì kàn yíxià tiáokuǎn.  
조항을 자세히 봐 주세요.

如果没问题，我们就签字。  
Rúguǒ méi wèntí, wǒmen jiù qiānzì.  
문제가 없으면 서명합시다.

合同的有效期是一年。  
Hétong de yǒuxiàoqī shì yì nián.  
계약의 유효기간은 1년입니다.

双方都要遵守合同。  
Shuāngfāng dōu yào zūnshǒu hétong.  
양측 모두 계약을 지켜야 합니다.

违约要赔偿损失。  
Wéiyuē yào péicháng sǔnshī.  
계약을 위반하면 손해를 배상해야 합니다.

我们需要修改这一条。  
Wǒmen xūyào xiūgǎi zhè yì tiáo.  
저희는 이 조항을 수정해야 합니다.

好的，我们重新打印一份。  
Hǎo de, wǒmen chóngxīn dǎyìn yí fèn.  
좋습니다, 다시 한 부 인쇄하겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 合同  /  hétong  /  [명사 (n.)]  /  계약서
- 한자 풀이: 合(합할 합) + 同(같을 동) → 서로 합의한 문서
- 例句: 我们签了一份合同。
- Pinyin: Wǒmen qiān le yí fèn hétong.
- 번역: 우리는 계약서 한 부를 체결했다.

### 2. 条款  /  tiáokuǎn  /  [명사 (n.)]  /  조항
- 한자 풀이: 条(가지 조) + 款(조목 관) → 문서의 조목
- 例句: 请看清楚每一条款。
- Pinyin: Qǐng kàn qīngchu měi yì tiáokuǎn.
- 번역: 모든 조항을 분명히 보세요.

### 3. 签字  /  qiānzì  /  [동사 (v.)]  /  서명하다
- 한자 풀이: 签(서명할 첨) + 字(글자 자) → 이름을 쓰다
- 例句: 请在合同上签字。
- Pinyin: Qǐng zài hétong shang qiānzì.
- 번역: 계약서에 서명해 주세요.

### 4. 有效期  /  yǒuxiàoqī  /  [명사 (n.)]  /  유효기간
- 한자 풀이: 有(있을 유) + 效(효험 효) + 期(기한 기) → 효력이 있는 기간
- 例句: 有效期到明年。
- Pinyin: Yǒuxiàoqī dào míngnián.
- 번역: 유효기간은 내년까지다.

### 5. 遵守  /  zūnshǒu  /  [동사 (v.)]  /  지키다, 준수하다
- 한자 풀이: 遵(좇을 준) + 守(지킬 수) → 따라 지키다
- 例句: 我们必须遵守规定。
- Pinyin: Wǒmen bìxū zūnshǒu guīdìng.
- 번역: 우리는 규정을 반드시 지켜야 한다.

### 6. 修改  /  xiūgǎi  /  [동사 (v.)]  /  수정하다
- 한자 풀이: 修(닦을 수) + 改(고칠 개) → 고치다
- 例句: 请修改这个条款。
- Pinyin: Qǐng xiūgǎi zhège tiáokuǎn.
- 번역: 이 조항을 수정해 주세요.

| 一年 | yì nián | 一을 1성(yī)으로 | 一은 2성 앞에서 4성(yì nián) |

## 语法点 (어법 포인트)

### 1. "是 + 명사" — ~이다
- 合同的有效期是一年。 Hétong de yǒuxiàoqī shì yì nián. 계약의 유효기간은 1년이다.

### 2. "都要 + 동사" — 모두 ~해야 한다
- 双方都要遵守合同。 Shuāngfāng dōu yào zūnshǒu hétong. 양측 모두 계약을 지켜야 한다.

### 3. "如果……就……" — 만약 ~하면 ~하다
- 如果没问题，我们就签字。 Rúguǒ méi wèntí, wǒmen jiù qiānzì. 문제가 없으면 서명합시다.

### 4. "需要 + 동사" — ~할 필요가 있다
- 我们需要修改这一条。 Wǒmen xūyào xiūgǎi zhè yì tiáo. 이 조항을 수정해야 합니다.

## 应用会话 (응용 회화 - 비즈니스)

A: 这是合同草案，请过目。  
   Zhè shì hétong cǎo'àn, qǐng guòmù.  
   이것은 계약서 초안입니다, 검토해 주세요.

B: 好的，我仔细看一下。  
   Hǎo de, wǒ zǐxì kàn yíxià.  
   네, 자세히 보겠습니다.

A: 有什么问题吗？  
   Yǒu shénme wèntí ma?  
   문제가 있나요?

B: 这一条需要修改一下。  
   Zhè yì tiáo xūyào xiūgǎi yíxià.  
   이 조항을 수정해야 합니다.

A: 没问题，我们马上改。  
   Méi wèntí, wǒmen mǎshàng gǎi.  
   문제없습니다, 바로 수정하겠습니다.

B: 改好了我们再看一遍。  
   Gǎi hǎo le wǒmen zài kàn yí biàn.  
   수정되면 다시 한 번 보겠습니다.

A: 好的，没问题的话我们就签字。  
   Hǎo de, méi wèntí de huà wǒmen jiù qiānzì.  
   좋습니다, 문제없으면 서명합시다.

B: 合作愉快！  
   Hézuò yúkuài!  
   즐거운 협력 되세요!
