第 十 课 : 10. 谈判 Tánpàn (협상)

## 本文 (본문)

我们开始谈判吧。  
Wǒmen kāishǐ tánpàn ba.  
협상을 시작합시다.

我们想谈谈价格问题。  
Wǒmen xiǎng tántan jiàgé wèntí.  
저희는 가격 문제를 이야기하고 싶습니다.

这个价格太高了。  
Zhège jiàgé tài gāo le.  
이 가격은 너무 높습니다.

您能再优惠一点儿吗？  
Nín néng zài yōuhuì yìdiǎnr ma?  
조금 더 할인해 주실 수 있나요?

这是我们的最低价。  
Zhè shì wǒmen de zuìdī jià.  
이것은 저희의 최저가입니다.

如果您多买，我们可以打折。  
Rúguǒ nín duō mǎi, wǒmen kěyǐ dǎzhé.  
많이 사시면 할인해 드릴 수 있습니다.

好的，那我们各让一步。  
Hǎo de, nà wǒmen gè ràng yí bù.  
좋습니다, 그럼 서로 한 걸음씩 양보합시다.

我们就这样说定了。  
Wǒmen jiù zhèyàng shuō dìng le.  
우리 이렇게 합의합시다.

---

## 主要词汇 (주요 단어)

### 1. 谈判  /  tánpàn  /  [동사 (v.)]  /  협상하다
- 한자 풀이: 谈(말할 담) + 判(판단할 판) → 의논하여 정하다
- 例句: 双方正在谈判。
- Pinyin: Shuāngfāng zhèngzài tánpàn.
- 번역: 양측이 협상 중이다.

### 2. 价格  /  jiàgé  /  [명사 (n.)]  /  가격
- 한자 풀이: 价(값 가) + 格(격식 격) → 값
- 例句: 价格可以商量。
- Pinyin: Jiàgé kěyǐ shāngliang.
- 번역: 가격은 상의할 수 있다.

### 3. 优惠  /  yōuhuì  /  [명사/형용사 (n./adj.)]  /  할인, 우대
- 한자 풀이: 优(넉넉할 우) + 惠(은혜 혜) → 후하게 대우
- 例句: 我们有优惠活动。
- Pinyin: Wǒmen yǒu yōuhuì huódòng.
- 번역: 저희는 할인 행사를 한다.

### 4. 最低价  /  zuìdī jià  /  [명사 (n.)]  /  최저가
- 한자 풀이: 最(가장 최) + 低(낮을 저) + 价(값 가) → 가장 낮은 값
- 例句: 这是最低价。
- Pinyin: Zhè shì zuìdī jià.
- 번역: 이것은 최저가입니다.

### 5. 打折  /  dǎzhé  /  [동사 (v.)]  /  할인하다
- 한자 풀이: 打(칠 타) + 折(꺾을 절) → 값을 꺾다
- 例句: 现在打八折。
- Pinyin: Xiànzài dǎ bā zhé.
- 번역: 지금 20% 할인합니다.

### 6. 让步  /  ràngbù  /  [동사 (v.)]  /  양보하다
- 한자 풀이: 让(사양할 양) + 步(걸음 보) → 한 발 물러서다
- 例句: 我们不会让步。
- Pinyin: Wǒmen bú huì ràngbù.
- 번역: 우리는 양보하지 않을 것이다.

## 语法点 (어법 포인트)

### 1. "……吧" — ~합시다 (권유)
- 我们开始谈判吧。 Wǒmen kāishǐ tánpàn ba. 협상을 시작합시다.

### 2. "太 + 형용사 + 了" — 너무 ~하다
- 这个价格太高了。 Zhège jiàgé tài gāo le. 이 가격은 너무 높습니다.

### 3. "能 + 동사" — ~할 수 있다
- 您能再优惠一点儿吗？ Nín néng zài yōuhuì yìdiǎnr ma? 조금 더 할인해 주실 수 있나요?

### 4. "如果……就……" — 만약 ~하면 ~하다
- 如果您多买，我们就可以打折。 Rúguǒ nín duō mǎi, wǒmen jiù kěyǐ dǎzhé. 많이 사시면 할인해 드릴 수 있습니다.

## 应用会话 (응용 회화 - 비즈니스)

A: 我们想谈谈价格问题。  
   Wǒmen xiǎng tántan jiàgé wèntí.  
   저희는 가격 문제를 이야기하고 싶습니다.

B: 好的，请说。  
   Hǎo de, qǐng shuō.  
   좋습니다, 말씀해 주세요.

A: 这个价格太高了。  
   Zhège jiàgé tài gāo le.  
   이 가격은 너무 높습니다.

B: 这是我们的最低价了。  
   Zhè shì wǒmen de zuìdī jià le.  
   이것은 저희의 최저가입니다.

A: 如果我们大量订购，能打折吗？  
   Rúguǒ wǒmen dàliàng dìnggòu, néng dǎzhé ma?  
   대량으로 주문하면 할인이 가능한가요?

B: 可以，订购一千件以上打九折。  
   Kěyǐ, dìnggòu yìqiān jiàn yǐshàng dǎ jiǔ zhé.  
   가능합니다, 1,000개 이상 주문 시 10% 할인해 드립니다.

A: 好的，那我们各让一步。  
   Hǎo de, nà wǒmen gè ràng yí bù.  
   좋습니다, 그럼 서로 한 걸음씩 양보합시다.

B: 我们就这样说定了。  
   Wǒmen jiù zhèyàng shuō dìng le.  
   우리 이렇게 합의합시다.
