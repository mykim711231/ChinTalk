第 十六 课 : 16. 询价 Xúnjià (가격 문의)

## 本文 (본문)

我想询价。  
Wǒ xiǎng xúnjià.  
저는 가격을 문의하고 싶습니다.

请问这个产品多少钱？  
Qǐngwèn zhège chǎnpǐn duōshao qián?  
이 제품은 얼마인가요?

每件的单价是多少？  
Měi jiàn de dānjià shì duōshao?  
개당 단가는 얼마인가요?

这个价格包括运费吗？  
Zhège jiàgé bāokuò yùnfèi ma?  
이 가격에 운임이 포함되나요?

您能报一个含税价吗？  
Nín néng bào yí ge hánshuì jià ma?  
세금 포함 가격을 알려 주실 수 있나요?

请给我一份报价单。  
Qǐng gěi wǒ yí fèn bàojiàdān.  
견적서 한 부를 주세요.

报价单多久能做好？  
Bàojiàdān duō jiǔ néng zuò hǎo?  
견적서는 얼마나 걸려 작성할 수 있나요?

我们两天内给您回复。  
Wǒmen liǎng tiān nèi gěi nín huífù.  
이틀 안에 답변 드리겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 询价  /  xúnjià  /  [동사 (v.)]  /  가격을 문의하다
- 한자 풀이: 询(물을 순) + 价(값 가) → 값을 묻다
- 例句: 我打电话询价。
- Pinyin: Wǒ dǎ diànhuà xúnjià.
- 번역: 나는 전화로 가격을 문의한다.

### 2. 单价  /  dānjià  /  [명사 (n.)]  /  단가
- 한자 풀이: 单(홑 단) + 价(값 가) → 하나의 값
- 例句: 单价是五十元。
- Pinyin: Dānjià shì wǔshí yuán.
- 번역: 단가는 50위안이다.

### 3. 包括  /  bāokuò  /  [동사 (v.)]  /  포함하다
- 한자 풀이: 包(쌀 포) + 括(묶을 괄) → 싸서 묶다
- 例句: 价格包括运费。
- Pinyin: Jiàgé bāokuò yùnfèi.
- 번역: 가격에는 운임이 포함된다.

### 4. 运费  /  yùnfèi  /  [명사 (n.)]  /  운임
- 한자 풀이: 运(옮길 운) + 费(쓸 비) → 운반 비용
- 例句: 运费另算。
- Pinyin: Yùnfèi lìng suàn.
- 번역: 운임은 별도 계산한다.

### 5. 含税  /  hánshuì  /  [형용사 (adj.)]  /  세금 포함의
- 한자 풀이: 含(머금을 함) + 税(세금 세) → 세금을 포함하다
- 例句: 这是含税价。
- Pinyin: Zhè shì hánshuì jià.
- 번역: 이것은 세금 포함 가격이다.

### 6. 报价单  /  bàojiàdān  /  [명사 (n.)]  /  견적서
- 한자 풀이: 报(알릴 보) + 价(값 가) + 单(문서 단) → 값을 적은 문서
- 例句: 请发报价单给我。
- Pinyin: Qǐng fā bàojiàdān gěi wǒ.
- 번역: 견적서를 저에게 보내 주세요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 多少钱 | duōshao qián | 少를 3성(shǎo)으로 | 多少의 少는 경성(shao) |
| 产品 | chǎnpǐn | 产·品 모두 3성 그대로 | 3성+3성 변화, 앞 产은 2성(chán pǐn) |
| 询价 | xúnjià | x를 'ㅆ'으로, 询 2성 놓침 | x는 혀를 입천장 가까이 대고, 询은 2성(xún) |
| 含税 | hánshuì | sh를 'ㅅ'으로, 税 4성 놓침 | sh는 권설음, 税는 4성(shuì) |
| 包括 | bāokuò | k를 'ㄱ'으로, 括 4성 놓침 | k는 송기음(ㅋ), 括은 4성(kuò) |

## 语法点 (어법 포인트)

### 1. "多少钱？" — 얼마인가요?
- 请问这个产品多少钱？ Qǐngwèn zhège chǎnpǐn duōshao qián? 이 제품은 얼마인가요?

### 2. "包括 + 명사 + 吗？" — ~가 포함되나요?
- 这个价格包括运费吗？ Zhège jiàgé bāokuò yùnfèi ma? 이 가격에 운임이 포함되나요?

### 3. "能 + 동사 + 吗？" — ~해 주실 수 있나요?
- 您能报一个含税价吗？ Nín néng bào yí ge hánshuì jià ma? 세금 포함 가격을 알려 주실 수 있나요?

### 4. "多久 + 동사？" — 얼마나 걸려 ~하나요?
- 报价单多久能做好？ Bàojiàdān duō jiǔ néng zuò hǎo? 견적서는 얼마나 걸려 완성할 수 있나요?

## 应用会话 (응용 회화 - 비즈니스)

A: 您好，我想询价。  
   Nín hǎo, wǒ xiǎng xúnjià.  
   안녕하세요, 가격을 문의하고 싶습니다.

B: 好的，您想了解哪个产品？  
   Hǎo de, nín xiǎng liǎojiě nǎ ge chǎnpǐn?  
   네, 어떤 제품을 알아보시겠어요?

A: 这个产品的单价是多少？  
   Zhège chǎnpǐn de dānjià shì duōshao?  
   이 제품의 단가는 얼마인가요?

B: 每件五十元。  
   Měi jiàn wǔshí yuán.  
   개당 50위안입니다.

A: 这个价格包括运费吗？  
   Zhège jiàgé bāokuò yùnfèi ma?  
   이 가격에 운임이 포함되나요?

B: 不包括，运费另算。  
   Bù bāokuò, yùnfèi lìng suàn.  
   포함되지 않습니다, 운임은 별도입니다.

A: 那请给我一份报价单。  
   Nà qǐng gěi wǒ yí fèn bàojiàdān.  
   그럼 견적서 한 부를 주세요.

B: 好的，我们两天内给您回复。  
   Hǎo de, wǒmen liǎng tiān nèi gěi nín huífù.  
   네, 이틀 안에 답변 드리겠습니다.
