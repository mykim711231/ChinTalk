第 十五 课 : 15. 拜访客户 Bàifǎng kèhù (거래처 방문)

## 本文 (본문)

我们约好了今天拜访客户。  
Wǒmen yuē hǎo le jīntiān bàifǎng kèhù.  
저희는 오늘 거래처를 방문하기로 약속했습니다.

您好，我是来拜访王总的。  
Nín hǎo, wǒ shì lái bàifǎng Wáng zǒng de.  
안녕하세요, 저는 왕 사장님을 뵈러 왔습니다.

请稍等，我去通报一下。  
Qǐng shāo děng, wǒ qù tōngbào yíxià.  
잠시만요, 말씀드리고 오겠습니다.

欢迎欢迎，请进。  
Huānyíng huānyíng, qǐng jìn.  
어서 오세요, 들어오세요.

我们这次来是想介绍新产品。  
Wǒmen zhè cì lái shì xiǎng jièshào xīn chǎnpǐn.  
이번에 온 목적은 신제품을 소개하는 것입니다.

这是我们的样品，请过目。  
Zhè shì wǒmen de yàngpǐn, qǐng guòmù.  
이것은 저희 샘플입니다, 검토해 주세요.

如果有兴趣，我们可以详谈。  
Rúguǒ yǒu xìngqù, wǒmen kěyǐ xiángtán.  
관심이 있으시면 자세히 상담할 수 있습니다.

谢谢您抽出时间。  
Xièxie nín chōuchū shíjiān.  
시간을 내 주셔서 감사합니다.

---

## 主要词汇 (주요 단어)

### 1. 拜访  /  bàifǎng  /  [동사 (v.)]  /  방문하다
- 한자 풀이: 拜(절 배) + 访(찾을 방) → 찾아가 뵙다
- 例句: 我去拜访客户。
- Pinyin: Wǒ qù bàifǎng kèhù.
- 번역: 나는 거래처를 방문한다.

### 2. 通报  /  tōngbào  /  [동사 (v.)]  /  알리다, 통보하다
- 한자 풀이: 通(통할 통) + 报(알릴 보) → 알려 전하다
- 例句: 请通报一声。
- Pinyin: Qǐng tōngbào yì shēng.
- 번역: 한번 알려 주세요.

### 3. 样品  /  yàngpǐn  /  [명사 (n.)]  /  샘플, 견본
- 한자 풀이: 样(모양 양) + 品(물건 품) → 보기 위한 물건
- 例句: 请看看样品。
- Pinyin: Qǐng kànkan yàngpǐn.
- 번역: 샘플을 보세요.

### 4. 过目  /  guòmù  /  [동사 (v.)]  /  검토하다, 보다
- 한자 풀이: 过(지날 과) + 目(눈 목) → 눈으로 살피다
- 例句: 请过目这份文件。
- Pinyin: Qǐng guòmù zhè fèn wénjiàn.
- 번역: 이 문서를 검토해 주세요.

### 5. 兴趣  /  xìngqù  /  [명사 (n.)]  /  흥미, 관심
- 한자 풀이: 兴(일 흥) + 趣(뜻 취) → 즐거운 관심
- 例句: 我对这个产品很有兴趣。
- Pinyin: Wǒ duì zhège chǎnpǐn hěn yǒu xìngqù.
- 번역: 나는 이 제품에 관심이 많다.

### 6. 抽出  /  chōuchū  /  [동사 (v.)]  /  (시간을) 내다
- 한자 풀이: 抽(뽑을 추) + 出(날 출) → 빼어 내다
- 例句: 请抽出一点时间。
- Pinyin: Qǐng chōuchū yìdiǎn shíjiān.
- 번역: 시간을 좀 내 주세요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 约好 | yuē hǎo | yu를 '유'로 발음 | yu(=ü)는 입술을 둥글게, 约은 1성 |
| 样品 | yàngpǐn | p를 'ㅂ'으로 무기음화 | p는 송기음(ㅍ), 品은 3성 |
| 兴趣 | xìngqù | q를 'ㅋ'처럼, x를 'ㅆ'처럼 | x·q는 혀를 입천장 가까이 대고 부드럽게 |
| 客户 | kèhù | k를 'ㄱ'으로 무기음화 | k는 송기음(ㅋ), 户는 4성 |
| 抽出 | chōuchū | ch를 'ㅊ'으로 평평하게 | ch는 권설음, 抽·出 모두 1성 |

## 语法点 (어법 포인트)

### 1. "约好 + 동사" — ~하기로 약속하다
- 我们约好了今天拜访客户。 Wǒmen yuē hǎo le jīntiān bàifǎng kèhù. 오늘 거래처를 방문하기로 약속했다.

### 2. "来 + 동사" — ~하러 오다
- 我是来拜访王总的。 Wǒ shì lái bàifǎng Wáng zǒng de. 저는 왕 사장님을 뵈러 왔습니다.

### 3. "去 + 동사" — ~하러 가다
- 我去通报一下。 Wǒ qù tōngbào yíxià. 말씀드리고 오겠습니다.

### 4. "谢谢 + 사람 + 동사" — ~해 주셔서 감사하다
- 谢谢您抽出时间。 Xièxie nín chōuchū shíjiān. 시간을 내 주셔서 감사합니다.

## 应用会话 (응용 회화 - 비즈니스)

A: 您好，我是来拜访王总的。  
   Nín hǎo, wǒ shì lái bàifǎng Wáng zǒng de.  
   안녕하세요, 왕 사장님을 뵈러 왔습니다.

B: 请问您预约了吗？  
   Qǐngwèn nín yùyuē le ma?  
   예약하셨나요?

A: 约好了，上午十点。  
   Yuē hǎo le, shàngwǔ shí diǎn.  
   예약했습니다, 오전 10시요.

B: 请稍等，我去通报一下。  
   Qǐng shāo děng, wǒ qù tōngbào yíxià.  
   잠시만요, 말씀드리고 오겠습니다.

A: 好的，谢谢。  
   Hǎo de, xièxie.  
   네, 감사합니다.

B: 欢迎欢迎，请进。  
   Huānyíng huānyíng, qǐng jìn.  
   어서 오세요, 들어오세요.

A: 这是我们新产品的样品，请过目。  
   Zhè shì wǒmen xīn chǎnpǐn de yàngpǐn, qǐng guòmù.  
   이것은 저희 신제품 샘플입니다, 검토해 주세요.

B: 好的，我很有兴趣。我们详谈吧。  
   Hǎo de, wǒ hěn yǒu xìngqù. Wǒmen xiángtán ba.  
   네, 관심이 많습니다. 자세히 이야기합시다.
