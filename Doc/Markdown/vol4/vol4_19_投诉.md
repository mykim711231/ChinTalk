第 十九 课 : 19. 投诉 Tóusù (클레임·불만)

## 本文 (본문)

我要投诉。  
Wǒ yào tóusù.  
저는 불만을 제기하려고 합니다.

这次收到的货物有问题。  
Zhè cì shōudào de huòwù yǒu wèntí.  
이번에 받은 물품에 문제가 있습니다.

有些产品已经损坏了。  
Yǒuxiē chǎnpǐn yǐjīng sǔnhuài le.  
일부 제품이 이미 파손되어 있습니다.

而且数量也不对。  
Érqiě shùliàng yě bú duì.  
게다가 수량도 맞지 않습니다.

这让我们非常失望。  
Zhè ràng wǒmen fēicháng shīwàng.  
이것은 저희를 매우 실망시켰습니다.

非常抱歉，我们会调查。  
Fēicháng bàoqiàn, wǒmen huì diàochá.  
정말 죄송합니다, 조사하겠습니다.

请提供照片作为证据。  
Qǐng tígōng zhàopiàn zuòwéi zhèngjù.  
증거로 사진을 제공해 주세요.

我们会尽快给您补偿。  
Wǒmen huì jǐnkuài gěi nín bǔcháng.  
최대한 빨리 보상해 드리겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 投诉  /  tóusù  /  [동사 (v.)]  /  불만을 제기하다, 클레임
- 한자 풀이: 投(던질 투) + 诉(하소연할 소) → 불만을 말하다
- 例句: 客户投诉了质量问题。
- Pinyin: Kèhù tóusù le zhìliàng wèntí.
- 번역: 고객이 품질 문제를 클레임했다.

### 2. 损坏  /  sǔnhuài  /  [동사/형용사 (v./adj.)]  /  파손되다
- 한자 풀이: 损(덜 손) + 坏(무너질 괴) → 상하여 못 쓰게 되다
- 例句: 货物在运输中损坏了。
- Pinyin: Huòwù zài yùnshū zhōng sǔnhuài le.
- 번역: 물품이 운송 중 파손되었다.

### 3. 数量  /  shùliàng  /  [명사 (n.)]  /  수량
- 한자 풀이: 数(셈 수) + 量(헤아릴 량) → 수의 분량
- 例句: 请核对数量。
- Pinyin: Qǐng héduì shùliàng.
- 번역: 수량을 대조해 주세요.

### 4. 调查  /  diàochá  /  [동사 (v.)]  /  조사하다
- 한자 풀이: 调(고를 조) + 查(살필 사) → 살펴보다
- 例句: 我们正在调查原因。
- Pinyin: Wǒmen zhèngzài diàochá yuányīn.
- 번역: 우리는 원인을 조사 중이다.

### 5. 证据  /  zhèngjù  /  [명사 (n.)]  /  증거
- 한자 풀이: 证(증거 증) + 据(근거 거) → 증명하는 근거
- 例句: 请保存好证据。
- Pinyin: Qǐng bǎocún hǎo zhèngjù.
- 번역: 증거를 잘 보관해 주세요.

### 6. 补偿  /  bǔcháng  /  [동사 (v.)]  /  보상하다
- 한자 풀이: 补(기울 보) + 偿(갚을 상) → 메워 갚다
- 例句: 我们会补偿损失。
- Pinyin: Wǒmen huì bǔcháng sǔnshī.
- 번역: 우리는 손해를 보상하겠다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 产品 | chǎnpǐn | 产·品 모두 3성 그대로 | 3성+3성 변화, 앞 产은 2성(chán pǐn) |
| 不对 | bú duì | 不를 4성(bù) 그대로 | 不은 4성 앞에서 2성(bú) |
| 失望 | shīwàng | sh를 'ㅅ'으로 | sh는 권설음, 失은 1성(shī) |
| 照片 | zhàopiàn | zh를 'ㅈ'으로, 照 4성 놓침 | zh는 권설음, 照는 4성(zhào) |
| 补偿 | bǔcháng | 偿을 '상'으로, 2성 놓침 | 偿은 2성(cháng), ch는 권설음 |

## 语法点 (어법 포인트)

### 1. "要 + 동사" — ~하려고 하다
- 我要投诉。 Wǒ yào tóusù. 불만을 제기하려고 합니다.

### 2. "已经 + 동사" — 이미 ~했다
- 有些产品已经损坏了。 Yǒuxiē chǎnpǐn yǐjīng sǔnhuài le. 일부 제품이 이미 파손되었다.

### 3. "而且" — 게다가
- 而且数量也不对。 Érqiě shùliàng yě bú duì. 게다가 수량도 맞지 않다.

### 4. "让 + 사람 + 형용사" — ~를 ~하게 하다
- 这让我们非常失望。 Zhè ràng wǒmen fēicháng shīwàng. 이것은 저희를 매우 실망시켰다.

## 应用会话 (응용 회화 - 비즈니스)

A: 您好，我要投诉。  
   Nín hǎo, wǒ yào tóusù.  
   안녕하세요, 불만을 제기하려고 합니다.

B: 非常抱歉，请问是什么问题？  
   Fēicháng bàoqiàn, qǐngwèn shì shénme wèntí?  
   정말 죄송합니다, 어떤 문제인가요?

A: 收到的货物有些已经损坏了。  
   Shōudào de huòwù yǒuxiē yǐjīng sǔnhuài le.  
   받은 물품 일부가 이미 파손되었습니다.

B: 真对不起，请提供照片。  
   Zhēn duìbuqǐ, qǐng tígōng zhàopiàn.  
   정말 죄송합니다, 사진을 제공해 주세요.

A: 好的，我马上发给你。  
   Hǎo de, wǒ mǎshàng fā gěi nǐ.  
   네, 바로 보내 드리겠습니다.

B: 我们会马上调查并补偿。  
   Wǒmen huì mǎshàng diàochá bìng bǔcháng.  
   바로 조사하고 보상해 드리겠습니다.

A: 希望你们能尽快处理。  
   Xīwàng nǐmen néng jǐnkuài chǔlǐ.  
   가능한 한 빨리 처리해 주시기 바랍니다.

B: 一定，给您添麻烦了。  
   Yídìng, gěi nín tiān máfan le.  
   반드시요, 불편을 끼쳐 드려 죄송합니다.
