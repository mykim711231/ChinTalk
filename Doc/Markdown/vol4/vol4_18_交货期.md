第 十八 课 : 18. 交货期 Jiāohuòqī (납기·배송)

## 本文 (본문)

请问交货期是多久？  
Qǐngwèn jiāohuòqī shì duō jiǔ?  
납기는 얼마나 되나요?

一般需要两周。  
Yìbān xūyào liǎng zhōu.  
보통 2주가 걸립니다.

能提前交货吗？  
Néng tíqián jiāohuò ma?  
납기를 앞당길 수 있나요?

我们需要在月底前收货。  
Wǒmen xūyào zài yuèdǐ qián shōuhuò.  
저희는 월말 전에 물건을 받아야 합니다.

如果有加急费用，我们可以付。  
Rúguǒ yǒu jiājí fèiyòng, wǒmen kěyǐ fù.  
급행 비용이 있으면 지불할 수 있습니다.

好的，我们尽量提前。  
Hǎo de, wǒmen jìnliàng tíqián.  
좋습니다, 최대한 앞당기겠습니다.

货物到了我们会通知您。  
Huòwù dào le wǒmen huì tōngzhī nín.  
물품이 도착하면 알려 드리겠습니다.

请注意查收。  
Qǐng zhùyì cháshōu.  
수령을 확인해 주세요.

---

## 主要词汇 (주요 단어)

### 1. 交货期  /  jiāohuòqī  /  [명사 (n.)]  /  납기
- 한자 풀이: 交(바칠 교) + 货(물건 화) + 期(기한 기) → 물건을 내주는 기한
- 例句: 交货期是两周。
- Pinyin: Jiāohuòqī shì liǎng zhōu.
- 번역: 납기는 2주이다.

### 2. 交货  /  jiāohuò  /  [동사 (v.)]  /  납품하다
- 한자 풀이: 交(바칠 교) + 货(물건 화) → 물건을 내주다
- 例句: 请按时交货。
- Pinyin: Qǐng ànshí jiāohuò.
- 번역: 제때 납품해 주세요.

### 3. 提前  /  tíqián  /  [동사 (v.)]  /  앞당기다
- 한자 풀이: 提(들 제) + 前(앞 전) → 앞으로 당기다
- 例句: 我们提前交货。
- Pinyin: Wǒmen tíqián jiāohuò.
- 번역: 우리는 납기를 앞당긴다.

### 4. 收货  /  shōuhuò  /  [동사 (v.)]  /  물건을 받다
- 한자 풀이: 收(거둘 수) + 货(물건 화) → 물건을 받다
- 例句: 我明天收货。
- Pinyin: Wǒ míngtiān shōuhuò.
- 번역: 나는 내일 물건을 받는다.

### 5. 加急  /  jiājí  /  [형용사 (adj.)]  /  급행의, 다급히
- 한자 풀이: 加(더할 가) + 急(급할 급) → 더 급하게
- 例句: 这是加急件。
- Pinyin: Zhè shì jiājí jiàn.
- 번역: 이것은 급행 물품이다.

### 6. 通知  /  tōngzhī  /  [동사 (v.)]  /  알리다, 통지하다
- 한자 풀이: 通(통할 통) + 知(알 지) → 알리다
- 例句: 我会通知你。
- Pinyin: Wǒ huì tōngzhī nǐ.
- 번역: 내가 너에게 알려 주겠다.

## 语法点 (어법 포인트)

### 1. "是 + 기간" — ~입니다
- 交货期是多久？ Jiāohuòqī shì duō jiǔ? 납기는 얼마나 되나요?

### 2. "能 + 동사 + 吗？" — ~할 수 있나요?
- 能提前交货吗？ Néng tíqián jiāohuò ma? 납기를 앞당길 수 있나요?

### 3. "需要 + 동사" — ~해야 하다
- 我们需要在月底前收货。 Wǒmen xūyào zài yuèdǐ qián shōuhuò. 월말 전에 물건을 받아야 합니다.

### 4. "尽量 + 동사" — 최대한 ~하다
- 我们尽量提前。 Wǒmen jìnliàng tíqián. 최대한 앞당기겠습니다.

## 应用会话 (응용 회화 - 비즈니스)

A: 请问交货期是多久？  
   Qǐngwèn jiāohuòqī shì duō jiǔ?  
   납기는 얼마나 되나요?

B: 一般需要两周。  
   Yìbān xūyào liǎng zhōu.  
   보통 2주가 걸립니다.

A: 能提前交货吗？  
   Néng tíqián jiāohuò ma?  
   납기를 앞당길 수 있나요?

B: 可以，不过需要加急费。  
   Kěyǐ, búguò xūyào jiājí fèi.  
   가능합니다, 다만 급행료가 필요합니다.

A: 没问题，我们月底前必须收货。  
   Méi wèntí, wǒmen yuèdǐ qián bìxū shōuhuò.  
   문제없습니다, 월말 전에 반드시 물건을 받아야 합니다.

B: 好的，我们尽量提前发货。  
   Hǎo de, wǒmen jìnliàng tíqián fāhuò.  
   좋습니다, 최대한 빨리 발송하겠습니다.

A: 谢谢，货物到了请通知我。  
   Xièxie, huòwù dào le qǐng tōngzhī wǒ.  
   감사합니다, 물품이 도착하면 알려 주세요.

B: 一定，请您放心。  
   Yídìng, qǐng nín fàngxīn.  
   반드시요, 안심하세요.
