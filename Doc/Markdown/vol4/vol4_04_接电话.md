第 四 课 : 04. 接电话 Jiē diànhuà (전화 응대)

## 本文 (본문)

您好，这里是贸易公司。  
Nín hǎo, zhèlǐ shì màoyì gōngsī.  
안녕하세요, 여기는 무역 회사입니다.

请问您找哪位？  
Qǐngwèn nín zhǎo nǎ wèi?  
실례지만 누구를 찾으세요?

请稍等，我帮您转接。  
Qǐng shāo děng, wǒ bāng nín zhuǎnjiē.  
잠시만요, 전화를 돌려 드리겠습니다.

不好意思，王经理正在开会。  
Bù hǎoyìsi, Wáng jīnglǐ zhèngzài kāihuì.  
죄송합니다, 왕 부장님은 지금 회의 중입니다.

您有什么事情需要转告吗？  
Nín yǒu shénme shìqing xūyào zhuǎngào ma?  
전해 드릴 내용이 있으신가요?

好的，我会告诉他。  
Hǎo de, wǒ huì gàosu tā.  
네, 그에게 전해 드리겠습니다.

请记一下我的电话。  
Qǐng jì yíxià wǒ de diànhuà.  
제 전화번호를 적어 주세요.

谢谢，再见！  
Xièxie, zàijiàn!  
감사합니다, 안녕히 계세요!

---

## 主要词汇 (주요 단어)

### 1. 电话  /  diànhuà  /  [명사 (n.)]  /  전화
- 한자 풀이: 电(번개 전) + 话(말 화) → 전기로 말하다
- 例句: 我给你打电话。
- Pinyin: Wǒ gěi nǐ dǎ diànhuà.
- 번역: 내가 너에게 전화할게.

### 2. 接  /  jiē  /  [동사 (v.)]  /  받다, 접하다
- 한자 풀이: 扌(손 수) + 妾 → 손으로 이어받다
- 例句: 请接电话。
- Pinyin: Qǐng jiē diànhuà.
- 번역: 전화 좀 받아 주세요.

### 3. 转接  /  zhuǎnjiē  /  [동사 (v.)]  /  전환 접속하다, 돌리다
- 한자 풀이: 转(돌릴 전) + 接(이을 접) → 이어 돌리다
- 例句: 我帮您转接到销售部。
- Pinyin: Wǒ bāng nín zhuǎnjiē dào xiāoshòubù.
- 번역: 영업부로 전화를 돌려 드리겠습니다.

### 4. 开会  /  kāihuì  /  [동사 (v.)]  /  회의하다
- 한자 풀이: 开(열 개) + 会(모일 회) → 회의를 열다
- 例句: 我们下午开会。
- Pinyin: Wǒmen xiàwǔ kāihuì.
- 번역: 우리는 오후에 회의합니다.

### 5. 转告  /  zhuǎngào  /  [동사 (v.)]  /  전하다, 전해 주다
- 한자 풀이: 转(돌릴 전) + 告(고할 고) → 말을 전하다
- 例句: 请转告他回电话。
- Pinyin: Qǐng zhuǎngào tā huí diànhuà.
- 번역: 그에게 전화 회신하라고 전해 주세요.

### 6. 稍等  /  shāo děng  /  [동사 (v.)]  /  잠시 기다리다
- 한자 풀이: 稍(잠깐 초) + 等(기다릴 등) → 잠시 기다리다
- 例句: 请稍等一会儿。
- Pinyin: Qǐng shāo děng yíhuìr.
- 번역: 잠시만 기다려 주세요.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 接 | jiē | j를 'ㅈ'으로 읽음 | j는 혀를 입천장에 대는 무기음, 1성(jiē) |
| 转接 | zhuǎnjiē | zh를 'ㅈ'으로, 转 3성 놓침 | zh는 권설음, 转은 3성(zhuǎn) |
| 转告 | zhuǎngào | 转·告 성조 혼동 | 转은 3성(zhuǎn), 告는 4성(gào) |
| 开会 | kāihuì | k를 'ㄱ'으로 무기음화 | k는 송기음(ㅋ), 会는 4성(huì) |
| 告诉 | gàosu | 诉를 4성(sù)으로 | 告诉의 诉는 경성(su) |

## 语法点 (어법 포인트)

### 1. "请问 + 의문문" — 실례지만 ~인가요?
- 请问您找哪位？ Qǐngwèn nín zhǎo nǎ wèi? 실례지만 누구를 찾으세요?

### 2. "帮 + 사람 + 동사" — ~를 위해 ~해 주다
- 我帮您转接。 Wǒ bāng nín zhuǎnjiē. 제가 전화를 돌려 드리겠습니다.

### 3. "正在 + 동사" — 지금 ~하는 중이다
- 王经理正在开会。 Wáng jīnglǐ zhèngzài kāihuì. 왕 부장님은 지금 회의 중입니다.

### 4. "会 + 동사" — ~할 것이다
- 我会告诉他。 Wǒ huì gàosu tā. 제가 그에게 전해 드리겠습니다.

## 应用会话 (응용 회화 - 비즈니스)

A: 您好，这里是贸易公司。  
   Nín hǎo, zhèlǐ shì màoyì gōngsī.  
   안녕하세요, 여기는 무역 회사입니다.

B: 您好，我找王经理。  
   Nín hǎo, wǒ zhǎo Wáng jīnglǐ.  
   안녕하세요, 왕 부장님을 찾습니다.

A: 不好意思，王经理正在开会。  
   Bù hǎoyìsi, Wáng jīnglǐ zhèngzài kāihuì.  
   죄송합니다, 왕 부장님은 지금 회의 중입니다.

B: 那他什么时候有空？  
   Nà tā shénme shíhou yǒu kòng?  
   그럼 언제쯤 시간이 있나요?

A: 会议四点结束，您稍后再打吧。  
   Huìyì sì diǎn jiéshù, nín shāohòu zài dǎ ba.  
   회의가 4시에 끝나니, 잠시 후에 다시 걸어 주세요.

B: 好的，麻烦您转告他给我回电话。  
   Hǎo de, máfan nín zhuǎngào tā gěi wǒ huí diànhuà.  
   네, 그에게 제게 전화 회신하라고 전해 주세요.

A: 没问题，请记一下您的姓名。  
   Méi wèntí, qǐng jì yíxià nín de xìngmíng.  
   문제없습니다, 성함을 말씀해 주세요.

B: 好的，谢谢，再见！  
   Hǎo de, xièxie, zàijiàn!  
   네, 감사합니다, 안녕히 계세요!
