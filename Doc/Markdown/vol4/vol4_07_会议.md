第 七 课 : 07. 会议 Huìyì (회의)

## 本文 (본문)

现在开会。  
Xiànzài kāihuì.  
지금 회의를 시작합니다.

请大家把手机调成静音。  
Qǐng dàjiā bǎ shǒujī tiáo chéng jìngyīn.  
모두 휴대폰을 무음으로 바꿔 주세요.

今天讨论下个季度的计划。  
Jīntiān tǎolùn xià ge jìdù de jìhuà.  
오늘은 다음 분기 계획을 논의하겠습니다.

谁先发言？  
Shuí xiān fāyán?  
누가 먼저 발언하시겠습니까?

我来说一下我的想法。  
Wǒ lái shuō yíxià wǒ de xiǎngfǎ.  
제가 제 생각을 말씀드리겠습니다.

我同意你的意见。  
Wǒ tóngyì nǐ de yìjiàn.  
저는 당신의 의견에 동의합니다.

这个提议很有道理。  
Zhège tíyì hěn yǒu dàolǐ.  
이 제안은 일리가 있습니다.

大家还有什么问题吗？  
Dàjiā hái yǒu shénme wèntí ma?  
다른 질문 있으신가요?

好，今天的会议到此结束。  
Hǎo, jīntiān de huìyì dào cǐ jiéshù.  
좋습니다, 오늘 회의는 이것으로 마치겠습니다.

---

## 主要词汇 (주요 단어)

### 1. 讨论  /  tǎolùn  /  [동사 (v.)]  /  토론하다, 논의하다
- 한자 풀이: 讨(칠 토) + 论(의논할 론) → 의논하다
- 例句: 我们讨论一下方案。
- Pinyin: Wǒmen tǎolùn yíxià fāng'àn.
- 번역: 우리 방안을 논의해 봅시다.

### 2. 计划  /  jìhuà  /  [명사/동사 (n./v.)]  /  계획
- 한자 풀이: 计(셈할 계) + 划(그을 획) → 미리 헤아리다
- 例句: 这是明年的计划。
- Pinyin: Zhè shì míngnián de jìhuà.
- 번역: 이것은 내년의 계획이다.

### 3. 发言  /  fāyán  /  [동사 (v.)]  /  발언하다
- 한자 풀이: 发(필 발) + 言(말씀 언) → 말을 하다
- 例句: 请按顺序发言。
- Pinyin: Qǐng àn shùnxù fāyán.
- 번역: 순서대로 발언해 주세요.

### 4. 意见  /  yìjiàn  /  [명사 (n.)]  /  의견
- 한자 풀이: 意(뜻 의) + 见(볼 견) → 생각을 보이다
- 例句: 你有什么意见？
- Pinyin: Nǐ yǒu shénme yìjiàn?
- 번역: 당신은 어떤 의견이 있나요?

### 5. 同意  /  tóngyì  /  [동사 (v.)]  /  동의하다
- 한자 풀이: 同(같을 동) + 意(뜻 의) → 뜻이 같다
- 例句: 我同意这个方案。
- Pinyin: Wǒ tóngyì zhège fāng'àn.
- 번역: 나는 이 방안에 동의한다.

### 6. 结束  /  jiéshù  /  [동사 (v.)]  /  끝나다, 마치다
- 한자 풀이: 结(맺을 결) + 束(묶을 속) → 묶어 끝내다
- 例句: 会议五点结束。
- Pinyin: Huìyì wǔ diǎn jiéshù.
- 번역: 회의는 5시에 끝난다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 手机 | shǒujī | sh를 'ㅅ'으로, 手 3성 놓침 | sh는 권설음, 手는 3성(shǒu) |
| 静音 | jìngyīn | j를 'ㅈ'으로, ng 종성 누락 | j는 무기음, jìng은 코끝 ng로 마무리 |
| 想法 | xiǎngfǎ | 想·法 모두 3성 그대로 | 3성+3성 변화, 앞 想은 2성(xiáng fǎ) |
| 发言 | fāyán | f를 'ㅍ'으로 | f는 윗니로 아랫입술 살짝 물고 마찰음, 言은 2성 |
| 结束 | jiéshù | 束 shù를 '수'로, 4성 놓침 | sh는 권설음, 束은 4성(shù) |

## 语法点 (어법 포인트)

### 1. "请 + 사람 + 동사" — ~에게 ~하도록 하다
- 请大家把手机调成静音。 Qǐng dàjiā bǎ shǒujī tiáo chéng jìngyīn. 모두 휴대폰을 무음으로 바꿔 주세요.

### 2. "谁先 + 동사？" — 누가 먼저 ~하나요?
- 谁先发言？ Shuí xiān fāyán? 누가 먼저 발언하시겠습니까?

### 3. "同意 + 명사" — ~에 동의하다
- 我同意你的意见。 Wǒ tóngyì nǐ de yìjiàn. 당신의 의견에 동의합니다.

### 4. "到此结束" — 여기서 마치다
- 会议到此结束。 Huìyì dào cǐ jiéshù. 회의는 이것으로 마칩니다.

## 应用会话 (응용 회화 - 비즈니스)

A: 现在开会。请大家安静一下。  
   Xiànzài kāihuì. Qǐng dàjiā ānjìng yíxià.  
   지금 회의를 시작합니다. 모두 조용히 해 주세요.

B: 好的，今天讨论什么？  
   Hǎo de, jīntiān tǎolùn shénme?  
   네, 오늘은 무엇을 논의하나요?

A: 今天讨论下个季度的销售计划。  
   Jīntiān tǎolùn xià ge jìdù de xiāoshòu jìhuà.  
   오늘은 다음 분기 판매 계획을 논의합니다.

B: 我来说一下我的想法。  
   Wǒ lái shuō yíxià wǒ de xiǎngfǎ.  
   제가 제 생각을 말씀드리겠습니다.

A: 请讲。  
   Qǐng jiǎng.  
   말씀해 주세요.

B: 我建议增加广告投入。  
   Wǒ jiànyì zēngjiā guǎnggào tóurù.  
   광고 투자를 늘릴 것을 제안합니다.

A: 我同意你的意见。  
   Wǒ tóngyì nǐ de yìjiàn.  
   당신의 의견에 동의합니다.

B: 好，那今天的会议到此结束。  
   Hǎo, nà jīntiān de huìyì dào cǐ jiéshù.  
   좋습니다, 그럼 오늘 회의는 이것으로 마치겠습니다.
