第 二十 课 : 20. 基础综合 Jīchǔ zōnghé (기초 종합)

## 本文 (본문)

你好！我叫李明。  
Nǐ hǎo! Wǒ jiào Lǐ Míng.  
안녕하세요! 저는 리밍입니다.

我是韩国人，今年二十岁。  
Wǒ shì Hánguó rén, jīnnián èrshí suì.  
저는 한국 사람이고 올해 스무 살입니다.

我是学生，我喜欢听音乐。  
Wǒ shì xuésheng, wǒ xǐhuan tīng yīnyuè.  
저는 학생이고 음악 듣기를 좋아합니다.

今天星期几？  
Jīntiān xīngqī jǐ?  
오늘 무슨 요일이에요?

今天星期三。  
Jīntiān xīngqīsān.  
오늘은 수요일입니다.

现在几点了？  
Xiànzài jǐ diǎn le?  
지금 몇 시예요?

现在下午三点。  
Xiànzài xiàwǔ sān diǎn.  
지금 오후 3시입니다.

今天天气很好。  
Jīntiān tiānqì hěn hǎo.  
오늘 날씨가 아주 좋습니다.

你家有几口人？  
Nǐ jiā yǒu jǐ kǒu rén?  
가족이 몇 명이에요?

我家有三口人，他们都很健康。  
Wǒ jiā yǒu sān kǒu rén, tāmen dōu hěn jiànkāng.  
우리 집은 세 식구이고 모두 아주 건강합니다.

谢谢你的帮助。  
Xièxie nǐ de bāngzhù.  
도와줘서 고마워요.

不客气。  
Bú kèqi.  
천만에요.

再见！  
Zàijiàn!  
안녕히 가세요!

## 主要词汇 (주요 단어)

### 1. 综合  /  zōnghé  /  [명사·동사 (n./v.)]  /  종합
- 한자 풀이: 综(모을 종) + 合(합할 합) → 모아 하나로 하다
- 例句: 这是基础综合课。
- Pinyin: Zhè shì jīchǔ zōnghé kè.
- 번역: 이것은 기초 종합 수업입니다.

### 2. 基础  /  jīchǔ  /  [명사 (n.)]  /  기초
- 한자 풀이: 基(터 기) + 础(주춧돌 초) → 기초
- 例句: 我学的是基础中文。
- Pinyin: Wǒ xué de shì jīchǔ Zhōngwén.
- 번역: 제가 배우는 것은 기초 중국어입니다.

### 3. 健康  /  jiànkāng  /  [형용사 (adj.)]  /  건강하다
- 한자 풀이: 健(굳셀 건) + 康(편안할 강) → 건강하다
- 例句: 他们都很健康。
- Pinyin: Tāmen dōu hěn jiànkāng.
- 번역: 그들은 모두 아주 건강합니다.

### 4. 帮助  /  bāngzhù  /  [동사·명사 (v./n.)]  /  돕다, 도움
- 한자 풀이: 帮(도울 방) + 助(도울 조) → 돕다
- 例句: 谢谢你的帮助。
- Pinyin: Xièxie nǐ de bāngzhù.
- 번역: 도와줘서 고마워요.

### 5. 介绍  /  jièshào  /  [동사 (v.)]  /  소개하다
- 한자 풀이: 介(끼일 개) + 绍(이을 소) → 소개하다
- 例句: 请介绍一下自己。
- Pinyin: Qǐng jièshào yíxià zìjǐ.
- 번역: 자신을 소개해 주세요.

### 6. 再见  /  zàijiàn  /  [동사 (v.)]  /  다시 만나다, 안녕히 가세요
- 한자 풀이: 再(다시 재) + 见(볼 견) → 다시 보자
- 例句: 再见！
- Pinyin: Zàijiàn!
- 번역: 안녕히 가세요!

## 语法点 (어법 포인트)

### 1. "叫/是" — 자기소개 종합
- 我叫李明，我是韩国人。 Wǒ jiào Lǐ Míng, wǒ shì Hánguó rén. 저는 리밍, 한국 사람입니다.

### 2. "几/什么" — 의문문 정리
- 今天星期几？ Jīntiān xīngqī jǐ? 오늘 무슨 요일이에요?
- 你家有几口人？ Nǐ jiā yǒu jǐ kǒu rén? 가족이 몇 명이에요?

### 3. "很 + 형용사" — 상태 표현 정리
- 天气很好 tiānqì hěn hǎo 날씨가 좋다, 他们都很健康 tāmen dōu hěn jiànkāng 모두 건강하다

### 4. "谢谢/不客气" — 감사 표현 정리
- 谢谢你的帮助。 Xièxie nǐ de bāngzhù. 도와줘서 고마워요.
- 不客气。 Bú kèqi. 천만에요.

## 应用会话 (응용 회화 - 일상)

A: 你好！我叫李明。  
   Nǐ hǎo! Wǒ jiào Lǐ Míng.  
   안녕하세요! 저는 리밍입니다.

B: 你好！我是金美娜，很高兴认识你。  
   Nǐ hǎo! Wǒ shì Jīn Měinà, hěn gāoxìng rènshi nǐ.  
   안녕하세요! 저는 김미나예요, 만나서 반가워요.

A: 你是哪国人？  
   Nǐ shì nǎ guó rén?  
   어느 나라 사람이에요?

B: 我是韩国人，今年二十岁。  
   Wǒ shì Hánguó rén, jīnnián èrshí suì.  
   저는 한국 사람이고 올해 스무 살이에요.

A: 今天天气很好，我们出去走走吧。  
   Jīntiān tiānqì hěn hǎo, wǒmen chūqù zǒuzou ba.  
   오늘 날씨가 좋으니 우리 나가서 걷죠.

B: 好啊！现在几点了？  
   Hǎo a! Xiànzài jǐ diǎn le?  
   좋아요! 지금 몇 시예요?

A: 现在下午三点。  
   Xiànzài xiàwǔ sān diǎn.  
   지금 오후 3시예요.

B: 那我们三点半见面吧。  
   Nà wǒmen sān diǎn bàn jiànmiàn ba.  
   그럼 우리 3시 반에 만나요.

A: 好的，再见！  
   Hǎo de, zàijiàn!  
   네, 안녕히 가세요!
