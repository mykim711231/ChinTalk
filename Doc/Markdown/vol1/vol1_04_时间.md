第 四 课 : 04. 时间 Shíjiān (시간)

## 本文 (본문)

现在几点了？  
Xiànzài jǐ diǎn le?  
지금 몇 시예요?

现在八点。  
Xiànzài bā diǎn.  
지금 8시예요.

我早上七点起床。  
Wǒ zǎoshang qī diǎn qǐchuáng.  
저는 아침 7시에 일어납니다.

我晚上十一点睡觉。  
Wǒ wǎnshang shíyī diǎn shuìjiào.  
저는 밤 11시에 잠을 잡니다.

上午九点上班。  
Shàngwǔ jiǔ diǎn shàngbān.  
오전 9시에 출근합니다.

下午五点下班。  
Xiàwǔ wǔ diǎn xiàbān.  
오후 5시에 퇴근합니다.

中午十二点吃午饭。  
Zhōngwǔ shí'èr diǎn chī wǔfàn.  
정오 12시에 점심을 먹습니다.

现在差十分三点。  
Xiànzài chà shí fēn sān diǎn.  
지금 3시 10분 전입니다.

我们九点见面吧。  
Wǒmen jiǔ diǎn jiànmiàn ba.  
우리 9시에 만나요.

---

## 主要词汇 (주요 단어)

### 1. 点  /  diǎn  /  [양사 (m.)]  /  시(時)
- 한자 풀이: 占(점칠 점) + 灬(불 화, 黑의 아랫부분) → 시각을 찍는 단위
- 例句: 现在三点。
- Pinyin: Xiànzài sān diǎn.
- 번역: 지금 3시입니다.

### 2. 分  /  fēn  /  [양사 (m.)]  /  분(分)
- 한자 풀이: 칼로 나눔 → 시간을 나누는 단위
- 例句: 三点十分。
- Pinyin: Sān diǎn shí fēn.
- 번역: 3시 10분입니다.

### 3. 现在  /  xiànzài  /  [명사 (n.)]  /  지금
- 한자 풀이: 现(나타날 현) + 在(있을 재) → 바로 이때
- 例句: 现在几点了？
- Pinyin: Xiànzài jǐ diǎn le?
- 번역: 지금 몇 시예요?

### 4. 起床  /  qǐchuáng  /  [동사 (v.)]  /  일어나다, 기상하다
- 한자 풀이: 起(일어날 기) + 床(침상 상) → 침대에서 일어나다
- 例句: 我七点起床。
- Pinyin: Wǒ qī diǎn qǐchuáng.
- 번역: 저는 7시에 일어납니다.

### 5. 睡觉  /  shuìjiào  /  [동사 (v.)]  /  잠을 자다
- 한자 풀이: 睡(잠잘 수) + 觉(잠 각) → 잠을 자다
- 例句: 我十一点睡觉。
- Pinyin: Wǒ shíyī diǎn shuìjiào.
- 번역: 저는 11시에 잡니다.

### 6. 上班  /  shàngbān  /  [동사 (v.)]  /  출근하다
- 한자 풀이: 上(오를 상) + 班(근무 반) → 근무하러 가다
- 例句: 我九点上班。
- Pinyin: Wǒ jiǔ diǎn shàngbān.
- 번역: 저는 9시에 출근합니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 分 | fēn | f를 'ㅍ/ㅎ'로 발음 | 윗니로 아랫입술을 살짝 물고 fēn |
| 十 | shí | sh를 '스'로 읽음 | 혀를 말아 올린 sh + 2성(shí) |
| 中午 | zhōngwǔ | zh를 'ㅈ', 午를 2성으로 읽음 | 혀를 말아 올린 zh + 午는 3성(wǔ) |
| 了 | le | le를 lē(1성)으로 읽음 | 了는 경성(le) |
| 早上 | zǎoshang | 上을 shàng(4성)으로 읽음 | 上은 경성(shang)으로 가볍게 |

## 语法点 (어법 포인트)

### 1. "X点 Y分" — 시각 표현
- 八点十分。 Bā diǎn shí fēn. 8시 10분.
- 九点半。 Jiǔ diǎn bàn. 9시 반.

### 2. "差" — "(~분) 전"
- 差五分三点。 Chà wǔ fēn sān diǎn. 3시 5분 전.

### 3. 하루의 구분 — 早上/上午/中午/下午/晚上
- 早上 zǎoshang 아침, 中午 zhōngwǔ 정오, 晚上 wǎnshang 저녁

### 4. "了" — 상태 변화 (~되었다)
- 现在几点了？ Xiànzài jǐ diǎn le? 지금 몇 시가 되었나요?

## 应用会话 (응용 회화 - 일상)

A: 现在几点了？  
   Xiànzài jǐ diǎn le?  
   지금 몇 시예요?

B: 现在八点半。  
   Xiànzài bā diǎn bàn.  
   지금 8시 반이에요.

A: 你几点上班？  
   Nǐ jǐ diǎn shàngbān?  
   몇 시에 출근해요?

B: 我九点上班，五点下班。  
   Wǒ jiǔ diǎn shàngbān, wǔ diǎn xiàbān.  
   9시에 출근하고 5시에 퇴근해요.

A: 那我们六点一起吃晚饭吧。  
   Nà wǒmen liù diǎn yìqǐ chī wǎnfàn ba.  
   그럼 우리 6시에 같이 저녁 먹어요.

B: 好啊，六点见！  
   Hǎo a, liù diǎn jiàn!  
   좋아요, 6시에 봐요!
