第 一 课 : 01. 问候 Wènhòu (인사)

## 本文 (본문)

你好！  
Nǐ hǎo!  
안녕하세요!

早上好！  
Zǎoshang hǎo!  
좋은 아침입니다!

下午好！  
Xiàwǔ hǎo!  
안녕하세요! (오후 인사)

晚上好！  
Wǎnshang hǎo!  
안녕하세요! (저녁 인사)

您好！  
Nín hǎo!  
안녕하십니까! (존칭)

你好吗？  
Nǐ hǎo ma?  
잘 지내세요?

我很好，谢谢。  
Wǒ hěn hǎo, xièxie.  
저는 잘 지내요, 고마워요.

你呢？  
Nǐ ne?  
당신은요?

我也很好。  
Wǒ yě hěn hǎo.  
저도 잘 지내요.

好久不见！  
Hǎojiǔ bú jiàn!  
오랜만이에요!

最近怎么样？  
Zuìjìn zěnmeyàng?

Zàijiàn!  
안녕히 가세요!

明天见！  
Míngtiān jiàn!  
내일 봐요!

## 主要词汇 (주요 단어)

### 1. 你  /  nǐ  /  [대명사 (pron.)]  /  너, 당신
- 한자 풀이: 亻(사람 인) + 尔 → 상대방을 가리키는 2인칭 대명사
- 例句: 你好吗？
- Pinyin: Nǐ hǎo ma?
- 번역: 잘 지내세요?

### 2. 好  /  hǎo  /  [형용사 (adj.)]  /  좋다, 좋은
- 한자 풀이: 女(여자 녀) + 子(아들 자) → 자녀가 곁에 있어 "좋다"
- 例句: 今天天气很好。
- Pinyin: Jīntiān tiānqì hěn hǎo.
- 번역: 오늘 날씨가 아주 좋다.

### 3. 早上  /  zǎoshang  /  [명사 (n.)]  /  아침
- 한자 풀이: 早(이를 조) + 上(위 상) → 하루 중 이른 때
- 例句: 我早上七点起床。
- Pinyin: Wǒ zǎoshang qī diǎn qǐchuáng.
- 번역: 나는 아침 7시에 일어난다.

### 4. 谢谢  /  xièxie  /  [동사 (v.)]  /  감사하다, 고맙다
- 한자 풀이: 谢(사례할 사) 중첩 → 정중한 감사 표현
- 例句: 谢谢你的帮助。
- Pinyin: Xièxie nǐ de bāngzhù.
- 번역: 도와줘서 고마워요.

### 5. 再见  /  zàijiàn  /  [동사 (v.)]  /  다시 만나다, 안녕히 가세요
- 한자 풀이: 再(다시 재) + 见(볼 견) → 다시 보자
- 例句: 明天再见！
- Pinyin: Míngtiān zàijiàn!
- 번역: 내일 다시 봐요!

### 6. 怎么样  /  zěnmeyàng  /  [대명사 (pron.)]  /  어떠한가, 어떠세요
- 한자 풀이: 怎么(어떻게) + 样(모양 양) → 어떠한 상태
- 例句: 最近怎么样？
- Pinyin: Zuìjìn zěnmeyàng?
- 번역: 요즘 어떠세요?

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 你好 | nǐ hǎo | 3성+3성을 그대로 "니하오" | 앞 3성은 2성으로 변해 "니2하오3" |
| 早上好 | zǎoshang hǎo | 上을 4성(shàng)으로 읽음 | 上은 경성(shang)으로 가볍게 |
| 谢谢 | xièxie | 두 谢 모두 4성으로 발음 | 뒤 谢은 경성(xie) |
| 怎么样 | zěnmeyàng | 么을 mō(1성)으로 읽음 | 么은 경성(me) |
| 好久不见 | hǎojiǔ bú jiàn | 久를 2성, 不를 4성 그대로 | 久는 3성(jiǔ), 不은 4성 앞에서 2성(bú) |

## 语法点 (어법 포인트)

### 1. "你好" — 가장 기본적인 인사
- 你好。 Nǐ hǎo. 안녕하세요. (친구·동년배 사이)
- 您好。 Nín hǎo. 안녕하십니까. (어른·윗사람에게)

### 2. "A 吗？" — 예/아니오 의문문
- 你好吗？ Nǐ hǎo ma? 잘 지내세요?
- 你忙吗？ Nǐ máng ma? 바쁘세요?

### 3. "呢" — 되묻기 ("~는요?")
- 我很好，你呢？ Wǒ hěn hǎo, nǐ ne? 저는 좋아요, 당신은요?

### 4. "好久不见" — 오랜만이다 (숙어)
- 好久不见！ Hǎojiǔ bú jiàn! 오랜만이에요!

## 应用会话 (응용 회화 - 일상)

A: 你好！好久不见！  
   Nǐ hǎo! Hǎojiǔ bú jiàn!  
   안녕! 오랜만이야!

B: 好久不见！最近怎么样？  
   Hǎojiǔ bú jiàn! Zuìjìn zěnmeyàng?  
   오랜만이야! 요즘 어때?

A: 我很好，谢谢。你呢？  
   Wǒ hěn hǎo, xièxie. Nǐ ne?  
   나는 잘 지내, 고마워. 너는?

B: 我也不错，就是有点儿忙。  
   Wǒ yě búcuò, jiùshì yǒudiǎnr máng.  
   나도 괜찮아, 그냥 좀 바빠.

A: 那我们改天一起吃饭吧。  
   Nà wǒmen gǎitiān yìqǐ chīfàn ba.  
   그럼 우리 다음에 같이 밥 먹자.

B: 好啊，就这么说定了。  
   Hǎo a, jiù zhème shuō dìng le.  
   좋아, 그렇게 약속하자.

A: 明天见！  
   Míngtiān jiàn!  
   내일 봐!

B: 明天见！  
   Míngtiān jiàn!  
   내일 봐!
