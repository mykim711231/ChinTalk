第 三 课 : 03. 数字 Shùzì (숫자)

## 本文 (본문)

一、二、三、四、五。  
Yī, èr, sān, sì, wǔ.  
일, 이, 삼, 사, 오.

六、七、八、九、十。  
Liù, qī, bā, jiǔ, shí.  
육, 칠, 팔, 구, 십.

十一、十二、十三。  
Shíyī, shí'èr, shísān.  
십일, 십이, 십삼.

二十、三十、四十。  
Èrshí, sānshí, sìshí.  
이십, 삼십, 사십.

一百、一千、一万。  
Yìbǎi, yìqiān, yíwàn.  
백, 천, 만.

我有两个弟弟。  
Wǒ yǒu liǎng gè dìdi.  
저는 남동생이 둘입니다.

这是我的电话号码。  
Zhè shì wǒ de diànhuà hàomǎ.  
이것은 제 전화번호입니다.

我的号码是一三五一二三四五六七八。  
Wǒ de hàomǎ shì yāo sān wǔ yāo èr sān sì wǔ liù qī bā.  
제 번호는 135-1234-5678입니다.

现在几点了？  
Xiànzài jǐ diǎn le?  
지금 몇 시예요?

三点十分。  
Sān diǎn shí fēn.  
3시 10분입니다.

---

## 主要词汇 (주요 단어)

### 1. 数字  /  shùzì  /  [명사 (n.)]  /  숫자
- 한자 풀이: 数(셀 수) + 字(글자 자) → 수를 나타내는 글자
- 例句: 你会说数字吗？
- Pinyin: Nǐ huì shuō shùzì ma?
- 번역: 숫자를 말할 줄 아세요?

### 2. 二  /  èr  /  [수사 (num.)]  /  2, 둘
- 한자 풀이: 두 개를 나타내는 상형문자
- 例句: 我有两个哥哥。
- Pinyin: Wǒ yǒu liǎng gè gēge.
- 번역: 저는 형이 둘입니다.

### 3. 十  /  shí  /  [수사 (num.)]  /  10, 열
- 한자 풀이: 열 개를 묶어 나타내는 가로줄
- 例句: 我有十个手指。
- Pinyin: Wǒ yǒu shí gè shǒuzhǐ.
- 번역: 저는 손가락이 열 개입니다.

### 4. 百  /  bǎi  /  [수사 (num.)]  /  100, 백
- 한자 풀이: 백을 뜻하는 단위 글자
- 例句: 这本书一百元。
- Pinyin: Zhè běn shū yìbǎi yuán.
- 번역: 이 책은 100위안입니다.

### 5. 个  /  gè  /  [양사 (m.)]  /  개 (수량사)
- 한자 풀이: 물건이나 사람을 세는 범용 양사
- 例句: 三个苹果。
- Pinyin: Sān gè píngguǒ.
- 번역: 사과 세 개.

### 6. 几  /  jǐ  /  [수사 (num.)]  /  몇
- 한자 풀이: 작은 수를 물을 때 쓰는 의문사
- 例句: 你有几个弟弟？
- Pinyin: Nǐ yǒu jǐ gè dìdi?
- 번역: 남동생이 몇 명이에요?

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 四 | sì | 1성으로 평평하게 '스'로 읽음 | 4성으로 짧게 내려 읽기 |
| 十 | shí | sh를 '스'로, 성조를 빼고 읽음 | 혀를 말아 올린 sh + 2성(shí) |
| 七 | qī | '치'로 발음 | 혀를 입천장에 대고 기식음 qī |
| 一百 | yìbǎi | 一을 yī(1성) 그대로 읽음 | 3성(비4성) 앞에서 4성(yì)으로 변함 |
| 一万 | yíwàn | 一을 yī(1성) 그대로 읽음 | 4성 앞에서 2성으로 변해 yíwàn |

## 语法点 (어법 포인트)

### 1. 1부터 10까지 — 기본 숫자
- 一二三四五六七八九十
- Yī èr sān sì wǔ liù qī bā jiǔ shí

### 2. "几" — 작은 수 묻기
- 几点了？ Jǐ diǎn le? 몇 시예요?
- 你有几个？ Nǐ yǒu jǐ gè? 몇 개 있어요?

### 3. "二"와 "两" — 2를 말하는 두 가지 방법
- 两个人。 Liǎng gè rén. 두 사람. (개수)
- 十二。 Shí'èr. 십이. (순서·숫자)

### 4. 전화번호 읽기 — "一"은 "yāo"
- 一三五。 Yāo sān wǔ. 일삼오.

   Xiànzài jǐ diǎn le?

   3시 10분입니다.
