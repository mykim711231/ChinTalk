第 十五 课 : 15. 季节 Jìjié (계절)

## 本文 (본문)

一年有几个季节？  
Yì nián yǒu jǐ gè jìjié?  
일 년에는 계절이 몇 개인가요?

一年有四个季节。  
Yì nián yǒu sì gè jìjié.  
일 년에는 네 계절이 있습니다.

它们是春、夏、秋、冬。  
Tāmen shì chūn, xià, qiū, dōng.  
그것은 봄, 여름, 가을, 겨울입니다.

春天很暖和。  
Chūntiān hěn nuǎnhuo.  
봄은 아주 따뜻합니다.

夏天很热。  
Xiàtiān hěn rè.  
여름은 아주 덥습니다.

秋天很凉快。  
Qiūtiān hěn liángkuai.  
가을은 아주 시원합니다.

冬天很冷。  
Dōngtiān hěn lěng.  
겨울은 아주 춥습니다.

你最喜欢哪个季节？  
Nǐ zuì xǐhuan nǎ gè jìjié?  
어떤 계절을 가장 좋아하세요?

我最喜欢春天。  
Wǒ zuì xǐhuan chūntiān.  
저는 봄을 가장 좋아합니다.

因为春天花都开了。  
Yīnwèi chūntiān huā dōu kāi le.  
왜냐하면 봄에는 꽃이 모두 피기 때문입니다.

---

## 主要词汇 (주요 단어)

### 1. 季节  /  jìjié  /  [명사 (n.)]  /  계절
- 한자 풀이: 季(계절 계) + 节(마디 절) → 계절
- 例句: 一年有四个季节。
- Pinyin: Yì nián yǒu sì gè jìjié.
- 번역: 일 년에는 네 계절이 있습니다.

### 2. 春天  /  chūntiān  /  [명사 (n.)]  /  봄
- 한자 풀이: 春(봄 춘) + 天(하늘 천) → 봄
- 例句: 春天很暖和。
- Pinyin: Chūntiān hěn nuǎnhuo.
- 번역: 봄은 아주 따뜻합니다.

### 3. 夏天  /  xiàtiān  /  [명사 (n.)]  /  여름
- 한자 풀이: 夏(여름 하) + 天(하늘 천) → 여름
- 例句: 夏天很热。
- Pinyin: Xiàtiān hěn rè.
- 번역: 여름은 아주 덥습니다.

### 4. 秋天  /  qiūtiān  /  [명사 (n.)]  /  가을
- 한자 풀이: 秋(가을 추) + 天(하늘 천) → 가을
- 例句: 秋天很凉快。
- Pinyin: Qiūtiān hěn liángkuai.
- 번역: 가을은 아주 시원합니다.

### 5. 冬天  /  dōngtiān  /  [명사 (n.)]  /  겨울
- 한자 풀이: 冬(겨울 동) + 天(하늘 천) → 겨울
- 例句: 冬天很冷。
- Pinyin: Dōngtiān hěn lěng.
- 번역: 겨울은 아주 춥습니다.

### 6. 暖和  /  nuǎnhuo  /  [형용사 (adj.)]  /  따뜻하다
- 한자 풀이: 暖(따뜻할 난) + 和(화할 화) → 따뜻하다
- 例句: 今天很暖和。
- Pinyin: Jīntiān hěn nuǎnhuo.
- 번역: 오늘은 아주 따뜻합니다.

## 语法点 (어법 포인트)

### 1. "一年有四个季节" — 계절 세기
- 春 chūn 봄, 夏 xià 여름, 秋 qiū 가을, 冬 dōng 겨울

### 2. "最 + 좋아하는 것" — 최상급 표현
- 你最喜欢哪个季节？ Nǐ zuì xǐhuan nǎ gè jìjié? 어떤 계절을 가장 좋아하세요?
- 我最喜欢春天。 Wǒ zuì xǐhuan chūntiān. 저는 봄을 가장 좋아합니다.

### 3. "因为 + 이유" — 이유 표현
- 因为春天花都开了。 Yīnwèi chūntiān huā dōu kāi le. 봄에는 꽃이 모두 피기 때문입니다.

### 4. "很 + 형용사" — 계절 날씨 표현
- 春天很暖和 chūntiān hěn nuǎnhuo 봄은 따뜻하다

## 应用会话 (응용 회화 - 일상)

A: 一年有几个季节？  
   Yì nián yǒu jǐ gè jìjié?  
   일 년에 계절이 몇 개예요?

B: 一年有四个季节，春夏秋冬。  
   Yì nián yǒu sì gè jìjié, chūn xià qiū dōng.  
   네 개예요, 봄 여름 가을 겨울.

A: 你最喜欢哪个季节？  
   Nǐ zuì xǐhuan nǎ gè jìjié?  
   어떤 계절을 가장 좋아해요?

B: 我最喜欢秋天。  
   Wǒ zuì xǐhuan qiūtiān.  
   저는 가을을 가장 좋아해요.

A: 为什么？  
   Wèishénme?  
   왜요?

B: 因为秋天很凉快，很舒服。  
   Yīnwèi qiūtiān hěn liángkuai, hěn shūfu.  
   가을은 시원하고 기분이 좋기 때문이에요.

A: 我也喜欢秋天。  
   Wǒ yě xǐhuan qiūtiān.  
   저도 가을을 좋아해요.
