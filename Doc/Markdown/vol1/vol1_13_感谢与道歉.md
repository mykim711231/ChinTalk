第 十三 课 : 13. 感谢与道歉 Gǎnxiè yǔ dàoqiàn (감사와 사과)

## 本文 (본문)

谢谢！  
Xièxie!  
감사합니다!

谢谢你！  
Xièxie nǐ!  
고마워요!

非常感谢！  
Fēicháng gǎnxiè!  
대단히 감사합니다!

不客气。  
Bú kèqi.  
천만에요.

没关系。  
Méi guānxi.  
괜찮아요.

对不起。  
Duìbuqǐ.  
죄송합니다.

不好意思。  
Bù hǎoyìsi.  
미안합니다. (가벼운 사과)

很抱歉。  
Hěn bàoqiàn.  
매우 죄송합니다.

没事。  
Méi shì.  
아무 일 아니에요. (괜찮아요)

谢谢你的帮助。  
Xièxie nǐ de bāngzhù.  
도와줘서 고마워요.

---

## 主要词汇 (주요 단어)

### 1. 谢谢  /  xièxie  /  [동사 (v.)]  /  감사하다
- 한자 풀이: 谢(사례할 사) 중첩 → 정중한 감사 표현
- 例句: 谢谢你的帮助。
- Pinyin: Xièxie nǐ de bāngzhù.
- 번역: 도와줘서 고마워요.

### 2. 感谢  /  gǎnxiè  /  [동사 (v.)]  /  감사하다
- 한자 풀이: 感(느낄 감) + 谢(사례할 사) → 진심으로 감사하다
- 例句: 非常感谢！
- Pinyin: Fēicháng gǎnxiè!
- 번역: 대단히 감사합니다!

### 3. 不客气  /  bú kèqi  /  [구 (phrase)]  /  천만에요
- 한자 풀이: 不 + 客气(예의) → 겸손한 응답
- 例句: 不客气。
- Pinyin: Bú kèqi.
- 번역: 천만에요.

### 4. 对不起  /  duìbuqǐ  /  [동사 (v.)]  /  죄송하다
- 한자 풀이: 对(마주할 대) + 不起(감당 못함) → 미안하다
- 例句: 对不起，我迟到了。
- Pinyin: Duìbuqǐ, wǒ chídào le.
- 번역: 죄송합니다, 늦었습니다.

### 5. 没关系  /  méi guānxi  /  [구 (phrase)]  /  괜찮다
- 한자 풀이: 没(없을 몰) + 关系(관계) → 괜찮다
- 例句: 没关系。
- Pinyin: Méi guānxi.
- 번역: 괜찮아요.

### 6. 抱歉  /  bàoqiàn  /  [동사 (v.)]  /  미안하다
- 한자 풀이: 抱(안을 포) + 歉(미안할 겸) → 미안해하다
- 例句: 很抱歉。
- Pinyin: Hěn bàoqiàn.
- 번역: 매우 죄송합니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 谢谢 | xièxie | 두 谢 모두 4성으로 읽음 | 뒤 谢은 경성(xie) |
| 不客气 | bú kèqi | 不를 bù(4성) 그대로 읽음 | 4성 앞에서 2성으로 변해 bú |
| 对不起 | duìbuqǐ | 不를 bù(4성)으로 읽음 | 不은 경성(bu) |
| 没关系 | méi guānxi | 系를 xì(4성)으로 읽음 | 系는 경성(xi) |
| 不好意思 | bù hǎoyìsi | 思를 sī(1성)으로 읽음 | 思는 경성(si) |

## 语法点 (어법 포인트)

### 1. 감사 표현 — 谢谢 / 感谢
- 谢谢！ Xièxie! 감사합니다!
- 非常感谢！ Fēicháng gǎnxiè! 대단히 감사합니다!

### 2. 감사에 대한 응답 — 不客气 / 不用谢
- 不客气。 Bú kèqi. 천만에요.
- 不用谢。 Bú yòng xiè. 별말씀을요.

### 3. 사과 표현 — 对不起 / 抱歉 / 不好意思
- 对不起。 Duìbuqǐ. 죄송합니다.
- 不好意思。 Bù hǎoyìsi. 미안합니다. (가벼운 사과)

### 4. 사과에 대한 응답 — 没关系 / 没事
- 没关系。 Méi guānxi. 괜찮아요.
- 没事。 Méi shì. 아무 일 아니에요.

## 应用会话 (응용 회화 - 일상)

A: 对不起，我迟到了。  
   Duìbuqǐ, wǒ chídào le.  
   죄송합니다, 늦었습니다.

B: 没关系，请进。  
   Méi guānxi, qǐng jìn.  
   괜찮아요, 들어오세요.

A: 谢谢你帮我拿东西。  
   Xièxie nǐ bāng wǒ ná dōngxi.  
   짐 들어줘서 고마워요.

B: 不客气。  
   Bú kèqi.  
   천만에요.

A: 不好意思，我弄错了。  
   Bù hǎoyìsi, wǒ nòng cuò le.  
   미안해요, 제가 잘못했어요.

B: 没事，没关系。  
   Méi shì, méi guānxi.  
   괜찮아요, 아무 일 아니에요.

A: 非常感谢！  
   Fēicháng gǎnxiè!  
   대단히 감사합니다!
