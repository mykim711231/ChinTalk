第 十四 课 : 14. 天气 Tiānqì (날씨)

## 本文 (본문)

今天天气怎么样？  
Jīntiān tiānqì zěnmeyàng?  
오늘 날씨 어때요?

今天天气很好。  
Jīntiān tiānqì hěn hǎo.  
오늘 날씨가 아주 좋습니다.

今天很热。  
Jīntiān hěn rè.  
오늘은 아주 덥습니다.

今天很冷。  
Jīntiān hěn lěng.  
오늘은 아주 춥습니다.

今天下雨了。  
Jīntiān xià yǔ le.  
오늘 비가 왔습니다.

今天下雪了。  
Jīntiān xià xuě le.  
오늘 눈이 왔습니다.

明天天气怎么样？  
Míngtiān tiānqì zěnmeyàng?  
내일 날씨는 어때요?

明天晴天。  
Míngtiān qíngtiān.  
내일은 맑습니다.

今天有风。  
Jīntiān yǒu fēng.  
오늘은 바람이 붑니다.

现在气温三十度。  
Xiànzài qìwēn sānshí dù.  
지금 기온은 30도입니다.

---

## 主要词汇 (주요 단어)

### 1. 天气  /  tiānqì  /  [명사 (n.)]  /  날씨
- 한자 풀이: 天(하늘 천) + 气(기운 기) → 하늘의 기운, 날씨
- 例句: 今天天气很好。
- Pinyin: Jīntiān tiānqì hěn hǎo.
- 번역: 오늘 날씨가 아주 좋습니다.

### 2. 热  /  rè  /  [형용사 (adj.)]  /  덥다
- 한자 풀이: 执(간체 성부) + 灬(불 화) → 불처럼 뜨겁다 (번체 熱는 埶+灬)
- 例句: 今天很热。
- Pinyin: Jīntiān hěn rè.
- 번역: 오늘은 아주 덥습니다.

### 3. 冷  /  lěng  /  [형용사 (adj.)]  /  춥다
- 한자 풀이: 冫(얼음 빙) + 令 → 얼음처럼 차다
- 例句: 冬天很冷。
- Pinyin: Dōngtiān hěn lěng.
- 번역: 겨울은 아주 춥습니다.

### 4. 下雨  /  xià yǔ  /  [동사 (v.)]  /  비가 오다
- 한자 풀이: 下(내릴 하) + 雨(비 우) → 비가 내리다
- 例句: 今天下雨了。
- Pinyin: Jīntiān xià yǔ le.
- 번역: 오늘 비가 왔습니다.

### 5. 晴天  /  qíngtiān  /  [명사 (n.)]  /  맑은 날
- 한자 풀이: 晴(갤 청) + 天(하늘 천) → 맑은 날씨
- 例句: 明天晴天。
- Pinyin: Míngtiān qíngtiān.
- 번역: 내일은 맑습니다.

### 6. 气温  /  qìwēn  /  [명사 (n.)]  /  기온
- 한자 풀이: 气(기운 기) + 温(따뜻할 온) → 공기의 온도
- 例句: 气温很高。
- Pinyin: Qìwēn hěn gāo.
- 번역: 기온이 아주 높습니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 怎么样 | zěnmeyàng | 么을 mō(1성)으로 읽음 | 么은 경성(me) |
| 雪 | xuě | u를 '우'로 발음 | 입술 오므린 ü + 3성(xuě) |
| 风 | fēng | f를 'ㅍ'으로 발음 | 윗니로 아랫입술을 살짝 물고 fēng |
| 热 | rè | r를 '르'로 발음 | 혀를 말아 올린 r + 4성(rè) |
| 冷 | lěng | 2성으로 올려 읽음 | 3성으로 굴려 읽기(lěng) |

## 语法点 (어법 포인트)

### 1. "天气怎么样？" — 날씨 묻기
- 今天天气怎么样？ Jīntiān tiānqì zěnmeyàng? 오늘 날씨 어때요?

### 2. "很 + 형용사" — 날씨 상태 표현
- 很热 hěn rè 아주 덥다, 很冷 hěn lěng 아주 춥다

### 3. "下 + 비/눈" — 비·눈이 오다
- 下雨 xià yǔ 비가 오다, 下雪 xià xuě 눈이 오다

### 4. "了" — 날씨 변화 표현
- 今天下雨了。 Jīntiān xià yǔ le. 오늘 비가 왔습니다.

## 应用会话 (응용 회화 - 일상)

A: 今天天气怎么样？  
   Jīntiān tiānqì zěnmeyàng?  
   오늘 날씨 어때요?

B: 今天天气很好，是晴天。  
   Jīntiān tiānqì hěn hǎo, shì qíngtiān.  
   오늘 날씨 아주 좋아요, 맑은 날이에요.

A: 气温多少度？  
   Qìwēn duōshao dù?  
   기온은 몇 도예요?

B: 现在三十度，很热。  
   Xiànzài sānshí dù, hěn rè.  
   지금 30도라 아주 더워요.

A: 明天会下雨吗？  
   Míngtiān huì xià yǔ ma?  
   내일 비가 올까요?

B: 明天会下雨，记得带伞。  
   Míngtiān huì xià yǔ, jìde dài sǎn.  
   내일 비가 올 거예요, 우산 챙기세요.

A: 谢谢提醒！  
   Xièxie tíxǐng!  
   알려줘서 고마워요!
