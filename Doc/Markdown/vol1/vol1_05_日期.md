第 五 课 : 05. 日期 Rìqī (날짜)

## 本文 (본문)

今天几月几号？  
Jīntiān jǐ yuè jǐ hào?  
오늘은 몇 월 며칠이에요?

今天十月五号。  
Jīntiān shí yuè wǔ hào.  
오늘은 10월 5일입니다.

今天是星期三。  
Jīntiān shì xīngqīsān.  
오늘은 수요일입니다.

今天几号？  
Jīntiān jǐ hào?  
오늘 며칠이에요?

明天十月六号。  
Míngtiān shí yuè liù hào.  
내일은 10월 6일입니다.

昨天十月四号。  
Zuótiān shí yuè sì hào.  
어제는 10월 4일입니다.

我的生日是三月八号。  
Wǒ de shēngrì shì sān yuè bā hào.  
제 생일은 3월 8일입니다.

今天是一月一号，元旦。  
Jīntiān shì yí yuè yí hào, yuándàn.  
오늘은 1월 1일, 새해 첫날입니다.

今天是十二月二十五号，圣诞节。  
Jīntiān shì shí'èr yuè èrshíwǔ hào, shèngdàn jié.  
오늘은 12월 25일, 크리스마스입니다.

这个月是十月。  
Zhège yuè shì shí yuè.  
이번 달은 10월입니다.

---

## 主要词汇 (주요 단어)

### 1. 月  /  yuè  /  [명사 (n.)]  /  월(月)
- 한자 풀이: 달의 모양을 본뜬 상형문자
- 例句: 现在是十月。
- Pinyin: Xiànzài shì shí yuè.
- 번역: 지금은 10월입니다.

### 2. 号  /  hào  /  [명사 (n.)]  /  일(日)
- 한자 풀이: 口(입 구) + 丂 → 번호, 날짜를 세는 단위 (간체; 번체 號는 虎+号)
- 例句: 今天五号。
- Pinyin: Jīntiān wǔ hào.
- 번역: 오늘은 5일입니다.

### 3. 今天  /  jīntiān  /  [명사 (n.)]  /  오늘
- 한자 풀이: 今(이제 금) + 天(하늘 천) → 오늘
- 例句: 今天几号？
- Pinyin: Jīntiān jǐ hào?
- 번역: 오늘 며칠이에요?

### 4. 明天  /  míngtiān  /  [명사 (n.)]  /  내일
- 한자 풀이: 明(밝을 명) + 天(하늘 천) → 밝아오는 날, 내일
- 例句: 明天见！
- Pinyin: Míngtiān jiàn!
- 번역: 내일 봐요!

### 5. 昨天  /  zuótiān  /  [명사 (n.)]  /  어제
- 한자 풀이: 昨(어제 작) + 天(하늘 천) → 어제
- 例句: 昨天是四号。
- Pinyin: Zuótiān shì sì hào.
- 번역: 어제는 4일입니다.

### 6. 生日  /  shēngrì  /  [명사 (n.)]  /  생일
- 한자 풀이: 生(날 생) + 日(날 일) → 태어난 날
- 例句: 生日快乐！
- Pinyin: Shēngrì kuàilè!
- 번역: 생일 축하해요!

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 日 | rì | r를 '르'로 발음 | 혀를 말아 올린 r + 4성(rì) |
| 月 | yuè | u를 '우'로 발음 | 입술을 둥글게 오므린 ü(yuè) |
| 号 | hào | h를 'ㅎ'으로 과장해 '하오'로 | h는 가볍게 '허'에 가까운 hào |
| 十 | shí | sh를 '스'로 읽음 | 혀를 말아 올린 sh + 2성(shí) |
| 生日 | shēngrì | sh·r를 모두 '스/르'로 읽음 | sh와 r 모두 혀를 말아 올리기 |

## 语法点 (어법 포인트)

### 1. "X月 X号" — 날짜 표현
- 十月五号。 Shí yuè wǔ hào. 10월 5일.
- 三月八号。 Sān yuè bā hào. 3월 8일.

### 2. 시간의 흐름 — 昨天/今天/明天
- 昨天 zuótiān 어제, 今天 jīntiān 오늘, 明天 míngtiān 내일

### 3. "几"로 날짜 묻기
- 今天几号？ Jīntiān jǐ hào? 오늘 며칠이에요?
- 今天几月几号？ Jīntiān jǐ yuè jǐ hào? 오늘 몇 월 며칠이에요?

## 应用会话 (응용 회화 - 일상)

A: 今天几月几号？  
   Jīntiān jǐ yuè jǐ hào?  
   오늘 몇 월 며칠이에요?

B: 今天十月五号。  
   Jīntiān shí yuè wǔ hào.  
   오늘 10월 5일이에요.

A: 明天是你的生日吗？  
   Míngtiān shì nǐ de shēngrì ma?  
   내일이 당신 생일인가요?

B: 不是，我的生日是十月八号。  
   Bú shì, wǒ de shēngrì shì shí yuè bā hào.  
   아니요, 제 생일은 10월 8일이에요.

A: 那我们八号一起吃饭吧。  
   Nà wǒmen bā hào yìqǐ chīfàn ba.  
   그럼 우리 8일에 같이 밥 먹어요.

B: 好啊，八号见！  
   Hǎo a, bā hào jiàn!  
   좋아요, 8일에 봐요!
