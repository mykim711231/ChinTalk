第 十一 课 : 11. 爱好 Àihào (취미)

## 本文 (본문)

你有什么爱好？  
Nǐ yǒu shénme àihào?  
취미가 뭐예요?

我喜欢听音乐。  
Wǒ xǐhuan tīng yīnyuè.  
저는 음악 듣는 것을 좋아합니다.

我喜欢看电影。  
Wǒ xǐhuan kàn diànyǐng.  
저는 영화 보는 것을 좋아합니다.

我喜欢运动。  
Wǒ xǐhuan yùndòng.  
저는 운동을 좋아합니다.

我会打篮球。  
Wǒ huì dǎ lánqiú.  
저는 농구를 할 줄 압니다.

我不会游泳。  
Wǒ bú huì yóuyǒng.  
저는 수영을 못합니다.

我妹妹喜欢画画。  
Wǒ mèimei xǐhuan huà huà.  
여동생은 그림 그리는 것을 좋아합니다.

我周末常常看书。  
Wǒ zhōumò chángcháng kàn shū.  
저는 주말에 자주 책을 읽습니다.

我们一起去唱歌吧。  
Wǒmen yìqǐ qù chànggē ba.  
우리 같이 노래 부르러 가요.

你的爱好真多。  
Nǐ de àihào zhēn duō.  
취미가 정말 많네요.

---

## 主要词汇 (주요 단어)

### 1. 爱好  /  àihào  /  [명사 (n.)]  /  취미
- 한자 풀이: 爱(사랑할 애) + 好(좋을 호) → 좋아하는 것
- 例句: 我的爱好是画画。
- Pinyin: Wǒ de àihào shì huà huà.
- 번역: 제 취미는 그림 그리기입니다.

### 2. 喜欢  /  xǐhuan  /  [동사 (v.)]  /  좋아하다
- 한자 풀이: 喜(기쁠 희) + 欢(기쁠 환) → 좋아하다
- 例句: 我喜欢听音乐。
- Pinyin: Wǒ xǐhuan tīng yīnyuè.
- 번역: 저는 음악 듣는 것을 좋아합니다.

### 3. 运动  /  yùndòng  /  [명사·동사 (n./v.)]  /  운동
- 한자 풀이: 运(움직일 운) + 动(움직일 동) → 몸을 움직이다
- 例句: 我喜欢运动。
- Pinyin: Wǒ xǐhuan yùndòng.
- 번역: 저는 운동을 좋아합니다.

### 4. 唱歌  /  chànggē  /  [동사 (v.)]  /  노래하다
- 한자 풀이: 唱(부를 창) + 歌(노래 가) → 노래를 부르다
- 例句: 我喜欢唱歌。
- Pinyin: Wǒ xǐhuan chànggē.
- 번역: 저는 노래하는 것을 좋아합니다.

### 5. 游泳  /  yóuyǒng  /  [동사 (v.)]  /  수영하다
- 한자 풀이: 游(헤엄칠 유) + 泳(헤엄칠 영) → 헤엄치다
- 例句: 我会游泳。
- Pinyin: Wǒ huì yóuyǒng.
- 번역: 저는 수영할 줄 압니다.

### 6. 音乐  /  yīnyuè  /  [명사 (n.)]  /  음악
- 한자 풀이: 音(소리 음) + 乐(풍류 악) → 음악
- 例句: 我喜欢听音乐。
- Pinyin: Wǒ xǐhuan tīng yīnyuè.
- 번역: 저는 음악 듣는 것을 좋아합니다.

## 语法点 (어법 포인트)

### 1. "喜欢 + 명사/동사구" — 좋아하는 것 말하기
- 我喜欢听音乐。 Wǒ xǐhuan tīng yīnyuè. 저는 음악 듣기를 좋아합니다.
- 我喜欢运动。 Wǒ xǐhuan yùndòng. 저는 운동을 좋아합니다.

### 2. "会 + 동사" — 할 줄 아는 능력
- 我会打篮球。 Wǒ huì dǎ lánqiú. 저는 농구할 줄 압니다.
- 我不会游泳。 Wǒ bú huì yóuyǒng. 저는 수영 못합니다.

### 3. "常常 + 동사" — 빈도 표현 (자주)
- 我常常看书。 Wǒ chángcháng kàn shū. 저는 자주 책을 읽습니다.

### 4. "一起 + 동사" — 같이 ~하다
- 我们一起去唱歌吧。 Wǒmen yìqǐ qù chànggē ba. 우리 같이 노래 부르러 가요.

## 应用会话 (응용 회화 - 일상)

A: 你有什么爱好？  
   Nǐ yǒu shénme àihào?  
   취미가 뭐예요?

B: 我喜欢看电影和听音乐。  
   Wǒ xǐhuan kàn diànyǐng hé tīng yīnyuè.  
   저는 영화 보고 음악 듣는 것을 좋아해요.

A: 你会游泳吗？  
   Nǐ huì yóuyǒng ma?  
   수영할 줄 알아요?

B: 不会，但是我会打篮球。  
   Bú huì, dànshì wǒ huì dǎ lánqiú.  
   아니요, 하지만 농구는 할 줄 알아요.

A: 我们周末一起去打篮球吧。  
   Wǒmen zhōumò yìqǐ qù dǎ lánqiú ba.  
   주말에 같이 농구하러 가요.

B: 好啊！  
   Hǎo a!  
   좋아요!

A: 你的爱好真多。  
   Nǐ de àihào zhēn duō.  
   취미가 정말 많네요.
