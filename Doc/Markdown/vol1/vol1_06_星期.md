第 六 课 : 06. 星期 Xīngqī (요일)

## 本文 (본문)

今天星期几？  
Jīntiān xīngqī jǐ?  
오늘은 무슨 요일이에요?

今天星期一。  
Jīntiān xīngqīyī.  
오늘은 월요일입니다.

星期一、星期二、星期三。  
Xīngqīyī, xīngqī'èr, xīngqīsān.  
월요일, 화요일, 수요일.

星期四、星期五、星期六。  
Xīngqīsì, xīngqīwǔ, xīngqīliù.  
목요일, 금요일, 토요일.

星期日也叫星期天。  
Xīngqīrì yě jiào xīngqītiān.  
일요일은 "星期天"이라고도 합니다.

周末是星期六和星期天。  
Zhōumò shì xīngqīliù hé xīngqītiān.  
주말은 토요일과 일요일입니다.

明天星期五。  
Míngtiān xīngqīwǔ.  
내일은 금요일입니다.

星期一到星期五我要上班。  
Xīngqīyī dào xīngqīwǔ wǒ yào shàngbān.  
월요일부터 금요일까지 저는 출근합니다.

这个星期我很忙。  
Zhège xīngqī wǒ hěn máng.  
이번 주 저는 바쁩니다.

下个星期见！  
Xiàge xīngqī jiàn!  
다음 주에 봐요!

---

## 主要词汇 (주요 단어)

### 1. 星期  /  xīngqī  /  [명사 (n.)]  /  요일, 주(週)
- 한자 풀이: 星(별 성) + 期(기약 기) → 별자리로 나눈 주기
- 例句: 这个星期我很忙。
- Pinyin: Zhège xīngqī wǒ hěn máng.
- 번역: 이번 주 저는 바쁩니다.

### 2. 今天  /  jīntiān  /  [명사 (n.)]  /  오늘
- 한자 풀이: 今(이제 금) + 天(하늘 천) → 오늘
- 例句: 今天星期三。
- Pinyin: Jīntiān xīngqīsān.
- 번역: 오늘은 수요일입니다.

### 3. 周末  /  zhōumò  /  [명사 (n.)]  /  주말
- 한자 풀이: 周(주 주) + 末(끝 말) → 한 주의 끝
- 例句: 周末你去哪儿？
- Pinyin: Zhōumò nǐ qù nǎr?
- 번역: 주말에 어디 가세요?

### 4. 上班  /  shàngbān  /  [동사 (v.)]  /  출근하다
- 한자 풀이: 上(오를 상) + 班(근무 반) → 근무하러 가다
- 例句: 我星期一上班。
- Pinyin: Wǒ xīngqīyī shàngbān.
- 번역: 저는 월요일에 출근합니다.

### 5. 忙  /  máng  /  [형용사 (adj.)]  /  바쁘다
- 한자 풀이: 忄(마음 심) + 亡(없을 망) → 마음이 급하다
- 例句: 我今天很忙。
- Pinyin: Wǒ jīntiān hěn máng.
- 번역: 저는 오늘 아주 바쁩니다.

### 6. 星期天  /  xīngqītiān  /  [명사 (n.)]  /  일요일
- 한자 풀이: 星期 + 天 → 일요일(口语 표현)
- 例句: 星期天我去公园。
- Pinyin: Xīngqītiān wǒ qù gōngyuán.
- 번역: 일요일에 공원에 갑니다.

## 语法点 (어법 포인트)

### 1. "星期 + 숫자" — 요일 표현
- 星期一 xīngqīyī 월요일, 星期二 xīngqī'èr 화요일
- 星期日 xīngqīrì 일요일

### 2. "A 到 B" — A부터 B까지
- 星期一到星期五 월요일부터 금요일까지

### 3. "几"로 요일 묻기
- 今天星期几？ Jīntiān xīngqī jǐ? 오늘 무슨 요일이에요?

### 4. "上/下/这个" — 주(週) 표현
- 上个星期 지난주, 这个星期 이번 주, 下个星期 다음 주

## 应用会话 (응용 회화 - 일상)

A: 今天星期几？  
   Jīntiān xīngqī jǐ?  
   오늘 무슨 요일이에요?

B: 今天星期五。  
   Jīntiān xīngqīwǔ.  
   오늘 금요일이에요.

A: 明天是周末吗？  
   Míngtiān shì zhōumò ma?  
   내일 주말인가요?

B: 对，明天星期六。  
   Duì, míngtiān xīngqīliù.  
   맞아요, 내일 토요일이에요.

A: 周末你有什么安排？  
   Zhōumò nǐ yǒu shénme ānpái?  
   주말에 무슨 계획 있어요?

B: 我星期天去公园。  
   Wǒ xīngqītiān qù gōngyuán.  
   일요일에 공원에 가요.

A: 下个星期见！  
   Xiàge xīngqī jiàn!  
   다음 주에 봐요!
