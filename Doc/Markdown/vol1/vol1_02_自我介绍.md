第 二 课 : 02. 自我介绍 Zìwǒ jièshào (자기소개)

## 本文 (본문)

我叫李明。  
Wǒ jiào Lǐ Míng.  
제 이름은 리밍입니다.

我是韩国人。  
Wǒ shì Hánguó rén.  
저는 한국 사람입니다.

我今年二十岁。  
Wǒ jīnnián èrshí suì.  
저는 올해 스무 살입니다.

我是学生。  
Wǒ shì xuésheng.  
저는 학생입니다.

我在首尔大学学习。  
Wǒ zài Shǒu'ěr Dàxué xuéxí.  
저는 서울대학교에서 공부합니다.

你叫什么名字？  
Nǐ jiào shénme míngzi?  
이름이 뭐예요?

我姓金，叫金美娜。  
Wǒ xìng Jīn, jiào Jīn Měinà.  
저는 성이 김이고 김미나라고 합니다.

认识你很高兴。  
Rènshi nǐ hěn gāoxìng.  
만나서 반갑습니다.

请多多关照。  
Qǐng duōduō guānzhào.  
잘 부탁드립니다.

我也很高兴认识你。  
Wǒ yě hěn gāoxìng rènshi nǐ.  
저도 만나서 반가워요.

---

## 主要词汇 (주요 단어)

### 1. 叫  /  jiào  /  [동사 (v.)]  /  ~라고 부르다
- 한자 풀이: 口(입 구) + 丩(얽힐 구) → 입으로 소리 내어 부르다
- 例句: 我叫李明。
- Pinyin: Wǒ jiào Lǐ Míng.
- 번역: 제 이름은 리밍입니다.

### 2. 名字  /  míngzi  /  [명사 (n.)]  /  이름
- 한자 풀이: 名(이름 명) + 字(글자 자) → 이름과 글자
- 例句: 你叫什么名字？
- Pinyin: Nǐ jiào shénme míngzi?
- 번역: 이름이 뭐예요?

### 3. 是  /  shì  /  [동사 (v.)]  /  ~이다
- 한자 풀이: 日(해 일) + 正(바를 정) → 바름을 가리켜 "이다"
- 例句: 我是学生。
- Pinyin: Wǒ shì xuésheng.
- 번역: 저는 학생입니다.

### 4. 学生  /  xuésheng  /  [명사 (n.)]  /  학생
- 한자 풀이: 学(배울 학) + 生(날 생) → 배우는 사람
- 例句: 我们都是学生。
- Pinyin: Wǒmen dōu shì xuésheng.
- 번역: 우리는 모두 학생입니다.

### 5. 人  /  rén  /  [명사 (n.)]  /  사람
- 한자 풀이: 사람의 모습을 본뜬 상형문자
- 例句: 我是韩国人。
- Pinyin: Wǒ shì Hánguó rén.
- 번역: 저는 한국 사람입니다.

### 6. 高兴  /  gāoxìng  /  [형용사 (adj.)]  /  기쁘다, 반갑다
- 한자 풀이: 高(높을 고) + 兴(일 흥) → 기분이 높아지다
- 例句: 认识你很高兴。
- Pinyin: Rènshi nǐ hěn gāoxìng.
- 번역: 만나서 반갑습니다.

## 语法点 (어법 포인트)

### 1. "我叫 + 이름" — 이름 소개
- 我叫李明。 Wǒ jiào Lǐ Míng. 저는 리밍입니다.
- 你叫什么？ Nǐ jiào shénme? 이름이 뭐예요?

### 2. "我是 + 명사" — 신분·국적 소개
- 我是学生。 Wǒ shì xuésheng. 저는 학생입니다.
- 我是韩国人。 Wǒ shì Hánguó rén. 저는 한국 사람입니다.

### 3. "什么" — 의문대명사 "무엇"
- 你叫什么名字？ Nǐ jiào shénme míngzi? 이름이 뭐예요?

### 4. "姓" — 성(姓)을 말할 때
- 我姓金。 Wǒ xìng Jīn. 저는 성이 김입니다.

## 应用会话 (응용 회화 - 일상)

A: 你好！我是李明。  
   Nǐ hǎo! Wǒ shì Lǐ Míng.  
   안녕하세요! 저는 리밍입니다.

B: 你好！我叫金美娜。  
   Nǐ hǎo! Wǒ jiào Jīn Měinà.  
   안녕하세요! 저는 김미나입니다.

A: 认识你很高兴。  
   Rènshi nǐ hěn gāoxìng.  
   만나서 반갑습니다.

B: 我也很高兴。你是哪国人？  
   Wǒ yě hěn gāoxìng. Nǐ shì nǎ guó rén?  
   저도 반가워요. 당신은 어느 나라 사람인가요?

A: 我是韩国人。你呢？  
   Wǒ shì Hánguó rén. Nǐ ne?  
   저는 한국 사람입니다. 당신은요?

B: 我也是韩国人。请多多关照。  
   Wǒ yě shì Hánguó rén. Qǐng duōduō guānzhào.  
   저도 한국 사람입니다. 잘 부탁드립니다.

A: 请多多关照！  
   Qǐng duōduō guānzhào!  
   잘 부탁드립니다!
