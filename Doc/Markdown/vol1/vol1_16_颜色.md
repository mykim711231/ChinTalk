第 十六 课 : 16. 颜色 Yánsè (색깔)

## 本文 (본문)

这是什么颜色？  
Zhè shì shénme yánsè?  
이것은 무슨 색이에요?

这是红色。  
Zhè shì hóngsè.  
이것은 빨간색입니다.

这是蓝色。  
Zhè shì lánsè.  
이것은 파란색입니다.

这是绿色。  
Zhè shì lǜsè.  
이것은 초록색입니다.

这是黄色。  
Zhè shì huángsè.  
이것은 노란색입니다.

这是白色。  
Zhè shì báisè.  
이것은 흰색입니다.

这是黑色。  
Zhè shì hēisè.  
이것은 검은색입니다.

你喜欢什么颜色？  
Nǐ xǐhuan shénme yánsè?  
무슨 색을 좋아하세요?

我喜欢蓝色。  
Wǒ xǐhuan lánsè.  
저는 파란색을 좋아합니다.

天空是蓝色的。  
Tiānkōng shì lánsè de.  
하늘은 파란색입니다.

---

## 主要词汇 (주요 단어)

### 1. 颜色  /  yánsè  /  [명사 (n.)]  /  색깔
- 한자 풀이: 颜(얼굴 안) + 色(빛 색) → 색깔
- 例句: 你喜欢什么颜色？
- Pinyin: Nǐ xǐhuan shénme yánsè?
- 번역: 무슨 색을 좋아하세요?

### 2. 红色  /  hóngsè  /  [명사 (n.)]  /  빨간색
- 한자 풀이: 红(붉을 홍) + 色(빛 색) → 빨간색
- 例句: 苹果是红色的。
- Pinyin: Píngguǒ shì hóngsè de.
- 번역: 사과는 빨간색입니다.

### 3. 蓝色  /  lánsè  /  [명사 (n.)]  /  파란색
- 한자 풀이: 蓝(쪽 람) + 色(빛 색) → 파란색
- 例句: 我喜欢蓝色。
- Pinyin: Wǒ xǐhuan lánsè.
- 번역: 저는 파란색을 좋아합니다.

### 4. 绿色  /  lǜsè  /  [명사 (n.)]  /  초록색
- 한자 풀이: 绿(푸를 록) + 色(빛 색) → 초록색
- 例句: 树叶是绿色的。
- Pinyin: Shùyè shì lǜsè de.
- 번역: 나뭇잎은 초록색입니다.

### 5. 白色  /  báisè  /  [명사 (n.)]  /  흰색
- 한자 풀이: 白(흰 백) + 色(빛 색) → 흰색
- 例句: 雪是白色的。
- Pinyin: Xuě shì báisè de.
- 번역: 눈은 흰색입니다.

### 6. 黑色  /  hēisè  /  [명사 (n.)]  /  검은색
- 한자 풀이: 黑(검을 흑) + 色(빛 색) → 검은색
- 例句: 我的头发是黑色的。
- Pinyin: Wǒ de tóufa shì hēisè de.
- 번역: 제 머리카락은 검은색입니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 绿色 | lǜsè | u를 '우'로 발음 | 입술 오므린 ü + 4성(lǜ) |
| 黑色 | hēisè | h를 'ㅎ'으로 과장해 '헤이'로 | h는 가볍게 1성(hēi) |
| 喜欢 | xǐhuan | 欢을 huān(1성)으로 읽음 | 欢은 경성(huan) |
| 黄色 | huángsè | 성조 없이 '황'으로 읽음 | 2성으로 올려 읽기(huáng) |
| 颜色 | yánsè | 颜을 1성·'얀'으로 읽음 | 颜은 2성(yán) |

---

## 语法点 (어법 포인트)

### 1. "什么颜色" — 색 묻기
- 这是什么颜色？ Zhè shì shénme yánsè? 이것은 무슨 색이에요?

### 2. "是 + 색 + 的" — 색 설명
- 天空是蓝色的。 Tiānkōng shì lánsè de. 하늘은 파란색입니다.

### 3. "喜欢 + 색" — 좋아하는 색 말하기
- 我喜欢蓝色。 Wǒ xǐhuan lánsè. 저는 파란색을 좋아합니다.

### 4. "这/那" — 이것/저것
- 这是什么？ Zhè shì shénme? 이것은 무엇인가요?

## 应用会话 (응용 회화 - 일상)

A: 你喜欢什么颜色？  
   Nǐ xǐhuan shénme yánsè?  
   무슨 색을 좋아해요?

B: 我喜欢蓝色。你呢？  
   Wǒ xǐhuan lánsè. Nǐ ne?  
   저는 파란색을 좋아해요. 당신은요?

A: 我喜欢绿色。  
   Wǒ xǐhuan lǜsè.  
   저는 초록색을 좋아해요.

B: 这是什么颜色？  
   Zhè shì shénme yánsè?  
   이건 무슨 색이에요?

A: 这是红色。  
   Zhè shì hóngsè.  
   이건 빨간색이에요.

B: 真漂亮！  
   Zhēn piàoliang!  
   정말 예뻐요!

A: 谢谢！  
   Xièxie!  
   고마워요!
