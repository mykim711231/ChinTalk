第 十八 课 : 18. 心情 Xīnqíng (감정·기분)

## 本文 (본문)

你最近怎么样？  
Nǐ zuìjìn zěnmeyàng?  
요즘 어떠세요?

我很开心。  
Wǒ hěn kāixīn.  
저는 아주 기쁩니다.

我很高兴。  
Wǒ hěn gāoxìng.  
저는 아주 기쁩니다.

我很难过。  
Wǒ hěn nánguò.  
저는 아주 슬픕니다.

我很生气。  
Wǒ hěn shēngqì.  
저는 아주 화가 납니다.

我有点儿累。  
Wǒ yǒudiǎnr lèi.  
저는 좀 피곤합니다.

我很紧张。  
Wǒ hěn jǐnzhāng.  
저는 아주 긴장됩니다.

我很担心。  
Wǒ hěn dānxīn.  
저는 아주 걱정됩니다.

我很满意。  
Wǒ hěn mǎnyì.  
저는 아주 만족합니다.

你今天心情怎么样？  
Nǐ jīntiān xīnqíng zěnmeyàng?  
오늘 기분이 어때요?

## 主要词汇 (주요 단어)

### 1. 心情  /  xīnqíng  /  [명사 (n.)]  /  기분
- 한자 풀이: 心(마음 심) + 情(뜻 정) → 마음의 상태
- 例句: 我今天心情很好。
- Pinyin: Wǒ jīntiān xīnqíng hěn hǎo.
- 번역: 오늘 기분이 아주 좋습니다.

### 2. 开心  /  kāixīn  /  [형용사 (adj.)]  /  기쁘다, 즐겁다
- 한자 풀이: 开(열 개) + 心(마음 심) → 마음이 열리다
- 例句: 我很开心。
- Pinyin: Wǒ hěn kāixīn.
- 번역: 저는 아주 기쁩니다.

### 3. 难过  /  nánguò  /  [형용사 (adj.)]  /  슬프다
- 한자 풀이: 难(어려울 난) + 过(지날 과) → 마음이 힘들다
- 例句: 我很难过。
- Pinyin: Wǒ hěn nánguò.
- 번역: 저는 아주 슬픕니다.

### 4. 生气  /  shēngqì  /  [동사 (v.)]  /  화가 나다
- 한자 풀이: 生(날 생) + 气(기운 기) → 화가 나다
- 例句: 别生气。
- Pinyin: Bié shēngqì.
- 번역: 화내지 마세요.

### 5. 累  /  lèi  /  [형용사 (adj.)]  /  피곤하다
- 한자 풀이: 糸(실 사) + 田 → 지치다
- 例句: 我有点儿累。
- Pinyin: Wǒ yǒudiǎnr lèi.
- 번역: 저는 좀 피곤합니다.

### 6. 担心  /  dānxīn  /  [동사 (v.)]  /  걱정하다
- 한자 풀이: 担(맡을 담) + 心(마음 심) → 마음을 졸이다
- 例句: 别担心。
- Pinyin: Bié dānxīn.
- 번역: 걱정하지 마세요.

## 语法点 (어법 포인트)

### 1. "心情怎么样？" — 기분 묻기
- 你今天心情怎么样？ Nǐ jīntiān xīnqíng zěnmeyàng? 오늘 기분 어때요?

### 2. "很 + 감정 형용사" — 감정 표현
- 很开心 hěn kāixīn 기쁘다, 很难过 hěn nánguò 슬프다, 很生气 hěn shēngqì 화가 나다

### 3. "有点儿 + 형용사" — 약한 정도 (~좀)
- 我有点儿累。 Wǒ yǒudiǎnr lèi. 저는 좀 피곤합니다.

### 4. "别 + 동사" — 금지/위로 (~하지 마)
- 别担心。 Bié dānxīn. 걱정하지 마세요.
- 别生气。 Bié shēngqì. 화내지 마세요.

## 应用会话 (응용 회화 - 일상)

A: 你今天心情怎么样？  
   Nǐ jīntiān xīnqíng zěnmeyàng?  
   오늘 기분이 어때요?

B: 我很开心。你呢？  
   Wǒ hěn kāixīn. Nǐ ne?  
   저는 아주 기뻐요. 당신은요?

A: 我有点儿累。  
   Wǒ yǒudiǎnr lèi.  
   저는 좀 피곤해요.

B: 怎么了？  
   Zěnme le?  
   무슨 일이에요?

A: 工作太忙了。  
   Gōngzuò tài máng le.  
   일이 너무 바빠서요.

B: 别担心，休息一下就好。  
   Bié dānxīn, xiūxi yíxià jiù hǎo.  
   걱정 마세요, 좀 쉬면 괜찮아질 거예요.

A: 谢谢！  
   Xièxie!  
   고마워요!
