第 十二 课 : 12. 电话 Diànhuà (전화)

## 本文 (본문)

喂，你好！  
Wéi, nǐ hǎo!  
여보세요, 안녕하세요!

请问您是哪位？  
Qǐngwèn nín shì nǎ wèi?  
실례지만 누구세요?

我是李明。  
Wǒ shì Lǐ Míng.  
저는 리밍입니다.

请问金美娜在吗？  
Qǐngwèn Jīn Měinà zài ma?  
실례지만 김미나 씨 계세요?

请稍等。  
Qǐng shāo děng.  
잠시만 기다려 주세요.

他不在。  
Tā bú zài.  
그는 자리에 없습니다.

你的电话号码是多少？  
Nǐ de diànhuà hàomǎ shì duōshao?  
전화번호가 뭐예요?

请给我打电话。  
Qǐng gěi wǒ dǎ diànhuà.  
저에게 전화해 주세요.

我晚上给你回电话。  
Wǒ wǎnshang gěi nǐ huí diànhuà.  
저녁에 다시 전화할게요.

信号不好，听不清楚。  
Xìnhào bù hǎo, tīng bù qīngchu.  
신호가 안 좋아서 잘 안 들립니다.

---

## 主要词汇 (주요 단어)

### 1. 电话  /  diànhuà  /  [명사 (n.)]  /  전화
- 한자 풀이: 电(번개 전) + 话(말 화) → 전화
- 例句: 请给我打电话。
- Pinyin: Qǐng gěi wǒ dǎ diànhuà.
- 번역: 저에게 전화해 주세요.

### 2. 喂  /  wéi  /  [감탄사 (int.)]  /  여보세요
- 한자 풀이: 입으로 부르는 소리를 나타냄 → 전화 첫인사
- 例句: 喂，你好！
- Pinyin: Wéi, nǐ hǎo!
- 번역: 여보세요, 안녕하세요!

### 3. 请问  /  qǐngwèn  /  [동사 (v.)]  /  묻겠습니다, 실례합니다
- 한자 풀이: 请(청할 청) + 问(물을 문) → 정중히 묻다
- 例句: 请问您是哪位？
- Pinyin: Qǐngwèn nín shì nǎ wèi?
- 번역: 실례지만 누구세요?

### 4. 号码  /  hàomǎ  /  [명사 (n.)]  /  번호
- 한자 풀이: 号(이름 호) + 码(숫자 마) → 번호
- 例句: 你的号码是多少？
- Pinyin: Nǐ de hàomǎ shì duōshao?
- 번역: 당신의 번호는 뭐예요?

### 5. 回电话  /  huí diànhuà  /  [동사 (v.)]  /  다시 전화하다
- 한자 풀이: 回(돌아올 회) + 电话 → 다시 전화하다
- 例句: 我晚上给你回电话。
- Pinyin: Wǒ wǎnshang gěi nǐ huí diànhuà.
- 번역: 저녁에 다시 전화할게요.

### 6. 信号  /  xìnhào  /  [명사 (n.)]  /  신호
- 한자 풀이: 信(믿을 신) + 号(신호 호) → 신호
- 例句: 信号不好。
- Pinyin: Xìnhào bù hǎo.
- 번역: 신호가 좋지 않습니다.

## 发音陷阱 (한국인 발음 함정)

| 대상 | 병음 | 흔한 오류 | 올바른 발음 |
|---|---|---|---|
| 喂 | wéi | 4성으로 읽음 | 전화 인사는 2성(wéi) |
| 请问 | qǐngwèn | q를 '치', 请을 2성으로 읽음 | q는 기식음, 请은 3성(qǐng) |
| 多少 | duōshao | 少를 shǎo(3성)으로 읽음 | 少는 경성(shao) |
| 清楚 | qīngchu | 楚를 chǔ(3성)으로 읽음 | 楚는 경성(chu) |
| 信号 | xìnhào | x를 'ㅅ'으로 읽음 | x는 혀끝을 내린 소리(xìn) |

## 语法点 (어법 포인트)

### 1. "喂" — 전화 첫인사
- 喂，你好！ Wéi, nǐ hǎo! 여보세요, 안녕하세요!

### 2. "请问 + 질문" — 정중한 물음
- 请问您是哪位？ Qǐngwèn nín shì nǎ wèi? 실례지만 누구세요?
- 请问他在吗？ Qǐngwèn tā zài ma? 실례지만 그분 계세요?

### 3. "在 / 不在" — 자리에 있다/없다
- 金美娜在吗？ Jīn Měinà zài ma? 김미나 씨 계세요?
- 他不在。 Tā bú zài. 그는 자리에 없습니다.

### 4. "给 + 사람 + 打电话" — ~에게 전화하다
- 请给我打电话。 Qǐng gěi wǒ dǎ diànhuà. 저에게 전화해 주세요.

## 应用会话 (응용 회화 - 일상)

A: 喂，你好！  
   Wéi, nǐ hǎo!  
   여보세요, 안녕하세요!

B: 你好！请问您是哪位？  
   Nǐ hǎo! Qǐngwèn nín shì nǎ wèi?  
   안녕하세요! 실례지만 누구세요?

A: 我是李明。金美娜在吗？  
   Wǒ shì Lǐ Míng. Jīn Měinà zài ma?  
   저는 리밍입니다. 김미나 씨 계세요?

B: 她不在，请稍等，我记一下。  
   Tā bú zài, qǐng shāo děng, wǒ jì yíxià.  
   그녀는 자리에 없어요. 잠시만요, 메모할게요.

A: 请告诉她给我回电话。  
   Qǐng gàosu tā gěi wǒ huí diànhuà.  
   그녀에게 저에게 다시 전화하라고 전해 주세요.

B: 好的，您的电话号码是多少？  
   Hǎo de, nín de diànhuà hàomǎ shì duōshao?  
   네, 전화번호가 어떻게 되세요?

A: 一三五一二三四五六七八。  
   Yāo sān wǔ yāo èr sān sì wǔ liù qī bā.  
   135-1234-5678이에요.

B: 好的，再见！  
   Hǎo de, zàijiàn!  
   네, 안녕히 계세요!
