# ChinTalk — 소리로 배우는 중국어 구조화 듣기

문장의 **의미 단위**를 확인하며 듣고, 한자·병음·한글을 켜고 끄며 따라 말하는 중국어 학습 PWA입니다.
첫 접속 때 전권 교재·단어장·음원 목록을 자동 저장합니다. 녹음 음원은 녹음 음성 모드에서 자동 저장을 켰을 때만 이어받으며, 기기 음성 모드에서는 자동 다운로드하지 않습니다. 기기 음성은 스마트폰에 해당 언어의 오프라인 음성팩이 필요합니다. 학습용 무료 앱입니다.

👉 **https://mykim711231.github.io/ChinTalk/**

## ✨ 주요 기능

- **구조화 듣기** — 본문 → 단어 → 문법 → 회화 → 발음 함정 순서의 한 과 구성, 문장별 스피커 재생
- **표시 토글** — 한자 / 병음 / 한글을 칩으로 즉시 켜고 끄기 (듣기만 연습하기 좋음)
- **의미단위 표시** — 단어/구/절 선택 없이 켜기/끄기만 사용. `我是 / 韩国人。`처럼 문장 구조에 맞춰 묶고, 전체 듣기는 본문·회화 탭의 문장을 그대로 재생
- **음성 재생 방식** — 기본값은 기기 음성(Web Speech), 중국어 음성 선택·속도 조절. 녹음 음성을 선택하면 사전 합성 mp3를 우선 재생
- **마스터리 4단계** — 본문 / 회화 / 본문+회화를 골라 블라인드 → 스크립트 → 쉐도잉(녹음·비교) → 최종 점검, 대상별 평가 저장
- **전체 듣기 자동 스크롤** — 본문·회화 및 마스터리 스크립트·쉐도잉에서 현재 문장을 따라 이동하고 재생 중인 문장을 표시. 멈추기 버튼은 상단에 유지하며 기기의 동작 줄이기 설정 반영
- **10분 데일리 루틴** — 선택한 본문·회화로 6단계 타이머 학습, 간체 위 글자별 병음 표시, 연속 학습(스트릭) 기록
- **편하게 듣기** — 해금된 과를 반복 재생. 기기 음성은 화면을 켜 두고 사용, 녹음 음성은 백그라운드 재생·잠금화면 컨트롤 지원
- **글자별 병음 · 단어장** — 병음을 한자 위에 한 글자씩 표시, 글자를 탭하면 단어 뜻·한자 풀이·예문(교재 단어장 기반)
- **학습 메뉴** — 10분 데일리 / 마스터리 정밀 학습 / 편하게 듣기에 공통으로 본문 / 회화 / 본문+회화 대상 지정. 본문+회화는 본문 다음에 모든 회화를 교재 순서로 학습
- **학습 듣기** — 과 화면의 본문·회화(7회)·단어(5회) 전체 듣기 옆에서 선택. 본문·회화: 모두 표시 → 소리만 → 한자·병음 → 병음만 → 한자만 → 따라 말하기(재생 시간만큼 쉼) → 한글만(순서 섞음, 한글 먼저 보이고 2초+한자 1자당 0.3초 뒤 음성). 단어: 모두 표시 → 한자·병음 → 병음만 → 한자만(따라 말하기) → 한글만(1.5초+1자당 0.2초). 자동 스크롤. 종료·중단·오류 시 기존 표시 설정 복귀. 기본 학습 모드에서도 사용 가능
- **문법·발음 함정 전체 듣기** — 두 탭에 전체 듣기와 한글 해설 포함 듣기 제공(학습 듣기 회차 반복은 제외). 문법은 예문 줄의 중국어(분리 가능한 약 94%)를 읽고, 한글 해설은 mp3가 없으면 기기 한국어 음성으로 읽음. 본문·회화 탭에도 "본문/회화 + 한글 듣기"(문장마다 중국어 뒤 한글 번역) 제공.
- **자동 오프라인 준비** — 전권 교재·단어장 자동 저장. 녹음 음성 모드에서 전체 음원 자동 다운로드·이어받기·진행률 표시. 기기 음성으로 바꾸면 다운로드 중단. 설정에서 중지하거나 권별로 직접 받기/삭제 가능
- **자동 업데이트** — 새 버전을 미리 저장하고 다음 실행에 적용. 다른 창·탭이 열려 있어도 업데이트 가능. 설정에서 현재 버전·빌드 확인, 업데이트 확인·적용 버튼 제공. 적용하면 홈 화면에서 다시 시작하며 학습 진도·설정·저장한 음원 유지. 자동 확인은 현재 화면을 이동시키지 않음
- **온보딩·설치 안내**
- **구형 기기 기본 모드** — Android 9 이하 또는 Android Chrome 138 이하, `browser.html` 호환 바로가기는 교재·듣기·진도·백업 제공. 데일리·마스터리·마이크 녹음·잠금화면 조작·설치 안내는 제한하고, 편하게 듣기는 전체 과를 바로 제공. 최신 기기의 일반 주소는 전체 기능 유지. 기본 모드도 같은 최신 앱·업데이트·학습 기록 사용
- **설치 호환성** — 192·512px PNG 및 안드로이드 마스크 아이콘 제공. 설치 앱만 종료되는 구형 Android 8·9에는 `browser.html` 호환 바로가기 제공(Chrome에서 열고 홈 화면에 추가 → 바로가기 만들기)
- **형광펜** — 이해도(초록/노랑/빨강)를 카드에 표시
- **학습 경로** — 8권 160과를 4개 레벨로 구성, 진도 자동 기록
- **눈이 편한 화면** — 글자 크기 3단계, 청색광 차단 4단계
- **백업 / 복원** — 진도·형광펜·설정을 JSON 파일로 저장하고 새 기기에서 복원
- **QR 공유**, 인앱 브라우저(카카오톡 등) 감지 안내, 도움말 검색
- **PWA** — 홈 화면에 설치, 오프라인 사용 (Workbox)

## 📚 학습 구성

| 레벨 | 권 | 주제 |
|---|---|---|
| Lv.1 왕초보 귀 트이기 | vol1–2 | 기초 일상, 생활 회화 |
| Lv.2 중국어 벽 뚫기 | vol3–4 | 여행 회화, 비즈니스 회화 |
| Lv.3 네이티브 리듬 정복 | vol5–6 | 고급·실무 회화, 네이티브 표현 |
| Lv.4 프리토킹 마스터 | vol7–8 | 의사소통 기능, 시사·논증 |

한 권은 20과, 전체 160과입니다. 음성(mp3)은 전 권(중국어 5,448개 + 한글 번역 1,574개, 약 117MB)이 합성되어 있습니다.

## 📲 설치 방법

- **Android (Chrome)** — 메뉴(⋮) → 홈 화면에 추가 / 앱 설치
- **iPhone / iPad (Safari)** — 공유(↑) → 홈 화면에 추가
- **PC (Chrome · Edge)** — 주소창 오른쪽의 설치(⊕) 아이콘

카카오톡 등 앱 안의 브라우저에서는 설치와 음성이 제한됩니다. 주소를 복사해 Chrome/Safari에서 열어 주세요.

## 🛠 개발

React 18 · Vite 5 · TypeScript · Zustand · Tailwind CSS 3 · vite-plugin-pwa · HashRouter

```bash
cd app
npm install
npm run dev          # 개발 서버 (http://localhost:5173/ChinTalk/)
npm run build        # 콘텐츠 빌드 + 타입 검사 + 프로덕션 빌드
npm run build:icons  # 기존 SVG에서 설치용 PNG 생성(브라우저 준비 후, 결과물 커밋)
npx playwright-core install chromium # 브라우저 테스트 최초 준비
npm run test:pwa     # 실제 서비스 워커로 다중 창 업데이트·실패 재시도·오프라인 검증
npm run test:follow  # 전체 듣기 자동 스크롤·현재 문장 표시·중단·화면 크기 검증
npm run test:basic   # 구형/축약 UA·호환 주소의 기본 모드와 최신 환경의 전체 기능 검증
npm run test:learning-listening # 학습 듣기 회차 순서(본문·회화 7회, 단어 5회)·섞기·표시 전환·중단·복귀·오프라인 검증
```

### 디렉터리

```
Doc/Markdown/vol{1..8}/   학습 콘텐츠 원본 (Markdown)
Doc/_design.md            설계 문서
app/scripts/              build-content.ts (MD → JSON), build-tts.ts (mp3 합성)
app/public/data/          빌드된 lessons-vol*.json, lessons-meta.json, zh-tts-manifest.json
app/public/tts/           사전 합성 mp3 (파일명 = sha1(정규화한 중국어).slice(0,12))
app/src/                  pages · components · stores · lib
```

### 음성(mp3) 합성

```bash
cd app
npm run build:tts    # msedge-tts (zh-CN-XiaoxiaoNeural, 48kbps mono) 로 합성, 이미 있는 파일은 건너뜀
```

기기 음성 모드(기본값)는 Web Speech API로 재생합니다. 녹음 음성 모드는 manifest에서 mp3를 찾고, 온라인에서 파일이 없을 때 기기 음성으로 대체합니다. 오프라인에서는 저장된 mp3만 사용합니다. 새 버전은 변경된 자료를 자동 저장하고 다음 실행 때 적용합니다.

### 배포

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해 GitHub Pages에 자동 배포합니다.
